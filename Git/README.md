# Git 系列教程：从"会背命令"到"理解模型"

> 面向"用过 `add/commit/push` 但一遇冲突就慌、一提 rebase 就怕"的学习者。全系列的立场：**Git 的难点不是命令多，而是大多数教程不教对象模型**——不理解 blob/tree/commit 这套模型，命令只能死记；理解了模型，所有命令都能自己推出来。
> 事实基准：Git 由 Linus Torvalds 于 2005 年 4 月创建；本系列覆盖 Git 2.2x~2.4x 的稳定行为，个别版本差异会注明（以 [git-scm.com](https://git-scm.com/doc) 官方文档为准）。

### 阶段划分

1. **模型与日常（01–02）**：先装"操作系统"（对象模型），再练"日常输入"（工作流）。
2. **协作核心（03–04）**：分支与远程是团队开发的主战场。
3. **历史工程（05–06）**：改写与撤销——Git 区别于旧 VCS 的超能力，也是事故高发区。
4. **进阶与内化（07–10）**：从"会用"到"讲得清原理、救得了现场"。

## 学习方法建议

1. 01 篇务必**动手**跑一遍底层命令（`git cat-file` 等），模型只有亲手摸过才算拥有；
2. 每篇末尾的"自测"不是装饰：能不看书写出答案，才算过；
3. 06 篇（撤销）与 10 篇（急救卡）建议打印/收藏——事故现场没有时间翻教程；
4. 与本仓库的衔接：uv 系列的依赖锁文件（`uv.lock`）应当提交进 Git——哪个文件该不该提交，在 02 篇有完整决策表。
