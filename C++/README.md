# C++ 系列教程：从零到音频/推理引擎开发

> 面向主语言是 Python、想读懂甚至参与 **whisper.cpp / sherpa-onnx / llama.cpp / onnxruntime** 这类 C++ 语音与推理基础设施的初学者。
> 全系列按 **C++17 及以上标准**编写；**每一个完整示例都经过 `g++ -std=c++17 -Wall -Wextra -pedantic` 编译并实际运行**，文中"预期输出"均为真实运行结果（验证环境：g++ 11.4.0 / Ubuntu 22.04）。

### 阶段划分

1. **基础（01–03）**：工具链 + 语法 + 内存模型。这是与 Python 差异最大的部分，务必动手。
2. **所有权与类（04–06）**：现代 C++ 的核心。理解了移动语义，才算入门 C++。
3. **标准库与泛型（07–11）**：日常开发 80% 的代码在这里。
4. **并发与实战（12–13）**：面向语音/AI 工程的收尾项目。

## 与本仓库其他方向的衔接

- **语音方向 Stage 7（端侧离线语音助手）** 中 whisper.cpp、sherpa-onnx、llama.cpp 的源码阅读与二次开发，直接用到本系列 04（所有权）、06（移动语义）、12（并发）。
- 13 篇实战的 **RingBuffer** 就是音频采集线程与推理线程之间的标准生产者-消费者结构，对应语音方向里反复出现的"流式处理"概念。

## 代码规范约定

全系列遵循：

- 不写 `using namespace std;`（02 篇解释原因）；
- 优先 `auto`、范围 `for`、`{}` 初始化、`constexpr`；
- 不用裸 `new`/`delete`（05/06 篇的教学反例除外，文中均已注明）；
- 编译命令统一 `g++ -std=c++17 -Wall -Wextra -pedantic`，多线程示例加 `-pthread`。

## 环境要求

任何带 g++ ≥ 8（建议 ≥ 11）的 Linux/macOS/WSL2 环境即可；CMake ≥ 3.16。无需 GPU。
