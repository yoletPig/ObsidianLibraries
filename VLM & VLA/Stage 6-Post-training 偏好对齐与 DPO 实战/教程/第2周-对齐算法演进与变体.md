## 1. 第一性原理：变体谱系的演化逻辑

### 1.1 根本矛盾：DPO 的两个结构性缺陷

DPO 的推导干净，但落地后暴露两个结构性问题，后续变体几乎都是对它们的定向手术：

**缺陷一：Reference 模型的显存与算力翻倍**。$\pi_{\text{ref}}$ 必须全程驻留显存且每个 batch 前向两次（policy + ref）。对 7B 模型是 14GB 的纯开销；对多模态大模型（视觉塔+LLM）更痛。且从推导看，$\pi_{\text{ref}}$ 只提供一个"KL 锚点"——能不能不携带锚点、靠损失函数自身结构防跑飞？

**缺陷二：长度偏置**（第 1 周失效 2）。根因是 **per-sequence 求和口径**：序列越长，$\log \pi$ 越负，长度信号混进奖励信号。DPO 的推导对此无能为力——因为闭式解 $\pi^* \propto \pi_{\text{ref}} e^{r/\beta}$ 本身就是"整个序列"层面的，长度归一化会破坏推导的严格性。

**演化树**（每个变体 = 一次定向手术）：

```text
DPO (2023): BT + 隐式奖励, 有 ref, sum 口径
├─ IPO (2023.10): 修"过拟合偏好噪声/奖励坍塌" -> 二次正则替代 sigmoid
├─ KTO (2024.02): 修"必须成对数据" -> 前景理论, 单边二元标签
├─ SimPO (2024.05): 修"ref 开销 + 长度偏置" -> 去ref + 长度归一化 + margin
└─ ORPO (2024.03): 修"需先 SFT 两阶段" -> SFT+对齐单阶段, odds ratio 惩罚
```

### 1.2 IPO：修"过拟合与奖励坍塌"

**问题**：DPO 在偏好数据有噪声（标注翻转/两回答质量接近）时会过拟合——sigmoid 的渐近性质使它无限压低"分错的对"的损失，把模型推向极端；实证上表现为训练集中 chosen 的似然被压到极低（**奖励坍塌/似然位移**，即 policy 对 chosen 本身的概率也掉下去了，违背"对齐不应破坏生成质量"的初衷）。

**手术**：把 BT 的 log-sigmoid 换成一个在最优解处性质更温和的**二次正则**形式。IPO 的目标函数（在最优解处强制 $\mathbb{E}[\text{分差}] = 1/\beta$ 的平方惩罚形式）：

$$
\mathcal{L}_{\text{IPO}} = \mathbb{E}\left[ \left( \log \frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \log \frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)} - \frac{1}{\beta} \right)^2 \right]
$$

与 DPO 的关键差异：DPO 的 sigmoid 无限奖励大分差；IPO 的二次惩罚**在分差达到 $1/\beta$ 后就不再鼓励继续拉大**——对噪声标签（本不该拉开大分差的对）天然鲁棒。保留 ref，所以显存问题没解决，它修的是另一个病。

### 1.3 KTO：修"必须成对"的数据获取瓶颈

**问题**：真实业务里偏好数据天然是**单边**的——用户点了赞/点了踩、人工抽检给了好/差标签，但"同一问题的好坏配对"需要额外拼装且配对质量参差。成对约束是 DPO 数据获取的最大瓶颈。

**手术**：KTO（*KTO: Model Alignment as Prospect Theoretic Optimization*）放弃 BT 模型，改用行为经济学的**前景理论**（Kahneman-Tversky）：人对得失的效用函数不对称——损失的痛感大于收益的快感（损失厌恶）。形式化：

$$
\mathcal{L}_{\text{KTO}} = \mathbb{E}_{(x, y)} \begin{cases}
-\lambda_w \, \sigma\big(\beta (r_\theta(x,y) - z_{\text{ref}})\big) & y \sim \text{desirable} \\
-\lambda_l \, \sigma\big(\beta (z_{\text{ref}} - r_\theta(x,y))\big) & y \sim \text{undesirable}
\end{cases}
$$

其中 $r_\theta$ 仍是 DPO 式隐式奖励（保留 ref），$z_{\text{ref}} = \beta \log \frac{\pi_\theta}{\pi_{\text{ref}}}$ 在参考分布上的 KL 校准项，$\lambda_w \neq \lambda_l$ 实现不对称权重（实验常取 $\lambda_l > \lambda_w$，体现损失厌恶——**压低差回答的力度大于抬高好回答**）。**只需二元标签（desirable/undesirable），不需成对**，且理论上只需"好/差"各自内部分布的信息即可优化。

### 1.4 SimPO：同时修"ref 开销"与"长度偏置"

学习计划点名的两项核心改进（自测考点），机制上环环相扣：

**改进一：完全抛弃 $\pi_{\text{ref}}$，改用序列平均 log 概率作奖励**：

$$
r_\theta(x, y) = \frac{\beta}{|y|} \log \pi_\theta(y \mid x)
$$

**长度归一化（除以 $|y|$）一石二鸟**：① 直接消除"长 = 低 logp"的系统性偏置（长度偏置的根因治疗）；② 平均后的 logp 是绝对量，不需要 ref 的差分来定义"相对改善"——**奖励从"比 ref 好多少"变为"这个序列的每 Token 平均置信度"**，ref 整个消失，显存与一半前向开销省掉。

**改进二：引入显式 margin $\gamma$**。没有 ref 锚定后，模型有个新的退化方向：**把所有回答（含 rejected）的概率都推低**——平均分差照样拉开，损失照样降，但生成质量崩了（这正是第 1 周失效 1 的变体）。SimPO 的对策：

$$
\mathcal{L}_{\text{SimPO}} = -\mathbb{E} \left[ \log \sigma \left( \frac{\beta}{|y_w|} \log \pi_\theta(y_w \mid x) - \frac{\beta}{|y_l|} \log \pi_\theta(y_l \mid x) - \gamma \right) \right]
$$

$\gamma > 0$ 要求**chosen 的归一化奖励必须至少高出 $\gamma$** 才算分对——这迫使 chosen 的绝对置信度必须维持在一个水准之上（不可能靠双双压低来作弊）。**margin 与去 ref 是共生设计**：ref 提供锚，去掉锚就必须显式立一个门槛。

代价与适用：SimPO 的超参更敏感（β、γ、lr 三者联动，γ=0.5~0.7、β=2~2.5 是论文附近的量级，但复现敏感性是社区共识）；它没有 DPO 的推导保证（是工程驱动的再设计）。**经验规则：Len 控制/推理类任务优先试 SimPO；通用对话与数据噪声大的场景，DPO/IPO 更稳。**

### 1.5 ORPO：修"两阶段流程"

ORPO（Odds Ratio Preference Optimization）不走"先 SFT 再对齐"的两阶段：把偏好惩罚直接缝进 SFT 损失——

$$
\mathcal{L}_{\text{ORPO}} = \mathcal{L}_{\text{SFT}}(y_w) + \lambda \, \mathbb{E}\left[ \log \frac{P_\theta(y_w \succ y_l \mid x)}{1 - P_\theta(y_w \succ y_l \mid x)} \right]
$$

其中偏好项用 **odds ratio**：$OR_\theta(y_w, y_l) = \frac{P_\theta(y_w|x)/(1-P_\theta(y_w|x))}{P_\theta(y_l|x)/(1-P_\theta(y_l|x))}$。SFT 项保证 chosen 的生成质量（对抗似然坍塌），odds 惩罚拉开好坏差距。**单阶段、无 ref**，从基座直接一步到位——代价是需要偏好对参与基础训练，无法利用已有的 SFT 检查点；且 SFT 项只对 chosen 计算，rejected 只受惩罚不受监督。

## 2. 实现与验证

### 2.1 SimPOLoss 实现与 DPO 对比测试

```python
"""
SimPOLoss 实现 + 与 DPOLoss 的行为对比测试。
运行方式: python stage6_week2_simppo.py   (依赖 stage6_week1_dpo_loss.py)
"""
import torch
import torch.nn.functional as F
from stage6_week1_dpo_loss import dpo_loss


def simpo_loss(policy_chosen_logps, policy_rejected_logps,
               len_chosen, len_rejected, beta=2.0, gamma=0.5):
    """
    SimPO: 长度归一化奖励 + margin, 无 reference。
    logps: [B] 回答区 per-sequence sum; len_*: [B] 回答 Token 数 (|y|)。
    """
    chosen = beta / len_chosen * policy_chosen_logps      # (β/|y_w|)·log π(y_w)
    rejected = beta / len_rejected * policy_rejected_logps
    loss = -F.logsigmoid(chosen - rejected - gamma).mean()
    return loss, chosen, rejected


def _tests():
    torch.manual_seed(0)
    B = 16
    pc = (-100 + torch.randn(B) * 0.1).requires_grad_(True)
    pl = (-150 + torch.randn(B) * 0.1).requires_grad_(True)
    lw = torch.full((B,), 100.0)                          # |y_w| = 100 tokens
    ll = torch.full((B,), 200.0)                          # |y_l| = 200 tokens (更长!)

    # ---- 测试 1: 长度偏置矫正 ----
    # 场景: rejected 更长。DPO(sum口径) 的分差会被长度污染; SimPO 不受影响。
    _, dpo_c, dpo_r, _ = dpo_loss(pc, pl, pc.detach(), pl.detach(), beta=0.1)
    _, sp_c, sp_r = simpo_loss(pc, pl, lw, ll)
    # DPO 下 rejected(更长,logp更负) 分差被长度贡献放大:
    dpo_margin_len_artifact = (dpo_c - dpo_r).mean().item()
    sp_margin = (sp_c - sp_r).mean().item()
    # SimPO 的归一化分差 ≈ beta*(pc/100 - pl/200) - gamma, 不含"长=更负"的伪信号
    expected = 2.0 * (pc.mean() / 100 - pl.mean() / 200) - 0.5
    assert abs(sp_margin - expected.item()) < 0.05, "SimPO margin 计算不符"

    # ---- 测试 2: margin γ 的防崩坏性质 ----
    # 双双压低概率 (pc/pl 同时减 50) 时:
    pc2 = pc - 50; pl2 = pl - 50
    loss_normal, *_ = simpo_loss(pc, pl, lw, ll)
    loss_collapse, *_ = simpo_loss(pc2, pl2, lw, ll)
    # DPO 式差分对"同降"不敏感(分差不变), SimPO 的绝对奖励使 loss 恶化:
    _, _, dpo_r_n = None, None, None
    loss_normal_dpo, *_ = dpo_loss(pc, pl, torch.zeros(B), torch.zeros(B), beta=0.1)
    loss_collapse_dpo, *_ = dpo_loss(pc - 50, pl - 50, torch.zeros(B), torch.zeros(B), beta=0.1)
    assert torch.isclose(loss_normal_dpo, loss_collapse_dpo, atol=1e-4), \
        "DPO 差分口径下'双双压低'不改变分差(其盲区)"
    assert loss_collapse > loss_normal, "SimPO 的 margin 应惩罚绝对置信度崩塌"

    # ---- 测试 3: 梯度传导 ----
    loss, *_ = simpo_loss(pc, pl, lw, ll)
    loss.backward()
    assert pc.grad is not None and pl.grad is not None and torch.isfinite(pc.grad).all()

    print("✅ SimPO 测试通过: 长度归一化 / margin 防崩坏 / 梯度正常")
    print(f"显存对比: DPO 需 policy+ref 双模型 (7B 约 28GB 权重); SimPO 仅 policy (约 14GB)")


if __name__ == "__main__":
    _tests()
```

**预期输出**：

```text
✅ SimPO 测试通过: 长度归一化 / margin 防崩坏 / 梯度正常
显存对比: DPO 需 policy+ref 双模型 (7B 约 28GB 权重); SimPO 仅 policy (约 14GB)
```

测试 2 是本篇最有信息量的断言：它数值化地展示了**DPO 差分口径的盲区**（策略把 chosen 和 rejected 一起压低，分差不变、损失不变——生成质量已崩但 DPO 无感），以及 **SimPO 的 margin 如何堵住这个漏洞**。这解释了"去 ref 必须配 margin"的共生关系，是自测"两项核心改进为什么能工作"的深层答案。

### 2.2 五算法对比表（交付核心）

| 算法 | Ref 模型 | 数据形态 | 核心机制 | 修 DPO 的什么病 | 主要代价 |
| --- | --- | --- | --- | --- | --- |
| **DPO** | 需要 | 成对 (y_w, y_l) | BT + 隐式奖励，sum 口径 | （基线） | ref 显存翻倍；长度偏置；噪声过拟合 |
| **IPO** | 需要 | 成对 | 二次正则替代 sigmoid，分差封顶 1/β | 噪声偏好过拟合、奖励坍塌 | 未解决 ref 与长度问题 |
| **KTO** | 需要 | **单边二元标签** | 前景理论效用，λ 不对称（损失厌恶） | 成对数据获取瓶颈 | 需估 KL 校准项 z_ref；仍有 ref |
| **SimPO** | **不需要** | 成对 | 长度归一化奖励 + 显式 margin γ | ref 开销 + 长度偏置 | 超参敏感（β/γ/lr 联动）；无推导保证 |
| **ORPO** | **不需要** | 成对 | SFT+odds 惩罚单阶段 | 两阶段流程成本 | 需从基座训起（不能接现成 SFT 点）；rejected 无监督项 |

**选型决策路径**：

```text
数据是单边标签? ──是──> KTO
      │否 (成对)
      ├── 只有基座、想做一步到位? ──是──> ORPO
      ├── 偏好数据噪声大/标注不一致? ──是──> IPO
      ├── 主诉求=长度控制/推理答案精炼, 且能接受调参? ──是──> SimPO
      └── 默认稳妥起点 ──────────────────> DPO (β=0.1, lr=SFT的1/10)
```

## 3. 工程权衡与失效模式

### 3.1 显存账本对比（7B，LoRA 场景另算）

| 方案 | 驻留权重 | 每 batch 前向次数 | 7B bf16 权重合计 |
| --- | --- | --- | --- |
| PPO | Actor+Ref+RM+Critic | 生成 N tokens × 每步多次 | 56 GB+ |
| DPO | Policy+Ref | 2 次（policy chosen/rejected 拼批 + ref 同） | 28 GB |
| SimPO/ORPO | Policy | 1 次 | **14 GB** |

（TRL 的 DPOTrainer 实际把 chosen/rejected 拼成一个 batch 一次前向，ref 前向同理——总前向是 2 次大 batch。LoRA 训练时 ref 可预计算缓存其 logps，进一步省时但不省驻留显存；SimPO 则连缓存都不需要。）

### 3.2 三个代表性失效模式

**失效 1：SimPO 的 γ 过小——"双双压低"崩坏重现**
- **症状**：SimPO 训练 margin 曲线正常上涨，但模型输出变短变模糊（"我不知道"类回答增多）。
- **根因**：γ 太小，约束不了绝对置信度下限；模型找到了"压低一切"的捷径——分差够 γ，但 chosen 的绝对质量已坏。
- **定位**：监控 `logps/chosen` 的归一化均值——若持续下降即中招（DPO 下 chosen logps 应缓降，SimPO 下归一化 chosen 奖励应稳中有升）。
- **修复**：增大 γ（0.5→0.7~1.0）或降 lr；亦可混入 SFT loss 做正则（CPO-SimPO 类变体思路）。

**失效 2：KTO 的 λ 配比失衡——模型"不敢说话"**
- **症状**：KTO 后输出普遍变得保守、拒答增多。
- **根因**：$\lambda_l$ 过大（损失厌恶权重过猛），压低 undesirable 的梯度主导训练，模型学到"少输出以少犯错"。
- **定位**：desirable/undesirable 两个子集的奖励曲线——undesirable 的下降斜率远大于 desirable 的上升即确认。
- **修复**：λ 配比回调（论文默认 λ_l/λ_w ≈ 1.33 起），或对 desirable 子集过采样对冲。

**失效 3：变体误用于数据形态——成对数据硬上 KTO 拆单边**
- **症状**：把成对数据拆成单边喂 KTO，效果反而不如直接 DPO。
- **根因**：成对数据的 chosen/rejected 在同一问题上强相关（共享上下文语义），拆单边后 KTO 的 KL 校准项拿到的分布信息比配对使用时稀疏；且 KTO 的优势场景（单边海量标签）没有被利用。
- **定位**：对比实验本身（DPO vs KTO 同数据）即诊断。
- **修复**：按数据形态选型（决策路径图），不要为变体而变体——**算法没有绝对优劣，只有与数据形态、痛点优先级的匹配**。

## 4. 延伸思考题

1. **SimPO 的理论缺口**：DPO 的损失有"闭式解 → BT"的推导保证，SimPO 没有。尝试回答：长度归一化奖励 $r = \frac{\beta}{|y|}\log \pi_\theta(y|x)$ 是否也对应某个 RL 目标的最优解形式？（开放题——社区共识是它更接近工程再设计而非严格推导；思考为什么"去 ref"在数学上几乎必然破坏闭式解结构。）
2. **不对称性实验**：KTO 的损失厌恶（$\lambda_l > \lambda_w$）对抑幻任务特别契合——幻觉回答是"必须压低"的。设计一个多模态 KTO 实验：desirable = 无幻觉回答、undesirable = 幻觉回答，λ_l 取 1.5 倍，对比对称 λ 的 POPE 表现。（提示：与第 3 周的幻觉偏好对接；预期不对称版对 FP 率的压制更强，但要监控通用能力。）
3. **动手实验**：用 2.1 的两个 loss 在同一批合成偏好对上各跑 200 步（第 1 周思考题 3 的玩具设置），对比：① 训练后回答长度分布的变化（DPO 是否变长、SimPO 是否稳定）；② chosen logps 的轨迹（SimPO 的 margin 是否真的守住了绝对置信度）。
