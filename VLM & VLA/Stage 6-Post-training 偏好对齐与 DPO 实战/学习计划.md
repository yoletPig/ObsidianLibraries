### 阶段六：Post-training 偏好对齐与 DPO 实战（3 - 4 周）

**阶段核心目标**：理解从传统 RLHF（Reward Model + PPO）到直接偏好优化（Direct Preference Optimization, DPO）等**免显式 Reward 模型**算法的演进路线。深入掌握偏好数据对 $(x, y_w, y_l)$ 的构造方法，在代码层面理解隐式奖励（Implicit Reward）计算，并能在多模态/文本大模型上成功运行 DPO/SimPO 训练，解决模型生成冗长、不遵循指令以及多模态视觉幻觉问题。

### 📅 逐周学习路线与 MVP 交付

#### 第 1 周：DPO 理论基石与数学推导

* **学习重点**：
* **RLHF 传统范式剖析**：
* 了解经典 RLHF 三阶段：SFT $\rightarrow$ 训练 Reward Model (RM) $\rightarrow$ PPO 强化学习。
* 理解 PPO 的痛点：显存开销极高（需同时加载 Actor, Critic, Reference, Reward 4个模型）、训练极易崩溃（KL 散度爆炸/ Reward Output 漂移）。


* **DPO 的推导与隐式奖励（Implicit Reward）**：
* 理解 Bradley-Terry (BT) 偏好模型。
* 重点推导 DPO 如何利用 Bradley-Terry 模型重构 KL 约束优化目标，证明 **策略模型（Policy $\pi_\theta$）自身即可等价充当隐式奖励模型（Implicit Reward Model）**：

$$r_\theta(x, y) = \beta \log \frac{\pi_\theta(y \mid x)}{\pi_{\text{ref}}(y \mid x)}$$


* 深入推导 DPO 损失函数：

$$\mathcal{L}_{\text{DPO}}(\theta; \pi_{\text{ref}}) = -\mathbb{E}_{(x, y_w, y_l)} \left[ \log \sigma \left( \beta \log \frac{\pi_\theta(y_w \mid x)}{\pi_{\text{ref}}(y_w \mid x)} - \beta \log \frac{\pi_\theta(y_l \mid x)}{\pi_{\text{ref}}(y_l \mid x)} \right) \right]$$


* 分析缩放因子 $\beta$ 的物理意义：约束 $\pi_\theta$ 不要远离参考模型 $\pi_{\text{ref}}$ 的强度。




* **推荐论文**：
* DPO 奠基论文: *Direct Preference Optimization: Your Language Model is Secretly a Reward Model* (NeurIPS 2023)


* **💡 第 1 周 MVP 交付**：
> 不借助任何三方对齐库，**用纯 PyTorch 手写一个 `DPOLoss` 函数**：输入 `policy_chosen_logps`, `policy_rejected_logps`, `ref_chosen_logps`, `ref_rejected_logps` 和超参数 $\beta$，计算出 `loss`、`chosen_rewards` 与 `rejected_rewards`，并通过单元测试验证其梯度传导正常。

#### 第 2 周：偏好对齐演进算法（SimPO, KTO, IPO, ORPO）

* **学习重点**：
* **DPO 的工程痛点**：
* **显存翻倍**：训练时必须同时在显存中保留一个被冻结的 $\pi_{\text{ref}}$（Reference Model）。
* **Length Bias (长度偏置)**：DPO 容易倾向于奖励更长的文本，而非内容更好的文本。


* **免 Reference 模型与主流变体**：
* **IPO (Identity Preference Optimization)**：引入二次正则化，解决 DPO 在偏好数据有噪声时过拟合、奖励坍塌的问题。
* **KTO (Kahneman-Tversky Optimization)**：不需要成对数据 $(y_w, y_l)$，只需单条样本加二元标签（Like / Dislike），降低数据采集难度。
* **SimPO (Simple Preference Optimization)**：完全抛弃 $\pi_{\text{ref}}$，改用长度归一化的 Log 概率作为 Reward，并引入固定 Margin：

$$\mathcal{L}_{\text{SimPO}} = -\mathbb{E} \left[ \log \sigma \left( \frac{\beta}{\vert{}y_w\vert{}} \log \pi_\theta(y_w \mid x) - \frac{\beta}{\vert{}y_l\vert{}} \log \pi_\theta(y_l \mid x) - \gamma \right) \right]$$


* **ORPO**：在 SFT 阶段直接结合Odds Ratio 惩罚，实现 SFT 与 Alignment 的一步到位。




* **推荐论文**：
* SimPO: *SimPO: Simple Preference Optimization for Large Language Models* (2024)
* KTO: *KTO: Model Alignment as Prospect Theoretic Optimization*


* **💡 第 2 周 MVP 交付**：
> 在你的 PyTorch Loss 代码库中扩展实现 `SimPOLoss`，比较 DPO 与 SimPO 在公式和内存占用上的差异，并撰写一份包含各种对齐算法（DPO / IPO / KTO / SimPO / ORPO）适用场景与优缺点的对比表格。

#### 第 3 周：多模态偏好数据集 (Multimodal Preference Data) 构造

* **学习重点**：
* **多模态偏好对 $(x, y_w, y_l)$ 的特殊性**：
* $x$: 图像 Input + Prompt 问题。
* $y_w$ (Chosen): 事实准确、无幻觉、逻辑严密、遵循指令的回答。
* $y_l$ (Rejected): 包含视觉幻觉（虚构不存在物体）、OCR 读错、空间坐标混淆、或答非所问的回答。


* **偏好数据自动构建方法**：
* **拒答/采样子（Rejection Sampling / Best-of-N）**：用同一模型在不同 Temperature 下生成 $N$ 个回答，通过 Verifier 或规则筛选出最好和最差的构建对。
* **幻觉诱导生成 (Hallucination-Driven Pairs)**：利用小模型生成有幻觉的回答作为 $y_l$，使用 SOTA 教师模型/Ground Truth 作为 $y_w$。
* **负样本修改法**：将正确的 Caption 中的名词或坐标人为替换为错误词汇（如把 "Red car" 改为 "Blue car"），快速合成高质量抗幻觉对。




* **开源偏好数据集参考**：
* `RLHF-V` / `RAG-V` / `Silly-VLM`


* **💡 第 3 周 MVP 交付**：
> 编写 Python 脚本，基于已有的 VLM 问答数据，自动合成 500 条专门针对**视觉幻觉/空间推理**的多模态偏好数据集（Format: `{"image": ..., "prompt": ..., "chosen": ..., "rejected": ...}`），并通过模型 Logit Margin 校验，确保 Chosen 与 Rejected 具有明显的语义质量梯度。

#### 第 4 周：VLM 偏好对齐训练实战与抑幻验证

* **学习重点**：
* **偏好对齐工程配置**：
* 使用 `TRL (Transformer Reinforcement Learning)` 或 `LLaMA-Factory` 接入 DPO / SimPO 训练。
* 掌握关键超参数调优：$\beta$ 的设定（常用 $0.1$ 或 $0.05$）、学习率设置（通常为 SFT 学习率的 $1/10$ 或更小，如 $5 \times 10^{-7}$）、Gradient Clipping。


* **监控指标解读 (WandB/TensorBoard)**：
* `rewards/chosen` & `rewards/rejected`：观察两者差距 (Margin) 是否在增大。
* `rewards/accuracies`：判断模型区分 chosen 和 rejected 的准确率（正常应稳步升至 0.7~0.9）。
* `logps/rejected` & `logps/chosen`：监控是否出现 Log Prob 异常暴跌（模型崩溃信号）。




* **💡 第 4 周 MVP 交付**：
> 1. 使用第 3 周构造的偏好数据集，基于 `TRL` 或 `LLaMA-Factory` 对 Qwen2-VL 或 LLaVA 进行一次 DPO / SimPO 微调。
> 2. 导出 WandB 训练曲线，重点展示 `rewards/margins` 的变化趋势。
> 3. 在 POPE 或 HallusionBench 评测集上测试偏好对齐前后的模型，**证明 DPO 微调后模型的视觉幻觉率显著下降（如 POPE 准确率提升 3% 以上）**。
