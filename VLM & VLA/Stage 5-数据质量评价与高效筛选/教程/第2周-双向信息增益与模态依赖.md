# 第 2 周教程：双向信息增益与模态依赖分析

> **本周要回答的三个问题**
> 1. "伪多模态数据"是什么？它对训练的实际危害有多大？
> 2. Image Necessity 与 Question Necessity 的公式怎么读？两次前向的具体实现逻辑是什么？
> 3. 双向增益如何组合成统一筛选公式？边界情况（负增益）怎么处理？

对应学习计划：第 2 周。交付物：Image Necessity 筛选模块——对 500 条数据分别做 `(Image+Q)` 与 `(Noise/Black Image+Q)` 两次前向，计算 $\Delta L_{\text{Img}}$，导出增益最大的前 30% 作为"强视觉依赖子集"。

**文献标注**（承接索引页）："Bidirectional Information Gain" 作为专名未检索到唯一出处，但其机制（PPL/Loss 差值度量图像因果贡献）已被 Visual Information Gain（arXiv:2602.17186, ICML 2026，把同类指标用于样本级与 Token 级选择）、RAP 的因果差异估计器（arXiv:2506.04755）等工作充分验证。本教程按机制严谨性编写，引用处标注已核实来源。

## 1. 第一性原理：把"看没看图"变成可测的因果量

### 1.1 根本矛盾：多模态数据的"名实不符"

Stage 3 已经建立了诊断直觉：模型的"语言先验捷径"（不看图靠关键词蒙对）。把镜头掉转对准**数据本身**，会得到更惊心的结论：大量多模态训练样本**根本不需要图**——

- VQAv2 类数据集中，相当比例问题（"这是什么颜色？"配一张大色块图；"这是室内还是室外？"）靠语言先验就能答对大半；
- 合成数据（Stage 4）放大了这一问题：教师模型按模板出题时，"需要看图才能答"不是硬约束；
- 数学/推理类多模态数据里，题目文本往往自含全部信息，图只是装饰。

**危害机制**（Stage 2 的梯度视角）：这类样本训练时，视觉通道的梯度贡献趋近于零，而语言通道在持续被强化——**等效于在做一次"掺了图片噪声的纯文本 SFT"**。数据集名义上是多模态，训练动力学上却是文本主导。更隐蔽的是它污染评测解读：模型在这类数据上的"高训练契合度"与视觉能力毫无关系。

### 1.2 Image Necessity：图像的因果贡献

定义（学习计划公式，符号统一）：

$$
\Delta L_{\text{Img}} = \underbrace{L\big(A \mid \tilde{X},\ Q\big)}_{\text{无有效图像时的损失}} - \underbrace{L\big(A \mid X,\ Q\big)}_{\text{真实图像时的损失}}
$$

其中 $\tilde{X}$ 是被破坏的图像（全黑图/纯噪声图/图序打乱）。读法：

- $\Delta L_{\text{Img}} \gg 0$：去掉图后模型对答案**更意外**了——图像携带了答案的信息，**真多模态样本**；
- $\Delta L_{\text{Img}} \approx 0$：有没有图模型对答案的意外程度不变——图像对预测**零因果贡献**，伪多模态样本；
- $\Delta L_{\text{Img}} < 0$：有图反而更意外——可疑信号（图文矛盾/错标，或模型被图像误导），进入人工审查名单。

**为什么这是因果度量而非相关度量**：它做的是一次**受控干预（intervention）**——固定 $Q$ 与 $A$，只对 $X$ 施加扰动，观测损失的响应。这与 Stage 3 的 No-image Baseline 是**同一个思想在数据侧的应用**：Stage 3 用它诊断"模型是否依赖视觉"，本阶段用同样的差分给"每条数据对视觉的依赖度"定量。一个探针，两个视角。

**实现选择的三个分叉点**：

1. **$\tilde{X}$ 的形态**：全黑图（干净、可复现，推荐）/ 高斯噪声图（更强扰动，可能触发模型 OOD 行为）/ 图序打乱（保留图像统计特征，适合检验"位置信息依赖"）。全黑图与噪声图会给出略不同的分数分布——**全流水线只用一种并归档**。
2. **loss 口径**：与第 1 周一致，回答区 per-token 平均；$\Delta L$ 是同一口径下的差。
3. **批量对照**：两次前向必须共享同一 batch 构成与 padding（只换 pixel_values），否则批处理差异混进差分。

### 1.3 Question Necessity：问题对视觉的"取景器"作用

$$
\Delta L_{\text{Q}} = L\big(A \mid X,\ \varnothing\big) - L\big(A \mid X,\ Q\big)
$$

其中 $\varnothing$ 是空问题（或通用指令如"描述图片"）。读法：固定真实图像，去掉具体问题后损失上升多少。$\Delta L_{\text{Q}} \gg 0$ 说明**这个问题精准地"取景"了图中的特定信息**——问题在引导模型利用视觉细节，而非泛泛看图。$\Delta L_{\text{Q}} \approx 0$ 的样本，问题与图像内容脱节（常见于模板拼凑的合成数据）。

### 1.4 双向组合：统一筛选公式

两维度量的四种组合画像：

| $\Delta L_{\text{Img}}$ | $\Delta L_{\text{Q}}$ | 画像 | 决策 |
| --- | --- | --- | --- |
| 高 | 高 | **强联动**：问题引导视觉聚焦，图像支撑答案 | **最高价值，保留** |
| 高 | 低 | 图像主导：答案依赖图，但问题太泛（"描述图片"类） | 保留（对齐阶段价值高） |
| 低 | 高 | 问题主导：问题精准但答案不靠图（文本推理题配图） | 视配比保留（文本推理也有价值） |
| 低 | 低 | **双无**：图和问题都与答案弱相关 | **丢弃** |

工程化的统一打分（加权组合，权重按筛选目标调节）：

$$
S = \alpha \cdot \widehat{\Delta L_{\text{Img}}} + \beta \cdot \widehat{\Delta L_{\text{Q}}}, \quad \widehat{\Delta} = \text{rank-normalize}(\Delta)
$$

（rank 归一化消除两个 Δ 量纲差异；SFT 阶段默认 $\alpha \geq \beta$，因为"图像必要性"是多模态训练的立身之本。）注意与第 1 周指标的**流水线关系**：NLL 筛"这条数据本身好不好"（第一步、最便宜），$\Delta L_{\text{Img}}$ 筛"这条数据配不配叫多模态"（第二步、多两次前向），两者是串联闸门而非替代。

## 2. 实现与验证

### 2.1 本周 MVP：Image Necessity 筛选模块

```python
"""
Image Necessity 筛选: 双前向计算 ΔL_Img, 导出强视觉依赖 Top 30%。
运行方式: python stage5_week2_imgnecessity.py --data sft_500.jsonl \
            --out visual_dependent.jsonl --frac 0.3
依赖: torch, transformers, pillow
"""
import argparse
import json
import torch
from PIL import Image


def make_black_image(size=(448, 448)):
    """破坏图像: 全黑图 (可复现; 换噪声图时在此处替换)"""
    return Image.new("RGB", size, (0, 0, 0))


@torch.no_grad()
def answer_nll(model, processor, rows, image_override, device):
    """对一批样本计算回答区 per-token NLL; image_override 统一替换图像"""
    texts, images = [], []
    for r in rows:
        msgs = [{"role": "user", "content": [
            {"type": "image"}, {"type": "text", "text": r["question"]}]}]
        prompt = processor.apply_chat_template(msgs, tokenize=False,
                                               add_generation_prompt=True)
        texts.append(prompt + r["answer"])
        images.append(image_override(r["image"]))
    inputs = processor(text=texts, images=images, return_tensors="pt",
                       padding=True).to(device)
    labels = inputs["input_ids"].clone()
    labels[inputs["attention_mask"] == 0] = -100
    # 回答区起点: 与第 1 周同构的两次渲染长度差
    for i, r in enumerate(rows):
        msgs = [{"role": "user", "content": [
            {"type": "image"}, {"type": "text", "text": r["question"]}]}]
        p = processor.apply_chat_template(msgs, tokenize=False,
                                          add_generation_prompt=True)
        plen = len(processor.tokenizer(p, add_special_tokens=False)["input_ids"])
        labels[i, :plen] = -100
    out = model(**inputs, labels=labels)
    logits = out.logits[:, :-1]
    tgt = labels[:, 1:]
    mask = tgt != -100
    logp = torch.log_softmax(logits.float(), dim=-1)
    tok_nll = -logp.gather(-1, tgt.clamp(min=0).unsqueeze(-1)).squeeze(-1)
    return ((tok_nll * mask).sum(1) / mask.sum(1).clamp(min=1)).tolist()


def rank_normalize(xs):
    order = sorted(range(len(xs)), key=lambda i: xs[i])
    rank = [0] * len(xs)
    for r, i in enumerate(order):
        rank[i] = r / max(1, len(xs) - 1)
    return rank


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--data", required=True); ap.add_argument("--out", default="visual_dependent.jsonl")
    ap.add_argument("--frac", type=float, default=0.3); ap.add_argument("--bs", type=int, default=8)
    args = ap.parse_args()
    device = "cuda" if torch.cuda.is_available() else "cpu"

    from transformers import AutoProcessor, Qwen2VLForConditionalGeneration
    MID = "Qwen/Qwen2-VL-2B-Instruct"                 # 参考模型 (与第1周归档绑定)
    model = Qwen2VLForConditionalGeneration.from_pretrained(
        MID, torch_dtype=torch.bfloat16).to(device).eval()
    processor = AutoProcessor.from_pretrained(MID)

    rows = [json.loads(l) for l in open(args.data)]
    assert len(rows) >= 100, "样本过少"
    delta = [0.0] * len(rows)
    for i in range(0, len(rows), args.bs):
        batch = rows[i: i + args.bs]
        nll_real = answer_nll(model, processor, batch, lambda im: im, device)
        nll_black = answer_nll(model, processor, batch,
                               lambda im: make_black_image(), device)
        for j, (a, b) in enumerate(zip(nll_black, nll_real)):
            delta[i + j] = a - b                       # ΔL_Img = L(无图) - L(有图)
        print(f"\r{i + len(batch)}/{len(rows)}", end="")

    ranked = rank_normalize(delta)
    order = sorted(range(len(rows)), key=lambda i: -delta[i])
    n_keep = int(len(rows) * args.frac)
    keep = order[:n_keep]

    # ---- 断言: 关键行为 ----
    assert all(d > -1.0 for d in delta), "ΔL 出现极端负值, 疑似实现错误"
    pos = sum(d > 0.02 for d in delta) / len(delta)
    print(f"\nΔL_Img: 中位={sorted(delta)[len(delta)//2]:.4f} "
          f"正增益占比={pos:.1%} (伪多模态嫌疑: {1-pos:.1%})")
    assert 0 < pos < 1, "全正/全负的 ΔL 分布不符合真实数据的预期形态"

    with open(args.out, "w") as f:
        for i in keep:
            f.write(json.dumps({**rows[i], "delta_img": round(delta[i], 4),
                                "visual_gain_rank": round(ranked[i], 4)},
                               ensure_ascii=False) + "\n")
    # 对照组导出 (供人工审查): ΔL 最低的 10%
    with open("pseudo_multimodal_review.json", "w") as f:
        json.dump([{**rows[i], "delta_img": round(delta[i], 4)}
                   for i in order[-len(rows) // 10:]], f, ensure_ascii=False, indent=1)
    print(f"强视觉依赖 Top{args.frac:.0%}: {n_keep} 条 -> {args.out}")
    print("伪多模态审查名单 (ΔL 最低 10%): pseudo_multimodal_review.json")


if __name__ == "__main__":
    main()
```

**预期输出形态**：

```text
500/500
ΔL_Img: 中位=0.0187 正增益占比=62.3% (伪多模态嫌疑: 37.7%)
强视觉依赖 Top30%: 150 条 -> visual_dependent.jsonl
伪多模态审查名单 (ΔL 最低 10%): pseudo_multimodal_review.json
```

**人工验收**：打开 `pseudo_multimodal_review.json` 抽查 20 条——预期是"这什么颜色？/大的还是小的？"之类语言先验可答的题目；若其中混有强视觉任务（OCR/定位）样本，优先怀疑全黑图替换后的 processor 处理或批 padding 错位。**正增益占比 60~70% 是真实混合数据集的典型形态**（VQAv2 类公开集的报告量级也在此附近）——如果你的数据集接近 100% 正增益，检查是否 ΔL 符号写反（常见 bug：`L(有图) - L(无图)`）。

### 2.2 与第 1 周打分的合并视图

把 `delta_img` 与第 1 周的 `nll/clip` 合并成一张四列打分表后，每条数据就有了完整画像。三个高价值交叉象限值得单独导出审查：

- **高 NLL + 低 $\Delta L_{Img}$**：模型觉得难、但难的不是图——文本推理或噪声，分流判断；
- **高 CLIP + 低 $\Delta L_{Img}$**：图文相关但答案不靠图——典型伪多模态；
- **低 CLIP + 高 $\Delta L_{Img}$**：CLIP 认为不相关但模型确实在用图——常是细粒度任务（CLIP 的已知弱区，第 1 周失效 3），**不要误删**。

## 3. 工程权衡与失效模式

### 3.1 决策表：破坏图像方式与参考模型

| 决策点 | 选项 | 推荐 |
| --- | --- | --- |
| $\tilde{X}$ 形态 | 全黑 / 噪声 / 图序打乱 | 全黑（可复现、不引入额外 OOD 噪声） |
| 参考模型 | 同底座 / 教师模型 / 更强模型 | 与第 1 周 NLL 打分**同一模型**（保证指标间可比） |
| ΔL 口径 | per-token 平均 / 整句和 | per-token（与第 1 周一致） |
| 截取策略 | Top-K by ΔL / 双阈值（$\Delta L_{Img}>\tau_1 \wedge S>\tau_2$） | 预算明确时 Top-K，质量底线优先时双阈值 |

### 3.2 三个代表性失效模式

**失效 1：全黑图"太黑"——ΔL 全体为负**
- **症状**：`ΔL_Img` 几乎全为负值，"强视觉依赖子集"实际选出的是"黑图下损失最高"的奇怪样本。
- **根因**：全黑图远超参考模型的训练分布（OOD），其对任何回答都给出高且无意义的损失；差分被 OOD 噪声主导而非"图像信息量"。
- **定位**：统计 `L(黑图)` 的分布——若整体远高于 `L(真实图)` 且方差极小，即确认 OOD 支配。
- **修复**：换更温和的破坏方式（高斯模糊/马赛克，保留低层统计特征）；或用"图像 Token 置换"（打乱视觉 Token 顺序，破坏语义保留分布）；或以"两倍标准差内的图像 + 随机裁剪不匹配图"做负对照。**修复后必须重跑正增益占比 sanity check。**

**失效 2：批内长度差异污染差分**
- **症状**：同一批样本重跑两次，ΔL 数值不稳定（±0.05 量级抖动）。
- **根因**：两次前向的 batch 构成或 padding 长度不同（DataLoader 顺序不确定），attention mask 与 position 差异传导进 loss。
- **定位**：固定样本子集、固定顺序跑三遍，方差应 <1e-4。
- **修复**：两次前向强制同构 batch（同一 `rows` 切片、同一 collator 配置）；确定性 `torch.use_deterministic_algorithms` 可选。

**失效 3：把 ΔL 当"质量分"单一使用**
- **症状**：只用 ΔL Top 30% 训练，模型视觉依赖变强但通用能力/文本推理退化。
- **根因**：ΔL 度量的是"模态联动强度"，不是"数据质量"——低 ΔL 的高质量文本推理数据同样有价值（Stage 2 的配比教训）。
- **定位**：对照第 3 周三维矩阵看被删样本的 NLL 分布——若删掉的多是低 NLL 好样本，即确认误用。
- **修复**：ΔL 只作为多模态占比的**调节旋钮**（配比中强视觉子集的权重），而非删除开关；与 NLL/CLIP 组合成第 3 周的矩阵视角。

## 4. 延伸思考题

1. **Token 级的 Image Necessity**：样本级 ΔL 之外，把差分下钻到 Token 级（$\Delta L_{\text{Img}}^{(t)} = L_t(\tilde{X}) - L_t(X)$），可以定位"答案中哪些 Token 真正依赖图像"（VIG 的工作正是此方向，arXiv:2602.17186）。设计一个用 Token 级 ΔL 增强训练的方案（如：对高依赖 Token 加权 loss），并讨论其与"整条样本加权"的优劣。
2. **问题必要性的边界**：$\Delta L_Q$ 高是否总是好事？构造反例——一个 $\Delta L_Q$ 极高但价值极低的样本形态。（提示：问题本身泄露答案的"反问式"样本——去掉问题后模型失去的是"抄答案"途径，不是视觉信息；这类样本 ΔL_Q 高、ΔL_Img 低，正是双向矩阵存在的意义。）
3. **动手实验**：对同一批数据分别用"全黑图"与"高斯模糊图"作为 $\tilde{X}$ 各跑一遍，画两条 ΔL 分布的对比直方图，并计算两种口径下 Top 30% 子集的 Jaccard 重合度。若重合度 <70%，写一段"破坏方式敏感性"说明放入筛选报告——这是筛选结论稳健性的必要证据。
