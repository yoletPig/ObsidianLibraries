## 1. 第一性原理：程序化工具为何优于教师模型

### 1.1 根本矛盾：语言模型给不了"数字级真值"

Stage 1 讲过 VLM 的空间编码先天薄弱；Stage 3 证实了教师 VLM 在空间任务上同样不可靠（Adversarial POPE 的脆性）。而 Grounding 数据需要的真值是**精确数字**（框坐标），让任何 LLM/VLM"说出"坐标都是在赌它的内在回归头——可控性与可验证性都差。

解法是把任务分解给两个各司其职的专家模型：

$$
\underbrace{\text{Grounding DINO}}_{\text{语言} \to \text{框 (开放词表检测)}} + \underbrace{\text{SAM}}_{\text{框/点} \to \text{精确 Mask (类无关分割)}} \Rightarrow \text{自动化标注}
$$

- **Grounding DINO**（*Grounding DINO: Marrying DINO with Grounded Pre-Training for Open-Set Object Detection*）：把文本编码（BERT）与图像特征做跨模态融合，输出**任意文本短语**对应的检测框——不需要预定义类别表（这是"开放词表"的含义，传统检测器如 YOLO 只认训练时见过的类别）。
- **SAM**（Segment Anything）：类无关的提示式分割，输入框/点提示即输出高质量 Mask。它"不懂语义"但"描边极准"。

**互补的关键在误差结构**：DINO 的框位置有像素级误差，SAM 的 Mask 边缘极准但需要语义提示——Grounded-SAM 把 DINO 的框喂给 SAM 取 Mask，语义来自 DINO、精度来自 SAM。**这种"语义头 + 几何头"的组合，误差可独立校验**（框对不对看 DINO 置信度与人工抽检，Mask 精度由 SAM 的架构保证），而教师 VLM 的输出误差不可分解、不可校验。这就是自动标注流水线的第一性优势。

### 1.2 坐标规范的工程决策

原始检测框是像素坐标 $[x_1, y_1, x_2, y_2]$（左上、右下）。训练数据需要归一化——**归一化基准必须与目标模型的推理约定完全一致**（Stage 3 失效 3 的教训）：

| 约定 | 公式 | 采用者 |
| --- | --- | --- |
| 0~1000 整数 | $\lfloor 1000 \cdot x / W \rfloor$ | Qwen2-VL 系 |
| 0~1 浮点 | $x / W$ | 部分学术模型 |
| 0~100 浮点 | $100 \cdot x / W$ | 部分历史实现 |

学习计划写的 `[ymin, xmin, ymax, xmax]` 顺序提醒我们另一件事：**分量顺序也是约定的一部分**。Qwen2-VL 系实际使用 $[x_1, y_1, x_2, y_2]$ 顺序。铁律：**以目标模型的官方文档/数据样例为准，配一条静态校验断言**（Stage 3 第 3 周 3.1 的正则校验器直接复用），整条管线全局唯一约定。

### 1.3 从几何到语言：空间关系的可计算定义

把两个检测框变成"空间关系 QA"，需要把"左/右/上/下"变成**可计算的几何谓词**。以水平关系为例（$a$, $b$ 为框中心）：

$$
\text{left}(a, b) \iff (x_a^{center} < x_b^{center}) \wedge \left(|y_a^{center} - y_b^{center}| < \alpha \cdot \min(h_a, h_b)\right)
$$

第二个条件是**抗角度歧义带**：两物体一高一低时（对角线摆放），纯 x 比较会说"左"，但人类感知会犹豫。引入 $\alpha$（经验 0.5~1.0）限定"只在纵向偏差不悬殊时才断言水平关系"，否则生成"左上方"这类复合关系或干脆跳过——**宁可少生成，不生成真值含糊的数据**。这是空间合成最重要的纪律，因为模型无法从自相矛盾的标注中学到一致的方位概念。

垂直关系对称（$y$ 比较为"上"，注意图像坐标系 y 轴向下）。相对尺寸关系（"大的那个"）用面积比较，同样设显著性阈值（面积比 >1.5 才断言"更大"）。

## 2. 系统架构与数据流

### 2.1 Grounded-SAM 自动标注流水线

```text
输入: 图片目录 + 感兴趣短语表 (或自动类别)
  │
  ▼
┌─ Grounding DINO ────────────────────────────┐
│ 文本短语 + 图片 → 检测框 [x1,y1,x2,y2] + 置信度 │
│ 过滤: score < 0.35 丢弃                       │
└─────────────────────────────────────────────┘
  ▼
┌─ SAM ───────────────────────────────────────┐
│ 框提示 → Mask (取面积最大连通域, 去碎片)        │
└─────────────────────────────────────────────┘
  ▼
┌─ QA 组装器 (程序化, 无 LLM 依赖) ─────────────┐
│ ① 坐标归一化 (0~1000) + 面积/中心计算          │
│ ② 两两框配对 → 几何谓词判定 (带抗歧义带)        │
│ ③ 模板填充: 定位类 / 空间关系类 / 计数类        │
│ ④ 每条数据附 provenance (来源框ID/分数)        │
└─────────────────────────────────────────────┘
  ▼
输出: JSONL 训练数据 (每图 2~6 条, 配对去重后)
```

QA 组装器刻意**不用 LLM**：模板化生成保证措辞可控（不会引入教师幻觉），几何真值保证答案精确。LLM 的用武之地在"多样化问法改写"——但那是第 1 周管线的职责，且改写只动 question 不动 answer（**答案永远由几何计算产生，这是本条线的红线**）。

### 2.2 三类模板的数据样例

```jsonl
{"image": "img_007.jpg", "dim": "grounding",
 "question": "请定位图中的杯子，输出其位置坐标。",
 "answer": "[312,487,456,701]", "provenance": {"detector": "grounding_dino", "score": 0.72}}
{"image": "img_007.jpg", "dim": "spatial",
 "question": "杯子和笔记本电脑哪个在图的左边？以相机视角回答。",
 "answer": "笔记本电脑", "provenance": {"pair": ["cup#0", "laptop#1"], "predicate": "left_of"}}
{"image": "img_007.jpg", "dim": "counting",
 "question": "图中共有几个杯子？", "answer": "2",
 "provenance": {"n_instances": 2, "min_score": 0.45}}
```

`provenance` 字段记录每条数据的真值来源与置信度——第 4 周过滤与后续坏例回溯全靠它。

### 2.3 3D / 多视角数据的构建逻辑（概念层）

学习计划要求的 3D/Pose/相机参数拼接，核心是**几何量 → 自然语言的映射表**设计：

| 几何量 | 来源 | 语言映射示例 |
| --- | --- | --- |
| 相机内参/外参 | 标定文件或 SfM 重建 | "相机距桌面约 0.8 米，俯视角约 30°"（量化分桶后模板化） |
| 物体 3D 框 / 6D Pose | RGB-D 传感器 / 位姿估计模型 | "马克杯在桌面左前方，杯口朝向右上方" |
| 深度图 | 深度相机 / 单目估计 | "离相机最近的物体是键盘（约 0.6m）" |
| ERP 全景 | 全景相机 | "正北方向是门，右侧（东）是窗户" |

工程要点：**连续几何量必须先分桶再进语言**——"俯视角 27.3°"这种数字对模型是噪声，"俯视/平视/仰视"三桶才是可学习的离散监督。映射表本身要版本化：换个分桶方案，全量数据要能重新生成（provenance 记录映射表版本）。

## 3. 实现与验证

### 3.1 本周 MVP：自动标注 + QA 生成脚本

几何部分（谓词、归一化、模板）**零依赖可运行**；检测部分给出 Grounding DINO 的接入代码，离线演示用伪检测器。

```python
"""
Grounded-SAM 自动标注 -> Grounding/Spatial QA 数据生成。
运行方式:
  真实: python stage4_week2_spatial.py --images ./imgs/ --out spatial.jsonl --use_dino
  离线: python stage4_week2_spatial.py --out spatial.jsonl   (伪检测器验证流程)
依赖: (真实模式) torch, transformers, supervision 或 Grounded-SAM 官方仓库
"""
import argparse
import itertools
import json
import random


# ---------- 几何核心 (零依赖, 可单测) ----------
def normalize_box(box, w, h, base=1000):
    """像素坐标 -> [x1,y1,x2,y2] 归一化整数 (Qwen2-VL 约定)"""
    x1, y1, x2, y2 = box
    return [round(base * x1 / w), round(base * y1 / h),
            round(base * x2 / w), round(base * y2 / h)]


def center(b):
    return ((b[0] + b[2]) / 2, (b[1] + b[3]) / 2)


def horizontal_rel(a, b, alpha=0.8):
    """a 相对 b 的水平关系; alpha 为抗歧义带系数。返回 'left'/'right'/None"""
    (cax, cay), (cbx, cby) = center(a), center(b)
    band = alpha * min(a[3] - a[1], b[3] - b[1])
    if abs(cay - cby) > band:
        return None                      # 纵向偏差过大, 不作水平断言
    return "left" if cax < cbx else "right"


def vertical_rel(a, b, alpha=0.8):
    (cax, cay), (cbx, cby) = center(a), center(b)
    band = alpha * min(a[2] - a[0], b[2] - b[0])
    if abs(cax - cbx) > band:
        return None
    return "above" if cay < cby else "below"   # 图像坐标系 y 向下


def bigger(a, b, ratio=1.5):
    area_a = (a[2] - a[0]) * (a[3] - a[1])
    area_b = (b[2] - b[0]) * (b[3] - b[1])
    if area_a > ratio * area_b:
        return "a"
    if area_b > ratio * area_a:
        return "b"
    return None


# ---------- QA 组装器 ----------
def build_qas(img_name, w, h, dets, rng):
    """dets: [{'label','box_px','score'}] -> QA 列表"""
    qas = []
    objs = [{"label": d["label"],
             "box": normalize_box(d["box_px"], w, h),
             "center": center(normalize_box(d["box_px"], w, h))} for d in dets]
    # ① 定位类: 每个物体一条
    for o in objs:
        qas.append({"image": img_name, "dim": "grounding",
                    "question": f"请定位图中的{o['label']}，输出其位置坐标。",
                    "answer": str(o["box"]),
                    "provenance": {"type": "gt_box"}})
    # ② 空间关系类: 两两配对, 只保留谓词成立 (含抗歧义带) 的对
    for a, b in itertools.combinations(objs, 2):
        hrel = horizontal_rel(a["box"], b["box"])
        vrel = vertical_rel(a["box"], b["box"])
        if hrel == "left":
            q, ans = f"{a['label']}和{b['label']}哪个在图的左边？以相机视角回答。", a["label"]
        elif hrel == "right":
            q, ans = f"{a['label']}和{b['label']}哪个在图的左边？以相机视角回答。", b["label"]
        elif vrel == "above":
            q, ans = f"{a['label']}和{b['label']}哪个在图的上方？", a["label"]
        elif vrel == "below":
            q, ans = f"{a['label']}和{b['label']}哪个在图的上方？", b["label"]
        else:
            continue                     # 对角摆放: 跳过, 宁缺毋滥
        qas.append({"image": img_name, "dim": "spatial", "question": q,
                    "answer": ans, "provenance": {"type": "predicate"}})
        bg = bigger(a["box"], b["box"])
        if bg:
            big = a["label"] if bg == "a" else b["label"]
            qas.append({"image": img_name, "dim": "spatial",
                        "question": f"{a['label']}和{b['label']}哪个更大？",
                        "answer": big, "provenance": {"type": "predicate"}})
    # ③ 计数类: 每个出现 ≥2 次的标签一条
    from collections import Counter
    for label, n in Counter(d["label"] for d in dets).items():
        if n >= 2:
            qas.append({"image": img_name, "dim": "counting",
                        "question": f"图中共有几个{label}？", "answer": str(n),
                        "provenance": {"type": "gt_count"}})
    rng.shuffle(qas)
    return qas


def detect_with_grounding_dino(image_path, phrases, device="cuda"):
    """真实检测入口 (Grounding DINO, HuggingFace 加载方式)"""
    from transformers import AutoProcessor, AutoModelForZeroShotObjectDetection
    from PIL import Image
    proc = AutoProcessor.from_pretrained("IDEA-Research/grounding-dino-tiny")
    model = AutoModelForZeroShotObjectDetection.from_pretrained(
        "IDEA-Research/grounding-dino-tiny").to(device)
    image = Image.open(image_path).convert("RGB")
    text = " . ".join(phrases) + " ."          # DINO 要求 ". " 分隔的小写短语
    inputs = proc(images=image, text=text, return_tensors="pt").to(device)
    with __import__("torch").no_grad():
        outputs = model(**inputs)
    results = proc.post_process_grounded_object_detection(
        outputs, inputs["input_ids"], box_threshold=0.35,
        text_threshold=0.30, target_sizes=[image.size[::-1]])[0]
    return [{"label": lbl.lower().strip(" ."),
             "box_px": [round(v, 1) for v in box.tolist()], "score": s}
            for box, lbl, s in zip(results["boxes"],
                                   results["text_labels"], results["scores"])]


def fake_detect(img_name, rng):
    """离线伪检测器: 确定性输出两张桌子上的物品"""
    scenes = {"img_000.jpg": [("cup", 200, 300, 260, 380, .8), ("laptop", 500, 250, 900, 550, .9),
                              ("cup", 300, 320, 350, 390, .7)],
              "img_001.jpg": [("book", 100, 400, 260, 480, .75), ("book", 500, 410, 640, 490, .68)],
              "img_002.jpg": [("plant", 700, 100, 900, 420, .85), ("laptop", 150, 300, 500, 560, .88)]}
    return [{"label": l, "box_px": [x1, y1, x2, y2], "score": s}
            for l, x1, y1, x2, y2, s in scenes.get(img_name, [("cup", 100, 200, 180, 300, .6)])]


if __name__ == "__main__":
    ap = argparse.ArgumentParser()
    ap.add_argument("--images", default="imgs"); ap.add_argument("--out", default="spatial.jsonl")
    ap.add_argument("--use_dino", action="store_true")
    args = ap.parse_args()
    rng = random.Random(0)

    all_qas = []
    for i in range(50):                       # 50 张图
        name = f"img_{i:03d}.jpg"
        dets = (detect_with_grounding_dino(f"{args.images}/{name}",
                ["cup", "laptop", "book", "plant", "bottle"]) if args.use_dino
                else fake_detect(name, rng))
        all_qas.extend(build_qas(name, 1000, 750, dets, rng))

    # ---- 断言: 真值自洽性 ----
    for qa in all_qas:
        if qa["dim"] == "grounding":
            b = eval(qa["answer"])            # 训练数据中 eval 可改为 json.loads
            assert 0 <= b[0] < b[2] <= 1000 and 0 <= b[1] < b[3] <= 1000, \
                f"非法归一化框: {b}"
        if qa["dim"] == "counting":
            assert int(qa["answer"]) >= 2
    assert len(all_qas) >= 200, f"产出不足: {len(all_qas)}"
    with open(args.out, "w") as f:
        f.writelines(json.dumps(q, ensure_ascii=False) + "\n" for q in all_qas)
    print(f"产出 {len(all_qas)} 条 -> {args.out}")


def _test_geometry():
    """几何谓词单测: 验证关键行为"""
    A = [100, 100, 200, 200]; B = [500, 120, 600, 220]     # A 在 B 左, 纵向接近
    assert horizontal_rel(A, B) == "left" and horizontal_rel(B, A) == "right"
    C = [500, 100, 600, 200]                                  # 与 B 纵向重叠, 同列
    assert horizontal_rel(C, B) == "left"
    D = [500, 800, 600, 900]                                  # 在 B 正下方远处
    assert vertical_rel(D, B) == "below" and horizontal_rel(D, B) is None
    E = [100, 100, 105, 105]                                  # 面积比悬殊
    assert bigger(E, A) == "b" and bigger(A, A) is None
    assert normalize_box([0, 0, 500, 375], 500, 375) == [0, 0, 1000, 1000]
    print("✅ 几何谓词/归一化单测通过")


_test_geometry() if __name__ == "__main__" else None
