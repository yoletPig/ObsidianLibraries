### 阶段四：数据合成与数据工程（4 - 6 周）

**阶段核心目标**：深刻理解“数据质量与分布决定模型能力上限”的技术信仰。掌握利用 SOTA 教师模型（GPT-4o、Qwen-Max 或本地大模型）进行多模态合成数据（Synthetic Data）生成、自指令演化（Self-Instruct / TaskCraft）、细粒度空间/视觉标注提取、以及高吞吐并发数据清洗与去重流水线。

---

### 📅 逐周学习路线与 MVP 交付

#### 第 1 周：多模态 Synthetic Data 范式与 Self-Instruct 机制

* **学习重点**：
* **合成数据（Synthetic Data）核心价值**：解决真实世界数据标注昂贵、长尾分布覆盖差、细粒度（Spatial / Reasoning）标注缺失的问题。
* **Self-Instruct / Evol-Instruct 思想**：
* **深度演化（Depth Evolution）**：增加约束、深化推理链（CoT）、提高问题复杂度。
* **广度演化（Breadth Evolution）**：基于 Seed Task 扩展全新的场景与领域。


* **VLM 多模态合成模式**：
* **Image-to-Text 改写/扩充**：利用视觉大模型重新提取密集的图像描述（Dense Captioning / Detailed Region Description）。
* **Text-to-Query 生成**：基于已有的图像与简短描述，反向推导复杂、多步推理的 VQA 问答对。




* **推荐论文**：
* Self-Instruct: *Self-Instruct: Aligning Language Models with Self-Generated Instructions*
* ShareGPT4V: *ShareGPT4V: Improving Large Multi-Modal Models with Better Captions*


* **💡 第 1 周 MVP 交付**：
> 编写 Python 脚本，以 30 张无标注原始图片为种子（Seed），设计 Prompt 模板调用 API（或本地 API 服务），利用 Evol-Instruct 思想生成 150 条包含思考过程（CoT）与细粒度细节分析的多模态 SFT 数据（JSONL 格式）。



---

#### 第 2 周：细粒度视觉、空间与感知数据自动化合成

* **学习重点**：
* **空间与几何数据合成（Spatial & Grounding Data Synthesis）**：
* 结合开放词表检测/分割工具（如 Grounding DINO、Grounded-SAM）自动提取图像中的 2D Bounding Box 或 Mask。
* 将提取出的坐标 `[ymin, xmin, ymax, xmax]` 与模板结合，合成如：“请定位图中[物体]的位置”或“比较[物体A]与[物体B]的相对空间关系”。


* **3D / 全景与多视角数据构建**：
* 理解从 2D 图像到 3D Bounding Box / Pose / 相机参数（Camera ERP 全景几何）的空间一致性数据标注拼接。
* 掌握 Camera/Object 3D 姿态及几何位置到自然语言 Prompt 的映射逻辑。




* **开源工具链**：
* `IDEA-Research/GroundingDINO`
* `IDEA-Research/Grounded-Segment-Anything`


* **💡 第 2 周 MVP 交付**：
> 搭建一个自动标注脚本：输入 50 张普通场景图片，使用 `Grounded-SAM` 提取图像中的核心物体 Bounding Box，并自动拼接生成 200 条标准格式的 Grounding/Spatial Reasoning 训练数据（包含归一化坐标与空间方向逻辑）。



---

#### 第 3 周：多步 Agent 轨迹与 Execution Trajectory 合成

* **学习重点**：
* **Agent 轨迹数据构造（TaskCraft / Agentic Data）**：
* 理解基于 Task, Environment, Action Space 自动构造多步操作轨迹的逻辑。
* 学习 **ReAct 范式** 轨迹生成：`Thought` $\rightarrow$ `Action` $\rightarrow$ `Observation` $\rightarrow$ `Final Answer`。


* **环境反馈与正负轨迹校验（Execution-based Verification）**：
* **正样本轨迹（Success Trajectory）**：环境执行返回成功（Execution Status = 0/Success）且目标达成的轨迹。
* **负样本轨迹与自我纠错（Failure & Self-Correction）**：故意引入错误 Action，训练模型识别失败环境反馈并进行自我修复。




* **推荐论文**：
* TaskCraft: *TaskCraft: Structuring Execution Trajectories for Agentic Post-Training*
* Agent Tuning: *AgentTuning: Enabling Generalized Agent Capabilities for LLMs*


* **💡 第 3 周 MVP 交付**：
> 编写一个简易的 Agent 轨迹生成器：在一个模拟环境（如 Python code interpreter 或 Web 简易交互器）中，自动记录 Agent 的多步工具调用过程，并生成 50 条带有环境反馈（Execution Observation）的可验证轨迹数据集。



---

#### 第 4 周：数据清洗、语义去重与多维过滤（Data Filtering & Deduplication）

* **学习重点**：
* **文本与图像语义去重（Deduplication）**：
* **MinHash / LSH (Locality-Sensitive Hashing)**：海量文本快速字面去重。
* **Embedding 向量去重**：使用 Sentence-Transformers 或 CLIP Embedding 计算余弦相似度（Cosine Similarity），剔除语义高度重合的冗余样本。


* **规则过滤与质量打分（Quality Filtering）**：
* **规则过滤（Rule-based）**：包含无意义字符、语法错误、格式非法（JSON 无法解析）、长度过短/过长的样本清洗。
* **模型打分过滤（Model-based / LLM-as-a-Judge）**：使用 Scoring Prompt 对合成数据的真实性、逻辑连贯性、指令遵循度打分（如 1~5 分），过滤低分样本。




* **推荐开源工具**：
* `datasketch` (MinHash / LSH)
* `facebookresearch/faiss` (高维向量相似度检索)


* **💡 第 4 周 MVP 交付**：
> 编写一个数据清洗 Pipeline 工具：输入 2,000 条混有噪声和冗余的合成数据，使用 MinHash 剔除字面重复项，使用 FAISS + CLIP Embedding（阈值 > 0.92）剔除语义重复项，最后用规则和校验模型筛出 Top 40% 的高质量样本。



---

#### 第 5 - 6 周：高吞吐合成 Pipeline 工程化与闭环验证

* **学习重点**：
* **高并发合成架构**：
* 避免单条 API 调用的低效问题，使用 `SGLang` 或 `vLLM` 搭建本地高吞吐批处理（Async / Multi-threading Batch Processing）生成引擎。
* 优化 Prompt 的 Prefix Caching（前缀缓存）降低重复 Prefill 开销。


* **合成数据的“产出 - 微调 - 验证”小闭环**：
* 将第 1~4 周合成并清洗后的数据，接入 Stage 2 的微调流程进行 SFT 训练。
* 在 Stage 3 的 Benchmark 上对比“使用基础公开数据” vs “加入合成数据后”的模型性能表现差异。




* **💡 第 5-6 周 MVP 交付**：
> 1. 搭建一套基于 Python `asyncio` + `vLLM/SGLang` 后端的高并发合成流水线，实现每分钟产出上百条高质量合成数据。
> 2. 最终交付一份包含 **3,000 条高质量、已去重、可验证的多模态/Agent SFT 数据集**（Hugging Face Dataset 格式）。
> 3. 用该数据集训练一个 Baseline 模型，记录评测得分提升情况。
