## 贯穿全阶段的一条主线

Stage 2 的全部内容都是围绕一个转换过程展开的工程学：

$$
\text{图文 JSON 数据} \xrightarrow{\text{Processor + Collator}} \text{模型输入四件套} \xrightarrow{\text{策略性训练}} \text{能力可控的 VLM Checkpoint}
$$

- 第 1 周解决**转换本身**（数据怎么变成张量）；
- 第 2 周解决**训练谁**（两阶段策略与参数效率）；
- 第 3 周解决**用什么数据训**（配方与遗忘）；
- 第 4 周解决**怎么训得动、训得快**（分布式与显存）；
- 自测周把四个环节串成完整能力闭环。

读完五篇后，你应该能对一个陌生的 VLM 训练报错，在 10 分钟内定位它属于"数据构造、训练策略、数据配方、工程配置"四类问题中的哪一类——这正是自测验收的内核。
