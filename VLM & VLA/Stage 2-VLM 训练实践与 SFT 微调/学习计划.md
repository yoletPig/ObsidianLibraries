### 阶段二：VLM 训练实践与 SFT 微调进阶（3 - 4 周）

**阶段核心目标**：彻底理解多模态模型从预训练对齐到 SFT（指令微调）的全套 Pipeline，掌握多模态数据构造、Loss 计算机制、数据配方（Data Mixture）调优，以及全量微调与 LoRA/QLoRA 的工程实现。

---

### 📅 逐周学习路线与 MVP 交付

#### 第 1 周：多模态数据格式与 Pipeline 深度构造

* **学习重点**：
* **ChatML 与多模态 Prompt 构造**：
* 深入理解对话模版（System Prompt + `<image>` Token + User Question + Assistant Answer）。
* 理解变长分辨率下的 Token 序列拼装（Padding / Packing 机制）。


* **Data Collator 与 Processor 运作机制**：
* 了解图片如何通过 Processor 转化为 Tensor（如 `pixel_values` 或 `image_grid_thw`）。
* 掌握 `labels` 的构造逻辑：**只有 Assistant 回答部分计算 Loss，Prompt / `<image>` / User 提问部分均设为 `-100`（Ignore Index）**。




* **推荐研读源码**：
* `LLaMA-Factory`: `src/llamafactory/data/collator/`
* `ms-swift`: 多模态 Data Processor 组装部分


* **💡 第 1 周 MVP 交付**：
> 手写一个独立的 PyTorch `Dataset` 与 `DataCollator` 类，加载 10 条自定义图文 JSON 数据，输出可直接送入模型的 `input_ids`、`attention_mask`、`pixel_values` 以及 `labels`，并用代码验证 `labels` 中 Prompt 对应的 Index 确实全部被掩码为 `-100`。



---

#### 第 2 周：VLM 训练阶段划分、Loss 设计与参数效率微调

* **学习重点**：
* **VLM 的多阶段训练策略 (Multi-stage Training)**：
1. **Stage 1: Feature Alignment (Pre-training)** — 冻结 Vision Tower 和 LLM，仅训练 Projector，让 LLM 认识视觉 Token。
2. **Stage 2: Visual Instruction Tuning (SFT)** — 解冻 Projector + LLM（或使用 LoRA/QLoRA），冻结 Vision Tower（或只微调 Vision Tower 顶层）。


* **Loss 梯度与计算**：
* 交叉熵损失函数在 Token 级的计算：$L = -\sum_{i} \log P(x_i \mid x_{<i}, \text{image})$。
* 理解为什么 Vision Token 默认不计算梯度损失，以及何时开启 Vision Tower 梯度更新。


* **微调策略选择**：
* **Full Finetuning** vs **LoRA** vs **QLoRA (4-bit)** 的显存占用计算（模型权重、梯度、优化器状态 $m$ & $v$ 的显存分配）。
* 思考：LoRA 权重是只挂在 LLM 的 Attention 上，还是也需要挂在 Projector 和 Vision Tower 上？




* **💡 第 2 周 MVP 交付**：
> 基于同一小批数据，做一组对照实验：
> 1. 实验 A：仅训练 Projector；
> 2. 实验 B：训练 Projector + LLM (LoRA)。
> 对比两者的训练 Loss 降幅速度与推理输出的语言表达连贯度，总结 Projector 独训与联合微调的区别。
> 
>

#### 第 3 周：数据配方 (Data Mixture) 与多任务消融实验

* **学习重点**：
* **多模态数据集构成分类**：
* 基础 VQA / Image Caption（通用视觉理解）
* OCR / Document / Chart 识别（细粒度文本/图表理解）
* Spatial Grounding / 坐标检测（Bounding Box 归一化坐标训练，如 `[ymin, xmin, ymax, xmax]`）
* Multi-step Reasoning / Visual CoT（思维链推导）


* **数据混合 (Data Mixture) 与重采样 (Resampling)**：
* 为什么简单的把所有数据拼在一起会导致某些能力遗忘？
* 学习数据配比策略（如通用数据 : OCR : 坐标数据 = 5 : 3 : 2）。


* **消融实验（Ablation Study）方法论**：如何通过控制变量验证某类数据加入后对特定 Benchmark 的正/负收益。


* **💡 第 3 周 MVP 交付**：
> 准备一个包含 3 种不同任务（通用描述、OCR 图表、空间坐标定位）的混合数据集（约 1000 条），设计两组不同的数据比例配方（例如 8:1:1 vs 4:3:3）。微调出两个 Checkpoint，对比它们在纯 OCR 提问和空间定位提问上的效果差异，撰写一份简短的消融分析笔记。



---

#### 第 4 周：大规模训练工程实践与显存调优

* **学习重点**：
* **分布式训练引擎与策略**：
* PyTorch DDP vs DeepSpeed (ZeRO-2, ZeRO-3)。
* 混合精度训练（FP16 vs BF16，理解为什么 BF16 在大模型训练中更不易产生 Over/Underflow）。


* **显存与吞吐优化**：
* **FlashAttention-2 / SDPA** 在多模态长序列中的使用。
* **Gradient Checkpointing（激活重算）** 降低显存开销。
* **Packed Training (Sample Packing)**：如何把多条短图文拼接成一条固定长度（如 4096）的 Sequence，避免 Padding 造成的算力浪费。


* **常见工程坑排查**：Loss 变成 NaN 的排查思路、Vision Tower 显存突刺 OOM 的解决方案。


* **💡 第 4 周 MVP 交付**：
> 使用 `LLaMA-Factory` 或原生脚本，配合 DeepSpeed ZeRO-2/3，在多卡环境（或单卡大显存环境）下开启 FlashAttention-2 与 Gradient Checkpointing，成功运行一次 10k 级数据量的 VLM SFT 训练，记录 GPU 显存占用、TFLOPS 吞吐率及训练总耗时。
