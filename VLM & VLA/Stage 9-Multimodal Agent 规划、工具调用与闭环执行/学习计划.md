### 阶段九：Multimodal Agent 规划、工具调用与闭环执行（4 - 6 周）

**阶段核心目标**：从“单步/多步问答模型”升级为“具备自主感知、任务规划（Planning）、记忆（Memory）、工具调用（Tool Use/Function Calling）与自我反思（Reflection）的视觉 Agent 智能体”。深入掌握多模态 Agent 的动作空间映射（Action Space）、屏幕/GUI 操作 Grounding、以及复杂多步执行轨迹（Execution Trajectories）的清洗与校验，构建高可靠的 Agent 闭环系统。

---

### 📅 逐周学习路线与 MVP 交付

#### 第 1 周：Agent 核心范式与 Tool Use / Function Calling 机制

* **学习重点**：
* **ReAct (Reasoning + Acting) 范式**：
* 理解 `Thought` $\rightarrow$ `Action` $\rightarrow$ `Observation` 交互循环流转。
* 掌握如何在 Prompt 中注入 Tool Schema（JSON/OpenAPI 定义），以及 VLM 如何将视觉/文本信息转化为结构化的函数参数（Function Calling）。


* **约束解码与语法约束 (Constrained Decoding)**：
* VLM 常常产生 JSON 语法错误或参数漏填。学习利用 JSON Schema 约束解码（如 Outlines、vLLM Guided Decoding、SGLang JSON Mode），强制模型输出 100% 合法的 Action JSON。


* **多模态工具链路设计**：
* 设计常见的视觉工具（如图像裁剪 Crop、高精度 OCR、Grounding DINO 坐标检测、Python 代码解释器）。




* **💡 第 1 周 MVP 交付**：
> 1. 手写一个基于 Python 的 **ReAct Agent 核心 Loop 引擎**。
> 2. 给定一张包含密集文本与物体的复杂图片，Agent 能自主选择调用 `Crop_Image_Tool`（对特定区域裁剪放大）和 `OCR_Tool`，将工具执行的 Observation 重新喂回 VLM，最终得出准确结论。
> 3. 接入约束解码，确保 100 次工具调用无一次 JSON 语法解析失败。
> 
>

#### 第 2 周：任务规划 (Planning)、反思 (Reflection) 与长短期记忆 (Memory)

* **学习重点**：
* **复杂任务规划 (Planning)**：
* **子目标拆解 (Sub-goal Decomposition)**：将复杂长路线指令拆解为有序的 Atomic Actions（原子动作）。
* **Tree of Thoughts (ToT) 与 MCTS (Monte Carlo Tree Search)** 在 Agent 路径选择中的应用。


* **环境反馈与自我反思 (Reflection & Self-Correction)**：
* 当工具执行失败或返回 Error Traceback 时，Agent 如何通过 `<reflection>` 标签分析失败原因并重试（Retry with Reprompting）。


* **视觉与文本记忆机制 (Memory Architecture)**：
* **短期记忆 (Short-term)**：Context Window 管理、History Trajectory 压缩与 Summarization。
* **长期记忆 (Long-term / Visual RAG)**：将历史关键帧/截图及对应的坐标与 Action 存入向量数据库，进行跨时域检索。




* **推荐论文**：
* ReAct: *ReAct: Synergizing Reasoning and Acting in Language Models*
* Reflexion: *Reflexion: Language Agents with Verbal Reinforcement Learning*


* **💡 第 2 周 MVP 交付**：
> 实现一个具有 **“自我纠错能力”的 Agent 实例**：当工具调用报错（如 Python 代码执行抛出 Exception，或调用的 API 超时）时，Agent 能够自动进入 Reflection 状态，分析 Error Traceback 并重新生成修正后的代码或参数，直至成功运行。



---

#### 第 3 周：视觉 GUI / Web / OS 操作控制 Agent (Screen Grounding Agent)

* **学习重点**：
* **GUI / Screen-Grounding 机制**：
* 如何将屏幕截图（UI Screenshot）映射为可交互的动作（点击 Click `(x, y)`、输入 Type `text`、滚动 Scroll `direction`）。
* 学习 **Set-of-Mark (SoM)** 提示工程：在截图上自动叠加编号标记（Bounding Boxes / Numeric Tags），降低 VLM 预测绝对坐标的难度。


* **Web/OS 自动化工具**：
* 使用 `Playwright` 或 `PyAutoGUI` 搭建自动化浏览器/桌面操作环境。
* 解析 SOTA GUI Agent 架构（如 OmniParser、SeeClick、CogAgent）。




* **推荐开源仓库与论文**：
* `microsoft/OmniParser` (将屏幕截图解析为结构化 UI 元素的工具)
* SeeClick: *SeeClick: Harnessing GUI Grounding for Advanced Visual GUI Agents*


* **💡 第 3 周 MVP 交付**：
> 结合 `Playwright` 自动化浏览器，搭建一个 **Web GUI 自动化 Agent**：
> 输入自然语言指令（如：“帮我在电商网站上找到评价最高的产品并加入购物车”），Agent 实时读取网页截图，使用 SoM 或 Grounding 标记按钮位置，生成点击/打字操作并在 Playwright 中执行，连续完成 5 步以上的网页操作。



---

#### 第 4 周：Agent 轨迹合成、Sanity Check 与异常数据清洗

* **学习重点**：
* **Agentic Post-training 轨迹数据构建 (TaskCraft-style)**：
* 基于 Teacher Model 或真实环境交互生成多步、多跳（Multi-hop）、多工具可验证的 Agent 轨迹（Execution Trajectories）。


* **轨迹清洗与 Sanity Check 规则**：
* **动作死循环检测（Loop Detection）**：识别并在数据集里剔除重复做同一个动作的无效轨迹。
* **逻辑断层检测**：校验 Thought 与 Action 之间是否存在因果倒置。
* **最短路径提取（Trajectory Pruning）**：去除执行过程中的试错和冗余动作，将 10 步试错轨迹精简为 4 步最优直线轨迹。


* **SFT / RL 闭环反哺**：将高质量轨迹数据格式化为多模态 SFT 数据，提升 VLM 的 Agent 属性。


* **推荐论文**：
* TaskCraft: *TaskCraft: Structuring Execution Trajectories for Agentic Post-Training*


* **💡 第 4 周 MVP 交付**：
> 编写一个 **Agent 轨迹校验工具 (Trajectory Filter)**：对 200 条多步 Agent 交互 Trace 进行自动化审查，识别并过滤掉“死循环”、“环境反馈异常”和“缺乏依据的盲目操作”的轨迹，清洗出一份高品质、可用于微调的 JSONL 轨迹数据集。



---

#### 第 5 - 6 周：端到端 Multimodal Agent 系统集成与项目实战

* **学习重点**：
* **多 Agent 协作架构 (Multi-Agent Workflows)**：
* 主控 Agent (Planner) + 专职 Agent (Vision Examiner, Coder, Reporter) 间的协作通信与消息传递。


* **系统工程化与鲁棒性（Robustness & Fault Tolerance）**：
* 并发 API 工具调用的超时控制、Fallback 备用方案、Guardrails 检查（防止生成危险代码或破坏性指令）。




* **💡 第 5-6 周 MVP 交付**：
> 端到端构建并交付一个 **Deep Research / Visual Task Agent 系统**：
> * **任务场景**：输入一个复杂指令（如：“对比两份带图表和公式的 PDF 报告，计算 X 数据的增长率，并绘制柱状图报告”）。
> * **系统闭环**：Agent 自主调用 PDF 解析工具抽图、调用 VLM 解析图表数据、调用 Python 解释器计算增长率并生成图像、最后汇总撰写完整的 markdown 报告。
> * **交付物**：提供完整的 Agent 系统源码、运行日志（Trace Logs）与可视化操作界面/Demo。
