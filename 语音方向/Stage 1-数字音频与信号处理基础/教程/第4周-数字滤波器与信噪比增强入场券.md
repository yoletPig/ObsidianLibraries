## 1. 第一性原理：滤波 = 对频率的选择性衰减

### 1.1 根本矛盾

真实录音永远是"目标信号 + 不想要的成分"：语音 + 背景噪声、回声、混响。**滤波（filtering）**的目标是设计一个系统，让想要的频率成分通过、把不想要的压下去。这要求我们能在频域"雕刻"频谱——第 2 周的 STFT 正是工具。

### 1.2 LTI 系统与卷积

数字滤波器几乎都是**线性时不变（LTI）**系统：输出是输入与**脉冲响应** $h[n]$ 的卷积：

$$
y[n] = (x * h)[n] = \sum_{k} h[k]\, x[n-k]
$$

LTI 系统有一个决定性的好性质：**卷积在频域变乘法**。对频率 $f$ 的复正弦输入，系统只是乘一个复数 $H(f)$（频率响应）：

$$
Y(f) = H(f) \cdot X(f)
$$

$|H(f)|$ 决定各频率被放大/衰减多少，$\angle H(f)$ 决定相位偏移。**设计滤波器 = 设计你想要的 $H(f)$**。低通、高通、带通、带阻，都是对 $|H(f)|$ 的不同形状要求。

### 1.3 FIR vs IIR

两类实现结构：

**FIR（Finite Impulse Response，有限脉冲响应）**：

$$
y[n] = \sum_{k=0}^{M} b_k\, x[n-k]
$$

只有前馈项。脉冲响应 $h = [b_0, \dots, b_M]$ 有限长。

**IIR（Infinite Impulse Response，无限脉冲响应）**：

$$
y[n] = \sum_{k=0}^{M} b_k\, x[n-k] \;-\; \sum_{k=1}^{N} a_k\, y[n-k]
$$

含反馈项（依赖过去的输出 $y$），脉冲响应理论上无限长。

| 维度 | FIR | IIR |
| --- | --- | --- |
| 稳定性 | 恒稳定（无反馈） | 可能不稳定（极点可在单位圆外） |
| 线性相位 | 容易（对称系数即可） | 基本做不到 |
| 达到同等陡峭过渡带 | 阶数高（计算多） | 阶数低（高效） |
| 典型应用 | 音频处理、抗混叠 | 模拟原型数字化（Butterworth 等） |

**线性相位为何重要**：语音若不同频率被延迟不同量（非线性相位），波形会"散开"产生相位失真。FIR 对称系数天然线性相位，这是音频偏爱 FIR 的核心原因。

**实现一个 FIR 低通**（窗函数法，直观理解）：

```python
import numpy as np
from scipy import signal as sps

def fir_lowpass(cutoff_hz: float, sr: int, numtaps: int = 101) -> np.ndarray:
    """窗函数法设计 FIR 低通，返回滤波器系数。"""
    nyq = sr / 2
    return sps.firwin(numtaps, cutoff_hz / nyq, window="hamming")

# 应用：对噪声语音做低通（演示，实际去噪用谱减法）
sr = 16000
t = np.arange(sr) / sr
x = np.sin(2*np.pi*440*t) + 0.5*np.sin(2*np.pi*6000*t)   # 440Hz + 6kHz 噪声
h = fir_lowpass(cutoff_hz=1000, sr=sr)
y = sps.lfilter(h, [1.0], x)
# 6kHz 成分应被大幅衰减
spec_in  = np.abs(np.fft.rfft(x[sr//2:]))
spec_out = np.abs(np.fft.rfft(y[sr//2:]))
freqs = np.fft.rfftfreq(sr//2, 1/sr)
idx_6k = np.argmin(np.abs(freqs - 6000))
atten_db = 20*np.log10(spec_out[idx_6k] / (spec_in[idx_6k] + 1e-12))
print(f"6kHz 成分被衰减 {atten_db:.1f} dB")
assert atten_db < -30, "低通未有效衰减 6kHz"
```

预期：6 kHz 被衰减 30 dB 以上。这就是"频域选择性"的最小实证。

## 2. 信噪比（SNR）：增强的度量语言

### 2.1 定义

$$
\text{SNR}_{\text{dB}} = 10 \log_{10} \frac{P_{\text{signal}}}{P_{\text{noise}}}
= 10 \log_{10} \frac{\mathbb{E}[s^2]}{\mathbb{E}[n^2]}
$$

- 0 dB：信号与噪声功率相等；
- 10 dB：信号功率是噪声的 10 倍；
- 负值：噪声比信号还强（恶劣场景）。

语音增强的一切目标都可以表述为"提升 SNR 的同时保留信号"。注意 SNR 是**功率比**，所以系数是 10 不是 20。

### 2.2 按指定 SNR 混合：`mix_at_snr()`（交付核心）

**数学推导**。给定干净语音 $s$ 和噪声 $n$，要混合成 $\text{SNR} = \gamma$ dB：

$$
y = s + \alpha n, \quad \text{其中 } \frac{P_s}{\alpha^2 P_n} = 10^{\gamma/10}
\;\Rightarrow\;
\alpha = \sqrt{\frac{P_s}{P_n \cdot 10^{\gamma/10}}}
$$

即噪声要先按目标 SNR 缩放，再叠加。

```python
import numpy as np

def _power(x: np.ndarray) -> float:
    return float(np.mean(x ** 2)) + 1e-12

def mix_at_snr(speech: np.ndarray, noise: np.ndarray,
                 snr_db: float) -> np.ndarray:
    """
    把噪声按指定 SNR 混入语音。
    返回与 speech 等长的混合信号。
    """
    assert speech.ndim == 1 and noise.ndim == 1
    # 噪声不够长则循环补齐
    if len(noise) < len(speech):
        reps = int(np.ceil(len(speech) / len(noise)))
        noise = np.tile(noise, reps)
    noise = noise[:len(speech)]

    ps, pn = _power(speech), _power(noise)
    scale = np.sqrt(ps / (pn * (10 ** (snr_db / 10))))
    return speech + scale * noise

# 验证：混合后实测 SNR 应≈目标值
sr = 16000
s = np.random.randn(sr * 2).astype(np.float32)     # 模拟语音
n = np.random.randn(sr * 2).astype(np.float32) * 1.0
for target in [20, 10, 5, 0, -5]:
    y = mix_at_snr(s, n, target)
    actual = 10*np.log10(_power(s) / _power(y - s))
    print(f"目标 {target:3d} dB -> 实测 {actual:.2f} dB")
    assert abs(actual - target) < 0.2, f"SNR 混合误差过大: {actual}"
```

预期：每个目标值与实测差 < 0.2 dB。这个函数是本周所有实验的数据生成器，务必跑通。

**易错点**：
- 用**峰值**而非**功率**定标 → SNR 不准；
- 忘记噪声循环补齐 → 长度不匹配报错；
- 混合后未检查是否削波（超过 ±1.0）→ 引入非线性失真，污染实验。

## 3. 谱减法：最经典的频域去噪

### 3.1 思想与推导

假设带噪信号 $y = s + n$，且噪声与语音不相关。在某个时频单元上，功率近似可加：

$$
|Y[m,k]|^2 \approx |S[m,k]|^2 + |N[m,k]|^2
$$

若我们能估计噪声功率谱 $\hat{N}^2[k]$（通常从**纯噪声段**平均得到），则语音功率谱估计为：

$$
|\hat{S}[m,k]|^2 = |Y[m,k]|^2 - \hat{N}^2[k]
$$

再用原相位重建波形。这就是**谱减法（Spectral Subtraction）**——1979 年 Boll 提出，是深度降噪的古典原型。

**噪声谱怎么来**：实际系统用 VAD 检测出"无语音的静音帧"，对这些帧的功率谱取平均，作为 $\hat{N}^2$。本周实验我们简化：直接给定一段纯噪声。

### 3.2 过减与谱下限

直接相减有两个问题：

1. **过减**：噪声估计不准时会减过头，把语音也削掉。引入过减因子 $\alpha \ge 1$：减 $\alpha \hat{N}^2$。
2. **负值**：$|Y|^2 - \hat{N}^2 < 0$ 时物理无意义。不能置零（会产生下一节的音乐噪声），要设**谱下限（spectral floor）** $\beta |Y|^2$：

$$
|\hat{S}|^2 = \max\big(|Y|^2 - \alpha \hat{N}^2,\;\; \beta |Y|^2\big)
$$

$\beta \in [0.001, 0.05]$：保底保留一点原始能量，避免彻底挖空。

### 3.3 音乐噪声：谱减法的致命伤

**症状**：去噪后的音频里出现随机的、忽隐忽现的"鸟鸣/金属碎片"声。

**根因**：噪声谱估计在时频面上有随机误差。某些时频单元噪声被高估 → 减成谱下限（接近 0）；相邻单元没被高估 → 保留正常能量。结果是**孤立的、随机分布的能量尖峰**散布在时频面上，听起来像散落的音符。

**定位**：画去噪后的语谱图，若背景不干净、有星星点点的亮斑，就是音乐噪声。

**缓解**：① 谱下限 $\beta$；② 时频平滑（对增益做邻域平均）；③ 用更准的噪声估计（MMSE、最小值跟踪）。这些正是 Stage 3 深度降噪模型要彻底解决的问题——**谱减法是你的对照基线**。

### 3.4 手写谱减法（交付）

复用第 2 周的 `stft()` / `istft()`：

```python
import numpy as np

def estimate_noise_spectrum(noise_only: np.ndarray, n_fft: int, hop: int,
                            win_len: int) -> np.ndarray:
    """从纯噪声段估计平均噪声功率谱 (n_fft//2+1,)。"""
    S = stft(noise_only, n_fft=n_fft, hop=hop, win_len=win_len)
    return np.mean(np.abs(S) ** 2, axis=0)

def spectral_subtraction(y: np.ndarray, noise_spec: np.ndarray,
                         n_fft: int, hop: int, win_len: int,
                         alpha: float = 1.0, beta: float = 0.01) -> np.ndarray:
    """
    STFT 域谱减法去噪。
    y: 带噪语音; noise_spec: 估计的噪声功率谱。
    """
    S = stft(y, n_fft=n_fft, hop=hop, win_len=win_len)     # (T, F) 复数
    mag2 = np.abs(S) ** 2
    # 过减 + 谱下限
    clean_mag2 = np.maximum(mag2 - alpha * noise_spec[None, :],
                            beta * mag2)
    # 用原相位重建
    S_clean = np.sqrt(clean_mag2) * np.exp(1j * np.angle(S))
    return istft(S_clean, hop=hop, win_len=win_len, length=len(y))

# ---- 端到端实验 ----
sr = 16000
# 用 librosa 载入真实语音与噪声
import librosa
s, _ = librosa.load(librosa.ex("trumpet"), sr=sr)   # 代指干净语音
s = s[:sr * 3]
noise = np.random.randn(len(s)).astype(np.float32)  # 白噪声
noise[:sr//2] *= 0   # 前 0.5s 留作"纯噪声估计段"的替代：这里直接用噪声本身估

target_snr = 5.0
y = mix_at_snr(s, noise, target_snr)
noise_spec = estimate_noise_spectrum(noise, n_fft=512, hop=160, win_len=400)
s_hat = spectral_subtraction(y, noise_spec,
                             n_fft=512, hop=160, win_len=400,
                             alpha=2.0, beta=0.01)

import soundfile as sf
sf.write("noisy.wav", y, sr)
sf.write("enhanced.wav", s_hat, sr)
print("已输出 noisy.wav / enhanced.wav，试听对比")
```

试听任务：`enhanced.wav` 应比 `noisy.wav` 干净，但背景能听到轻微音乐噪声——亲手确认这个缺陷，你就理解了为什么需要深度学习降噪。

## 4. 客观评价指标：量化"变好了多少"

主观试听不可复现，工程必须用客观指标。三个必须掌握的：

### 4.1 PESQ（语音质量，有参考）

ITU-T P.862 标准，模拟人耳感知，输出 -0.5 ~ 4.5 分（越高越好）。适合窄带/宽带语音质量评估。**局限**：对现代深度降噪的改进不够敏感，且需要干净参考。

### 4.2 STOI（可懂度，有参考）

Short-Time Objective Intelligibility，度量"能不能听清说了什么"，输出 0~1。对语音增强比 PESQ 更贴近"可懂度"目标。

### 4.3 SI-SNR（尺度不变信噪比）

$$
\text{SI-SNR} = 10\log_{10} \frac{\|\alpha s\|^2}{\|\hat{s} - \alpha s\|^2},\quad
\alpha = \frac{\hat{s}^\top s}{\|s\|^2}
$$

先把估计 $\hat{s}$ 投影到参考方向再算比值，消除整体增益的影响。分离/增强任务的标准损失与指标。

### 4.4 交付：对比表脚本

```python
# pip install pesq pystoi
from pesq import pesq
from pystoi import stoi
import numpy as np

def evaluate(clean: np.ndarray, noisy: np.ndarray,
             enhanced: np.ndarray, sr: int) -> dict:
    n = min(len(clean), len(noisy), len(enhanced))
    clean, noisy, enhanced = clean[:n], noisy[:n], enhanced[:n]
    def si_snr(est, ref):
        ref = ref - ref.mean(); est = est - est.mean()
        alpha = np.dot(est, ref) / (np.dot(ref, ref) + 1e-12)
        proj = alpha * ref
        return 10*np.log10(np.sum(proj**2) / (np.sum((est-proj)**2) + 1e-12))
    return {
        "PESQ_noisy": pesq(sr, clean, noisy, "wb"),
        "PESQ_enh":   pesq(sr, clean, enhanced, "wb"),
        "STOI_noisy": stoi(clean, noisy, sr, extended=False),
        "STOI_enh":   stoi(clean, enhanced, sr, extended=False),
        "SISNR_noisy": si_snr(noisy, clean),
        "SISNR_enh":  si_snr(enhanced, clean),
    }

res = evaluate(s, y, s_hat, sr)
print(f"{'指标':<12}{'去噪前':>10}{'去噪后':>10}")
for key in ["PESQ", "STOI", "SISNR"]:
    print(f"{key:<12}{res[key+'_noisy']:>10.3f}{res[key+'_enh']:>10.3f}")
assert res["SISNR_enh"] > res["SISNR_noisy"], "谱减法应提升 SI-SNR"
```

**预期**：三项指标去噪后全部上升（5 dB 白噪声场景下，SI-SNR 通常提升 3-6 dB）。这张表就是本周交付的核心——**用数字证明谱减法有效，同时你已通过试听知道它的天花板在哪**。

**踩坑提示**：`pesq` 库对采样率有要求（`wb` 模式要 16 kHz），且要求数组等长、非 NaN；若报 `NoUtterancesError`，说明参考信号能量过低。

## 5. 工程权衡与失效模式

### 5.1 权衡

- **过减因子 $\alpha$**：大 → 更干净但削语音、音乐噪声更重；小 → 残留噪声多。工程靠网格搜索 + 指标定标。
- **噪声估计方式**：静态（假设噪声平稳）简单但对非平稳噪声失效 → 这是 MCRA、最小值跟踪等自适应估计的动机。
- **相位处理**：谱减法保留带噪相位，重建音质受限；更好的相位估计是另一条研究线。

### 5.2 失效模式

1. **噪声非平稳**：键盘声、人声背景——静态噪声谱完全失配，去噪几乎无效。定位：画噪声段的功率谱随时间变化；修复：换自适应估计或深度模型。
2. **削波**：混合或去噪后超过 ±1.0。症状：波形顶部削平、引入谐波。修复：归一化或降低增益。
3. **音乐噪声**：见 3.3。这是谱减法的固有缺陷，不是实现 bug——但 $\beta$ 设 0 会极度放大它。

## 6. 延伸思考题（含解析）

**Q1**：为什么谱减法要在**功率谱**域相减，而不是幅度谱或复数谱？
**A**：噪声与语音不相关时，交叉项期望为零，功率近似可加；复数谱相位无法直接相减（相位不是能量量）；幅度谱不满足可加性。功率域是唯一近似线性可分解的表示。

**Q2**：`mix_at_snr` 里为什么缩放的是**噪声**而不是语音？
**A**：约定以语音为基准（信号功率固定），调节噪声强度达到目标比值；缩放语音会改变"信号本身"，不符合"加噪"语义。

**Q3**：音乐噪声为什么听起来是"离散的音乐碎片"而不是连续噪声？
**A**：减过头的单元被压到谱下限，能量残留随机散布在时频面上；孤立的窄带能量峰在听觉上被解析成一个个短促的音调——即"碎片"。时频平滑能抹平这种孤立性。

**Q4**：PESQ 和 STOI 哪个更适合评估"电话语音降噪"？
**A**：两者互补：STOI 更贴近"能否听清"（电话的核心诉求），PESQ 反映整体质量。论文通常同时报告；若只能选一个，语音通信场景优先 STOI。

**Q5**：真实系统没有"纯噪声段"可估计，怎么办？
**A**：用 VAD 在线标记静音帧并递推更新噪声谱；或用最小值跟踪（噪声功率谱的滑动最小值近似）；深度方法则直接端到端学习，不需要显式噪声估计——这是 Stage 3 的方向。
