# 第 1 周教程：说话人表征学习——从 i-vector 到 ECAPA-TDNN

> **本周要回答的三个问题**
> 1. 一段 3 秒的语音和一段 30 秒的语音，如何都变成**同一个固定维度**的声纹向量？
> 2. 统计池化（Stats Pooling）在数学上做了什么？为什么它是"变长 → 定长"的关键？
> 3. ArcFace/AAM-Softmax 这类度量学习损失，如何让"同人聚拢、异人分离"？

对应学习计划：第 1 周。交付物：用预训练 `spkrec-ecapa-voxceleb` 提取 192 维声纹，验证"同人余弦相似度 > 0.75、异人 < 0.4"的经验区间，并解释阈值校准的必要性。

## 1. 第一性原理：说话人识别 = 表征 + 度量

### 1.1 问题定义

给定一段语音，判断"是谁说的"。三个子任务：

- **验证（Verification, 1:1）**：这段语音是否属于声称的某人？（门禁、支付）
- **辨认（Identification, 1:N）**：这段语音是底库 N 人中的谁？
- **分离（Diarization）**：这段音频里有几个人、各说了什么？（本周为第 3-4 周铺路）

三个任务共享同一个原子能力：**把变长语音映射成定长的说话人表征（embedding），且该空间里"同人近、异人远"**。

### 1.2 表征学习的两代演进

**第一代：i-vector（统计模型）**

把语音的 GMM 超向量（supervector）投影到一个低维"总变化空间"（Total Variability Space）：

$$
\mathbf{M} = \mathbf{m} + T\mathbf{w}
$$

$\mathbf{M}$ 是语音的超向量，$\mathbf{m}$ 是全局均值，$T$ 是总变化矩阵，$\mathbf{w}$ 就是 i-vector（通常 400 维）。它用因子分析把"说话人差异 + 信道差异"混在一个空间里，再用概率 LDA 等后端分离。

**局限**：依赖 GMM 特征统计、信道鲁棒性靠后端修补、无法端到端用判别损失优化。被深度方法全面取代。

**第二代：x-vector → ECAPA-TDNN（深度端到端）**

核心思想：用神经网络逐帧提特征，**池化**成段级向量，再用度量学习损失训练。这条路线就是本周重点。

---

## 2. x-vector：池化让"变长 → 定长"

### 2.1 架构三段式

$$
\text{帧级特征} \xrightarrow{\text{TDNN 帧级层}} \text{逐帧向量} \xrightarrow{\text{统计池化}} \text{段级向量} \xrightarrow{\text{段级层}} \text{x-vector}
$$

1. **帧级层**：TDNN（时延神经网络，等价于一维因果卷积）逐帧提取上下文特征；
2. **统计池化（Stats Pooling）**：把所有帧的向量聚合成定长——**这是变长到定长的关键**；
3. **段级层**：全连接层进一步压缩，输出 x-vector（如 512 维）。

### 2.2 统计池化的数学（本周自测题）

对 $T$ 帧的特征向量序列 $\{\mathbf{h}_1, \dots, \mathbf{h}_T\}$（每个 $\mathbf{h}_t \in \mathbb{R}^d$）：

$$
\boldsymbol{\mu} = \frac{1}{T}\sum_{t=1}^{T} \mathbf{h}_t \quad \text{（均值）}
$$

$$
\boldsymbol{\sigma} = \sqrt{\frac{1}{T}\sum_{t=1}^{T} \mathbf{h}_t^2 - \boldsymbol{\mu}^2} \quad \text{（标准差）}
$$

池化输出 = 拼接 $[\boldsymbol{\mu}; \boldsymbol{\sigma}] \in \mathbb{R}^{2d}$。

**直觉**：均值刻画"这个人的平均音色"，标准差刻画"音色的起伏方式"。两者合起来，无论输入 3 秒还是 30 秒，输出都是固定 $2d$ 维——**变长问题被池化解决**。

### 2.3 ECAPA-TDNN：现代骨架

ECAPA 在 x-vector 基础上三个升级：

1. **SE-Res2Block**：Squeeze-Excitation（通道注意力）+ Res2Net（多尺度卷积），增强特征表达；
2. **多层特征聚合**：把多个中间层的输出拼接起来用，融合不同抽象层次；
3. **Attentive Stats Pooling**：池化不再是简单均值，而是**注意力加权**——重要帧（信息量大的帧）权重高：

$$
\boldsymbol{\mu} = \sum_t \alpha_t \mathbf{h}_t, \quad \alpha_t = \text{softmax}(\text{MLP}(\mathbf{h}_t))
$$

SpeechBrain 的 `spkrec-ecapa-voxceleb` 输出 **192 维**声纹，正是这套架构的产物。

## 3. 度量学习：让空间"同人近、异人远"

### 3.1 分类损失的局限

若用普通 softmax 分类 N 个说话人，模型只学会"区分训练集里的 N 人"，对没见过的人泛化差。声纹要的是**开放集**能力：任意两人的相似度可比。

### 3.2 AAM-Softmax / ArcFace

核心思想：**把分类边界从"特征空间"搬到"角度空间"**，并强制拉大同人、拉大异人的角度间隔。

对特征 $\mathbf{x}$ 与第 $i$ 类中心 $\mathbf{W}_i$（都归一化），夹角 $\theta_i$。ArcFace 在目标类的角度上加惩罚 $m$：

$$
\mathcal{L} = -\log \frac{e^{s \cdot \cos(\theta_{y} + m)}}{e^{s \cdot \cos(\theta_{y} + m)} + \sum_{j \neq y} e^{s \cdot \cos \theta_j}}
$$

- $m$（margin）：把目标类角度"推开"，强迫同人样本聚得更紧；
- $s$（scale）：缩放，控制分布锐度。

**效果**：训练后，同人样本在超球面上紧凑成簇，异人之间被 margin 撑开。推理时只需算**余弦相似度**即可判断。

### 3.3 为什么推理用余弦相似度

归一化后的声纹向量在单位超球面上，余弦相似度 = 内积 = 角度的单调函数。两个声纹 $\mathbf{e}_1, \mathbf{e}_2$：

$$
\text{sim} = \frac{\mathbf{e}_1 \cdot \mathbf{e}_2}{\|\mathbf{e}_1\| \|\mathbf{e}_2\|}
$$

同人接近 1，异人接近 0 或负值。

## 4. 实现与验证（交付核心）

### 4.1 提取声纹并验证相似度区间

```bash
pip install speechbrain
```

```python
import torch
import torchaudio
from speechbrain.inference.speaker import EncoderClassifier

classifier = EncoderClassifier.from_hparams(
    source="speechbrain/spkrec-ecapa-voxceleb",
    savedir="pretrained_models/spkrec-ecapa")

def embed(path):
    signal, sr = torchaudio.load(path)
    if sr != 16000:
        signal = torchaudio.functional.resample(signal, sr, 16000)
    with torch.no_grad():
        emb = classifier.encode_batch(signal)   # (1, 1, 192)
    return emb.squeeze().numpy()

# 准备：3 位说话人，每人 2 条音频
# spk1_a.wav, spk1_b.wav, spk2_a.wav, spk2_b.wav, spk3_a.wav, spk3_b.wav
import numpy as np
files = {
    "spk1_a": "data/spk1_a.wav", "spk1_b": "data/spk1_b.wav",
    "spk2_a": "data/spk2_a.wav", "spk2_b": "data/spk2_b.wav",
    "spk3_a": "data/spk3_a.wav", "spk3_b": "data/spk3_b.wav",
}
embs = {k: embed(p) for k, p in files.items()}

def cos_sim(a, b):
    return float(np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b)))

# 同人相似度
same = [cos_sim(embs["spk1_a"], embs["spk1_b"]),
        cos_sim(embs["spk2_a"], embs["spk2_b"]),
        cos_sim(embs["spk3_a"], embs["spk3_b"])]
# 异人相似度
diff = [cos_sim(embs["spk1_a"], embs["spk2_a"]),
        cos_sim(embs["spk1_a"], embs["spk3_a"]),
        cos_sim(embs["spk2_a"], embs["spk3_a"])]

print("同人相似度:", [f"{s:.3f}" for s in same])
print("异人相似度:", [f"{s:.3f}" for s in diff])
assert min(same) > 0.75, "同人相似度应 > 0.75"
assert max(diff) < 0.4, "异人相似度应 < 0.4"
print("声纹空间验证通过：同人 > 0.75，异人 < 0.4 ✓")
```

**预期**：同人三条相似度都在 0.75-0.95，异人都在 0.4 以下。这个"区间分离"是声纹可用的直接证据。

### 4.2 关键提醒：阈值不是常数

`0.75 / 0.4` 只是 **VoxCeleb 干净英语 + 这个模型**下的经验值。换数据集、换语言、换信道，整个分布会平移——**这就是阈值必须校准的原因**（第 2 周主题：EER 与 minDCF 就是校准工具）。

**为什么需要校准**（本周自测题）：
- 不同录音条件（麦克风、房间）让同人相似度整体下移；
- 不同人群（语言、年龄）让异人相似度分布变化；
- 攻击样本（合成语音）会落在异常区域。

生产上用一个**开发集**（已知同人/异人对）画出相似度分布，再按业务可接受的误识/误拒率定阈值——绝不是拍脑袋用 0.75。

## 5. 工程权衡与失效模式

### 5.1 权衡

- **表征维度**：高（512）表达力强但检索贵；低（128/192）省存储。ECAPA 192 是甜点；
- **池化方式**：均值池化简单；注意力池化更准但多一点计算；
- **训练数据**：VoxCeleb 英语为主；中文/目标域需补充数据微调。

### 5.2 失效模式

1. **短语音不稳定**：< 1 秒的片段声纹方差大。修复：保证切块 ≥ 1.5 秒或多块平均。
2. **信道失配**：训练干净、部署嘈杂 → 相似度整体下移。修复：前端降噪（联动 Stage 3）+ 域内校准。
3. **双胞胎/相似音色**：天生声纹接近，任何模型都难分。属于任务固有上限，需结合其他信号。
4. **阈值硬编码**：直接照搬 0.75 到生产，误识率失控。修复：第 2 周的 EER 校准流程。

## 6. 延伸思考题（含解析）

**Q1**：x-vector 的统计池化层在做什么？为什么 ECAPA 的多层聚合更好？
**A**：池化对所有帧取均值 + 标准差，把变长序列压成定长段级向量。ECAPA 拼接多个中间层输出再池化，融合了浅层（声学细节）与深层（抽象身份）信息，表达更全面。

**Q2**：声纹模型怎么处理变长语音？3 秒和 30 秒的向量能直接比吗？
**A**：靠池化层把任意时长聚合成固定维度，所以可直接比余弦相似度。但时长太短（<1 秒）统计不稳定，相似度方差大，建议 ≥1.5 秒。

**Q3**：为什么不用普通 softmax 而用 ArcFace/AAM-Softmax？
**A**：softmax 只学区分训练集 N 人，开放集泛化差。ArcFace 在角度空间加 margin，直接优化"同人紧、异人散"的几何结构，学出的表征对任意新人都可比——这是开放集验证的前提。

**Q4**：同人 0.75、异人 0.4 这个阈值能直接用于生产吗？
**A**：不能。它只是特定数据集 + 模型的经验值。换域后分布平移，必须用开发集重新校准（第 2 周的 EER 流程），按业务可接受的误识率定阈值。

**Q5**：i-vector 为什么被 x-vector 取代？
**A**：i-vector 依赖 GMM 统计与独立后端（信道补偿靠 PLDA），无法端到端用判别损失优化，且信道鲁棒性靠补丁。x-vector 端到端学习、池化处理变长、配度量学习损失，精度与工程简洁性全面胜出。
