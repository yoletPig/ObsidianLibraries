# Stage 4 教程索引：说话人分离与声纹识别

本目录是《学习计划》的配套教程，按周组织。每篇教程遵循统一框架：**第一性原理与数学本质 → 系统架构与数据流 → 工程权衡与失效模式 → 实现与验证（可运行代码）→ MVP 交付指导 → 延伸思考题（含解析）**。

> 本阶段回答两个问题：**"这是谁在说话？"**（声纹识别/验证）与 **"这段话里有几个人、各自说了什么？"**（说话人分离）。前者是后者的积木——分离系统的每一步都在用声纹表征做"是不是同一个人"的判断。

## 贯穿全阶段的一条主线

$$
\text{音频} \xrightarrow{\text{VAD/切块}} \text{片段} \xrightarrow{\text{ECAPA 声纹}} \text{embedding} \xrightarrow{\text{聚类/EEND}} \text{说话人标签} \xrightarrow{\text{与 ASR 对齐}} \text{会议转写}
$$

声纹表征（第 1-2 周）是整条链路的原子能力；分离（第 3-4 周）是它的组合应用；联合系统（第 5-6 周）把它与 Stage 2 的 ASR 焊成产品。

## 前置依赖

- Stage 1 的 `AudioPipeline`（16 kHz 统一入口）；Stage 3 的前端（可选，用于验证"先增强再分离"）；
- 依赖：`pip install pyannote.audio speechbrain resemblyzer faiss-cpu pyannote.metrics`；
- `pyannote.audio` 需要 Hugging Face token 并接受模型条款（注册后在设置页生成）。
