## 贯穿全阶段的一条主线

$$
\text{文本} \xrightarrow{\text{文本前端}} \text{音素/字符} \xrightarrow{\text{声学模型}} \text{梅尔谱/语义token} \xrightarrow{\text{声码器/flow}} \text{波形}
$$

零样本克隆的关键在第二步注入"参考音频的说话人信息"：或作为说话人 embedding，或作为 prompt token 拼进序列。理解这两种注入方式，就理解了所有克隆系统。

## 前置依赖

- Stage 1 的 Mel 特征知识（第 3 周）——TTS 的中间表示就是梅尔谱；
- 云 GPU（预算已确认）用于微调；推理可在本地；
- 依赖：`pip install cosyvoice f5-tts`（或按各仓库官方安装），`encodec`、`funasr`、`MFA`（强制对齐）。

## 与性能优化方向的联动

第 2 周的**音频离散化（RVQ）**与性能优化方向的**向量量化/标量量化**互为镜像——学完这里，你在量化方向的面试就多了一层"音频视角"的弹药。
