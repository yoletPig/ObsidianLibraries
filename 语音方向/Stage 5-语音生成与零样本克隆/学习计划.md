### 阶段五：语音生成与零样本声音克隆（6 - 8 周）

**阶段核心目标**：打通「文本 → 自然语音」的完整生成链路：声码器（Vocoder）三代演进、非自回归 TTS、LM-based TTS，并逐个拆解零样本克隆三大流派——**CosyVoice 2（主线）、F5-TTS（flow matching 路线）、GPT-SoVITS（少样本社区路线）**。最终完成一次 TTS LoRA 微调，产出可用你的声音克隆的推理服务。

> 💰 TTS 训练/微调必须上云（预算无上限）。声码器与 TTS 骨架训练只读代码不亲训，精力集中在微调与推理优化。

### 📅 逐周学习路线与 MVP 交付

#### 第 1 周：TTS 全景与声码器演进

* **学习重点**：
* **TTS 范式史**：拼接合成 → 统计参数合成（HTS）→ Tacotron（Seq2Seq + Attention）→ FastSpeech（非自回归时长预测）→ VITS（端到端 VAE + 流）。
* **声码器三代**：
* Griffin-Lim（无模型，相位重建）→ WaveNet（自回归采样）→ **HiFi-GAN**（GAN 并行生成，当前主流）→ BigVGAN / Vocos（频域）。
* **梅尔谱 ↔ 波形**的映射难点：一对多问题（同一幅度谱对应无数相位），VAE/Flow/GAN 各自的破解方式。
* **VITS 拆解**：VAE + Normalizing Flow + MAS 单调对齐搜索，为什么「一个模型管所有」。

* **推荐论文**：
* *FastSpeech 2: Fast and High-Quality End-to-End Text to Speech*
* *HiFi-GAN: Generative Adversarial Networks for Efficient and High Fidelity Speech Synthesis*
* *VITS: Conditional Variational Autoencoder with Adversarial Learning for End-to-End Text-to-Speech*

* **💡 第 1 周 MVP 交付**：
> 画出「Tacotron2 + HiFi-GAN」与「VITS 端到端」两条推理链路对比图，标注每个模块的输入输出（文本 → 音素 → 梅尔谱 → 波形）与各步耗时占比；用官方模型各合成一句你的自我介绍，做主观 MOS 打分（找 3 个朋友盲评）。

#### 第 2 周：LM-based TTS——语音语言模型范式

* **学习重点**：
* **VALL-E 思想**：把语音离散化为 Neural Audio Codec token（EnCodec），TTS 变成「文本 token → 音频 token」的语言建模；AR + NAR 两段式。
* **音频离散化**：EnCodec / SoundStream 的 RVQ（残差向量量化）——多层 codebook 是什么、带宽怎么算（为 Stage 6 量化主题联动）。
* **Flow Matching 登场**：Llama-Omni、MaskGCT、Seed-TTS 谱系；为什么工业界从 VALL-E 系转向 flow matching。
* **零样本克隆的通用配方**：3-10 秒参考音频 → 说话人 embedding / prompt token → 条件生成。

* **推荐论文**：
* *VALL-E: Neural Codec Language Models are Zero-Shot Text to Speech Synthesizers*
* *MaskGCT: Zero-Shot Text-to-Speech with Masked Generative Codec Transformer*

* **💡 第 2 周 MVP 交付**：
> 用 `encodec` 或 `funasr` 的 speech tokenizer 把一段语音离散成 token 序列，打印每层 codebook 的序列长度与词表大小，计算「1 秒语音 = 多少 token」；再用 transformers 的 LLM 对这个 token 序列计算困惑度，直观感受「语音作为语言」的可行性。

#### 第 3-4 周：CosyVoice 2 深度拆解（主线）

* **学习重点**：
* **架构三件套**：① 监督语义离散 token（FSQ，非 EnCodec 风格）；② 自回归 LLM 把文本映射成语义 token；③ Causal Flow Matching 解码器（Conditional Flow Matching + Causal 化支持流式）。
* **流式机制**：chunk-aware causal flow matching，首包延迟 150 ms 量级的工程实现；有限状态 Transducer（FST）纠错。
* **中英跨语言与指令跟随**：`[laughter]`、`[breath]`、情感指令控制；3 秒参考音频的零样本克隆实现。
* **训练细节**：5 小时 vs 17 万小时预训练数据规模的影响；Instruct 版本的指令数据构造。

* **推荐论文**：
* *CosyVoice: A Scalable Multilingual Zero-shot Text-to-speech Synthesizer based on Supervised Semantic Tokens*
* *CosyVoice 2: Scalable Streaming Speech Synthesis with Large Language Models*

* **💡 第 3-4 周 MVP 交付**：
> ① 部署 `CosyVoice2-0.5B` 推理（云 GPU），实现零样本克隆：录 10 秒你的声音 → 生成任意文本；② 通读 `cosyvoice/llm/llm.py` 与 flow matching 解码器源码，写出「文本 → FSQ token → mel → 波形」全链路 Shape 变化图（沿用你 VLM 阶段的维度追踪方法论）；③ 测量流式首包延迟与 RTF。

#### 第 5 周：F5-TTS 与 GPT-SoVITS 对比拆解

* **学习重点**：
* **F5-TTS**：Flow Matching + DiT（Diffusion Transformer 骨架），无时长模型、无音素依赖（直接用字符）的极简设计；Sway Sampling 推理加速。
* **GPT-SoVITS**：GPT 风格语言模型 + SoVITS（VITS 改造）；少样本（1 分钟）到零样本的连续谱；中文社区生态与数据标注工具链。
* **三路横向对比**：推理速度 / 克隆相似度 / 鲁棒性（吞字、重复）/ 微调成本 / 流式能力五维雷达图。

* **推荐论文**：
* *F5-TTS: A Fairytaler that Fakes Fluent and Faithful Speech with Flow Matching*
* GPT-SoVITS GitHub README 与社区技术报告

* **💡 第 5 周 MVP 交付**：
> 三模型同台竞技：用同一段 10 秒参考音频 + 5 条测试文本（含中英混读、数字、绕口令），分别用 CosyVoice 2 / F5-TTS / GPT-SoVITS 合成，组织盲评（相似度/自然度/鲁棒性打分），输出五维雷达图与你的选型结论。

#### 第 6-8 周：TTS 微调实战 + 推理服务化

* **学习重点**：
* **微调路线**：GPT-SoVITS 1 分钟少样本微调（最低成本）→ CosyVoice SFT 模式（5-10 小时录音数据构造）→ F5-TTS LoRA。
* **数据工程**：录音规范（48 kHz、干声）、ASR 转写打标签（用你 Stage 2 的 SenseVoice！）、强制对齐（MFA）、质量过滤。
* **推理服务化**：vLLM 风格流式服务、音频分块下发、并发压测；为 Stage 7 云端服务与 Stage 8 端侧助手预热。

* **💡 第 6-8 周 MVP 交付**：
> ① 录制/准备至少 30 分钟个人干声数据，完成一次 TTS 微调（GPT-SoVITS 或 CosyVoice SFT，云端执行）；② 盲评微调前后的说话人相似度与 WER（合成语音再喂 ASR 测可懂度）；③ 用 FastAPI + 流式响应把微调模型包成 HTTP 服务，压测并发 10 路合成的 RTF 与延迟。
