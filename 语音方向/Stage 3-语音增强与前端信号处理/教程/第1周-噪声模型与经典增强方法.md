## 1. 第一性原理：增强 = 在时频域估计"干净的增益"

### 1.1 统一框架

几乎所有单通道语音增强都可归结为：对每个时频单元估计一个**增益** $G[m,k]$，乘到带噪频谱上：

$$
\hat{S}[m,k] = G[m,k] \cdot Y[m,k]
$$

不同方法的区别只在**如何估计 $G$**。谱减法用功率相减，维纳滤波用最小均方误差——都是对同一个增益的不同估计策略。

### 1.2 观测模型

$$
y[n] = s[n] + v[n]
$$

$s$ 是干净语音，$v$ 是噪声。在时频域，假设两者不相关：

$$
|Y|^2 = |S|^2 + |V|^2
$$

**后验信噪比（posteriori SNR）**——直接用观测量算：

$$
\gamma = \frac{|Y[m,k]|^2}{\hat{\sigma}_v^2[k]}
$$

其中 $\hat{\sigma}_v^2[k]$ 是噪声功率谱估计。**先验信噪比（priori SNR）**——干净语音与噪声之比，这是我们需要但观测不到的量：

$$
\xi = \frac{|S[m,k]|^2}{\hat{\sigma}_v^2[k]}
$$

所有经典增强器的核心任务：**从可观测的 $\gamma$ 估计不可观测的 $\xi$**。

### 1.3 噪声分类

| 类型 | 特征 | 例子 | 增强难度 |
| --- | --- | --- | --- |
| 平稳 | 统计特性不随时间变 | 白噪声、风扇、空调 | 易（噪声谱固定，好估） |
| 非平稳 | 统计特性快速变化 | 键盘、街道、多人背景 | 难（噪声谱追不上） |
| 类语音 | 本身就是语音 | 背景人声（鸡尾酒会） | 最难（与目标同类） |

**噪声谱估计**是经典方法的命门：
- 平稳噪声：从初始静音段平均即可；
- 非平稳：需**自适应跟踪**——MCRA（Minima Controlled Recursive Averaging）或最小值跟踪（Minimum Statistics）。

## 2. 维纳滤波：最小均方误差意义下的最优增益

### 2.1 推导

维纳滤波要找一个增益 $G$，使估计 $\hat{S} = G \cdot Y$ 与真实 $S$ 的均方误差最小：

$$
\min_G \; \mathbb{E}\big[|S - G Y|^2\big]
$$

对 $G$ 求导置零，利用 $S$ 与 $V$ 不相关：

$$
G_{\text{wiener}} = \frac{\mathbb{E}[|S|^2]}{\mathbb{E}[|Y|^2]}
= \frac{\mathbb{E}[|S|^2]}{\mathbb{E}[|S|^2] + \mathbb{E}[|V|^2]}
= \frac{\xi}{1 + \xi}
$$

**这就是那个最优增益**。直觉：$\xi$ 越大（语音远强于噪声），增益越接近 1（全保留）；$\xi$ 越小（噪声占主导），增益越接近 0（全压掉）。

用先验信噪比 $\xi$ 表达：

$$
\boxed{\,G = \frac{\xi}{1 + \xi}\,}
$$

这正是学习计划自测题里的那个公式。

### 2.2 核心困难：$\xi$ 未知

$\xi$ 依赖未知的 $|S|^2$。经典做法是**Decision-Directed（判决导向）**估计。

### 2.3 Decision-Directed 方法

Ephraim-Malah 的决策导向法用**上一帧的增强结果**来估计当前帧的先验信噪比：

$$
\hat{\xi}[m,k] = \alpha \underbrace{\frac{|\hat{S}[m-1,k]|^2}{\hat{\sigma}_v^2[k]}}_{\text{上一帧增强结果外推}}
+ (1-\alpha) \underbrace{\max(\gamma[m,k] - 1, 0)}_{\text{当前帧后验粗估}}
$$

两项的含义：

- **第一项**（权重 $\alpha$）：用上一帧已增强的 $|\hat{S}|^2$ 外推当前——**时间平滑**，抑制噪声引起的瞬时波动；
- **第二项**（权重 $1-\alpha$）：当前帧的后验 $\gamma - 1$（$\gamma$ 是含噪的，减 1 大致去噪）——**快速响应**，跟上语音突然出现。

**$\alpha$ 的作用**（本周自测题）：

- $\alpha$ 大（如 0.98）：强平滑 → 音乐噪声少、但响应慢，辅音瞬态被抹平；
- $\alpha$ 小（如 0.5）：响应快 → 但平滑弱，音乐噪声回来。

**为什么能抑制音乐噪声**（对比谱减法）：谱减法直接功率相减，噪声谱估计误差造成随机孤立尖峰；Decision-Directed 的时间平滑让增益在时频面上连续变化，孤立尖峰被抹平。

### 2.4 噪声功率谱估计

本周用**初始静音段平均**（简化版），并实现一个基础的**递归平均**应对缓慢变化：

$$
\hat{\sigma}_v^2[k] \leftarrow \beta \hat{\sigma}_v^2[k] + (1-\beta)|Y[m,k]|^2 \quad \text{（仅在判定为噪声帧时更新）}
$$

配合简单能量 VAD 决定是否更新。生产用 MCRA/最小值跟踪。

## 3. 实现与验证（交付核心）

### 3.1 Decision-Directed 维纳滤波

复用 Stage 1 的 `stft()` / `istft()`：

```python
import numpy as np

def wiener_dd(y: np.ndarray, noise_spec: np.ndarray,
              n_fft: int, hop: int, win_len: int,
              alpha: float = 0.98, gain_floor: float = 0.05) -> np.ndarray:
    """
    Decision-Directed 维纳滤波增强。
    y: 带噪语音; noise_spec: 噪声功率谱 (n_fft//2+1,)
    alpha: DD 平滑因子; gain_floor: 增益下限防音乐噪声
    """
    S = stft(y, n_fft=n_fft, hop=hop, win_len=win_len)   # (T, F) 复数
    mag2 = np.abs(S) ** 2
    T, F = mag2.shape
    eps = noise_spec + 1e-12

    gain = np.ones((T, F))
    prev_clean2 = mag2[0]                                  # 初始用带噪谱

    for m in range(T):
        gamma = mag2[m] / eps                              # 后验信噪比
        xi_dd = alpha * (prev_clean2 / eps) + (1 - alpha) * np.maximum(gamma - 1, 0)
        G = xi_dd / (1 + xi_dd)                            # 维纳增益
        G = np.maximum(G, gain_floor)                       # 增益下限
        gain[m] = G
        prev_clean2 = (G ** 2) * mag2[m]                   # 本帧增强结果供下帧

    S_clean = S * gain
    return istft(S_clean, hop=hop, win_len=win_len, length=len(y))
```

### 3.2 多 SNR 实验与对比表

```python
import numpy as np
import librosa
from pesq import pesq
from pystoi import stoi

sr = 16000
s, _ = librosa.load(librosa.ex("trumpet"), sr=sr)
s = s[:sr * 3]
noise = np.random.randn(len(s)).astype(np.float32)
noise_spec = np.mean(np.abs(stft(noise, 512, 160, 400)) ** 2, axis=0)

def metrics(clean, noisy, enh, sr=16000):
    n = min(len(clean), len(noisy), len(enh))
    clean, noisy, enh = clean[:n], noisy[:n], enh[:n]
    return {
        "PESQ": pesq(sr, clean, enh, "wb"),
        "STOI": stoi(clean, enh, sr, extended=False),
        "PESQ_noisy": pesq(sr, clean, noisy, "wb"),
    }

print(f"{'SNR':>4} | {'PESQ带噪':>8} {'PESQ增强':>8} | {'STOI带噪':>8} {'STOI增强':>8}")
for snr_db in [0, 5, 10]:
    y = mix_at_snr(s, noise, snr_db)           # 复用 Stage 1 第 4 周
    enh = wiener_dd(y, noise_spec, 512, 160, 400)
    m = metrics(s, y, enh)
    print(f"{snr_db:>3}dB | {m['PESQ_noisy']:>8.3f} {m['PESQ']:>8.3f} "
          f"| {m['STOI_noisy']:>8.3f} {m['STOI']:>8.3f}")
```

**预期**：三行输出，每行增强后 PESQ/STOI 均高于带噪。0 dB 提升最明显，10 dB 提升较小（本来就干净）。

## 4. 工程权衡与失效模式

### 4.1 权衡

- **$\alpha$ 平滑**：大 → 稳但钝（抹瞬态）；小 → 快但噪。0.95-0.98 是经验区间；
- **增益下限 `gain_floor`**：太低 → 音乐噪声；太高 → 残留噪声。0.01-0.1；
- **噪声估计**：初始段平均简单但对非平稳失效——这是下周深度方法要解决的。

### 4.2 失效模式

1. **非平稳噪声失效**：键盘声、背景人声——静态噪声谱严重失配。定位：看增强后噪声是否"跟着变"；修复：自适应估计或深度模型。
2. **音乐噪声**：$\alpha$ 太小或 `gain_floor` 太低。试听有"鸟鸣"；修复：加大 $\alpha$、提下限。
3. **辅音被抹**：平滑过强把 /s/ /t/ 的瞬态压掉，可懂度降。修复：降 $\alpha$、缩短平滑窗。
4. **音乐噪声与失真的混淆**：PESQ 升但听感"发闷"——这是过度平滑。PESQ 对平滑不敏感，需配合试听与 STOI。

## 5. 延伸思考题（含解析）

**Q1**：维纳增益 $G = \xi/(1+\xi)$ 中 $\xi$ 是什么？为什么它观测不到？
**A**：$\xi$ 是先验信噪比，干净语音功率与噪声功率之比。它含未知的 $|S|^2$，观测里只有 $S+V$ 的混合，故不可直接测，必须估计。

**Q2**：先验 $\xi$ 与后验 $\gamma$ 的区别？
**A**：后验 $\gamma = |Y|^2/\sigma_v^2$ 用含噪观测 $Y$ 算，可直接得但被噪声污染；先验 $\xi = |S|^2/\sigma_v^2$ 用干净 $S$，是真值但未知。DD 法用后验和历史增强结果去估先验。

**Q3**：$\alpha$ 平滑因子如何权衡？取 0 和 1 分别退化为什么？
**A**：$\alpha$ 大强平滑（稳但钝），$\alpha$ 小快响应（快但噪）。$\alpha=0$ 退化为纯后验（每帧独立、音乐噪声重）；$\alpha=1$ 完全依赖上一帧（响应极慢）。

**Q4**：Decision-Directed 为什么比谱减法音乐噪声少？
**A**：DD 的时间平滑使增益在时频面连续变化，噪声谱估计误差造成的孤立尖峰被相邻帧平均掉；谱减法逐帧独立相减，误差直接表现为随机尖峰。

**Q5**：为什么非平稳噪声下经典方法失效？深度方法凭什么能行？
**A**：经典方法依赖显式的噪声功率谱估计，非平稳噪声的谱追不准。深度模型端到端学习"带噪→干净"的映射，隐式建模噪声的时变结构，不需显式估噪声谱——这是第 2 周的主题。
