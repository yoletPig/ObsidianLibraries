## 1. 第一性原理：增强 = 在时频域估计"干净的增益"

### 1.1 统一框架

几乎所有单通道语音增强都可归结为：对每个时频单元估计一个**增益** $G[m,k]$，乘到带噪频谱上：

$$
\hat{S}[m,k] = G[m,k] \cdot Y[m,k]
$$

**这个公式在干什么**：把带噪语音做 STFT（Stage 1 第 2 周的手写 `stft()`）后，得到一张"时间 × 频率"的二维表格 $Y[m,k]$——$m$ 是帧号（时间），$k$ 是频率 bin。增强就是给表里**每个格子**配一个小旋钮 $G[m,k] \in [0,1]$：这个格子听起来像语音（清辅音、元音共振峰）就把旋钮拧到接近 1（全保留），像噪声就拧到接近 0（压掉）。旋完再逆变换回波形。整周要做的事只有一件：**怎么决定每个旋钮的位置**。

不同方法的区别只在**如何估计 $G$**。谱减法用功率相减，维纳滤波用最小均方误差——都是对同一个增益的不同估计策略。

### 1.2 观测模型

$$
y[n] = s[n] + v[n]
$$

**这个公式在干什么**：麦克风收到的每一个样本都是"干净语音 + 噪声"的叠加——$s$ 是干净语音，$v$ 是噪声。这个加性假设是整周一切推导的地基（混响导致的卷积噪声不在此列，那是另一个课题）。

在时频域，假设两者不相关，功率可直接相加：

$$
|Y|^2 = |S|^2 + |V|^2
$$

**这个公式在干什么**：为什么"功率"能直接相加？展开 $|S+V|^2 = |S|^2 + |V|^2 + 2\text{Re}(SV^*)$，多出来的交叉项是语音与噪声的乘积——两者不相关时它的时间平均趋于 0，于是剩下一个漂亮的加法式。它告诉你：**只要你估得出 $|V|^2$（噪声功率谱），就能从 $|Y|^2$ 里"减"出语音功率**——这就是第 2.4 节噪声估计如此重要的原因。

由此定义两个信噪比。**后验信噪比（posterior SNR，记号 $\gamma$）**——直接用观测量算：

$$
\gamma = \frac{|Y[m,k]|^2}{\hat{\sigma}_v^2[k]}
$$

**先验信噪比（priori SNR，记号 $\xi$，希腊字母 xi）**——干净语音与噪声之比，这是我们需要但观测不到的量：

$$
\xi = \frac{|S[m,k]|^2}{\hat{\sigma}_v^2[k]}
$$

**这两个符号在干什么**：分母都是噪声功率谱估计 $\hat{\sigma}_v^2[k]$（"v 的方差"按频率 bin 给出）。$\gamma$ 用的是 $|Y|^2 = |S|^2 + |V|^2$——所以 $\gamma$ 在纯噪声段围绕 1 波动（$|S|^2\approx 0$），有语音时明显大于 1；它**可测但被噪声污染**。$\xi$ 用的是干净的 $|S|^2$——它是"真正的信噪比"，**是真相但不可测**。类比：$\gamma$ 是"体检时带病测出的指标"，$\xi$ 是"健康的真实程度"；增强算法的全部智慧在于**从 $\gamma$ 估计 $\xi$**（第 2.3 节的 Decision-Directed 就是干这个的）。

### 1.3 噪声分类

| 类型 | 特征 | 例子 | 增强难度 |
| --- | --- | --- | --- |
| 平稳 | 统计特性不随时间变 | 白噪声、风扇、空调 | 易（噪声谱固定，好估） |
| 非平稳 | 统计特性快速变化 | 键盘、街道、多人背景 | 难（噪声谱追不上） |
| 类语音 | 本身就是语音 | 背景人声（鸡尾酒会） | 最难（与目标同类） |

**噪声谱估计**是经典方法的命门：
- 平稳噪声：从初始静音段平均即可；
- 非平稳：需**自适应跟踪**——MCRA（Minima Controlled Recursive Averaging，Cohen 2003）或最小值跟踪（Minimum Statistics，Martin 2001）：前者"只在最小值附近的帧做递归平均"，后者"滑窗取最小值天然落在噪声上"。本教程用最简单的静音段 + VAD 门控递归平均（2.4 节），为的是把精力集中在增益估计上。

## 2. 维纳滤波：最小均方误差意义下的最优增益

### 2.1 推导

维纳滤波要找一个增益 $G$，使估计 $\hat{S} = G \cdot Y$ 与真实 $S$ 的均方误差最小：

$$
\min_G \; \mathbb{E}\big[|S - G Y|^2\big]
$$

**这个公式在干什么**：在所有可能的增益里，挑"平均而言猜得最准"的那个。$\mathbb{E}[\cdot]$ 是对所有随机情况（语音内容、噪声实现）取期望；$|S - GY|^2$ 是"猜错的能量"。直觉上这是一个定价问题：$Y$ 是"含噪报价"，$G$ 是你对该报价的信任度——信任度该多高，才能让"猜错的总代价"最小？

对 $G$ 求导置零（就算允许 $G$ 取复数，最优解也是下面这个实数值），利用 $S$ 与 $V$ 不相关（交叉项 $\mathbb{E}[V S^*] = 0$ 消失）：

$$
G_{\text{wiener}} = \frac{\mathbb{E}[|S|^2]}{\mathbb{E}[|Y|^2]}
= \frac{\mathbb{E}[|S|^2]}{\mathbb{E}[|S|^2] + \mathbb{E}[|V|^2]}
= \frac{\xi}{1 + \xi}
$$

**这三步在干什么**：最优信任度 = "信号功率占观测功率的比例"。语音越强，越信观测；噪声越强，越不信。代入先验信噪比 $\xi$ 得到盒装的最优增益：

$$
\boxed{\,G = \frac{\xi}{1 + \xi}\,}
$$

这正是学习计划自测题里的那个公式。**动手感受它的形状**（拿计算器按两下比背公式有用）：

| 先验 SNR $\xi$ | 增益 $G=\frac{\xi}{1+\xi}$ | 策略 |
| --- | --- | --- |
| 9（≈9.5 dB） | 0.90 | 语音很强 → 几乎全保留 |
| 1（0 dB） | 0.50 | 五五开 → 砍半（-6 dB） |
| 0.11（≈-9.5 dB） | 0.10 | 噪声主导 → 只留 10% |
| 0 | 0 | 纯噪声 → 全压掉 |

注意 $G$ 永远在 $(0,1)$ 之间且**永不突然跳变**——这与谱减法的"硬开关"形成对比，是维纳滤波音乐噪声更少的原因之一。

### 2.2 核心困难：$\xi$ 未知

$\xi$ 依赖未知的 $|S|^2$——你手里只有带噪的 $Y$。经典做法是 **Decision-Directed（判决导向）**估计，出自 Ephraim & Malah 1984 年那篇著名论文（同一篇提出了 MMSE-STSA 幅度估计器）。

### 2.3 Decision-Directed 方法

> **一句话直觉**：像医生复诊——对当前病情的判断 = 大部分参考"上一次的诊断结果"（$\alpha$），小部分参考"今天的化验单"（$1-\alpha$）。两路信息按固定比例混合，既稳又不太迟钝。

Ephraim-Malah 的决策导向法用**上一帧的增强结果**来估计当前帧的先验信噪比：

$$
\hat{\xi}[m,k] = \alpha \underbrace{\frac{|\hat{S}[m-1,k]|^2}{\hat{\sigma}_v^2[k]}}_{\text{上一帧增强结果外推}}
+ (1-\alpha) \underbrace{\max(\gamma[m,k] - 1, 0)}_{\text{当前帧后验粗估}}
$$

逐符号拆开：

- $|\hat{S}[m-1,k]|^2$：**上一帧刚增强完**的干净功率谱——它是我们手里对"语音长什么样"最好的猜测；
- 除以 $\hat{\sigma}_v^2[k]$：换算成先验 SNR 的单位；
- $\gamma[m,k]-1$：由 1.2 节 $|Y|^2 = |S|^2+|V|^2$ 可知 $\gamma-1 \approx |S|^2/\hat{\sigma}_v^2 = \xi$——**减 1 就是粗略地把噪声份额剔掉**；$\max(\cdot, 0)$ 防止噪声波动让它变负；
- $\alpha$：两路信息的混合比例（$\alpha \in [0,1)$）。

两项的含义：

- **第一项**（权重 $\alpha$）：用上一帧已增强的 $|\hat{S}|^2$ 外推当前——**时间平滑**，抑制噪声引起的瞬时波动；
- **第二项**（权重 $1-\alpha$）：当前帧的后验粗估——**快速响应**，跟上语音突然出现。

**$\alpha$ 的作用**（本周自测题）：

| $\alpha$ | 行为 | 代价 |
| --- | --- | --- |
| 大（0.98） | 强平滑，增益曲线连续 | 音乐噪声少；但响应慢，辅音瞬态被抹平 |
| 小（0.5） | 快速跟上变化 | 瞬态保得好；但平滑弱，音乐噪声回来 |

**为什么能抑制音乐噪声**（对比谱减法）：谱减法直接功率相减，噪声谱估计误差造成随机孤立尖峰——一帧在、一帧不在的"孤岛"信号，听感是"汩汩水声/鸟鸣"；Decision-Directed 的时间平滑让增益在时频面上连续变化，孤立尖峰被相邻帧平均掉。

### 2.4 噪声功率谱估计

本周用**初始静音段平均**（简化版），并实现一个基础的**递归平均**应对缓慢变化：

$$
\hat{\sigma}_v^2[k] \leftarrow \beta \hat{\sigma}_v^2[k] + (1-\beta)|Y[m,k]|^2 \quad \text{（仅在判定为噪声帧时更新）}
$$

**这个公式在干什么**：指数滑动平均（EMA）——新估计 = "93% 旧估计 + 7% 当前观测"（取 $\beta=0.93$ 时）。$\beta$ 越大越"恋旧"（平滑、抗突发），越小越"追新"。关键在括号里的条件：**只在 VAD 判定当前帧是噪声时才更新**——否则语音帧的功率会被当成噪声学进去，把语音一起削掉。这就是"VAD 门控"。生产系统用 MCRA/最小值跟踪替代这个手工开关（1.3 节）。

> **一句话总结**：经典增强 = 在每个时频格上估增益；维纳滤波给出最优增益 $G=\xi/(1+\xi)$；$\xi$ 测不到，就用"上一帧结果 + 当前粗估"按 $\alpha$ 混合来估（Decision-Directed）；而整个体系的地基——噪声功率谱——全靠估计，估不准则满盘皆输，这正是第 2 周深度方法要接管的环节。

## 3. 实现与验证（交付核心）

### 3.1 Decision-Directed 维纳滤波

复用 Stage 1 的 `stft()` / `istft()`。对照 2.3 节公式逐行读，你会发现代码就是递推式的直接翻译：

```python
import numpy as np

def wiener_dd(y: np.ndarray, noise_spec: np.ndarray,
              n_fft: int, hop: int, win_len: int,
              alpha: float = 0.98, gain_floor: float = 0.05) -> np.ndarray:
    """
    Decision-Directed 维纳滤波增强。
    y: 带噪语音; noise_spec: 噪声功率谱 (n_fft//2+1,)
    alpha: DD 平滑因子; gain_floor: 增益下限防音乐噪声
    """
    S = stft(y, n_fft=n_fft, hop=hop, win_len=win_len)   # (T, F) 复数
    mag2 = np.abs(S) ** 2                                 # |Y|^2
    T, F = mag2.shape
    eps = noise_spec + 1e-12                              # 防 0 除

    gain = np.ones((T, F))
    prev_clean2 = mag2[0]                # 递推初值：用带噪谱代替未知的干净谱

    for m in range(T):
        gamma = mag2[m] / eps                              # 后验 SNR γ
        xi_dd = alpha * (prev_clean2 / eps) + (1 - alpha) * np.maximum(gamma - 1, 0)
        G = xi_dd / (1 + xi_dd)                            # 维纳增益 G = ξ/(1+ξ)
        G = np.maximum(G, gain_floor)                       # 增益下限，压音乐噪声
        gain[m] = G
        prev_clean2 = (G ** 2) * mag2[m]                   # |Ŝ[m]|^2 = G^2|Y|^2，供下帧

    S_clean = S * gain                                     # 幅度乘增益，相位保留
    return istft(S_clean, hop=hop, win_len=win_len, length=len(y))
```

> **动手验证**：把 `alpha` 设为 0 跑一遍——$\hat\xi$ 退化为纯后验粗估 $\max(\gamma-1,0)$，听感上音乐噪声立刻回来；这就是 2.3 节"平滑"作用的直接证据。

### 3.2 多 SNR 实验与对比表

```python
import numpy as np
import librosa
from pesq import pesq
from pystoi import stoi

sr = 16000
# 用一段真实语音（librosa 自带的 LibriSpeech 样例，或换成你自己的 16k 录音）
s, _ = librosa.load(librosa.ex("libri1"), sr=sr)
s = s[:sr * 3]
noise = np.random.randn(len(s)).astype(np.float32)   # 白噪声
noise_spec = np.mean(np.abs(stft(noise, 512, 160, 400)) ** 2, axis=0)

def metrics(clean, noisy, enh, sr=16000):
    n = min(len(clean), len(noisy), len(enh))
    clean, noisy, enh = clean[:n], noisy[:n], enh[:n]
    return {
        "PESQ": pesq(sr, clean, enh, "wb"),
        "STOI": stoi(clean, enh, sr, extended=False),
        "PESQ_noisy": pesq(sr, clean, noisy, "wb"),
        "STOI_noisy": stoi(clean, noisy, sr, extended=False),
    }

print(f"{'SNR':>4} | {'PESQ带噪':>8} {'PESQ增强':>8} | {'STOI带噪':>8} {'STOI增强':>8}")
for snr_db in [0, 5, 10]:
    y = mix_at_snr(s, noise, snr_db)           # 复用 Stage 1 第 4 周
    enh = wiener_dd(y, noise_spec, 512, 160, 400)
    m = metrics(s, y, enh)
    print(f"{snr_db:>3}dB | {m['PESQ_noisy']:>8.3f} {m['PESQ']:>8.3f} "
          f"| {m['STOI_noisy']:>8.3f} {m['STOI']:>8.3f}")
```

> PESQ 需要 `pip install pesq`（含 C 扩展）。PESQ 的宽带模式 `"wb"` 只支持 8/16 kHz 采样率——这也是语音处理统一用 16 kHz 的原因之一。

**预期**：三行输出，每行增强后 PESQ/STOI 均高于带噪（0 dB 时 PESQ 提升最明显，可达 +0.3~0.8；10 dB 时提升较小，本来就干净）。STOI 本身对"降噪但轻微失真"不敏感，数值变化不如 PESQ 明显，属正常现象。

### 3.3 与谱减法对比 + $\alpha$ 消融

> 谱减法出处：Boll 1979《Suppression of Acoustic Noise in Speech Using Spectral Subtraction》。这里的 `alpha=2.0` 是"过减因子"（多减一点噪声、压低残留），`beta=0.01` 是"谱底"（负值不置零而是压到 $0.01\cdot|Y|^2$，正是 Boll 为抑制音乐噪声提出的技巧——Berouti 等人同年的工作将其参数化为 $\alpha,\beta$）。

```python
# 同一 5dB 样本：谱减法（Stage 1） vs 维纳 DD
y5 = mix_at_snr(s, noise, 5)
enh_ss = spectral_subtraction(y5, noise_spec, 512, 160, 400, alpha=2.0, beta=0.01)
enh_dd = wiener_dd(y5, noise_spec, 512, 160, 400, alpha=0.98)

for name, enh in [("谱减法", enh_ss), ("维纳DD", enh_dd)]:
    m = metrics(s, y5, enh)
    print(f"{name}: PESQ={m['PESQ']:.3f} STOI={m['STOI']:.3f}")

# alpha 消融：0.5 / 0.9 / 0.98
for a in [0.5, 0.9, 0.98]:
    enh = wiener_dd(y5, noise_spec, 512, 160, 400, alpha=a)
    m = metrics(s, y5, enh)
    print(f"alpha={a}: STOI={m['STOI']:.3f}")
```

**预期**：维纳 DD 通常略优于谱减法；$\alpha$ 消融显示 0.98 的平滑最稳（音乐噪声最少）。试听三者确认音乐噪声差异——**这是理解"为什么经典方法不够"的关键体验**。

## 4. 工程权衡与失效模式

### 4.1 权衡

- **$\alpha$ 平滑**：大 → 稳但钝（抹瞬态）；小 → 快但噪。0.95-0.98 是经验区间；
- **增益下限 `gain_floor`**：太低 → 音乐噪声；太高 → 残留噪声。0.01-0.1；
- **噪声估计**：初始段平均简单但对非平稳失效——这是下周深度方法要解决的。

### 4.2 失效模式

1. **非平稳噪声失效**：键盘声、背景人声——静态噪声谱严重失配。定位：看增强后噪声是否"跟着变"；修复：自适应估计或深度模型。
2. **音乐噪声**：$\alpha$ 太小或 `gain_floor` 太低。试听有"鸟鸣"；修复：加大 $\alpha$、提下限。
3. **辅音被抹**：平滑过强把 /s/ /t/ 的瞬态压掉，可懂度降。修复：降 $\alpha$、缩短平滑窗。
4. **音乐噪声与失真的混淆**：PESQ 升但听感"发闷"——这是过度平滑。PESQ 对平滑不敏感，需配合试听与 STOI。

## 5. 延伸思考题（含解析）

**Q1**：维纳增益 $G = \xi/(1+\xi)$ 中 $\xi$ 是什么？为什么它观测不到？
**A**：$\xi$ 是先验信噪比，干净语音功率与噪声功率之比。它含未知的 $|S|^2$，观测里只有 $S+V$ 的混合，故不可直接测，必须估计。

**Q2**：先验 $\xi$ 与后验 $\gamma$ 的区别？
**A**：后验 $\gamma = |Y|^2/\sigma_v^2$ 用含噪观测 $Y$ 算，可直接得但被噪声污染；先验 $\xi = |S|^2/\sigma_v^2$ 用干净 $S$，是真值但未知。DD 法用后验和历史增强结果去估先验。

**Q3**：$\alpha$ 平滑因子如何权衡？取 0 和 1 分别退化为什么？
**A**：$\alpha$ 大强平滑（稳但钝），$\alpha$ 小快响应（快但噪）。$\alpha=0$ 退化为纯后验（每帧独立、音乐噪声重）；$\alpha=1$ 完全依赖上一帧（响应极慢）。

**Q4**：Decision-Directed 为什么比谱减法音乐噪声少？
**A**：DD 的时间平滑使增益在时频面连续变化，噪声谱估计误差造成的孤立尖峰被相邻帧平均掉；谱减法逐帧独立相减，误差直接表现为随机尖峰。

**Q5**：为什么非平稳噪声下经典方法失效？深度方法凭什么能行？
**A**：经典方法依赖显式的噪声功率谱估计，非平稳噪声的谱追不准。深度模型端到端学习"带噪→干净"的映射，隐式建模噪声的时变结构，不需显式估噪声谱——这是第 2 周的主题。
