## 1. 凸集与凸函数

### 1.1 凸集

集合 $C$ 是**凸的**，若对任意 $x, y \in C$ 与 $\theta \in [0,1]$：

$$
\theta x + (1-\theta) y \in C
$$

读法：**集合里任取两点，连线整段还在集合里**。圆盘凸、环不行；半平面凸；两个不相交圆盘的并集不凸（Boyd《Convex Optimization》§2.1）。

### 1.2 凸函数

函数 $f$ 是**凸的**，若定义域是凸集且对任意 $x, y$ 与 $\theta \in [0,1]$：

$$
f(\theta x + (1-\theta) y) \le \theta f(x) + (1-\theta) f(y)
$$

读法：**函数图像在任意弦的下方**（碗状）。严格凸要求不等号对 $x\ne y$ 严格成立。

### 1.3 判定技巧

- **一阶条件**：可微凸函数满足 $f(y) \ge f(x) + \nabla f(x)^\top(y-x)$——每点的切平面全部在函数下方；
- **二阶条件**：二阶可微时 $f$ 凸 $\iff$ Hessian 处处半正定（09 篇的 Hessian 直接复用）；$f = x^2$ 的 Hessian 是 $2I$，凸；$f = x^2 - y^2$ 不定，不凸；
- **保凸运算**（工程速查）：凸 + 凸 = 凸；仿射变换后仍凸；非负加权和仍凸；$\max(f, g)$ 仍凸；凸函数与非负数复合 $h(f(x))$ 仍凸（$h$ 凸且不降，如 $\exp$）。**组合这些规则能证明 90% 的实用凸性**（Boyd §3.2）；
- 例子：线性函数（既凸又凹）、$\|x\|$ 全部范数、$\exp(x)$、$-\log x$、二次型 $x^\top A x$（$A\succeq 0$）。

## 2. 为什么凸问题"好"

### 2.1 局部极小即全局极小

反证：若 $x^*$ 是局部极小但存在更低的 $y$，则弦 $(y, x^*)$ 上的点（凸组合）由凸性保证函数值 $\le \theta f(x^*) + (1-\theta) f(y) < f(x^*)$，且这些点可以任意靠近 $x^*$——与局部极小矛盾。**所以凸函数上：找到的任何局部极小就是全局极小**，SGD 不会"卡在坏地方"，只存在"还没走到"。

### 2.2 对偶间隙：另一个礼物

凸问题的对偶问题（3 节）与原问题之间有**弱对偶性恒成立**（对偶最优值 $\le$ 原问题最优值），且在温和条件下（Slater 条件：存在严格可行点）**强对偶成立**——上下界重合。非凸问题的对偶可能有"洞"（对偶间隙大），这时对偶界就没用了。这解释了为什么 12 篇里 KL 散度（凸）能当"可优化的代理"而不会骗人。

### 2.3 求解器生态

凸问题有多项式时间算法（内点法，Boyd §11），成熟求解器（CVXPY/MOSEK/ECOS/OSQP）输入问题描述即出全局最优解+最优性证书。**工程含义**：一旦建模成凸问题，"如何优化"这个问题本身就消失了。

## 3. 拉格朗日对偶：约束的"工程用法"

### 3.1 拉格朗日函数：把约束写进目标

标准形式 $\min f_0(x)\ \text{s.t.}\ f_i(x) \le 0,\ h_j(x) = 0$。引入**拉格朗日乘子** $\lambda_i \ge 0, \nu_j$：

$$
L(x, \lambda, \nu) = f_0(x) + \sum_i \lambda_i f_i(x) + \sum_j \nu_j h_j(x)
$$

工程读法：**把违反约束的"价格"加进目标**。$\lambda$ 是违约单价——目标函数多赚 1 块、违约代价 $\lambda$ 块。直觉上 $L$ 是"利润 − 罚款"，优化者会选择"要么守规矩要么交罚款"。**这把约束优化变成了对 $x$ 的无约束优化**，这正是深度学习里各种约束处理技巧（惩罚法、增广拉格朗日、ADMM）的原型（**经验做法**：简单场景直接用大常数惩罚 $\mu f_i(x)_+$，精细场景用增广拉格朗日避免病态）。

### 3.2 对偶函数与对偶问题

对 $x$ 最小化 $L$ 得到**对偶函数** $g(\lambda, \nu) = \inf_x L(x,\lambda,\nu)$。可以证明（Boyd §5.2）：

$$
g(\lambda, \nu) \le p^\star \quad \text{对一切可行乘子成立（弱对偶）}
$$

即 $g$ 是最优值的**下界工厂**。把下界最大化（$\max_{\lambda\ge0} g$）就是**对偶问题**——一个总是凸的问题。强对偶时上下界相遇，$\lambda^\star$ 还给出**影子价格**：约束松 1 单位，目标值变好 $|\lambda^\star|$ 单位——资源定价、灵敏度分析全靠它。

### 3.3 手算一个最小例子

$$
\min\ x_1^2 + x_2^2 \quad \text{s.t.}\quad x_1 + x_2 = 2
$$

几何：原点为心的等高线圆，与直线 $x_1+x_2=2$ 的最近切点。拉格朗日函数 $L = x_1^2+x_2^2 + \nu(x_1+x_2-2)$。驻点条件：

$$
2x_1 + \nu = 0,\quad 2x_2 + \nu = 0 \Rightarrow x_1 = x_2,\ \text{代入约束}\ x_1 = x_2 = 1,\ \nu = -2
$$

最优值 $p^\star = 2$，$\nu^\star = -2$ 的影子价格含义：把约束右端放宽为 2.01（圆心到直线距离变化），最优值变为 $\frac{2.01^2}{2} = 2.0201$——每放宽 1 单位代价下降 2 单位，正是 $|\nu^\star| = 2$。（可作为练习自行验证。）

### 3.4 把对偶函数算出来看看

延续 3.3 的例子，亲手算一次"下界工厂"。对固定的 $\nu$，先对 $x$ 取下确界：

$$
g(\nu) = \inf_{x}\ \left[x_1^2 + x_2^2 + \nu(x_1+x_2-2)\right]
$$

对 $x_1, x_2$ 分别驻点：$x_1 = x_2 = -\nu/2$，代回：

$$
g(\nu) = 2\cdot\frac{\nu^2}{4} + \nu(-\nu - 2) = -\frac{\nu^2}{2} - 2\nu
$$

这是一条开口向下的抛物线——**对偶问题** $\max_\nu g(\nu)$：驻点 $-\nu - 2 = 0 \Rightarrow \nu = -2$，$g(-2) = -2 + 4 = 2$。与原问题最优值 $p^\star = 2$ 相等——**强对偶**达成（此问题满足 Slater 型条件）。整个过程演示了对偶的标准工作流：

1. 原问题 → 拉格朗日函数（把约束标价）；
2. 对 $x$ 最小化 → 对偶函数（得到最优值的下界曲线）；
3. 最大化对偶函数 → 对偶最优解与最优乘子。

**经验做法**：不等式约束时对偶问题天生是凸的（对偶函数是若干仿射函数的逐点下确界），所以"对偶化"是把任意问题至少变成"有一个可算下界"的手段——非凸问题（如整数规划、神经网络验证）的拉格朗日松弛正是这样用于求界与分支定界。

## 4. KKT 条件

凸问题且强对偶成立时，$x^\star$ 为最优解的充要条件是存在乘子满足**Karush–Kuhn–Tucker 条件**（Boyd §5.5.3）：

1. **平稳性**：$\nabla f_0(x^\star) + \sum_i \lambda_i^\star \nabla f_i(x^\star) + \sum_j \nu_j^\star \nabla h_j(x^\star) = 0$（拉格朗日函数对 $x$ 的梯度为零）；
2. **原始可行**：$f_i(x^\star) \le 0,\ h_j(x^\star) = 0$；
3. **对偶可行**：$\lambda_i^\star \ge 0$；
4. **互补松弛**：$\lambda_i^\star f_i(x^\star) = 0$——"要么约束不起作用（$\lambda=0$），要么贴着约束（$f_i=0$）"。

工程读法：KKT 是"无约束时 $\nabla f = 0$"在约束世界的完整替身；**互补松弛**解释了 LASSO 为什么大量系数恰好为 0（L1 的解贴在菱形尖角上，03 篇几何在此复活）。SVM 的支撑集（只有少数支撑向量非零）同样是互补松弛的直接产物。

## 5. 案例：SVM 的优化形式

硬间隔 SVM 的原问题（不必会解，要会读）：

$$
\min_{w, b}\ \frac12\|w\|^2 \quad \text{s.t.}\quad y_i(w^\top x_i + b) \ge 1,\ \forall i
$$

逐项拆解：

- 目标 $\frac12\|w\|^2$：**最大化间隔** $= \frac{2}{\|w\|}$ 的等价二次形式，系数 1/2 纯为求导去 2；凸（09 篇：Hessian $= I \succ 0$）；
- 约束 $y_i(w^\top x_i + b) \ge 1$：每个样本被正确分类且留出至少 1 的边距（$y_i \in \{\pm1\}$）；
- 对偶化后由互补松弛可知：**只有间隔边界上的点（支撑向量）$\lambda_i > 0$**，其余样本统统 $\lambda_i = 0$——这就是"支撑向量机"名字的数学来源；
- 把核技巧 $x_i^\top x_j \to K(x_i, x_j)$ 加进对偶形式，就成了核 SVM——**对偶形式让核方法成为可能**，这是"为什么要学对偶"的最有力例证。

## 6. CVXPY 最小示例

CVXPY 的哲学：你写"问题长什么样"，它负责识别凸性并调用求解器。

```python
# pip install cvxpy
import cvxpy as cp
import numpy as np

rng = np.random.default_rng(0)
A = rng.standard_normal((30, 5))
b = A @ np.array([1.0, -2.0, 0.5, 3.0, -1.0]) + 0.1 * rng.standard_normal(30)

# 最小二乘(13篇的正规方程问题): min ||Ax - b||_2^2
x = cp.Variable(5)
prob = cp.Problem(cp.Minimize(cp.sum_squares(A @ x - b)))
prob.solve()
print(x.value)          # ≈ [ 0.998 -2.003 0.497 3.004 -1.002] 还原真参数

# 加一个约束试试: 系数绝对值之和不超过 6(类 LASSO)
prob2 = cp.Problem(cp.Minimize(cp.sum_squares(A @ x - b)),
                   [cp.norm1(x) <= 6])
prob2.solve()
print(x.value, prob2.status)   # status: optimal——求解器保证全局最优
```

注意 `cp.norm1(x) <= 6` 是凸约束（凸函数与常数的比较），CVXPY 用**凸分析规则（DCP）**自动验证——你第一次体会到"保凸运算"（1.3 节）变成了一套可执行的类型检查。

## 7. 哪些问题是凸的：速查表

| 问题 | 形式 | 凸? |
| --- | --- | --- |
| 线性规划 LP | 线性目标 + 线性约束 | 是 |
| 最小二乘 | $\|Ax-b\|_2^2$ | 是（无约束） |
| 二次规划 QP | 二次凸目标 + 线性约束（SVM、马科维茨组合） | 是 |
| 几何规划/熵最大化 | 特定形式 | 是（经变换） |
| LASSO / 弹性网 | $\ell_2$ 损失 + $\ell_1$ 惩罚 | 是 |
| **逻辑回归** | 交叉熵损失对 $w$ | 是（常被误以为不是） |
| 神经网络训练 | 复合非线性 | **否**（09 篇的鞍点/局部极小回到舞台） |
| 混合整数规划 | 含整数变量 | 否 |
| 一般 RL 策略优化 | 非凸 + 随机 | 否 |

两个高频认知纠偏：**逻辑回归是凸的**（交叉熵对 logits 凹、对权重凸），所以"逻辑回归有局部极小"是错的；**矩阵的秩 / $\ell_0$ 范数不是凸的**，它们的凸松弛才是核范数 / $\ell_1$（03 篇截断 SVD 与 1.3 节保凸运算的用武之地）。

## 本篇小结

- 凸集 = 连线不出界；凸函数 = 弦在曲线上方；判定靠 Hessian 半正定或保凸运算表。
- 凸问题的两大红利：局部极小即全局极小；强对偶（Slater 条件下）给出可计算的下界与影子价格。
- 拉格朗日函数 = 目标 + 违约罚款，是"约束→无约束"的通用转换器；对偶函数是下界工厂；手算例子给出 $p^\star=2$、$\nu^\star=-2$。
- KKT 四条 = 约束世界的"$\nabla f=0$"，互补松弛解释稀疏解（LASSO 尖角、SVM 支撑向量）。
- SVM 原问题逐项可读；CVXPY 让"识别凸性"变成自动检查；查表结论：LP/QP/最小二乘/逻辑回归凸，神经网络/整数规划不凸。
