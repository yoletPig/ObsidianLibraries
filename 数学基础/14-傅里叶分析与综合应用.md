## 1. 为什么需要频域

### 1.1 正弦分解的直觉

时域看信号：一条扭动的曲线，"看不清结构"。频域看信号：**一串正弦波的配方表**——每个频率成分的幅度和相位。傅里叶的洞察（Fourier, 1822《热的解析理论》；现代教材见 Oppenheim & Willsky《Signals and Systems》ch. 3-4）：**任何（合理的）信号都可以写成不同频率正弦波的叠加**，且这种分解是唯一的。

为什么这有用：

- **诊断**：机器振动异常 → 频谱在轴承特征频率出现尖峰（故障诊断的基本功）；
- **压缩**：人耳听不见 20kHz 以上 → MP3 直接砍掉高频成分；
- **滤波**：噪声和信号混在一起往往"频率上不重叠"，频域里一刀切开（本章实战）；
- **卷积变乘法**：卷积定理让"求和滑窗"这类 $O(n^2)$ 操作变成 $O(n\log n)$（第 4 节）。

### 1.2 一个手工例子

$x(t) = \sin(2\pi\cdot5t) + 0.5\sin(2\pi\cdot20t)$：5Hz 的波（幅度 1）加 20Hz 的波（幅度 0.5）。时域里它是一条复杂的曲线；频域里就是**两根竖线**：位于 5Hz 高 1、位于 20Hz 高 0.5。频谱分析的终极目标就是把一切信号读成这样两根线。

## 2. DFT 与 NumPy fft 实操

### 2.1 DFT 定义

对 $N$ 个采样点 $x_0, \ldots, x_{N-1}$：

$$
X[k] = \sum_{n=0}^{N-1} x[n]\,e^{-2\pi i\,kn/N}, \qquad k = 0, \ldots, N-1
$$

读法：$X[k]$ 是"频率为 $k$ 个周期/全长"的正弦基与信号的**内积**（01 篇点积的重逢）——数值大说明信号里该频率成分多。三件必知：

1. **共轭对称**：实信号的 $X[N-k] = \overline{X[k]}$，后半段是镜像冗余，画图只取前 $N/2$；
2. **频率轴**：第 $k$ 个 bin 对应 $f_k = k \cdot f_s / N$（$f_s$ 为采样率）；
3. **幅度标定**：正弦幅度 $A$ 的谱峰高度约为 $A\cdot N/2$（单边谱，除以 $N/2$ 归一化后还原物理幅度）。

### 2.2 实操与频谱图解读

```python
import numpy as np
import matplotlib.pyplot as plt

fs, N = 200, 200                 # 采样率 200Hz, 采 200 点(=1 秒)
t = np.arange(N) / fs
x = np.sin(2*np.pi*5*t) + 0.5*np.sin(2*np.pi*20*t)   # 5Hz + 0.5×20Hz

X = np.fft.fft(x)
freqs = np.fft.fftfreq(N, d=1/fs)     # 频率轴: k*fs/N
half = N // 2
amp = np.abs(X[:half]) / (N / 2)      # 单边幅度谱

plt.plot(freqs[:half], amp)
plt.xlabel('Hz'); plt.ylabel('amplitude'); plt.savefig('spectrum.png', dpi=120)
print(freqs[np.argmax(amp)], amp.max())          # 5.0 1.0
k2 = np.argsort(amp)[-2]
print(freqs[k2], amp[k2])                        # 20.0 0.5
```

典型输出：主峰恰在 5.0 Hz、幅度 1.0；次峰在 20.0 Hz、幅度 0.5——与构造公式逐项吻合（因为 1 秒内两种波都走完了整数个周期，无泄漏；**经验做法**：截取非整数周期会产生"频谱泄漏"，主瓣展宽，工程上用加窗（Hann）抑制）。

## 3. 采样定理与混叠

### 3.1 采样定理

连续信号要在计算机里变成一串点。**Nyquist–Shannon 采样定理**（Oppenheim ch. 7）：采样率 $f_s$ 下，能无损表示的最高频率是

$$
f_{\text{Nyq}} = \frac{f_s}{2}
$$

超过 $f_{\text{Nyq}}$ 的成分不会消失，而会**折返**（aliasing）：频率 $f$ 的成分与 $|f_s - f|$（更一般 $|f - m f_s|$）的成分在采样点上**完全无法区分**。

### 3.2 混叠演示：80Hz 信号 vs 20Hz 信号

用 $f_s = 100$ Hz 采样（Nyquist 50Hz）。80Hz 的信号在采样点上与 20Hz 的信号**逐点相同**：

$$
\sin\left(2\pi\cdot80\cdot\frac{n}{100}\right) = \sin\left(2\pi n - 2\pi\cdot20\cdot\frac{n}{100}\right) = -\sin\left(2\pi\cdot20\cdot\frac{n}{100}\right)
$$

（第二个等号用 $\sin(2\pi n - \theta) = -\sin\theta$——频率相同、只差一个正负号/相位。）也就是说：**欠采样的高频成分会伪装成低频成分混进你的频谱**，而且事后无法分离。

```python
fs = 100
n = np.arange(40) / fs          # 0.4 秒
x80 = np.sin(2*np.pi*80*n)      # 真实 80Hz,欠采样
x20 = np.sin(2*np.pi*20*n)      # 20Hz 对比
plt.plot(n, x80, 'o-', label='80Hz sampled @100Hz (aliased)')
plt.plot(n, -x20, 's--', label='-20Hz (folded)')
plt.legend(); plt.savefig('aliasing.png', dpi=120)
# 图注:两组采样点完全重合——80Hz 在 fs=100 下"变成"了 20Hz(相位翻转)。
# 这就是录音里"车轮倒转"、雷达里"鬼影目标"的原理。
```

**工程铁律（经验做法）**：采样前必须加**抗混叠低通滤波器**（截止 $f_s/2$ 以下），模拟信号链里没有它，数字域一切频谱分析都不可信。语音标准 16kHz 采样（8kHz 带宽）就是"人耳分辨率 vs 存储成本"折中后的行业共识。

## 4. 卷积定理与 STFT

### 4.1 卷积定理

**时域卷积 = 频域乘法**（Oppenheim ch. 4）：

$$
x * h \;\Longleftrightarrow\; X \cdot H
$$

直观例子：滑动平均（去噪最常用的"笨办法"）就是信号与方框窗的卷积。方框的频谱是 $\mathrm{sinc}$ 形（中央低旁、两侧有副瓣）——所以滑动平均是**不够好的低通滤波器**（副瓣会漏高频进来）。频域视角一眼看穿它的缺陷，并给出修法：设计频率响应再 $I_{\text{FFT}}$ 回时域。

```python
rng = np.random.default_rng(0)
fs, n = 512, 1024            # 采样率 512Hz, 共 2 秒
t = np.arange(n) / fs
clean = np.sin(2*np.pi*8*t)                                  # 纯净 8Hz
x = clean + 0.3*rng.standard_normal(n)                       # + 白噪
# FFT 低通: 保留 |f| <= 30Hz
X = np.fft.fft(x)
freqs = np.fft.fftfreq(n, d=1/fs)
Xf = X.copy(); Xf[np.abs(freqs) > 30] = 0
xf = np.fft.ifft(Xf).real
# 去噪效果用与纯净信号的相关系数衡量
print(np.corrcoef(x, clean)[0, 1])    # 原始:≈0.87(被噪声拖累)
print(np.corrcoef(xf, clean)[0, 1])   # 滤波后:≈0.995
```

（`fs=512` 时白噪均匀铺满 $\pm256$Hz；FFT 只保留 $\pm30$Hz，噪声能量砍掉约 $1 - 60/512 \approx 88\%$，而 8Hz 信号无损——相关系数从约 0.87 升到 0.995 就是这个带宽数字的直接体现。）

### 4.2 STFT：给频谱加上时间轴

FFT 对**整段**信号做全局分解——频率对了，但"什么时候发生的"丢了（这在语音里致命："HELlo" 和 "helLO" 的全局频谱不同，但你需要知道每个音素的时刻）。**短时傅里叶变换**（STFT）的做法：加窗（如 25ms）、滑动（如 10ms 步进）、逐窗 FFT，得到二维的 **(时间 × 频率) 能量图 = 频谱图 spectrogram**。不确定性原理约束：窗越短时间越准、频率越糊，反之亦然——这是不可两全的物理极限（Gabor 极限）。

**梅尔频谱前置**：把 STFT 的频率轴按人耳感知（低频密、高频疏的 mel 刻度）重排、再取对数能量，就是梅尔频谱——《语音方向》Stage 1 的标准输入特征，本章的 STFT 正是它的直接前置（工程库 `librosa.feature.melspectrogram` 一行调用，但内部就是本节流程）。

## 5. 综合实战：带噪正弦去噪——FFT 滤波 vs 卡尔曼平滑

### 5.1 任务设计

信号：频率缓慢变化的正弦（"啁啾"式），叠加高斯白噪声。用两种完全不同的武器去噪：

- **FFT 滤波**：全局频域切掉高频（第 4 节的方法）；
- **卡尔曼平滑**：13 篇的 2D 状态 [位置, 速度] 逐点跟踪（把"信号值"当位置、"斜率"当速度）。

关键问题：**两种方法的适用边界在哪里？**——这才是实战要回答的。

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(42)
fs, T = 100.0, 8.0
t = np.arange(int(fs*T)) / fs
# 真信号: 频率从 2Hz 线性滑到 12Hz 的啁啾
f_inst = 2 + (12-2) * t / T
phase = 2*np.pi*np.cumsum(f_inst)/fs
clean = np.sin(phase)
noisy = clean + 0.6*rng.standard_normal(len(t))

def snr_db(err_pow, sig_pow):
    return 10*np.log10(sig_pow/err_pow)

# ---- 方法1: FFT 低通(截止 15Hz) ----
X = np.fft.fft(noisy)
freqs = np.fft.fftfreq(len(t), d=1/fs)
Xf = X.copy(); Xf[np.abs(freqs) > 15] = 0
xf = np.fft.ifft(Xf).real

# ---- 方法2: 卡尔曼(常数速度模型跟踪信号值) ----
from filterpy.kalman import KalmanFilter
kf = KalmanFilter(dim_x=2, dim_z=1)
kf.F = np.array([[1., 1/fs], [0., 1.]])   # dt = 1/fs
kf.H = np.array([[1., 0.]])
kf.P *= 1e3; kf.R = np.array([[0.36**2 * 4]])  # 观测噪声方差(经验调参)
kf.Q = np.array([[1e-6, 0], [0, 1e-5]])        # 平滑信号允许小幅漂移
xk = []
for z in noisy:
    kf.predict(); kf.update(z); xk.append(kf.x[0])
xk = np.array(xk)

sig_pow = np.var(clean)
print(f"原始      SNR = {snr_db(np.var(noisy-clean), sig_pow):6.2f} dB")
print(f"FFT 滤波  SNR = {snr_db(np.var(xf-clean),     sig_pow):6.2f} dB")
print(f"卡尔曼    SNR = {snr_db(np.var(xk-clean),     sig_pow):6.2f} dB")

plt.figure(figsize=(11, 4))
plt.plot(t, noisy, alpha=0.25, label='noisy')
plt.plot(t, clean, 'k', lw=1.5, label='clean')
plt.plot(t, xf, 'r', lw=1, label='FFT lowpass')
plt.plot(t, xk, 'g', lw=1, label='Kalman')
plt.legend(); plt.xlabel('t / s'); plt.savefig('denoise_compare.png', dpi=120)
# 图注:信号前段(低频)FFT 滤波几乎完美复原;频率滑到 12Hz 后开始失真甚至
# 被截止;卡尔曼全程贴住信号但残留更多抖动。两条 SNR 会给出同样结论。
```

### 5.2 结果怎么读（以本组参数的典型行为为准）

| 方法 | 低频稳态信号 | 快变/滑频信号 | 延迟 | 依赖假设 |
| --- | --- | --- | --- | --- |
| FFT 低通 | 极佳（SNR 提升可达 10–20dB） | 失真（滑频段被截止或泄漏） | 无（但非因果：需要整段数据） | 信号**频带固定** |
| 卡尔曼 | 好 | 好（模型允许状态移动） | 有（半步预测的相位滞后） | 信号**状态模型正确** |

定量预期：本例白噪带宽 $f_s/2 = 50$Hz，FFT 只留 15Hz → 噪声能量砍掉 70%，理论上 SNR 提高约 $10\log_{10}(50/15) \approx 5.2$ dB（信号无损能量归一后的更优值；实际输出以运行结果为准）；但啁啾滑到 12Hz 附近后频带边缘效应开始侵蚀增益。卡尔曼的 $Q/R$ 决定"跟随 vs 平滑"的性格（13 篇 6 节）——**这两条边界的根源不同：FFT 输给"非平稳"，卡尔曼输给"模型失配"**。

**经验做法（选型口诀）**：平稳信号、离线处理、追求极致 SNR → 频域方法；在线实时、信号会漂移、需要不确定性输出 → 卡尔曼系；现代雷达/惯导融合两者都用（频域做检测、卡尔曼做跟踪）——《自动驾驶》Stage 4 的多目标跟踪正是这套组合拳。

## 本篇小结

- 频域 = 正弦配方表；DFT 的 $X[k]$ 是信号与频率基的内积，实信号谱共轭对称、只画前半。
- 采样定理：$f_s/2$ 是硬边界，超界成分折返成混叠（80Hz@100Hz 与 20Hz 逐点重合），模拟端抗混叠滤波不可省。
- 卷积定理（时域卷积=频域乘法）解释滑动平均的 sinc 缺陷并给出频域滤波方案；STFT 加时间轴，是梅尔频谱的直接前置。
- 实战对比：FFT 滤波赢在平稳信号（理论增益 $10\log_{10}(f_{\text{Nyq}}/\text{截止})$ dB），卡尔曼赢在非平稳与在线场景；两者的失败模式（非平稳 vs 模型失配）互为镜像。
