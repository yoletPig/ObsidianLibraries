## 1. 样本空间与概率公理

### 1.1 基本对象

- **样本空间** $\Omega$：随机实验所有可能结果的集合（掷两枚硬币：$\Omega = \{正正, 正反, 反正, 反反\}$）；
- **事件**：$\Omega$ 的子集，如"至少一枚正面" $= \{正正, 正反, 反正\}$；
- **概率** $P$：给事件赋一个 $[0,1]$ 之间的数。

### 1.2 三条公理（Kolmogorov）

$$
1.\ P(A) \ge 0; \qquad 2.\ P(\Omega) = 1; \qquad 3.\ A,B\ \text{互斥时}\ P(A \cup B) = P(A) + P(B)
$$

全部概率运算都从这三条推出（Casella & Berger《Statistical Inference》§1.2）。最常用的推论是**补集**与**容斥**：

$$
P(\bar{A}) = 1 - P(A), \qquad P(A \cup B) = P(A) + P(B) - P(A \cap B)
$$

容斥公式的用法：掷两枚骰子，"第一枚是 6 或第二枚是 6"的概率 = $\frac16 + \frac16 - \frac1{36} = \frac{11}{36}$（直接数一下 11 个格子，正好吻合）。

## 2. 条件概率与独立性

### 2.1 条件概率

$$
P(A \mid B) = \frac{P(A \cap B)}{P(B)}, \quad P(B) > 0
$$

读法："在 $B$ 已经发生的世界里，$A$ 的概率"。本质是把样本空间缩小到 $B$ 内部重新归一化。

**数值示例**：掷两枚骰子，已知点数之和为 8，问第一枚是偶数的概率？和为 8 的组合有 5 个（等可能）：$(2,6),(3,5),(4,4),(5,3),(6,2)$；其中第一枚为偶数的有 $(2,6),(4,4),(6,2)$ 共 3 个：

$$
P(\text{第一枚偶} \mid \text{和}=8) = \frac{3}{5}
$$

（无条件时第一枚为偶数的概率是 $1/2$——"和为 8"这个信息改变了你的判断，这就是条件概率存在的意义。）

### 2.2 独立性

$A$ 与 $B$ **独立**定义为 $P(A \cap B) = P(A)\,P(B)$，等价于 $P(A\mid B) = P(A)$——"知道 $B$ 发生不改变 $A$ 的概率"。

小心三个易错点：

1. **独立 ≠ 互斥**：互斥意味着 $P(A\cap B)=0$，而独立要求 $P(A\cap B) = P(A)P(B)$；两个概率大于 0 的事件不可能既独立又互斥。
2. **独立不能靠感觉**：连续掷骰子每一枚独立；但"抽到的两张牌都是 A"中的两次抽取（不放回）不独立。
3. **机器学习里的"朴素"**：朴素贝叶斯假设"给定类别后各特征独立"——这是**条件独立**，与边缘独立是两回事（见 11 篇）。

## 3. 全概率公式与贝叶斯定理

### 3.1 全概率公式

把样本空间按 $B_1, \ldots, B_n$ 切成互斥完备的几块：

$$
P(A) = \sum_i P(A \mid B_i)\,P(B_i)
$$

例：某零件由甲乙两台机床生产，甲产 60%、次品率 2%；乙产 40%、次品率 5%。随机取一件是次品的概率：

$$
P(\text{次}) = 0.02 \times 0.6 + 0.05 \times 0.4 = 0.012 + 0.020 = 0.032
$$

### 3.2 贝叶斯定理

由条件概率定义直接翻转：

$$
\underbrace{P(B_i \mid A)}_{\text{后验}} = \frac{P(A \mid B_i)\,\underbrace{P(B_i)}_{\text{先验}}}{\underbrace{P(A)}_{\text{证据}}}, \qquad P(A) = \sum_j P(A\mid B_j)P(B_j)
$$

它回答的问题只有一个：**拿到新证据后，如何更新信念**。"先验 → 似然 × 先验 / 证据 → 后验"这个结构会原封不动地出现在 07 篇的贝叶斯推断和 13 篇的卡尔曼滤波（预测即先验、更新即贝叶斯）里。

### 3.3 经典案例：医疗检测的假阳性（完整算）

设定（数字均为假设但真实可算）：某病人群患病率 $P(D) = 0.01$；检测**灵敏度** $P(+\mid D) = 0.99$（病人大概率测出阳性）；**假阳性率** $P(+\mid \bar{D}) = 0.05$（健康人也有 5% 测出阳性）。问：测出阳性的人**真的患病**的概率？

第一步，全概率公式算 $P(+)$：

$$
P(+) = P(+\mid D)P(D) + P(+\mid \bar{D})P(\bar{D}) = 0.99 \times 0.01 + 0.05 \times 0.99 = 0.0099 + 0.0495 = 0.0594
$$

第二步，贝叶斯定理：

$$
P(D \mid +) = \frac{0.99 \times 0.01}{0.0594} = \frac{0.0099}{0.0594} = \frac{1}{6} \approx 0.167
$$

**结论震撼但合理**：阳性结果下只有约 16.7% 真的患病。直观解释（把数字想象成 10000 人）：100 个病人里 99 个测出阳性；9900 个健康人里仍有 495 个假阳性——阳性队伍共 594 人，真病人只占 99/594 = 1/6。低先验（罕见事件）会被假阳性稀释，这就是"基率谬误"（base rate fallacy）。

**工程对应**：风控/反作弊系统告警的"精度"天然被低基率压低；告警阈值（相当于检测灵敏度）的选取必须结合基率，否则误报会淹没团队。

```python
p_d, p_pos_given_d, p_pos_given_nod = 0.01, 0.99, 0.05
p_pos = p_pos_given_d * p_d + p_pos_given_nod * (1 - p_d)
p_d_given_pos = p_pos_given_d * p_d / p_pos
print(p_pos)          # 0.0594
print(p_d_given_pos)  # 0.16666666666666669 = 1/6
```

## 4. 贝叶斯更新：链式使用

贝叶斯定理不是一次性公式，而是**循环**：今天的后验是明天的先验。设观察依次到来，每来一个证据就更新一次：

$$
P(H \mid e_1, e_2) = P(H \mid e_1)\ \text{用}\ e_2\ \text{再更新一次}
$$

这种"滚动更新信念"的模式就是**序贯推断**：卡尔曼滤波每帧更新一次状态信念（13 篇）；垃圾邮件过滤器每封邮件更新词表权重；量化策略每根 K 线更新对参数的估计。数学骨架全在本节。

## 5. 朴素贝叶斯文本分类：最小实现

### 5.1 模型

垃圾邮件分类：类别 $C \in \{\text{spam}, \text{ham}\}$，邮件由词袋 $\mathbf{w} = (w_1, \ldots, w_m)$ 表示。贝叶斯定理 + "词之间条件独立"（朴素假设）：

$$
P(C \mid \mathbf{w}) \propto P(C) \prod_i P(w_i \mid C)
$$

用**对数**防止几百个小概率连乘下溢（**经验做法**：工程实现一律在 log 空间做贝叶斯）：

$$
\log P(C \mid \mathbf{w}) \propto \log P(C) + \sum_i \log P(w_i \mid C)
$$

词概率用**拉普拉斯平滑**（避免没见过的词把整个乘积清零）：

$$
P(w \mid C) = \frac{\text{词}\ w\ \text{在}\ C\ \text{类中的次数} + 1}{C\ \text{类总词数} + |V|}
$$

### 5.2 代码

```python
import numpy as np

docs = [
    ("限时 中奖 点击 领取 奖金", 1),
    ("点击 链接 免费 领取 礼品", 1),
    ("中奖 奖金 点击 即可 领取", 1),
    ("明天 开会 讨论 项目 进度", 0),
    ("项目 评审 会议 通知 请 查收", 0),
    ("本周 三 开会 讨论方案", 0),
]
vocab = sorted({w for d, _ in docs for w in d.split()})
v2i = {w: i for i, w in enumerate(vocab)}
V = len(vocab)

count_spam = np.ones(V)          # +1 拉普拉斯平滑的先验
count_ham  = np.ones(V)
n_spam = n_ham = V               # 分母起点也是 V
for d, y in docs:
    idx = [v2i[w] for w in d.split()]
    if y: count_spam[idx] += 1; n_spam += len(idx)
    else: count_ham[idx]  += 1; n_ham  += len(idx)

log_p_spam, log_p_ham = np.log(count_spam / n_spam), np.log(count_ham / n_ham)
prior = np.log(3 / 6)            # 两类各 3 封

def classify(text):
    idx = [v2i.get(w, -1) for w in text.split()]
    s_spam = prior + log_p_spam[idx].sum()
    s_ham  = prior + log_p_ham[idx].sum()
    return ("spam" if s_spam > s_ham else "ham"), s_spam, s_ham

print(classify("点击 领取 中奖 奖金"))   # ('spam', -19.7..., -25.9...)
print(classify("项目 会议 通知"))        # ('ham', -23.7..., -15.4...)
print(classify("中奖 开会 点击 讨论"))   # 词表混杂时的边界案例,可自行验证
```

（输出数值以本地运行为准；分类结论是确定的。）这个 30 行实现就是 Naive Bayes 的全部——真实工业界的垃圾过滤、简单情感分类至今仍用它做 baseline，速度快到微秒级，且可解释（哪个词贡献了 spam 分数一目了然）。

### 5.3 为什么"朴素"还这么能打

条件独立假设显然是假的（"中奖""奖金"总是同时出现），但这导致的主要后果是**后验概率的绝对值被高估**，而**分类边界（谁大谁小）往往还是对的**。这是"模型错了但有用"的经典案例（ Domingos & Pazzani 1997 的分析）。

## 本篇小结

- 三条公理推出一切概率运算；容斥公式处理"或"，条件概率处理"已知"。
- 独立 = $P(A\cap B) = P(A)P(B)$ = "知道一个不改变另一个"；互斥与独立不能兼得。
- 全概率公式"分块算总量"，贝叶斯定理"翻转条件方向"：后验 = 似然×先验/证据。医疗检测算例：先验 1%、灵敏度 99%、假阳性 5% → 阳性中真患病仅 1/6。
- 贝叶斯更新可以滚动使用，是序贯推断（卡尔曼滤波）的骨架。
- 朴素贝叶斯 = 贝叶斯 + 条件独立假设 + log 空间 + 拉普拉斯平滑；模型假设错但分类边界常常对。
