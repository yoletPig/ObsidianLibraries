## 1. 导数、梯度与方向导数

### 1.1 从一元到多元

一元函数的导数 $f'(x)$ 是"该点的瞬时斜率"。多元函数每个方向都有一个斜率，**梯度**把它们打包：

$$
\nabla f = \left[\frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \ldots \right]^\top
$$

例：$f(x,y) = x^2 + 2y^2$ 在点 $(2, 2)$ 处 $\nabla f = [2x, 4y]^\top = [4, 8]^\top$。

### 1.2 方向导数：为什么是点积

沿单位向量 $\mathbf{u}$ 前进一小步，函数值的变化率：

$$
D_{\mathbf{u}}f = \nabla f \cdot \mathbf{u}
$$

推导（一元链式法则的直接应用）：$g(t) = f(\mathbf{x}_0 + t\mathbf{u})$，则 $D_\mathbf{u}f = g'(0) = \sum_i \frac{\partial f}{\partial x_i} u_i$——正是点积。由点积的几何形式（01 篇）：

$$
D_{\mathbf{u}}f = \|\nabla f\|\,\|\mathbf{u}\|\cos\theta = \|\nabla f\|\cos\theta \quad(\mathbf{u}\ \text{为单位向量})
$$

$\theta = 0$ 时最大：**梯度方向是上升最快的方向，$-\nabla f$ 是下降最快的方向，速率 $= \|\nabla f\|$**；垂直方向 ($\theta=90°$) 变化率为 0——等高线在每一点与梯度垂直，这就是"梯度垂直于等高线"的由来（Boyd《Convex Optimization》§9；图示见任何多元微积分教材）。

## 2. 链式法则与计算图

### 2.1 一元链式法则

$\frac{dz}{dx} = \frac{dz}{dy}\cdot\frac{dy}{dx}$——复合函数的导数是各段导数的乘积。

### 2.2 多元链式法则：乘积升级为"加权求和"

一个中间变量被多条路径使用时，梯度要**沿每条路径求和**：

$$
\frac{\partial L}{\partial x} = \sum_{\text{路径}} \prod_{\text{路径上的边}} \frac{\partial(\text{下游})}{\partial(\text{上游})}
$$

### 2.3 手算一个小计算图

模型 $L = (wx + b - y)^2$，数据 $x=2, y=1$，参数 $w=0.5, b=0.1$：

$$
\begin{aligned}
\hat{y} &= wx + b = 1.1 \\
e &= \hat{y} - y = 0.1 \\
L &= e^2 = 0.01
\end{aligned}
$$

反向传播（从 $L$ 往回走，注意 $\hat y$ 同时出现在 $e$ 中）：

$$
\frac{\partial L}{\partial e} = 2e = 0.2,\quad
\frac{\partial e}{\partial \hat{y}} = 1,\quad
\frac{\partial \hat{y}}{\partial w} = x = 2,\quad
\frac{\partial \hat{y}}{\partial b} = 1
$$

$$
\frac{\partial L}{\partial w} = 0.2 \times 1 \times 2 = 0.4, \qquad
\frac{\partial L}{\partial b} = 0.2 \times 1 \times 1 = 0.2
$$

**经验做法**：把每个中间量的数值写在旁边、反向时逐边乘过去（多路径相加）——这个"纸笔反向传播"习惯能让你在任何框架报 NaN 时快速定位是哪条边炸了。《PyTorch 与深度学习》05 篇的 `gradcheck` 做的是同一件事的自动化。

## 3. 多元极值与 Hessian

### 3.1 极值的必要条件

驻点：$\nabla f = \mathbf{0}$。但驻点可能是极小、极大或**鞍点**——需要二阶信息。

### 3.2 Hessian 与凹凸性

Hessian 是二阶偏导排成的（对称）矩阵：

$$
H_{ij} = \frac{\partial^2 f}{\partial x_i \partial x_j}
$$

它在驻点附近的角色相当于一元情形的二阶导数（Strang《Linear Algebra》§6.5；Boyd《Convex Optimization》§3.1.4）：

- $H$ **正定**（所有特征值 $>0$）→ 该点是**局部极小**；
- $H$ 负定（全 $<0$）→ 局部极大；
- $H$ **不定**（有正有负）→ **鞍点**：某些方向是谷、另一些方向是脊；
- $H$ 半正定（全 $\ge 0$）处处成立 → $f$ 是**凸函数**（任何局部极小即全局极小，10 篇的主角）。

例：$f = x^2 - y^2$ 的 Hessian 是 $\mathrm{diag}(2, -2)$，不定 → 原点是鞍点：沿 $x$ 方向上坡、沿 $y$ 方向下坡。

```python
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-2, 2, 200); y = np.linspace(-2, 2, 200)
X, Y = np.meshgrid(x, y)
Z = X**2 - Y**2
fig = plt.figure(figsize=(10, 4))
ax1 = fig.add_subplot(121, projection='3d')
ax1.plot_surface(X, Y, Z, cmap='coolwarm', alpha=0.8)
ax1.set_title('f = x^2 - y^2:  马鞍面')
ax2 = fig.add_subplot(122)
ax2.contour(X, Y, Z, levels=20)
ax2.plot(0, 0, 'r*', ms=15); ax2.set_title('鞍点(红星):沿x是谷,沿y是脊')
plt.savefig('saddle.png', dpi=120)
```

图注：3D 图就是一片薯片/马鞍；等高线图里鞍点周围一圈双曲线，红点处梯度为 0 但既非最高也非最低。**高维神经网络损失面里鞍点远比局部极小常见**（维度越高越难"每个方向都向上"），这是深度学习优化困难但总能"逃出去"的原因之一（Dauphin et al., 2014）。

## 4. 梯度下降：完整推导与可视化

### 4.1 推导

目标 $\min f(\mathbf{x})$。在当前点 $\mathbf{x}_t$ 做一阶泰勒展开：

$$
f(\mathbf{x}_t + \Delta) \approx f(\mathbf{x}_t) + \nabla f(\mathbf{x}_t)^\top \Delta
$$

要让函数值下降，取 $\Delta = -\alpha\,\nabla f(\mathbf{x}_t)$（沿最速下降方向、步长 $\alpha > 0$）：

$$
\boxed{\ \mathbf{x}_{t+1} = \mathbf{x}_t - \alpha\,\nabla f(\mathbf{x}_t)\ }
$$

每步的预计下降量为 $\alpha\|\nabla f\|^2 \ge 0$（保证 $\alpha$ 足够小时有效）。

### 4.2 等高线上的步进轨迹

对 $f(x,y) = x^2 + 2y^2$，$\nabla f = [2x, 4y]^\top$。从 $(2,2)$ 出发，$\alpha = 0.1$：

| 步 | $\mathbf{x}_t$ | $\nabla f$ | $f$ |
| --- | --- | --- | --- |
| 0 | (2.000, 2.000) | (4.0, 8.0) | 12.000 |
| 1 | (1.600, 1.200) | (3.2, 4.8) | 5.440 |
| 2 | (1.280, 0.720) | (2.56, 2.88) | 2.675 |
| 3 | (1.024, 0.432) | (2.05, 1.73) | 1.422 |

注意每步都**垂直穿过等高线**（1.2 节的结论），且轨迹会拐弯——因为椭圆等高线的"最陡方向"是逐点变化的。

```python
import numpy as np
import matplotlib.pyplot as plt

def f(v):  return v[0]**2 + 2*v[1]**2
def g(v):  return np.array([2*v[0], 4*v[1]])

x = np.linspace(-2.4, 2.4, 200); y = np.linspace(-2.4, 2.4, 200)
X, Y = np.meshgrid(x, y)
plt.contour(X, Y, f(np.stack([X, Y])), levels=15, cmap='Blues')

for alpha, c in [(0.1, 'green'), (0.42, 'orange'), (0.55, 'red')]:
    v = np.array([2.0, 2.0]); path = [v.copy()]
    for _ in range(20):
        v = v - alpha * g(v)
        path.append(v.copy())
        if np.linalg.norm(v) < 1e-6: break
    path = np.array(path)
    plt.plot(path[:,0], path[:,1], 'o-', ms=3, color=c, label=f'lr={alpha}')
plt.legend(); plt.gca().set_aspect('equal'); plt.savefig('gd_paths.png', dpi=120)
# 图注:绿(0.1)平滑锯齿逼近;橙(0.42)大步几乎直线坠落;
# 红(0.55)在 y 方向来回振荡发散——同一函数,三种命运只差一个学习率。
```

### 4.3 学习率的三种命运（1D 数值演示）

最干净的演示用 $f(x) = x^2$，梯度 $2x$，从 $x_0 = 2$ 出发。迭代公式 $x_{t+1} = x_t - \alpha\cdot 2x_t = (1-2\alpha)x_t$：

$$
\alpha = 0.5:\ 2 \to 0\ \text{（一步到达,巧合最优）};\qquad
\alpha = 0.1:\ 2 \to 1.6 \to 1.28 \to 1.024\ (\times 0.8\ \text{平稳收敛})
$$

$$
\alpha = 1.1:\ 2 \to -2.4 \to 2.88 \to -3.456\ (\times 1.2\ \text{振荡放大,发散!})
$$

规律：$|1-2\alpha| < 1$（即 $\alpha < 1$）才收敛；**学习率超过 $2/L$（$L$ 为曲率上界）必然振荡发散**。结论的推广（Boyd §9.3）：二次函数上梯度下降的收敛率由 $\alpha$ 与 Hessian 最大特征值决定——这也是 13 篇卡尔曼滤波"增益别设太大"的同源直觉。

**经验做法**：深度学习里 Hessian 未知且昂贵，学习率靠"从 1e-3/1e-4 起步 + 观察损失曲线（锯齿大→调小；平台期→调大或换优化器）+ warmup/cosine 调度"来管理；Adam 等自适应方法本质是在给每个坐标"私定"有效步长。

## 5. 随机梯度下降的直觉

### 5.1 从"全量"到"抽样"

损失 $\frac{1}{n}\sum_i \ell_i(\theta)$ 的精确梯度要遍历全数据——$n$ 上百万时不可行。SGD 每步只抽一小批（mini-batch）算梯度：

$$
\mathbf{x}_{t+1} = \mathbf{x}_t - \alpha\, \nabla \ell_{\mathcal{B}_t}(\mathbf{x}_t), \qquad \mathcal{B}_t \subset \{1..n\}
$$

### 5.2 为什么噪声是"可接受的价格"

- 批梯度 $\nabla\ell_{\mathcal{B}}$ 是真梯度 $\nabla f$ 的**无偏估计**：$\mathbb{E}[\nabla\ell_{\mathcal{B}}] = \nabla f$——方向平均来看是对的，只是每步带噪声；
- 噪声的副产品：**帮着逃出浅局部极小和鞍点**（在谷底附近来回晃，反而可能被弹出）；
- 成本从 $O(n)$ 降到 $O(|\mathcal{B}|)$，而且 early on 的噪声大步子比"精确但慢"更快到达好区域。

**经验做法**：batch 大小的权衡——大批次梯度噪声小、GPU 利用率高，但泛化有时变差且更新次数变少；小批次噪声大、正则效果好但吞吐低。工程上常按"显存装得下的最大值"附近再二分搜索。

## 本篇小结

- 梯度 = 各方向斜率的打包；方向导数 $= \nabla f\cdot\mathbf{u}$，负梯度是最速下降方向，梯度垂直等高线。
- 多元链式法则 = 沿计算图逐边乘、多路径加；手算 $\partial L/\partial w = 0.4$ 的例子就是一次微型反向传播。
- Hessian 特征值定极值类型：全正极小、全负极大、有正有负鞍点；高维损失面鞍点占多数。
- 梯度下降 $\mathbf{x}_{t+1} = \mathbf{x}_t - \alpha\nabla f$；二次函数上 $\alpha$ 决定收敛/发散（阈值 $2/L$），等高线轨迹图展示了三种命运。
- SGD 用有噪声但无偏的小批梯度换速度，噪声顺带帮助逃离坏驻点。
