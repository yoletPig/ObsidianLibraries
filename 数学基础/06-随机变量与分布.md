## 1. 三种表示：PMF、PDF、CDF

### 1.1 离散型：PMF

**概率质量函数**（PMF）给离散随机变量的每个取值直接赋概率：$p(x_i) = P(X = x_i)$，全体求和为 1。掷骰子：$p(1) = \cdots = p(6) = \frac16$——六根一样高的竖条。

### 1.2 连续型：PDF

连续随机变量取任何单点的概率为 0，概率密度函数（PDF）描述的是**单位长度上的概率浓度**：

$$
P(a \le X \le b) = \int_a^b f(x)\,dx, \qquad \int_{-\infty}^{+\infty} f(x)\,dx = 1
$$

关键读法：$f(x)$ 本身**不是概率**，可以大于 1；只有积分后才概率。正态 PDF 在 $x=\mu$ 处值约 $0.399$，在 $\sigma$ 很小时整条曲线会又高又窄（高度可以远超 1），但曲线下面积恒为 1。

### 1.3 统一视角：CDF

**累积分布函数**（CDF）对两类变量统一定义：$F(x) = P(X \le x)$。图像是一条从 0 爬升到 1 的曲线：离散型是阶梯，连续型是光滑曲线，且

$$
F'(x) = f(x) \ \text{(连续情形)}, \qquad P(a < X \le b) = F(b) - F(a)
$$

工程里最常用的问法"P95 延迟是多少"就是在问 CDF 的反函数（见第 5 节分位数）。

```python
import numpy as np
import matplotlib.pyplot as plt

fig, axes = plt.subplots(1, 3, figsize=(13, 3.4))
x = np.linspace(-4, 4, 400)
pdf = np.exp(-x**2 / 2) / np.sqrt(2 * np.pi)
axes[0].plot(x, pdf); axes[0].set_title('PDF (正态):积分才是概率')
axes[1].plot(x, np.cumsum(pdf) * (x[1]-x[0])); axes[1].set_title('CDF:从 0 爬到 1')
ks = np.arange(1, 7)
axes[2].bar(ks, np.ones(6)/6); axes[2].set_title('PMF (骰子):竖条直接是概率')
for ax in axes: ax.grid(alpha=0.3)
plt.savefig('pmf_pdf_cdf.png', dpi=120)
```

图注：PDF 下的面积 = 概率；CDF 单调爬升、永远落在 $[0,1]$；PMF 竖条高度直接可读。

## 2. 期望、方差、协方差：工程含义

### 2.1 期望：加权平均

$$
\mathbb{E}[X] = \sum_i x_i p(x_i) \quad\text{或}\quad \int x f(x)\,dx
$$

期望是分布的"重心"。它对**线性变换**表现完美：$\mathbb{E}[aX+b] = a\mathbb{E}[X]+b$，且任意两个变量都有 $\mathbb{E}[X+Y] = \mathbb{E}[X]+\mathbb{E}[Y]$（不需要独立）。

### 2.2 方差：散布

$$
\mathrm{Var}(X) = \mathbb{E}[(X-\mathbb{E}X)^2] = \mathbb{E}[X^2] - (\mathbb{E}X)^2
$$

方差的黄金规则（Casella & Berger §4.3，推导为课后练习）：

$$
\mathrm{Var}(aX + b) = a^2\,\mathrm{Var}(X), \qquad
\mathrm{Var}(X+Y) = \mathrm{Var}(X) + \mathrm{Var}(Y) + 2\,\mathrm{Cov}(X, Y)
$$

**当 $X, Y$ 独立时协方差项为零，方差直接相加**。工程含义——**噪声叠加**：两级放大器的独立噪声 $\sigma_1^2, \sigma_2^2$，总噪声 $\sigma = \sqrt{\sigma_1^2+\sigma_2^2}$。注意是**方差相加、标准差开方**：两个 $\sigma=1$ 的独立噪声相加，总标准差是 $\sqrt2 \approx 1.414$，不是 2。这正是 08 篇"平均值的标准误 $\sigma/\sqrt{n}$"（$n$ 个独立观测平均后方差为 $\sigma^2/n$）的来源，也是量化里"$n$ 天独立收益的波动率按 $\sqrt{n}$ 增长"（波动率的时间平方根法则）的来源。

### 2.3 协方差与相关系数

协方差的定义与矩阵形式（协方差矩阵）在 04 篇已经从数据视角讲过；概率视角完全一致：$\mathrm{Cov}(X,Y) = \mathbb{E}[(X-\mu_X)(Y-\mu_Y)]$。回忆结论：$|\mathrm{Cov}|$ 大 = 联动强，相关系数 $\rho = \mathrm{Cov}/(\sigma_X\sigma_Y)$ 无量纲、落在 $[-1,1]$。

## 3. 重要分布逐个讲

### 3.1 均匀分布 $U(a, b)$

一段区间上"人人平等"：PDF 是高度 $\frac{1}{b-a}$ 的矩形。用途：随机数发生器的底层（`np.random.uniform`）、无信息先验、蒙特卡洛采样。

### 3.2 伯努利分布 Bernoulli(p)

单次抛硬币：$P(X=1)=p$，$P(X=0)=1-p$。$\mathbb{E} = p$，$\mathrm{Var} = p(1-p)$。用途：任何"成功/失败"单次试验；神经网络 dropout 的掩码就是 $p=\text{keep\_rate}$ 的伯努利。

### 3.3 二项分布 Binomial(n, p)

$n$ 次独立伯努利中成功的次数：

$$
P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}, \qquad \mathbb{E} = np,\quad \mathrm{Var} = np(1-p)
$$

例：$n=10,\ p=0.5$：$\mathbb{E} = 5$，$\mathrm{Var} = 2.5$。用途：A/B 测试里"1000 次曝光中点击数"（08 篇的主角）、批处理中坏盘数量。

### 3.4 正态分布 $N(\mu, \sigma^2)$

$$
f(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)
$$

钟形曲线，$\mu$ 管位置、$\sigma$ 管宽度。必背数字（$1\sigma/2\sigma/3\sigma$ 法则）：落在 $\mu \pm 1\sigma$ 内约 68.3%，$\pm 2\sigma$ 内约 95.4%（工程上粗略记 95%），$\pm 3\sigma$ 内约 99.7%。它是 CLT 的极限分布（3.5 节），因而无处不在——但"无处不在"不等于"处处适用"，见第 6 节。

### 3.5 中心极限定理：用掷骰子看

**CLT**（陈述）：独立同分布、方差有限的随机变量 $X_1,\ldots,X_n$，当 $n$ 大时其**均值**近似服从 $N(\mu, \sigma^2/n)$——不管 $X$ 本身是什么分布。（出处：Casella & Berger《Statistical Inference》§5.3；严谨版本为 Lindeberg–Levy。）

骰子单点是均匀分布（离正态最远），演示它的均值如何一步步变正态：

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(0)
n_sim = 100000
fig, axes = plt.subplots(1, 3, figsize=(12, 3.2))
for ax, n in zip(axes, [1, 2, 10]):
    # 模拟 n_sim 次"掷 n 枚骰子取平均"
    means = rng.integers(1, 7, size=(n_sim, n)).mean(axis=1)
    ax.hist(means, bins=40, density=True)
    se = np.sqrt(35/12 / n)          # 骰子方差 35/12,均值的标准误 = sigma/sqrt(n)
    ax.set_title(f'n={n}, 理论 SE={se:.3f}')
    ax.grid(alpha=0.3)
plt.savefig('clt_dice.png', dpi=120)
# 图注:n=1 是平顶的均匀;n=2 出现三角分布;n=10 已经是漂亮的钟形。
# 同时注意横轴越来越窄:SE 从 1.708 缩到 0.540,这正是 sigma/sqrt(n)。
```

CLT 是统计学的"免费午餐"：样本均值近正态，于是 08 篇的置信区间和 z 检验对**任意**有方差的数据都能用——前提是样本量够大且观测独立。

### 3.6 指数分布与泊松分布：等待与到达

两者是一对（**经验做法**：记住"泊松管个数、指数管等待"）：

- **泊松** Poisson(λ)：单位时间随机事件发生的**次数**，$P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}$，$\mathbb{E} = \mathrm{Var} = \lambda$。场景：客服每小时来电数、服务器每天故障数、雷达一帧内目标数（自动驾驶）。
- **指数** Exp(λ)：两次独立事件之间的**等待时间**，$f(t) = \lambda e^{-\lambda t}$，$\mathbb{E} = 1/\lambda$，$\mathrm{Var} = 1/\lambda^2$。场景：硬件故障前的无故障运行时间（MTBF $= 1/\lambda$）、两次用户点击的间隔。它有**无记忆性**：等了 10 分钟没来，再等的分布和刚开始一样——这是它与正态最大的性格差异。

数值例：λ=5 次/小时的来电，平均等待 12 分钟；下一小时内恰好 5 通的概率 $P(X=5) = \frac{5^5 e^{-5}}{120} \approx 0.1755$（可用 `scipy.stats.poisson.pmf(5, 5)` 验证）。

## 4. 分位数

**分位数**是 CDF 的反函数读法：$q$ 分位数 $x_q$ 满足 $P(X \le x_q) = q$。常用：

- 中位数（$q=0.5$）：对肥尾数据比均值稳健（第 6 节你就知道为什么）；
- P95/P99：延迟工程的标准指标——"99 分位延迟 200ms"意思是 100 个请求里约 1 个超过 200ms；
- z 分位数：标准正态的 0.975 分位是 $1.96$——08 篇置信区间里的那个 1.96 就是它。

```python
import numpy as np
rng = np.random.default_rng(1)
lat = np.concatenate([rng.exponential(50, 999), [8000]])   # 999 个正常 + 1 个超时尖刺
print(np.mean(lat))                  # ≈ 58 ms:被一个尖刺拉高
print(np.percentile(lat, 99))        # ≈ 200 ms 量级:几乎不受尖刺影响
# 结论:报告长尾延迟时,P99/中位数比均值诚实(经验做法:监控一律用分位数)
```

## 5. 为什么"假设正态"危险：肥尾

### 5.1 问题

正态分布的尾部衰减是 $e^{-x^2/2}$，快得惊人：偏离均值 5σ 的概率约 $2.9\times10^{-7}$（约 350 万分之一）。但很多真实数据——尤其**金融收益率**——尾部比这肥得多：极端事件的发生率远超正态的预言。

历史坐标：1987 年 10 月 19 日"黑色星期一"，道琼斯指数单日下跌 22.6%。若按正态建模（当时美股日波动率约 1%），这是一个约 22.6σ 的事件，正态模型给出的概率约 $10^{-112}$——按宇宙年龄内的交易日数（约 $10^{13}$ 天）也算不出一次。现实是它发生了。肥尾的常用度量是**峰度**（kurtosis）：正态为 3，肥尾分布远大于 3。

### 5.2 演示：正态收益 vs 肥尾收益

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

rng = np.random.default_rng(7)
n = 5000
normal_r = rng.normal(0, 0.01, n)               # 正态假设的日收益: sigma=1%
# t(3) 标准差 = scale*sqrt(df/(df-2)) = scale*sqrt(3),乘 0.01/sqrt(3) 使总波动与正态组相同
t_r = stats.t.rvs(df=3, loc=0, scale=0.01/np.sqrt(3), size=n)  # 肥尾(同总波动)

def report(r, name):
    kurt = stats.kurtosis(r, fisher=False)     # >3 即肥尾
    worst = r.min() / r.std()
    print(f"{name}: 峰度={kurt:.1f}  最差日={worst:.1f}σ")
    return r

report(normal_r, "正态收益")
report(t_r,     "肥尾收益")

x = np.linspace(-8, 8, 500) * 0.01
plt.hist([normal_r, t_r], bins=80, density=True, label=['normal', 'fat-tail t(3)'])
plt.plot(x, stats.t.pdf(x/(0.01/np.sqrt(3)), 3)/(0.01/np.sqrt(3)), 'r', lw=1)
plt.legend(); plt.yscale('log'); plt.savefig('fat_tail.png', dpi=120)
# 图注:对数纵轴下,尾部差异一目了然——t(3) 分布在 5σ 之外仍有可观概率,
# 而正态曲线早已贴地。
```

典型输出：正态收益峰度 ≈ 3、最差日约 3–4σ；肥尾收益峰度可达 10–30、最差日 6–10σ。

### 5.3 工程教训

- **量化**：基于正态假设的 VaR（在险价值）系统性低估极端回撤——这就是为什么实务中改用历史模拟、t 分布或极值理论（本仓库量化投资方向会展开）；
- **服务/系统监控**：请求延迟也常是重尾的（GC 停顿、缓存击穿），用均值+正态区间报警会漏掉真正的尾延迟事故——所以监控用 P99（第 4 节）；
- **经验做法**：拿到任何数值数据，先画直方图/Q-Q 图、算峰度，再决定用不用正态工具箱；"假设正态"是待验证的假设，不是默认配置。

## 本篇小结

- PMF 竖条是概率，PDF 曲线积分才是概率，CDF 统一两者且反函数给分位数。
- 期望线性可加；独立时方差相加、标准差按 $\sqrt{\cdot}$ 合成——噪声叠加、标准误、波动率平方根法则都是这一条的不同马甲。
- 六个分布各有分工：均匀（无信息）、伯努利（单次成败）、二项（n 次成败计数）、正态（CLT 的极限、对称噪声）、泊松（单位时间次数）、指数（等待时间、无记忆）。
- CLT：独立观测的均值近似正态，SE $=\sigma/\sqrt n$——统计学推论的通行证。
- 正态尾部太薄：金融收益等肥尾数据用正态建模会系统性低估极端事件（1987 年 22.6σ 事件）；先验峰度再选工具，监控用分位数。
