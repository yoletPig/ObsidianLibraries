## 1. 似然函数：概率的"反向阅读"

### 1.1 从概率到似然

写分布时我们习惯"参数固定、数据随机"：$p(x \mid \theta)$。现在反过来——**数据已经到手，参数未知**：

$$
L(\theta) = p(x_1, \ldots, x_n \mid \theta)
$$

同一个函数，读法完全不同（Casella & Berger《Statistical Inference》§7.2）：

- **概率视角**：$\theta$ 固定，问"不同 $x$ 出现的可能性"——是 $x$ 的函数；
- **似然视角**：$x$ 固定（已观测），问"哪个 $\theta$ 让这批数据最不像巧合"——是 $\theta$ 的函数。

例：抛 10 次硬币出现 7 次正面。$p = 0.5$ 的"解释力"是 $\binom{10}{7}0.5^{10} \approx 0.117$；$p=0.7$ 的解释力是 $\binom{10}{7}0.7^7 0.3^3 \approx 0.267$。数据说：$p=0.7$ 的世界比 $p=0.5$ 的世界更可能产生我看到的序列。

### 1.2 为什么取对数

$n$ 个独立观测的似然是连乘 $L(\theta) = \prod_i p(x_i\mid\theta)$，数值极小且求导麻烦，一律取对数变成连加：

$$
\ell(\theta) = \log L(\theta) = \sum_i \log p(x_i \mid \theta)
$$

$\log$ 单调递增，最大化 $L$ 与最大化 $\ell$ 等价。**这个 $\ell(\theta)$ 正是后面"交叉熵损失"的雏形**——请记住它的形状：负的它就是损失。

## 2. MLE：两个完整推导

### 2.1 伯努利：抛硬币估计 p

$n$ 次试验 $k$ 次正面，似然 $L(p) = p^k(1-p)^{n-k}$，对数似然：

$$
\ell(p) = k\log p + (n-k)\log(1-p)
$$

求导置零：

$$
\frac{d\ell}{dp} = \frac{k}{p} - \frac{n-k}{1-p} = 0
\;\Rightarrow\; k(1-p) = (n-k)p
\;\Rightarrow\; \hat{p}_{\text{MLE}} = \frac{k}{n}
$$

7 正 3 反 → $\hat p = 0.7$。直觉完全符合："频率即概率"。二阶导 $\ell''(p) = -\frac{k}{p^2} - \frac{n-k}{(1-p)^2} < 0$ 确认是极大值（凹函数，呼应 10 篇）。

### 2.2 正态：估计 μ 和 σ²

数据 $x_1,\ldots,x_n \sim N(\mu, \sigma^2)$，对数似然：

$$
\ell(\mu, \sigma^2) = -\frac{n}{2}\log(2\pi) - \frac{n}{2}\log\sigma^2 - \frac{1}{2\sigma^2}\sum_i (x_i-\mu)^2
$$

对 $\mu$ 求导置零：$\sum_i (x_i - \mu) = 0 \Rightarrow \hat\mu = \bar{x}$。代回后对 $\sigma^2$ 求导置零：

$$
\hat\sigma^2_{\text{MLE}} = \frac{1}{n}\sum_i (x_i - \bar{x})^2
$$

注意分母是 $n$ **不是 $n-1$**——MLE 的方差估计**有偏**（系统性偏小，因为用了 $\bar x$ 而真 μ 未知），这就是样本方差用 $n-1$（贝塞尔校正）的原因（Casella & Berger §7.3.1 有完整证明）。`np.var(x, ddof=1)` 的 `ddof=1` 就是在做这个校正。

```python
import numpy as np
rng = np.random.default_rng(0)
x = rng.normal(2.0, 3.0, size=1000)
mu_hat = x.mean()
var_mle = ((x - mu_hat)**2).mean()        # /n
var_unbiased = x.var(ddof=1)              # /(n-1)
print(mu_hat)          # ≈ 2.02
print(var_mle)         # ≈ 8.82  (真实 9,但偏低)
print(var_unbiased)    # ≈ 8.83  更接近 9;大样本差异小,小样本差异可观
```

## 3. 交叉熵与 MLE：分类为什么用交叉熵

### 3.1 从似然到损失

分类模型输出 $K$ 类概率 $\hat{p}_1, \ldots, \hat{p}_K$，一条标签为 $y$ 的样本。这批"数据 = 类别标签"的似然是 $L = \hat{p}_y$——模型给正确类别打的概率。让数据最像 = 最大化 $\log \hat{p}_y$ = 最小化 $-\log \hat{p}_y$。对 $n$ 条独立样本：

$$
\text{NLL} = -\sum_i \log \hat{p}_{i,y_i} = -\sum_i \sum_k y_{ik} \log \hat{p}_{ik} = \sum_i H(\mathbf{y}_i, \hat{\mathbf{p}}_i)
$$

最后一步正是**交叉熵**：$\mathbf{y}$ 是 one-hot 标签。所以：

> **分类用交叉熵损失 = 对类别分布做最大似然估计。** 不是"哪个损失函数感觉上合适"，而是 MLE 的直接推论。

12 篇会从信息论角度再讲一遍交叉熵（最优码长视角），两条路殊途同归。数值例子：3 分类，真实标签第 2 类，模型 A 给 $\hat p = [0.1, 0.8, 0.1]$，模型 B 给 $[0.3, 0.4, 0.3]$：$H = -\log 0.8 = 0.223$ vs $H = -\log 0.4 = 0.916$——概率打对了损失就低。

```python
import numpy as np
def cross_entropy(logits, y):
    # 稳定的 softmax+CE 实现(减 max 防溢出,经验做法)
    z = logits - logits.max(axis=-1, keepdims=True)
    logp = z - np.log(np.exp(z).sum(axis=-1, keepdims=True))
    return -logp[y]

print(cross_entropy(np.log(np.array([0.1, 0.8, 0.1])), 1))  # 0.2231
print(cross_entropy(np.log(np.array([0.3, 0.4, 0.3])), 1))  # 0.9163
print(cross_entropy(np.log(np.array([0.02, 0.02, 0.96])), 2))  # 0.0408:很自信且对
```

## 4. 先验、后验与共轭先验

### 4.1 贝叶斯推断的框架

MLE 只用数据说话；贝叶斯派坚持把已有知识写成**先验**分布 $\pi(\theta)$，再由数据修正：

$$
\underbrace{p(\theta \mid x)}_{\text{后验}} = \frac{p(x \mid \theta)\,\pi(\theta)}{\int p(x\mid\theta)\pi(\theta)\,d\theta}
= \frac{\text{似然} \times \text{先验}}{\text{证据}}
$$

（05 篇医疗检测是它的离散版本；这里是连续参数版本。）

### 4.2 共轭先验：Beta-Bernoulli 完整算例

**共轭先验**：先验与后验属于同一分布族，更新只需"数数"，不需要数值积分。伯努利的共轭是 **Beta 分布** $\mathrm{Beta}(\alpha, \beta)$，密度 $f(p) \propto p^{\alpha-1}(1-p)^{\beta-1}$。

代入贝叶斯公式（似然 $p^k(1-p)^{n-k}$，先验 $p^{\alpha-1}(1-p)^{\beta-1}$）：

$$
\underbrace{p^{\alpha+k-1}(1-p)^{\beta+n-k-1}}_{\text{直接数指数!}}
\quad\Longrightarrow\quad
\mathrm{Posterior} = \mathrm{Beta}(\alpha + k,\ \beta + n - k)
$$

**更新规则：看见一个正面给 $\alpha$ 加 1，一个反面给 $\beta$ 加 1**——先验就像"虚拟样本"。手算：先验 $\mathrm{Beta}(2, 2)$（轻度的"我信 p 在 0.5 附近"），观测 10 次抛出 7 正：

$$
\mathrm{Posterior} = \mathrm{Beta}(2+7,\ 2+3) = \mathrm{Beta}(9, 5)
$$

后验均值 $\frac{9}{14} \approx 0.643$（被先验从 0.7 拉向 0.5），后验众数 $\frac{9-1}{9+5-2} = \frac{8}{12} \approx 0.667$。若先验换成无信息的 $\mathrm{Beta}(1,1)$（均匀分布），后验为 $\mathrm{Beta}(8,4)$，均值 $\frac{8}{12} = \frac{2}{3} \approx 0.667$——先验越弱，越接近 MLE。

```python
import numpy as np
from scipy import stats
import matplotlib.pyplot as plt

p = np.linspace(0, 1, 500)
for (a, b), c in [((2, 2), 'gray'), ((1, 1), 'green'), ((9, 5), 'red'), ((8, 4), 'blue')]:
    plt.plot(p, stats.beta.pdf(p, a, b), color=c, label=f'Beta({a},{b})')
plt.axvline(0.7, ls='--', c='k', lw=0.8, label='MLE=0.7')
plt.legend(); plt.xlabel('p'); plt.ylabel('density')
plt.savefig('beta_posterior.png', dpi=120)
# 图注:两条彩色后验都压在 MLE 附近;Beta(2,2) 先验(灰)让峰值略偏左(被拉向0.5)。
print(stats.beta(9, 5).mean())   # 0.6428571428571429
print(stats.beta(8, 4).mean())   # 0.6666666666666666
```

### 4.3 MAP：贝叶斯与频率派的折中

**最大后验估计**（MAP）取后验的峰值而不是整个分布：

$$
\hat\theta_{\text{MAP}} = \arg\max_\theta\ \log p(x\mid\theta) + \log \pi(\theta)
$$

关键观察：**MAP = MLE + 先验的对数项**，而均匀先验下两项相同——

> **MAP 是 MLE 的带正则版本**：$\mathrm{Beta}(\alpha,\beta)$ 先验之于伯努利，就像 L2 正则之于线性回归（高斯先验）与 L1 正则（拉普拉斯先验）。

上例：先验 $\mathrm{Beta}(2,2)$ 时 $\hat p_{\text{MAP}} = 0.667 < \hat p_{\text{MLE}} = 0.7$——先验把估计往 0.5 拉，样本越少拉得越明显。这与神经网络训练中 weight decay 的角色完全同构。

### 4.4 为什么深度学习只用"点估计"

神经网络的参数是百万到千亿维：完整贝叶斯要算参数的**后验分布**（千万亿维的积分），计算上不可行。工程上的务实路线（**经验做法**，有理论支持但非唯一解）：

- **点估计**：SGD 找到一个 $\hat\theta$ 就用（MAP 主义的近似——weight decay 充当高斯先验）；
- **用近似量化不确定性**：集成学习（多个随机种子训练取平均）、MC Dropout、温度缩放校准；
- 大模型时代的主流是"点估计 + 大数据压低方差"——数据多到先验和后验形状都无关紧要时，MLE 就够用了。

## 本篇小结

- 似然 = 把 $p(x\mid\theta)$ 反过来读：数据固定、参数是自变量；连乘取对数得 $\ell(\theta)$。
- 伯努利 MLE = 频率 $k/n$；正态 MLE = $(\bar x, \frac{1}{n}\sum(x_i-\bar x)^2)$，方差天然有偏、用 $n-1$ 校正。
- 分类交叉熵 = 负对数似然：最大化模型给正确标签的概率。softmax+CE 不是众多选项之一，而是 MLE 的必然。
- 共轭先验让贝叶斯更新变成数数：Beta-Bernoulli 算例后验 $\mathrm{Beta}(9,5)$，先验以"虚拟样本"方式把估计拉向自己。
- MAP = MLE + log 先验 = 带正则的 MLE；深度学习因参数维度只能做点估计，用集成/校准近似不确定性。
