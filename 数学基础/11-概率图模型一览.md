## 1. 为什么要图模型

### 1.1 问题的根源：联合分布爆炸

$n$ 个二值随机变量的联合分布需要 $2^n - 1$ 个独立参数。$n=50$ 时是千万亿量级——不可能存储、更不可能估计。出路只有一种：**利用变量之间的独立性结构，把大联合拆成小因子**。

### 1.2 图 = 独立性的地图

概率图模型用一张图编码"谁直接影响谁"（Koller & Friedman《Probabilistic Graphical Models》第 3 章）：

- **有向图（贝叶斯网络）**：边表示因果/依赖方向，联合分布按链式法则**沿图分解**：

$$
P(X_1, \ldots, X_n) = \prod_i P(X_i \mid \mathrm{Pa}(X_i))
$$

- **无向图（马尔可夫网络）**：边表示"有连线才允许直接相关"，用势函数乘积分解（MRF/Ising 模型，本篇不展开）。

分解的威力：如果每个节点最多 $k$ 个父节点，参数量从 $2^n$ 降到 $n\cdot 2^k$。**图模型不是一种算法，而是一种"结构化建模声明"**——你画出结构，独立性和参数共享就自动生效。

## 2. 贝叶斯网络：洒水器网络手算

### 2.1 网络结构与 CPT

经典教学网络（Russell & Norvig《AIMA》；Koller & Friedman 同款）：阴天 → 洒水器开 & 下雨；洒水器开或下雨 → 草地湿。

```
        Cloudy (C)
        /       \
  Sprinkler(S)  Rain(R)
        \       /
         Wet(W)
```

条件概率表（CPT，数字为教学设定）：

| 事件 | 概率 |
| --- | --- |
| $P(C)$ | 0.5 |
| $P(S=\mathrm{on}\mid C)$ / $P(S=\mathrm{on}\mid \bar C)$ | 0.1 / 0.5 |
| $P(R\mid C)$ / $P(R\mid \bar C)$ | 0.8 / 0.2 |
| $P(W\mid S,R)$ / $P(W\mid S,\bar R)$ | 0.99 / 0.9 |
| $P(W\mid \bar S,R)$ / $P(W\mid \bar S,\bar R)$ | 0.9 / 0.0 |

联合分布按图分解为 4 个小因子：$P(C,S,R,W) = P(C)P(S\mid C)P(R\mid C)P(W\mid S,R)$——参数从 15 个降到 9 个。

### 2.2 手算 $P(W)$：枚举消元

把 $S, R$ 边缘化（对 4 种组合求和），每种组合按图分解：

$$
\begin{aligned}
P(S,R) &= \sum_C P(C)P(S\mid C)P(R\mid C) \\
P(S,R)     &= 0.5\cdot0.1\cdot0.8 + 0.5\cdot0.5\cdot0.2 = 0.04+0.05 = 0.09 \\
P(S,\bar R)&= 0.5\cdot0.1\cdot0.2 + 0.5\cdot0.5\cdot0.8 = 0.01+0.20 = 0.21 \\
P(\bar S,R)&= 0.5\cdot0.9\cdot0.8 + 0.5\cdot0.5\cdot0.2 = 0.36+0.05 = 0.41 \\
P(\bar S,\bar R) &= 0.5\cdot0.9\cdot0.2 + 0.5\cdot0.5\cdot0.8 = 0.09+0.20 = 0.29
\end{aligned}
$$

$$
P(W) = 0.09(0.99) + 0.21(0.9) + 0.41(0.9) + 0.29(0) = 0.0891+0.189+0.369 = 0.6471
$$

草地湿的无条件概率约 64.7%。**反过来的推断（证据上溯）**才是图模型的招牌：看到草地湿，"下过雨"的后验是多少？用 05 篇贝叶斯：$P(R\mid W) = \frac{\sum_{S,C} P(C,S,R,W)}{P(W)}$——分母 0.6471 已算出，分子把 $R$ 固定为真再枚举（课后练习 1）。

### 2.3 三种基本连接模式（条件独立的判定钥匙）

- **链式** $A \to B \to C$：给定 $B$，$A$ 与 $C$ 独立（信息被 $B$ 挡住）；
- **分叉** $A \leftarrow B \to C$：给定 $B$，$A$ 与 $C$ 独立（共同原因被观察则隔离）；
- **汇合** $A \to B \leftarrow C$：默认独立，但**观察 $B$ 或其后代反而使 $A, C$ 相关**（explaining away：草湿了，"下雨"和"洒水器"两个独立假设变成互相竞争的解释）。

第三种最反直觉也最重要——它解释了为什么"加证据可能让两个独立变量相关起来"。本仓库《自动驾驶》Stage 4 的多传感器融合（速度计与雷达读数在"真实车速"汇合）正是这个结构。

## 3. 隐马尔可夫模型与前向算法

### 3.1 模型定义

HMM 处理"**隐藏状态序列 + 可观测输出序列**"（Rabiner 1989 的经典综述是标准出处）。两个假设把联合分布压缩成两套小矩阵：

- **马尔可夫性**：$P(z_t \mid z_{t-1}, \ldots, z_1) = P(z_t \mid z_{t-1})$（转移矩阵 $A$）；
- **输出独立性**：$P(x_t \mid z_t, x_{<t}) = P(x_t \mid z_t)$（发射矩阵 $B$）。

$$
P(z_{1:T}, x_{1:T}) = P(z_1) \prod_{t=2}^{T} P(z_t \mid z_{t-1}) \prod_{t=1}^{T} P(x_t \mid z_t)
$$

经典示例（天气 → 活动）：隐藏状态 {Rainy, Sunny}，观测 {walk, shop, clean}：

| 转移 $A$ | Rainy | Sunny | | 发射 $B$ | walk | shop | clean |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **Rainy** | 0.7 | 0.3 | | **Rainy** | 0.1 | 0.4 | 0.5 |
| **Sunny** | 0.4 | 0.6 | | **Sunny** | 0.6 | 0.3 | 0.1 |

初始分布 $\pi = [0.6, 0.4]$（Rainy, Sunny）。

### 3.2 前向算法

**问题**：观测序列 $x_{1:3} = (\text{walk}, \text{shop}, \text{clean})$ 出现的概率是多少？暴力枚举 $2^3 = 8$ 条路径可以算，但 $T$ 一大就指数爆炸。前向算法用**动态规划**：递推"看到前 $t$ 个观测、当前在状态 $i$"的概率 $\alpha_t(i)$：

$$
\alpha_1(i) = \pi_i B_{i}(x_1), \qquad
\alpha_t(i) = \left(\sum_j \alpha_{t-1}(j) A_{ji}\right) B_i(x_t), \qquad
P(x_{1:T}) = \sum_i \alpha_T(i)
$$

复杂度 $O(T\cdot n^2)$——线性于序列长度。**每一步就是 05 篇的"全概率公式 + 贝叶斯结构"换了个马甲**。

### 3.3 Python 实现（含逐行验证）

```python
import numpy as np

states = ['Rainy', 'Sunny']
obs    = ['walk', 'shop', 'clean']
A = np.array([[0.7, 0.3],     # 转移: 行=昨天, 列=今天
              [0.4, 0.6]])
B = np.array([[0.1, 0.4, 0.5],  # 发射: 行=状态, 列=观测
              [0.6, 0.3, 0.1]])
pi = np.array([0.6, 0.4])

def forward(obs_idx):
    T, n = len(obs_idx), len(states)
    alpha = np.zeros((T, n))
    alpha[0] = pi * B[:, obs_idx[0]]                # 第 0 步: 先验×发射
    for t in range(1, T):
        for i in range(n):
            alpha[t, i] = (alpha[t-1] @ A[:, i]) * B[i, obs_idx[t]]
    return alpha, alpha[-1].sum()

alpha, prob = forward([obs.index(o) for o in obs])
print(alpha)
# [[0.06     0.24   ]   ← walk: Rainy 0.6×0.1=0.06, Sunny 0.4×0.6=0.24
#  [0.0552   0.0486 ]   ← shop: (0.06×0.7+0.24×0.4)×0.4=0.0552; (0.06×0.3+0.24×0.6)×0.3=0.0486
#  [0.02904  0.004572]]  ← clean
print(prob)                     # 0.033612 —— 与教科书(Rabiner/AIMA)手算值完全一致
```

（数值逐行可验：$\alpha_1 = [0.06, 0.24]$；$\alpha_2(\text{Rainy}) = (0.06\cdot0.7 + 0.24\cdot0.4)\times0.4 = 0.0552$；最终 $0.02904 + 0.004572 = 0.033612$。）前向算法是 HMM 三大问题之一（似然评估）；另外两个——解码用 Viterbi（同样 DP，把求和换 max）、训练用 Baum-Welch（EM，07 篇 MLE 的迭代版）——本篇只点名，细节见 Rabiner 1989。

## 4. 从 HMM 到 RNN 再到注意力

### 4.1 观念演化线

把三代序列模型放在一起看，是同一条"表达能力 vs 结构约束"的螺旋：

| | HMM | RNN/LSTM | Transformer |
| --- | --- | --- | --- |
| 状态 | 离散隐状态 $z_t$ | 连续隐向量 $h_t$ | 无循环状态(注意力直连) |
| 依赖建模 | 一阶马尔可夫 | 任意长(理论上) | 任意长(显式成对) |
| 参数 | 小矩阵,可数 | 循环权重共享 | 注意力矩阵 $O(T^2)$ |
| 推断 | DP 精确 | BPTT 近似 | 前向一遍 |

- **HMM 的遗产**：隐变量 + 递推推断（$\alpha$ 递推就是"每次只携带一个摘要向量向前走"）；这也是 RNN 的形状——**RNN 可以读成"连续状态空间版的 HMM"，只是隐状态不再离散、转移变成神经网络**；
- **RNN 的困境**：信息必须逐步压缩进 $h_t$，长程依赖衰减（《PyTorch 与深度学习》07 篇的梯度消失实验）；
- **注意力的解放**：干脆不再维护"单一摘要"，让每个位置直接查表访问所有历史位置（$QK^\top V$）——代价是从 $O(T)$ 参数膨胀到 $O(T^2)$ 的注意力图。**GPT 的因果自回归 $P(x_t \mid x_{<t})$ 恰恰是 HMM 链式分解的连续化版本**：都把联合分布拆成一串条件，只是条件的表达方式天差地别。

### 4.2 学习顺序建议（经验做法）

理解 HMM 的前向/Viterbi 递推，对读 Transformer 的自回归与 KV cache 直觉帮助极大——"带着摘要走"与"开卷查表"是序列建模的两个端点，现代大模型在中间地带（状态空间模型 Mamba 的"线性递推+选择性记忆"又是回到递推端）。

## 5. 现代视角：LLM 时代图模型还需要吗

**如实评价：概念价值大于直接使用。** 分两面说：

**淡出的部分**：传统贝叶斯网络推断（变量消元、junction tree）与手工 HMM，在工业 NLP/CV 主线里已被端到端深度学习取代——精度、工程吞吐、数据红利都站在后者一边。手工设计 CPT 的性价比在 2020 年代急剧下降。

**留下且更重要的部分**：

1. **条件独立性思维**：因果图（do-演算、混杂调整）在 A/B 实验（08 篇辛普森悖论）与因果 ML 中是核心语言——图模型是学因果推断的必修前置；
2. **结构化输出**：机器人规划、医疗诊断、供应链等"变量少、结构强、数据少"的领域，图模型仍是最优解；自动驾驶的占用栅格与多目标跟踪（数据关联本质是 HMM 变体）仍在用；
3. **解释 LLM 的语言**：自回归分解、马尔可夫性质、EM/Baum-Welch 与 EM 式期望最大化思想（mixing-of-experts、RLHF 里的一些算法骨架）都从这套理论里长出来；
4. **不确定性的纪律**：图模型逼你显式写下"哪些变量独立"——这个习惯在调参之外的系统设计里永远值钱。

**结论**：把本篇当作"读论文与做系统设计的语法书"，而不是"日常调库的工具书"。

## 本篇小结

- 图模型把独立性画成图，联合分布沿图分解，参数从指数级降到局部因子级。
- 洒水器网络完整手算：$P(W) = 0.6471$；三种连接模式中"汇合"最反直觉（explaining away）。
- HMM = 马尔可夫性 + 输出独立性；前向算法用 DP 把 $O(n^T)$ 降到 $O(Tn^2)$，代码 20 行、数值 0.033612 与经典文献一致。
- HMM→RNN→注意力是"离散递推 → 连续递推 → 显式查表"的演化；GPT 的自回归分解是 HMM 链式分解的连续化后代。
- LLM 时代图模型作为工具淡出、作为语言（条件独立、因果、EM）常青。
