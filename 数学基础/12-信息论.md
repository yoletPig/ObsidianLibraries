## 1. 自信息与熵

### 1.1 自信息：惊讶度的度量

一个概率为 $p$ 的事件发生，你有多惊讶？信息论给的定义：

$$
I(x) = \log_2 \frac{1}{p(x)} = -\log_2 p(x) \quad \text{单位: bit}
$$

三条性质决定了它只能长这样（Cover & Thomas《Elements of Information Theory》第 2 章）：概率越小越惊讶（单调递减）；必然事件（$p=1$）零惊讶；独立事件同时发生，惊讶度**相加**（$\log$ 把乘法变加法）。数字手感：$p = 0.5$ → 1 bit；$p = 0.1$ → 3.32 bits；$p = 0.01$ → 6.64 bits。

### 1.2 熵：平均惊讶度

**熵**是自信息在分布上的期望：

$$
H(p) = -\sum_x p(x)\log_2 p(x)
$$

- 抛均匀硬币：$H = -2\times\frac12\log_2\frac12 = 1$ bit——一次抛硬币最多携带 1 bit；
- 偏硬币 $p = (0.9, 0.1)$：$H = -0.9\log_2 0.9 - 0.1\log_2 0.1 = 0.9(0.152) + 0.1(3.322) = 0.137 + 0.332 = 0.469$ bit——**越偏越确定，熵越低**；
- 均匀分布是同支撑集上熵最大的分布（最大可到 $\log_2 n$）。

工程解读：熵衡量"这个随机源平均每次输出带来多少不确定度"。语言建模、策略优化、特征选择里的一切"信息量"讨论都以它为地基。

## 2. 编码视角：熵是最优平均码长的下界

### 2.1 从"压缩"理解熵

把随机源的输出编码成 0/1 串传输。香农**无噪声编码定理**（Cover & Thomas 第 5 章）：

> 任何无损编码方案的平均码长 $\bar{L} \ge H(p)$，且存在编码（如算术编码）使 $\bar{L}$ 任意接近 $H(p)$。

**熵 = 压缩的理论极限**。直觉：给高概率符号配短码、低概率符号配长码（Huffman 思想），平均码长才能压到下界。

### 2.2 数字演示

偏硬币 $p = (0.9, 0.1)$：单符号最优编码也得各 1 bit，平均码长 1 bit——离 $H = 0.469$ 很远。但把**两个**输出打包成一个块（4 种块：正正/正反/反正/反反，概率 $0.81/0.09/0.09/0.01$）做 Huffman，平均码长约 0.9 bit/符号；块长 4、8 时逐步逼近 0.469。

```python
import numpy as np

def entropy_bits(p):
    p = np.asarray(p, dtype=float)
    return -np.sum(p * np.log2(p))

print(entropy_bits([0.5, 0.5]))   # 1.0
print(entropy_bits([0.9, 0.1]))   # 0.4689955935892812
# 大数定律版验证:生成 i.i.d. 序列,其"理想码长"(自信息均值)收敛到熵
rng = np.random.default_rng(0)
x = rng.choice([0, 1], size=200000, p=[0.9, 0.1])
print(-np.log2(np.where(x == 0, 0.9, 0.1)).mean())  # ≈ 0.469,与熵一致
```

**为什么训练视角关心这个**：损失函数 = 平均负对数似然 = 模型对数据分配的平均自信息。**损失逼近数据在模型下的熵**，就是"模型把数据压缩到极致"的另一种说法——语言模型的 next-token 预测本质是在学压缩（这一观点的展开见 Hutter 奖与 recent "LLM=compressor" 文献）。

## 3. 交叉熵与 KL 散度

### 3.1 定义与恒等式

用分布 $q$ 给"真实来自 $p$ 的数据"编码的平均码长叫**交叉熵**：

$$
H(p, q) = -\sum_x p(x)\log_2 q(x)
$$

它与 KL 散度（相对熵）只差一个常数：

$$
\mathrm{KL}(p \| q) = \sum_x p(x)\log_2\frac{p(x)}{q(x)} = H(p, q) - H(p) \;\ge\; 0
$$

**KL = 用错误分布 q 编码 p 数据时，多付的平均码长（惩罚/税）**。等号当且仅当 $p = q$。这两个量的差 $H(p)$ 与模型无关，所以**最小化交叉熵 $\iff$ 最小化 KL**——分类训练里两个词混用而不出错的数学原因（07 篇从 MLE 角度推过同一个结论）。

### 3.2 非对称性：数值演示

KL 不是距离——它没有对称性，也没有三角不等式。取 $P = (0.5, 0.5)$（公平硬币），$Q = (0.9, 0.1)$（偏硬币）：

$$
\mathrm{KL}(P\|Q) = 0.5\log_2\frac{0.5}{0.9} + 0.5\log_2\frac{0.5}{0.1} = 0.5(-0.848) + 0.5(2.322) = 0.737\ \text{bit}
$$

$$
\mathrm{KL}(Q\|P) = 0.9\log_2\frac{0.9}{0.5} + 0.1\log_2\frac{0.1}{0.5} = 0.9(0.848) + 0.1(-2.322) = 0.531\ \text{bit}
$$

同一对分布，两个方向差 0.206 bit。方向不同，"错在哪里被罚得最重"完全不同——这正是下一节的主题。

### 3.3 正向 KL 与反向 KL：行为差异

设 $p$ 是复杂目标分布（比如双峰），$q$ 是简单的近似族（比如单高斯）。最小化两个方向会得到**性格相反**的 $q$：

- **正向 $\mathrm{KL}(p\|q)$**（期望在 $p$ 下取，即"数据采样"方向）：$q$ 被迫覆盖 $p$ 的所有高概率区，否则 $p$ 处 $q\to0$ 会被罚到无穷（$\log(p/q)$ 爆炸）——**mass-covering，摊开贴**。用一批来自 $p$ 的样本就能算（每次 $-\log q(x_i)$ 的均值），这就是 MLE/监督学习的可计算性来源：交叉熵损失 = 正向 KL 里的模型项；
- **反向 $\mathrm{KL}(q\|p)$**（期望在 $q$ 下取）：$q$ 只敢待在 $p$ 的某个峰附近，一旦踏上 $p=0$ 的区域罚到无穷——**mode-seeking，锁峰**。

**为什么变分推断/蒸馏训练常用反向 KL**（严格说"反向"是相对数据拟合方向而言）：因为 $\mathrm{KL}(q\|p)$ 的期望在 $q$ 下取——而 $q$ 是我们自己输出的分布，**可以采样、可以解析求导**；$p$ 往往只有未归一化的形式（采样不可行），反向 KL 恰好只需要"在 q 的样本处评估 p"，把不可算变成了可算（变分推断 ELBO、VAE、RLHF 中的策略约束均如此，MacKay《Information Theory, Inference and Learning Algorithms》ch. 33 的双峰图是标准演示）。代价是模式坍缩——反向 KL 只解释一个峰，这正是 VAE 后验"保守"、蒸馏学生模型"偏科"的数学根源。

```python
import numpy as np

def KL(p, q):
    p, q = np.asarray(p, float), np.asarray(q, float)
    mask = p > 0
    return float(np.sum(p[mask] * np.log2(p[mask] / q[mask])))

P, Q = [0.5, 0.5], [0.9, 0.1]
print(KL(P, Q))      # 0.7369655941662062
print(KL(Q, P))      # 0.531002577396755   非对称!
# 交叉熵 = H + KL
print(0.5*(-np.log2(0.9)) + 0.5*(-np.log2(0.1)))  # 1.7370 → H(P,Q)
print(entropy_bits(P) + KL(P, Q))                  # 1.0 + 0.7370 = 1.7370 ✓
```

## 4. 互信息：相关系数的"非线性补丁"

### 4.1 定义

$$
I(X;Y) = \mathrm{KL}\big(p(x,y)\,\|\,p(x)p(y)\big) = H(X) - H(X\mid Y)
$$

读法：**知道 $Y$ 之后，$X$ 的不确定度减少了多少**。性质：非负；独立时为 0；对称（$I(X;Y) = I(Y;X)$）；能捕捉任意统计依赖。

### 4.2 与相关系数的区别

相关系数 $\rho$ 只度量**线性**关系。构造反例：$Y = X^2$，$X \sim N(0,1)$——$\mathrm{Cov}(X,Y) = 0$（对称性抵消），$\rho = 0$，但 $Y$ 由 $X$ 完全决定，$I(X;Y) > 0$ 且相当大。

```python
import numpy as np

rng = np.random.default_rng(0)
x = rng.standard_normal(200000)
y = x**2
print(np.corrcoef(x, y)[0, 1])   # ≈ 0.0 (数值上约 1e-3)——相关系数瞎了

# 互信息(离散化估计,经验做法:分箱数取 ~sqrt(N) 并检查稳定性)
def mi_binned(a, b, bins=64):
    c, _, _ = np.histogram2d(a, b, bins=bins)
    pxy = c / c.sum()
    px = pxy.sum(axis=1, keepdims=True); py = pxy.sum(axis=0, keepdims=True)
    mask = pxy > 0
    return np.sum(pxy[mask] * np.log2(pxy[mask] / (px @ py)[mask]))

print(mi_binned(x, y))    # ≈ 1.0 bit 量级——强依赖被捕获
print(mi_binned(x, rng.standard_normal(200000)))  # ≈ 0.001,独立变量的对照
```

**经验做法**：特征筛选时 $\rho$ 只能抓线性冗余，$I(X;Y)$ 抓任意依赖但估计需要更多样本且对分箱敏感；两者是互补而非替代。**$\rho=0$ 绝不等于独立，$I=0$ 才等于独立**——这句话在量化（因子正交化）与因果筛查里都救命。

## 5. 困惑度：语言模型的体温计

### 5.1 定义

困惑度（perplexity）= 交叉熵的指数化：

$$
\mathrm{PPL} = 2^{H(p, q)} = e^{\ \overline{\mathrm{NLL}}_{\text{nats}}}
$$

读法：**"模型平均在每个位置像在多少个词里纠结"**。均匀猜 1000 词的词表：$\mathrm{PPL} = 1000$；若模型把平均 NLL（以 e 为底）压到 3.2 nats，$\mathrm{PPL} = e^{3.2} \approx 24.5$——相当于每个位置在约 25 个词里犹豫。

### 5.2 使用须知（经验做法）

- 困惑度只在**同一词表、同一分词器、同一数据切分**下可比——BPE 词表不同则 PPL 不可横向对比；
- PPL 低不等于下游任务好（它度量"拟合文本分布"，不度量指令遵循/推理）；
- 训练日志里 `loss ≈ 2.7`（nats）与 `PPL ≈ 14.9` 是同一个数的两种写法（$e^{2.7} \approx 14.88$）。

## 6. GPT 损失函数 = 交叉熵的完整解释

把全链条一次打通。GPT 是自回归语言模型：给定前文 $x_{<t}$，输出词表上的分布 $q_\theta(\cdot \mid x_{<t})$（softmax）。训练目标是最小化：

$$
L(\theta) = -\frac{1}{T}\sum_{t=1}^{T}\log q_\theta(x_t^\star \mid x_{<t})
$$

逐层拆解这一行：

1. 每个 $-\log q_\theta(x_t^\star\mid x_{<t})$ 是 **one-hot 标签下的交叉熵**（07 篇 3.1 节的公式逐字复现）；
2. 对整段数据求和取平均后，它等于 $\hat H(p_{\text{data}}, q_\theta)$——**数据经验分布与模型分布的交叉熵**；
3. 由 3.1 节恒等式，$= H(p_{\text{data}}) + \mathrm{KL}(p_{\text{data}}\|q_\theta)$，前者是数据本身的常数——**所以最小化训练损失 = 最小化"数据 → 模型"方向的正向 KL = 最大似然 = 把数据压缩到接近其真实熵**（监督学习走正向、变分推断走反向，见 3.3 节的对照）；
4. 训练完成后 $\exp(L)$ 就是困惑度，评估集上的它就是模型的"平均分支因子"。

**一句话总结**：GPT 的损失、分类的交叉熵、KL 散度、MLE、熵、压缩极限——是同一个数学对象在六个场景里的名字。

## 本篇小结

- 自信息 $-\log_2 p$ 是惊讶度；熵是平均惊讶度：均匀硬币 1 bit，偏硬币 0.469 bit。
- 香农编码定理：熵是最优平均码长的下界——损失函数逼近数据熵 = 学会压缩。
- 交叉熵 $H(p,q) = H(p) + \mathrm{KL}(p\|q)$；KL 非对称（0.737 vs 0.531 的演示）：正向 KL 摊开覆盖（MLE/监督学习可计算），反向 KL 锁峰（变分/蒸馏因"只需在 q 的样本处评估 p"而可行，代价是模式坍缩）。
- 互信息抓任意依赖（$Y=X^2$ 的 $\rho=0$ 反例），$\rho=0$ 不等于独立。
- 困惑度 = 交叉熵指数化 = 平均纠结词数；GPT 损失 = 逐 token one-hot 交叉熵 = 正向 KL = MLE = 压缩极限的逼近。
