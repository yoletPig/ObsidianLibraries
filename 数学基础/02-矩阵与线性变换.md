## 1. 矩阵 = 变换的编码

### 1.1 从函数的角度

线性变换是一个满足"线性"的函数 $T$：$T(\mathbf{u}+\mathbf{v}) = T(\mathbf{u})+T(\mathbf{v})$ 且 $T(c\mathbf{u}) = cT(\mathbf{u})$。线性变换完全由**基向量的去向**决定：知道 $\hat{i}\to(a,c)$、$\hat{j}\to(b,d)$，就知道了整个空间怎么动。把这两个去向按列排好：

$$
A = \begin{bmatrix} a & b \\ c & d \end{bmatrix}, \qquad
T(\mathbf{x}) = A\mathbf{x}
$$

**矩阵的列 = 基向量的去向**。这是理解矩阵最重要的一句话（Strang《Linear Algebra》§2.1；3Blue1Brown 的"线性变换的本质"是最佳可视化）。

### 1.2 三种基本变换的图像

- **旋转**（逆时针 $\theta$）：$\hat{i}\to(\cos\theta,\sin\theta)$，$\hat{j}\to(-\sin\theta,\cos\theta)$：

$$
R(\theta) = \begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix},
\qquad R(90^\circ) = \begin{bmatrix} 0 & -1 \\ 1 & 0 \end{bmatrix}
$$

- **缩放**：对角阵 $S=\mathrm{diag}(2, 3)$ 把横向拉长 2 倍、纵向拉长 3 倍。
- **剪切**：$\begin{bmatrix} 1 & 1 \\ 0 & 1 \end{bmatrix}$ 让 $\hat{i}$ 不动、$\hat{j}$ 斜到 $(1,1)$——整个平面像扑克牌一样被推斜，底部固定。

```python
import numpy as np
import matplotlib.pyplot as plt

def draw_transform(A, title):
    # 单位方格网，看它被 A 变成什么样
    pts = []
    for t in np.linspace(0, 1, 11):
        pts.append([t * np.array([1, 0]), t * np.array([0, 1])])
    grid = [np.array([t, 0]) for t in np.linspace(0, 1, 11)] + \
           [np.array([0, t]) for t in np.linspace(0, 1, 11)]
    fig, ax = plt.subplots(figsize=(4, 4))
    for t in np.linspace(0, 1, 6):  # 网格线
        line = np.stack([np.linspace(0, 1, 50), np.full(50, t)], axis=1)
        ax.plot(*(line @ A.T).T, 'lightgray')
        line = np.stack([np.full(50, t), np.linspace(0, 1, 50)], axis=1)
        ax.plot(*(line @ A.T).T, 'lightgray')
    e1 = np.array([1, 0]) @ A.T; e2 = np.array([0, 1]) @ A.T
    ax.quiver(0, 0, e1[0], e1[1], angles='xy', scale_units='xy', scale=1, color='r')
    ax.quiver(0, 0, e2[0], e2[1], angles='xy', scale_units='xy', scale=1, color='b')
    ax.set_title(title); ax.set_aspect('equal'); ax.set_xlim(-2, 2); ax.set_ylim(-2, 2)
    plt.savefig(f'transform_{title}.png', dpi=120)

th = np.pi / 3
draw_transform(np.array([[np.cos(th), -np.sin(th)], [np.sin(th), np.cos(th)]]), 'rotate60')
draw_transform(np.diag([2.0, 0.5]), 'scale')
draw_transform(np.array([[1.0, 1.0], [0.0, 1.0]]), 'shear')
```

图注：rotate60 中红色箭头（$\hat{i}$ 的去向）指向 60° 方向；scale 中横向网格被拉宽、纵向压扁；shear 中竖线全部倾斜但底边不动。

### 1.3 判断"是不是线性变换"

平移 $T(\mathbf{x}) = \mathbf{x} + [1,0]^\top$ **不是**线性变换（$T(\mathbf{0}) \ne \mathbf{0}$），所以它不能用矩阵乘法表示——但可以用齐次坐标（补一个维度）表示，图形学就是这么干的。**经验做法**：看到"旋转+平移"，工程上就是 $3\times3$ 齐次矩阵；卡尔曼滤波（13 篇）里则是"旋转/缩放 + 偏置"拆成两步处理。

## 2. 矩阵乘法的四种理解

$A\mathbf{x}$ 和 $AB$ 至少有四种读法，各有用武之地：

### 2.1 变换复合

$AB\mathbf{x}$ 表示"先施加 $B$ 的变换，再施加 $A$ 的"。注意顺序：**从右往左读**。旋转 90° 再剪切 ≠ 先剪切再旋转——矩阵乘法不满足交换律，因为两次变换的先后确实不可交换。验证：$R(90^\circ)S \ne S R(90^\circ)$（$S=\mathrm{diag}(2,3)$），读者可自行相乘对比。

### 2.2 列的组合（最重要的工程读法）

$$
A\mathbf{x} = x_1 \cdot A_{:,1} + x_2 \cdot A_{:,2} + \cdots
$$

结果向量是 $A$ 各列的**线性组合**，权重就是 $\mathbf{x}$ 的分量。所以 $A\mathbf{x}$ 的所有可能取值构成 $A$ 的**列空间**——这直接引出"方程组何时有解"：$A\mathbf{x}=\mathbf{b}$ 有解 $\iff$ $\mathbf{b}$ 落在 $A$ 的列空间里（Strang《Linear Algebra》§3.2）。

### 2.3 行×列（手算规则）

$C_{ij} = \sum_k A_{ik}B_{kj}$：$A$ 的第 $i$ 行点乘 $B$ 的第 $j$ 列。这是考试用的定义，也是最慢的理解方式——但它解释了 shape 规则：$(m\times n)(n\times p) = m\times p$，中间两个 $n$ 必须咬合。

### 2.4 批量内积（深度学习读法）

若把 $A$ 看成 $m$ 个行向量、$B$ 看成 $p$ 个列向量，则 $C = AB$ 是一个**所有行与所有列两两点积的表格**：$C_{ij} = \langle A_{i,:}, B_{:,j}\rangle$。注意力机制里的 $QK^\top$、推荐系统的用户-物品打分矩阵，本质都是这个读法——**矩阵乘法 = 批量算相似度**。

```python
A = np.array([[2.0, 0.0], [1.0, 3.0]])
x = np.array([3.0, 2.0])
# 2.2 列的组合视角，逐项验证
col_combo = x[0] * A[:, 0] + x[1] * A[:, 1]
print(A @ x, col_combo)     # [6. 9.] [6. 9.]  完全一致

# 2.4 批量内积视角
B = np.array([[1.0, 2.0], [0.0, 1.0]])
C = A @ B
print(C[0, 1], A[0, :] @ B[:, 1])  # 4.0 4.0 —— C[i,j] 就是行点列
```

## 3. 逆与秩

### 3.1 逆：变换的"撤销"

$A^{-1}$ 满足 $A^{-1}A = I$，几何上就是**把 $A$ 干的事原路退回**。$2\times2$ 手算公式：

$$
A = \begin{bmatrix} a & b \\ c & d \end{bmatrix}, \quad
A^{-1} = \frac{1}{ad - bc}\begin{bmatrix} d & -b \\ -c & a \end{bmatrix}
$$

分母 $ad-bc$ 是**行列式**：几何上是单位方块被变换后的**面积缩放因子**。$\det A = 0$ 意味着空间被压扁（降维），信息被不可逆地抹掉——所以没有逆。

### 3.2 秩：变换后空间的维度

- $\mathrm{rank}(A)$ = 列空间的维度 = **变换后还剩几维**；
- $2\times2$ 矩阵：秩 2（可逆，面保住了）、秩 1（整个平面被压成一条线）、秩 0（全灭）；
- 例：$\begin{bmatrix} 1 & 2 \\ 2 & 4 \end{bmatrix}$ 的第二列是第一列的 2 倍，秩 1——它把所有向量都压到方向 $(1,2)$ 的直线上。

```python
A = np.array([[1.0, 2.0], [2.0, 4.0]])
print(np.linalg.matrix_rank(A))    # 1
print(np.linalg.det(A))            # 0.0（精确为 0 时逆不存在）
np.linalg.inv(A)                   # LinAlgError: Singular matrix
```

### 3.3 方程组三种命运

$A\mathbf{x}=\mathbf{b}$（$n$ 个未知数）的解由秩决定（Strang《Linear Algebra》§3.3）：

- $\mathrm{rank}(A) = \mathrm{rank}([A|\mathbf{b}]) = n$：唯一解；
- 两者相等但 $< n$：无穷多解（有一个自由度 ≥ 1 的"解空间"）；
- $\mathrm{rank}(A) < \mathrm{rank}([A|\mathbf{b}])$：无解——$\mathbf{b}$ 在列空间之外。工程上退而求其次求"最接近的解"，那就是 13 篇的最小二乘。

## 4. 消元与 LU 概览

### 4.1 高斯消元的思想

解方程组时，用第一行去消下面各行的第一个未知数，再用第二行消第三行的第二个……把 $A$ 变成上三角阵 $U$，然后从下往上回代。手算一例：

$$
\begin{cases} 2x + y = 5 \\ x + 3y = 10 \end{cases}
\;\xrightarrow{\text{行2} -= \frac{1}{2}\text{行1}}\;
\begin{cases} 2x + y = 5 \\ \tfrac{5}{2}y = \tfrac{15}{2} \end{cases}
\Rightarrow y = 3,\ x = 1
$$

### 4.2 LU 分解

消元过程可以记录下来：$A = LU$，其中 $L$（下三角）存"每一步消元用了什么组合"，$U$（上三角）是消元结果。于是 $A\mathbf{x}=\mathbf{b}$ 拆成两步易解的三角方程：先解 $L\mathbf{y}=\mathbf{b}$（前向代入），再解 $U\mathbf{x}=\mathbf{y}$（回代）。**工程价值**：$LU$ 分解只做一次，之后换不同的 $\mathbf{b}$ 只需两次三角代入——求解同款方程组（卡尔曼滤波每个时间步换一个新观测 $\mathbf{b}$）的成本大幅下降。

```python
import numpy as np
from scipy.linalg import lu

A = np.array([[2.0, 1.0], [1.0, 3.0]])
b = np.array([5.0, 10.0])
P, L, U = lu(A)          # scipy 带行交换的 LU
print(L, U, sep='\n')
# L ≈ [[1,0],[0.5,1]], U ≈ [[2,1],[0,2.5]]——正是手算的消元路径
```

## 5. NumPy 求解 Ax=b：用 solve，别用 inv

### 5.1 正确姿势

```python
import numpy as np

A = np.array([[2.0, 1.0],
              [1.0, 3.0]])
b = np.array([5.0, 10.0])

x = np.linalg.solve(A, b)
print(x)                       # [1. 3.]
print(A @ x)                   # [ 5. 10.]  验证

# 手算验证（3.1 节公式）：det = 2*3-1*1 = 5
Ainv_manual = np.array([[3.0, -1.0], [-1.0, 2.0]]) / 5.0
print(Ainv_manual @ b)         # [1. 3.]  一致
```

### 5.2 为什么不用 inv

**经验做法**：`x = np.linalg.inv(A) @ b` 数值上更差且更慢。原因有三：(1) 先显式构造 $A^{-1}$ 再乘，浮点误差比直接消元多一轮累积；(2) `solve` 走 LAPACK 的 LU 分解路径，复杂度同样是 $O(n^3)$ 但常数更小；(3) 若 $A$ 接近奇异，`inv` 会给出巨大的、毫无意义的数，而 `solve` 至少会警告。数值分析的标准结论：**永远把 inv 当作教学对象，把 solve 当作工程工具**（参考：LAPACK Users' Guide；Strang《Linear Algebra》§1.6 习题区同款建议）。

### 5.3 超定方程的预告

当方程比未知数多（$m > n$，比如用 100 个数据点拟合 2 个参数），$A\mathbf{x}=\mathbf{b}$ 一般无精确解，此时求 $\min\|A\mathbf{x}-\mathbf{b}\|_2$ 的解叫**最小二乘**，用 `np.linalg.lstsq(A, b)`。它的完整矩阵推导放在 13 篇——那里你会看到"正规方程" $A^\top A\mathbf{x} = A^\top\mathbf{b}$ 正是本篇 2.2 节"列的组合"思想的延续。

## 本篇小结

- 矩阵的列 = 基向量的去向；矩阵乘向量 = 列的线性组合。抓住这一句，旋转/缩放/剪切都是查表题。
- 矩阵乘法四读法：**复合变换**（从右往左）、**列组合**（解方程）、**行×列**（手算）、**批量内积**（深度学习）。
- 行列式 = 面积缩放因子；$\det = 0$ 即压扁，逆不存在。秩 = 变换后剩余维度，它决定方程组是唯一解、无穷解还是无解。
- 消元把 $A$ 分解为 $A = LU$，换右端项复用分解。工程上解 $A\mathbf{x}=\mathbf{b}$ 用 `np.linalg.solve`（LU 路径），`np.linalg.inv` 留给推导公式。
