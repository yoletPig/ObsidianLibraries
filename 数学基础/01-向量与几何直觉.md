## 1. 向量的两种身份：列表 vs 箭头

### 1.1 列表视角（代数）

计算机里的向量就是一列有序的数：

$$
\mathbf{v} = \begin{bmatrix} 3 \\ -1 \\ 2 \end{bmatrix}
$$

Python 里它就是一个 `np.array([3, -1, 2])`。列表视角回答"怎么存、怎么算"：加法是逐位相加，数乘是逐位相乘。

### 1.2 箭头视角（几何）

同样这个 $\mathbf{v}$，在三维空间里是从原点指向点 $(3, -1, 2)$ 的一支箭：有**方向**，有**长度** $\sqrt{3^2+(-1)^2+2^2}=\sqrt{14}\approx 3.742$。箭头视角回答"它是什么意思"：一个样本的特征是一条箭头，两个 embedding 的关系要看两条箭头的夹角。

### 1.3 什么时候用哪个视角

- 做**存储、运算、批量处理**时用列表视角（NumPy 的强项）；
- 谈**相似度、距离、投影、变换**时切换到箭头视角（几何直觉）。

工程里最常见的错误是只用列表视角：把 embedding 当成"一列数"，于是面对"为什么余弦相似度用点积除以长度"这类问题时没有图像可依。

```python
import numpy as np

v = np.array([3.0, -1.0, 2.0])
w = np.array([1.0, 4.0, -2.0])

print(v + w)          # [ 4.  3.  0.]  逐位相加 = 首尾相接的箭头
print(2 * v)          # [ 6. -2.  4.]  同方向拉长 2 倍
print(np.linalg.norm(v))  # 3.7416573867739413 = sqrt(14)
```

## 2. 线性组合与张成空间

### 2.1 线性组合

给定两个向量 $\mathbf{u}, \mathbf{v}$，任意形如

$$
a\,\mathbf{u} + b\,\mathbf{v}, \quad a, b \in \mathbb{R}
$$

的向量称为它们的**线性组合**（linear combination）。几何上：先缩放两支箭头，再首尾相接。

### 2.2 张成空间

所有可能的线性组合构成的集合，叫这两个向量的**张成空间**（span）。三种典型情形（2D 为例）：

- $\mathbf{u}=[1,0]^\top,\ \mathbf{v}=[0,1]^\top$：张成整个平面——它们**线性无关**；
- $\mathbf{v}=2\mathbf{u}$：所有组合都落在同一条直线上——**线性相关**，其中一个是多余的；
- 更一般地，$n$ 维空间中**最多需要 $n$ 个线性无关向量**来张成全空间（Strang《Linear Algebra》第 3 章）。

### 2.3 为什么工程上关心"相关"

特征矩阵中两列高度相关（例如"身高(cm)"和"身高(米)"），意味着其中一列不带来新信息——线性代数上叫秩亏，统计上叫多重共线性。这也是 04 篇 PCA 能"压缩"数据的根本前提：**数据其实是低维的，只是被嵌在高维坐标里**。

```python
u = np.array([1.0, 0.0])
v = np.array([0.0, 1.0])
# 用权重 (a, b) 组合出平面上任意点
for a, b in [(2, 3), (-1, 0.5), (0, 0)]:
    print(a * u + b * v)   # 正是坐标点 (a, b)
```

## 3. 范数：给"长度"下三种定义

### 3.1 定义

范数（norm）是把向量映射为非负实数、满足"长度"公理的函数。机器学习中最常用的三个（Casella & Berger 与各优化教材通用记法）：

$$
\|\mathbf{x}\|_1 = \sum_i |x_i|, \qquad
\|\mathbf{x}\|_2 = \sqrt{\sum_i x_i^2}, \qquad
\|\mathbf{x}\|_\infty = \max_i |x_i|
$$

以 $\mathbf{x} = [3, -4]^\top$ 为例：$\|\mathbf{x}\|_1 = 7$，$\|\mathbf{x}\|_2 = 5$，$\|\mathbf{x}\|_\infty = 4$。永远有 $\|\mathbf{x}\|_\infty \le \|\mathbf{x}\|_2 \le \|\mathbf{x}\|_1$。

### 3.2 各自的工程含义

- **L2**：欧氏距离，"直线距离"。对大分量敏感——梯度为 $2x_i$，分量越大推得越猛。
- **L1**：曼哈顿距离，"出租车距离"。对所有分量一视同仁（导数恒为 $\pm 1$），因此倾向于把一些分量**直接推到 0**。
- **L∞**：只惩罚最大的那个分量，"木桶效应"式度量。

### 3.3 为什么 L1 产生稀疏：等高线图像

考虑约束 $\|\mathbf{x}\|_p \le c$ 下的可行域形状：

- L2 的可行域是**圆盘**（光滑，处处圆滚滚）；
- L1 的可行域是**菱形**（四个尖角都在坐标轴上）。

把损失函数的等高线（同心的椭圆）叠上去：椭圆从外向内收缩，**最先碰到可行域的那个点**就是最优解。与圆盘相碰的点一般在"普通位置"（两个坐标都不为 0）；与菱形相碰的点**大概率撞在尖角上**——而尖角正好落在坐标轴上，即某个分量恰好为 0。这就是 LASSO（L1 正则）产生稀疏解的几何原因（Boyd《Convex Optimization》§6.3.2 有同款图；统计学原始出处 Tibshirani 1996）。

```python
import matplotlib.pyplot as plt

# 画出 ||x||_1 = 1（菱形）与 ||x||_2 = 1（圆）的等高线
t = np.linspace(0, 2 * np.pi, 200)
x2, y2 = np.cos(t), np.sin(t)                    # L2 单位球
x1 = np.array([1, 0, -1, 0, 1]); y1 = np.array([0, 1, 0, -1, 0])  # L1 单位球

fig, ax = plt.subplots(figsize=(5, 5))
ax.plot(x2, y2, label='L2 ball')
ax.plot(x1, y1, label='L1 ball')
# 损失等高线: (x-1.4)^2+(y-1.4)^2 = r^2，从大到小收缩
for r in [2.2, 1.8, 1.4, 1.0]:
    ax.plot(1.4 + r * np.cos(t), 1.4 + r * np.sin(t), 'gray', lw=0.5)
ax.axhline(0, color='k', lw=0.3); ax.axvline(0, color='k', lw=0.3)
ax.set_aspect('equal'); ax.legend(); ax.set_title('L1 vs L2 unit balls')
plt.savefig('norm_balls.png', dpi=120)
# 图注：灰椭圆收缩时，先触到菱形的尖角（坐标轴上）→ L1 稀疏；
# 触到圆的位置几乎从不在轴上 → L2 稠密。
```

**经验做法**：想要"自动特征选择 / 压缩权重数量"用 L1；只想要"温和地压小权重、防止过拟合"用 L2。深度学习里 weight decay 默认是 L2，因为稀疏性对神经网络通常不是目标。

## 4. 点积与相似度

### 4.1 定义与两个等价形式

$$
\mathbf{u} \cdot \mathbf{v} = \sum_i u_i v_i = \|\mathbf{u}\|\,\|\mathbf{v}\|\cos\theta
$$

左边是**代数**（逐位相乘再求和），右边是**几何**（长度×长度×夹角余弦）。这个等式是整个 embedding 时代的数学基石。

### 4.2 从点积读出三件事

固定 $\mathbf{u}, \mathbf{v}$ 的长度，点积只由夹角决定：

- 同向（$\theta=0$）：$\cos\theta = 1$，点积达到最大——"意思一致"；
- 垂直（$\theta=90°$）：$\cos\theta = 0$——"不相关"（正交 = 信息上互不干扰，这是 04 篇 PCA 主成分互相正交的直觉来源）；
- 反向（$\theta=180°$）：$\cos\theta = -1$——"意思相反"。

### 4.3 余弦相似度

把夹角单独提取出来：

$$
\cos\theta = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|\,\|\mathbf{v}\|}
$$

手算一例：$\mathbf{u} = [2, 1]^\top$（"猫"），$\mathbf{v} = [1, 1]^\top$（"狗"），$\mathbf{w} = [-1, 2]^\top$（"汽车"）：

$$
\cos(\mathbf{u}, \mathbf{v}) = \frac{2+1}{\sqrt{5}\cdot\sqrt{2}} = \frac{3}{\sqrt{10}} \approx 0.949, \qquad
\cos(\mathbf{u}, \mathbf{w}) = \frac{-2+2}{\sqrt{5}\cdot\sqrt{5}} = 0
$$

猫和狗方向接近（0.949），猫和汽车正交（0）。

### 4.4 为什么 embedding 检索用它

文本/图像 embedding 的检索流程本质是：把查询和候选都映成高维向量，然后**按余弦相似度排序**。用余弦而不是点积的原因：点积会偏爱**长向量**（一个范数很大的向量跟谁点积都大），余弦先归一化长度、只看方向。工程实现上有个关键优化（**经验做法**）：预先把所有候选做 $\ell_2$ 归一化（`v / np.linalg.norm(v)`），之后余弦相似度就退化为一次矩阵乘法 $\cos \approx X_{\text{norm}} \cdot \mathbf{q}_{\text{norm}}$，GPU/BLAS 上一次 `@` 就能对百万级候选排序。

```python
def cosine(u, v):
    return float(u @ v / (np.linalg.norm(u) * np.linalg.norm(v)))

cat   = np.array([2.0, 1.0])
dog   = np.array([1.0, 1.0])
car   = np.array([-1.0, 2.0])
print(cosine(cat, dog))  # 0.9486832980505138  = 3/sqrt(10)
print(cosine(cat, car))  # 0.0                 正交
print(cosine(cat, -dog)) # -0.9486832980505138 反向

# 批量检索：先归一化，再点积
docs = np.array([cat, dog, car])           # 3 个候选
docs_n = docs / np.linalg.norm(docs, axis=1, keepdims=True)
q = cat / np.linalg.norm(cat)
print(docs_n @ q)        # [0.9487, 0.9487, 0.0]——一次 matmul 完成检索打分
```

（注意这个 2 维玩具例子里猫狗恰好等分；真实 embedding 是几百维，方向分辨率高得多。）

## 5. NumPy 实操清单

本系列反复用到的向量操作，一次列全：

```python
import numpy as np

x = np.array([3.0, -1.0, 2.0])
y = np.array([1.0, 4.0, -2.0])

np.dot(x, y)             # 点积（1D 等价于 x @ y）
x @ y                    # 同上，推荐写法
np.linalg.norm(x)        # L2 范数，默认 ord=2
np.linalg.norm(x, 1)     # L1 范数 = 6.0
np.linalg.norm(x, np.inf)# L∞ 范数 = 3.0
np.outer(x, y)           # 外积：3x3 矩阵，u v^T——02/13 篇的主角
np.cross(x[:2], y[:2])   # 叉积（仅 2D/3D 有定义）
np.linalg.norm(x - y)    # 欧氏距离（L2）
np.sum(x > 0)            # 非负分量个数——向量的"逻辑"用法

# 常见陷阱：1D 数组没有行/列之分
print(x.shape)           # (3,)  ——既不是 (3,1) 也不是 (1,3)
print(x[:, None].shape)  # (3,1) 手动变列向量
print(x[None, :].shape)  # (1,3) 手动变行向量
```

**经验做法**：在 NumPy/PyTorch 之间搬运代码时，绝大多数 shape 报错源于 1D 向量与 `(n,1)` 列向量混用。本系列的约定：数学推导里向量是列向量，代码里用 1D 数组，需要矩阵乘法时显式用 `[:, None]` 变形。

## 本篇小结

- 向量有两重身份：**一列数**（代数，可计算）与**一支箭头**（几何，可想象），工程上要来回切换。
- 线性组合 = 缩放 + 相加；张成空间回答"这几个向量能覆盖多大的世界"；线性相关意味着存在冗余，这正是压缩与降维的立足点。
- 三种范数三种性格：L2 偏心（罚大分量）、L1 公平（产生稀疏，几何原因是菱形尖角在坐标轴上）、L∞ 只看短板。
- 点积 = 逐位乘和 = 长度×长度×夹角余弦。余弦相似度剥掉长度只看方向，是 embedding 检索的打分函数；工程上先 $\ell_2$ 归一化再 `@` 一次完成批量检索。
