03 章 DP 的局限是"需要环境模型"。MC 与 TD 共同迈出那一步：**不需要 $P$，直接从经验中学习值函数**（model-free prediction，Sutton & Barto, 2nd ed., 第 5–6 章）。它们的全部区别只在一件事上：**用什么当"真值"去修正当前估计**。

## 1. 蒙特卡洛：等回合结束算总账

**思想**：值函数的定义是回报的期望。那就按定义来——采样完整回合，实测一次回报 $G_t$，用它更新估计（Sutton & Barto, 2nd ed., §5.1）：

$$V(s_t) \leftarrow V(s_t) + \alpha\left[G_t - V(s_t)\right]$$

$G_t - V(s_t)$ 叫 **MC 误差**：实测回报与当前估计之差。这是最朴素的"样本均值"思想。

### 1.1 首访 vs 每次访问

一个回合里同一状态可能出现多次。两种记账口径（Sutton & Barto, 2nd ed., §5.1）：

- **首次访问 MC**：每回合中每个状态只用**第一次**出现时的回报更新；
- **每次访问 MC**：每次出现都更新。

两者都收敛到 $V^\pi$（首访 MC 收敛证明简单：独立同分布样本的均值；每次访问 MC 收敛到同一极限但形式更绕，Singh & Sutton, 1996）。实现上首访版用"倒序算 $G_t$ + 已访问集合"最省事。

### 1.2 增量式均值：每步 $O(1)$ 更新

均值的标准式 $Q_n = \frac{1}{n}\sum_{i=1}^n r_i$ 需要存全部历史；展开重排得到增量式（Sutton & Barto, 2nd ed., §2.4，02 章已用过）：

$$\mu_n = \mu_{n-1} + \frac{1}{n}(r_n - \mu_{n-1})$$

一般化 $\frac{1}{n} \to \alpha$（固定步长）就是所有 RL 更新的通式 $V \leftarrow V + \alpha(\text{目标} - V)$。**"目标 − 当前估计"这个残差结构在 RL 里无处不在**：MC 误差、TD 误差、优势函数、DQN 的 Huber 损失、PPO 的 ratio 目标全是它的变体。

## 2. TD(0)：每一步都学习

### 2.1 更新式与"自举"

MC 必须等回合结束才知道 $G_t$。时序差分（Temporal-Difference，Sutton, 1988, *Machine Learning*；Sutton & Barto, 2nd ed., §6.1–6.2）说：**用"立即奖励 + 下一状态的当前估计"当目标**：

$$V(s_t) \leftarrow V(s_t) + \alpha\left[\,r_{t+1} + \gamma V(s_{t+1}) - V(s_t)\,\right]$$

其中：

$$\delta_t = r_{t+1} + \gamma V(s_{t+1}) - V(s_t) \quad \text{（TD 误差）}$$

关键性质：$r_{t+1} + \gamma V(s_{t+1})$ 是 $V^\pi(s_t)$ 的**有偏估计**（$V(s_{t+1})$ 自己就是个近似值），但方差小得多——只涉及一步随机性（一个转移），而 $G_t$ 涉及整条轨迹所有随机性（Sutton & Barto, 2nd ed., §6.2 末尾的讨论；Guez et al., 2018 给出了系统分析）。**用估计值更新估计值**这件事叫**自举（bootstrapping）**——名字借自统计学，含义就是"自己拉自己的鞋带把自己提起来"。

### 2.2 TD 误差：预测的"逐期修正量"

对 TD 误差求和有一个漂亮的恒等式（gamma=1 无折扣时最直观）：

$$G_t - V(s_t) = \delta_t + \gamma\delta_{t+1} + \gamma^2\delta_{t+2} + \cdots + \gamma^{T-t-1}\delta_{T-1}$$

即 **MC 误差 = 整条轨迹 TD 误差的折扣和**（Sutton & Barto, 2nd ed., 式 6.5）。这说明 MC 与 TD 不是两个世界，而是同一条光谱的两个端点：MC = 用全部未来的 TD 误差修正一次，TD(0) = 每一步只修正一步。n-step 方法（§4）就是中间的任意切点。08 章 GAE 的 $\lambda$ 参数会把这个光谱参数化。

## 3. 收敛实验：5 状态随机游走

### 3.1 实验设定

一排 5 个非终止状态 $1..5$，两端是终止（左端奖励 0、右端奖励 +1），随机策略等概率左右走，$\gamma=1$。理论真值可解析：$V^*(i) = i/6$（等价于"从状态 $i$ 出发先撞到右端的概率"，Sutton & Barto 例 6.2 的迷你版）。起点取中央状态 3。

```python
import numpy as np

def true_V():
    return np.array([i / 6.0 for i in range(1, 6)])   # [0.167 0.333 0.5 0.667 0.833]

def episode_random(rng):
    """随机策略采样一条完整轨迹，返回 [(s, r), ...]，含终止奖励"""
    s = 3
    traj = []
    while True:
        a = rng.choice([-1, 1])
        ns = s + a
        r = 1.0 if ns == 6 else 0.0
        traj.append((s, r))
        s = ns
        if s in (0, 6):
            return traj

def mc_first_visit(n_episodes=200, alpha=0.1, seed=0):
    rng = np.random.default_rng(seed)
    V = np.full(5, 0.5)
    rms = []
    for ep in range(n_episodes):
        traj = episode_random(rng)
        G, visited = 0.0, set()
        for s, r in reversed(traj):          # 倒序：先算 G 再记账
            G = r + G                        # gamma = 1
            if s not in visited:             # 首访口径
                visited.add(s)
                V[s - 1] += alpha * (G - V[s - 1])   # 增量式均值
        rms.append(np.sqrt(np.mean((V - true_V()) ** 2)))
    return V, np.array(rms)

def td0(n_episodes=200, alpha=0.1, seed=0):
    rng = np.random.default_rng(seed)
    V = np.full(5, 0.5)
    rms = []
    for ep in range(n_episodes):
        s = 3
        while s not in (0, 6):
            a = rng.choice([-1, 1])
            ns = s + a
            r = 1.0 if ns == 6 else 0.0
            target = r + (0.0 if ns in (0, 6) else V[ns - 1])  # 终止状态值 0
            V[s - 1] += alpha * (target - V[s - 1])            # TD(0) 更新
            s = ns
        rms.append(np.sqrt(np.mean((V - true_V()) ** 2)))
    return V, np.array(rms)

V_mc, _ = mc_first_visit(alpha=0.01, seed=0)
V_td, _ = td0(alpha=0.01, seed=0)
print("真值:     ", np.round(true_V(), 3))
print("MC  估计: ", np.round(V_mc, 3))
print("TD0 估计: ", np.round(V_td, 3))
```

运行结果（200 回合、$\alpha=0.01$、种子固定）：

```text
真值:      [0.167 0.333 0.5   0.667 0.833]
MC  估计:  [0.209 0.396 0.447 0.654 0.809]
TD0 估计:  [0.193 0.326 0.494 0.657 0.824]
```

两种方法都逼近真值，但逐状态看：TD(0) 的估计误差（0.026, 0.007, 0.006, 0.010, 0.009）整体小于 MC（0.042, 0.063, 0.053, 0.013, 0.024）——**同一回合数下 TD 信息利用效率更高**。

### 3.2 学习曲线：100 次运行平均 RMS

单次运行噪声大（RL 方法论：必须多运行平均），跑 100 个独立种子：

```python
def avg_rms(algo, alpha, n_runs=100, n_episodes=200):
    total = np.zeros(n_episodes)
    for run in range(n_runs):
        _, rms = algo(n_episodes=n_episodes, alpha=alpha, seed=run)
        total += rms
    return total / n_runs

a_mc1 = avg_rms(mc_first_visit, 0.1)
a_td1 = avg_rms(td0, 0.1)
a_mc01 = avg_rms(mc_first_visit, 0.01)
a_td01 = avg_rms(td0, 0.01)
for ep in [0, 9, 49, 99, 199]:
    print(f"第{ep+1:4d}回合: MC(a=.1)={a_mc1[ep]:.4f} TD0(a=.1)={a_td1[ep]:.4f} | "
          f"MC(a=.01)={a_mc01[ep]:.4f} TD0(a=.01)={a_td01[ep]:.4f}")
```

真实运行结果（100 次运行平均）：

```text
第   1回合: MC(a=.1)=0.2256 TD0(a=.1)=0.2222 | MC(a=.01)=0.2344 TD0(a=.01)=0.2343
第  10回合: MC(a=.1)=0.1516 TD0(a=.1)=0.1289 | MC(a=.01)=0.2219 TD0(a=.01)=0.2220
第  50回合: MC(a=.1)=0.0958 TD0(a=.1)=0.0557 | MC(a=.01)=0.1741 TD0(a=.01)=0.1746
第 100回合: MC(a=.1)=0.0903 TD0(a=.1)=0.0540 | MC(a=.01)=0.1289 TD0(a=.01)=0.1285
第 200回合: MC(a=.1)=0.0905 TD0(a=.1)=0.0554 | MC(a=.01)=0.0719 TD0(a=.01)=0.0684
```

三个可复现的结论：

1. **$\alpha=0.1$ 时 TD 全面更快**：第 10 回合 TD 已到 0.129，MC 要到 50 回合才到 0.096；且 TD 的稳态残差（≈0.055）低于 MC（≈0.090）。
2. **$\alpha=0.01$ 时前期两者打平**，200 回合后 MC（0.0719）反而略低于 TD（0.0684 前）的差距缩小——小步长下 MC 的"无偏"开始显现，这与 Sutton & Barto 图 6.2 的形态一致。
3. **$\alpha=0.1$ 下两者都停在"噪声地板"**（不降到 0）：固定步长 $\alpha$ 的稳态误差由 $\alpha$ 与轨迹噪声方差共同决定（$\text{floor} \sim \sqrt{\alpha \cdot \text{Var}}$ 量级），想真正归零需要 $\alpha$ 衰减（Sutton & Barto, 2nd ed., §2.4/§2.5 关于非常数 $\alpha$ 收敛条件的讨论）。

| 维度 | MC | TD(0) |
| --- | --- | --- |
| 目标 | 实测 $G_t$（真回报） | 自举 $r + \gamma V(s_{t+1})$ |
| 偏差 | 无偏（$G_t$ 是 $V^\pi$ 的无偏样本） | 有偏（依赖 $V$ 的当前误差） |
| 方差 | 高（整条轨迹所有随机性） | 低（只一步转移的随机性） |
| 数据效率 | 低（必须等回合结束） | 高（在线、每步更新） |
| 适用 | 必须有终止（episodic） | terminating 与 continuing 都行 |
| 收敛 | $\alpha$ 满足 Robbins-Monro 条件收敛 | 收敛到 $V^\pi$（表格、策略固定） |

## 4. n-step 与资格迹：光谱的参数化

### 4.1 n-step TD

把"1 步自举"推广成"n 步自举"（Sutton & Barto, 2nd ed., §7.1）：

$$G_t^{(n)} = r_{t+1} + \gamma r_{t+2} + \cdots + \gamma^{n-1} r_{t+n} + \gamma^n V(s_{t+n})$$

$$V(s_t) \leftarrow V(s_t) + \alpha\left[G_t^{(n)} - V(s_t)\right]$$

$n=1$ 就是 TD(0)，$n=\infty$（到回合尾）就是 MC。**n 是偏差-方差旋钮**：n 越大越接近 MC（偏差小、方差大），越小越接近 TD（偏差大、方差小）。经验上 $n \in [3, 8]$ 常常是甜点区——偏差刚引入一点，方差已经砍掉一大截（"经验做法"，具体最优值随任务变）。

### 4.2 资格迹 TD($\lambda$)（概念）

n-step 有个工程缺陷：要同时维护 n 个估计、且更新 $G_t^{(n)}$ 需要往后看 n 步。**资格迹（eligibility traces）**用"向前看"替代"向后看"（Sutton & Barto, 2nd ed., §7.2–7.5；Sutton 1988 原始提出）：

- 每个状态维护一个迹值 $e(s) \in [0,1]$：被访问时 $e(s) \leftarrow 1$，每步衰减 $e(s) \leftarrow \gamma\lambda e(s)$；
- 每步收到 $\delta_t$ 后，对所有状态按 $V(s) \leftarrow V(s) + \alpha\, \delta_t\, e(s)$ 一次更新。

$\lambda \in [0,1]$ 是指数加权参数：$\lambda=0$ 退化为 TD(0)，$\lambda \to 1$ 近似 MC（但在线、增量，且对 episodic/continuing 都适用）。**"最近访问的状态责任更大"——迹就是信用分配的指数衰减记忆**。深度 RL 里 $\lambda$ 以另一种面貌出现：08 章 GAE 的 $\lambda$ 与资格迹在数学上等价（对优势估计做指数加权），09 章 PPO 默认 $\lambda=0.95$ 就是它的现代继承者。

## 5. 常见误区

1. **用 MC 处理没有终止的任务。** continuing 任务没有"回合结束"，$G_t$ 无穷长——MC 直接不可用。症状：跑了很久每个状态的 $V$ 还在慢速漂移，因为"总账"永远没算完。TD 无此限制（这也是 TD 在工程上占主导的原因之一）。
2. **自举 + 函数近似 + off-policy 三件套直接叠加**（Deadly Triad，Sutton & Barto, 2nd ed., §11.3 的命名）。本章任务里三者最多出现一件，所以 TD(0) 收敛良好；06 章 DQN 里三者全齐，不稳定性就成为默认现象。现在记住结论即可：**见到 off-policy TD + 函数近似，先怀疑发散**。
3. **首访 MC 的实现顺序错误。** 必须倒序先算 $G_t$ 再判"首访"；正序遍历时你拿不到 $G_t$（不知道未来），很多人在这里直接用了 $r_t$ 当 $G_t$——更新方向全错。症状：值收敛到的不是 $V^\pi$ 而是某个"即时奖励场"。
4. **$\alpha$ 固定不衰减，然后困惑"为什么误差停在 0.05 不动了"。** 本章 §3.2 结论 3 就是这个现象的实测。表格法可以让 $\alpha_n = 1/N(s)$（严格均值）归零；函数近似/深度 RL 里固定小步长 + 噪声地板是常态，评估指标要允许噪声带。
5. **TD 的 target 忘记"终止状态值为 0"。** `target = r + gamma * V[next]` 在 $s_{t+1}$ 是终止状态时应为 `target = r`。本章代码用 `0.0 if ns in (0,6) else V[ns-1]` 处理；DQN 里它变成 `(1 - terminated)` 乘法因子（06 章）。这是 RL 实现出现率第一的 bug。

## 本篇小结

- MC 按定义学：用实测回报 $G_t$ 更新，无偏但高方差、必须 episodic；TD 自举：用 $r + \gamma V(s')$ 更新，有偏但低方差、在线增量。两者是同一条光谱的端点。
- 增量式均值 $\mu_n = \mu_{n-1} + \frac{1}{n}(r_n - \mu_{n-1})$ 及其 $\alpha$ 推广是所有 RL 更新的通用外壳："目标 − 估计"残差结构贯穿全系列。
- TD 误差 $\delta_t$ 是基本货币：MC 误差 = 折扣 TD 误差之和；05/08/09 章的优势函数、GAE 全部建立在 $\delta$ 上。
- n-step 与资格迹 TD($\lambda$) 把光谱参数化；工程甜点在中间（n=3–8 或 $\lambda=0.9\text{–}0.97$）。
- 实验结论（100 运行平均）：$\alpha=0.1$ 时 TD 每个阶段都快于 MC 且稳态残差更低（0.055 vs 0.090）；固定步长存在噪声地板。
- 下一章把"值函数怎么学"变成"策略怎么改进"：Q-learning 与 SARSA。

## 练习

1. 把 §3.1 的 `mc_first_visit` 改成每次访问 MC（去掉 visited 集合），100 运行平均对比两者收敛曲线。理论上两者极限相同，你观察到差异了吗？在哪个阶段？
2. 实现 n-step TD（n=1, 2, 4, 8, 完整回合）在随机游走上的版本，100 运行平均画 RMS 曲线族。验证"n 增大 → 早期更慢（偏差小但方差大）"还是相反，并解释。
3. $\alpha$ 衰减实验：MC 用 $\alpha_n = 1/N(s)$（每个状态的访问计数分之一），验证误差能持续降到接近 0；对比固定 $\alpha=0.01$ 的噪声地板。
4. 手算：轨迹 $(s_1, 0), (s_2, 0), (s_3, +1)$ 终止，$V_0(s_i)=0.5$，$\gamma=1$，$\alpha=0.1$。分别用 MC（一次性更新 $s_1$）与 TD(0)（逐步更新）计算 $V_1(s_1)$，并验证"MC 误差 = TD 误差之和"恒等式。
5. 思考题：为什么"TD 收敛更快"和"MC 无偏"两者可以同时为真而不矛盾？（提示：快慢取决于更新信号的方差与可用时机，无偏性是关于估计期望的性质；TD 偏差在 $V \to V^\pi$ 时趋于 0。）
