动态规划（DP）假设环境模型 $P(s'|s,a)$ 与 $R$ 完全已知。听起来"作弊"，但它是唯一能**看清算法骨架**的入口：没有采样噪声干扰，每一步更新在数学上做什么一目了然。Sutton & Barto (2nd ed.) 第 4 章整章就干这一件事。

## 1. 贝尔曼方程：把"未来"折进"现在"

### 1.1 状态值函数与动作值函数

**状态值函数** $V^\pi(s)$：从状态 $s$ 出发、一直按策略 $\pi$ 行动的期望回报（Sutton & Barto, 2nd ed., §3.5）：

$$V^\pi(s) = \mathbb{E}_\pi[G_t \mid s_t = s]$$

**动作值函数** $Q^\pi(s,a)$：在 $s$ 先执行动作 $a$、之后按 $\pi$ 行动的期望回报：

$$Q^\pi(s,a) = \mathbb{E}_\pi[G_t \mid s_t = s, a_t = a]$$

两者通过策略互相换算：$V^\pi(s) = \sum_a \pi(a|s) Q^\pi(s,a)$。值函数是 RL 的"地图"——有了它，策略就退化为"站在每个路口选值最高的方向"。

### 1.2 贝尔曼期望方程推导（分步）

起点是 01 章留下的递归式 $G_t = r_{t+1} + \gamma G_{t+1}$。对它取条件期望：

$$V^\pi(s) = \mathbb{E}_\pi[G_t \mid s_t=s] = \mathbb{E}_\pi\left[r_{t+1} + \gamma G_{t+1} \mid s_t=s\right] = \mathbb{E}_\pi[r_{t+1} \mid s_t=s] + \gamma\, \mathbb{E}_\pi[G_{t+1} \mid s_t=s]$$

第一项是"立即奖励的期望"；第二项的关键动作是把联合期望拆成"对动作求期望 → 对下一状态求期望"（全期望公式）：

$$\mathbb{E}_\pi[G_{t+1} \mid s_t=s] = \sum_a \pi(a|s) \sum_{s'} P(s'|s,a)\, V^\pi(s')$$

合并得到**贝尔曼期望方程**（Sutton & Barto, 2nd ed., 式 4.4）：

$$\boxed{V^\pi(s) = \sum_a \pi(a|s) \sum_{s'} P(s'|s,a)\left[R(s,a) + \gamma V^\pi(s')\right]}$$

直觉解读：**"当前状态的值 = 各动作的（立即奖励 + 折扣后的下一状态值）按策略加权的平均"**。它把 $V^\pi$ 定义成一个线性方程组：$|S|$ 个方程、$|S|$ 个未知数，理论上可以解析求解——但 $|S|$ 稍大就不可行（$10^6$ 状态的矩阵求逆是 $10^{18}$ 量级运算），所以 DP 用**迭代法**解它。

同理，对 $Q$ 写出贝尔曼期望方程，并对策略取 max，得到**贝尔曼最优方程**（Sutton & Barto, 2nd ed., 式 4.9）：

$$V^*(s) = \max_a \sum_{s'} P(s'|s,a)\left[R(s,a) + \gamma V^*(s')\right]$$

注意两处差别：平均（$\sum_a \pi$）换成了 max，$\pi$ 消失了——最优解不依赖策略。非线性（max）意味着最优值函数对应**确定性贪心策略**即最优。

## 2. 实验环境：4×4 GridWorld

约定一个贯穿本章的环境（Sutton & Barto, 2nd ed., §4.1 图 4.1 的同款）：

```python
import numpy as np

class GridWorld:
    """4x4 网格：起点左上，终点右下。
    动作: 0=上 1=右 2=下 3=左；每走一步奖励 -1；撞墙留在原地；终点即回合结束。"""
    def __init__(self, n=4):
        self.n = n
        self.terminal = {(n-1, n-1)}

    def step(self, s, a):
        r, c = s
        if a == 0:   r = max(r - 1, 0)
        elif a == 1: c = min(c + 1, self.n - 1)
        elif a == 2: r = min(r + 1, self.n - 1)
        elif a == 3: c = max(c - 1, 0)
        return (r, c), -1.0        # 转移是确定的：P(s'|s,a)=1

    def is_terminal(self, s):
        return s in self.terminal

env = GridWorld(4)
print(env.step((2, 3), 1))   # ((3, 3), -1.0)：从(2,3)向右走到终点，奖励-1
print(env.step((0, 0), 0))   # ((0, 0), -1.0)：向上撞墙，留在原地
```

运行结果：

```text
((3, 3), -1.0)
((0, 0), -1.0)
```

最优行为很明显（走曼哈顿最短路，6 步到终点），但它能验证我们的算法有没有算对。

## 3. 策略评估：给定策略算值

**问题**：给定 $\pi$，求 $V^\pi$。做法是把贝尔曼期望方程当作**更新规则反复迭代**（Sutton & Barto, 2nd ed., §4.1）：

$$V_{k+1}(s) = \sum_a \pi(a|s) \sum_{s'} P(s'|s,a)\left[R + \gamma V_k(s')\right]$$

$\{V_k\}$ 收敛到 $V^\pi$ 的保证来自压缩映射：$|S|$ 有限时该算子是 $\gamma$-压缩，误差以 $\gamma^k$ 几何速度衰减（Banach 不动点定理）。实现里用 $\delta = \max_s |V_{k+1}(s) - V_k(s)| < \theta$ 做停止条件。

```python
def policy_evaluation(env, policy, gamma=1.0, theta=1e-4, max_iter=1000, verbose=False):
    """policy: shape (n, n, 4)，每个状态的动作概率分布
       返回 (V, 收敛所用 sweep 数)。sweep = 一轮全状态扫描"""
    n = env.n
    V = np.zeros((n, n))                     # V_0 = 0，终点值恒为 0
    for sweep in range(max_iter):
        delta = 0.0
        for r in range(n):
            for c in range(n):
                if env.is_terminal((r, c)):
                    continue                 # 终止状态没有"未来"，值恒 0
                v_old = V[r, c]
                v_new = 0.0
                for a, pa in enumerate(policy[r, c]):
                    ns, rew = env.step((r, c), a)
                    v_new += pa * (rew + gamma * V[ns])   # 贝尔曼期望更新
                V[r, c] = v_new
                delta = max(delta, abs(v_old - v_new))
        if verbose and sweep in (0, 1, 2, 3, 10, 20, 50, 100, 200):
            print(f"  sweep {sweep:4d}: delta={delta:.6f}")
        if delta < theta:
            return V, sweep + 1
    return V, max_iter

n = 4
env = GridWorld(n)
policy = np.full((n, n, 4), 0.25)            # 均匀随机策略（四方向等概率）
V, sweeps = policy_evaluation(env, policy, gamma=1.0, theta=1e-4, verbose=True)
print(f"收敛用了 {sweeps} 次 sweep")
print("均匀随机策略的 V^pi (gamma=1):")
print(np.round(V, 1))
```

这个矩阵与 Sutton & Barto 图 4.1 一致。读图三件事：

1. 值全为负——随机策略会撞墙、兜圈子，从左上角期望要吃 **59.4 步惩罚**才能到终点（对比最优 6 步）。
2. 值从终点向外**单调变差**——信息从终止状态沿更新规则"逆流而上"，每轮 sweep 传播一格。这就是 **backup 图**的物理意义：值从后继向前回灌。
3. 收敛速度受两点控制：$\gamma$（越小收敛越快）与**信息传播距离**（离终点越远的状态越晚获得准确值，sweep 数 ≥ 最短路径长度）。

> **经验做法**：就地更新（Gauss-Seidel，改完立刻用）与双缓冲更新（Jacobi，一轮内用旧表）结果相同，但就地更新**收敛更快**——本例 312 vs 471 sweeps，快 34%。原因是新信息当轮就用上了。表格法就这么写；深度 RL 里的 target 网络反而是刻意禁止就地更新（06 章）。

## 4. 策略迭代：评估与改进交替

**想法**（Sutton & Barto, 2nd ed., §4.3）：知道 $V^\pi$ 后，可以做**策略改进定理**（policy improvement theorem）保证不亏的一步——对每个状态贪心化：

$$\pi'(s) = \arg\max_a \sum_{s'} P(s'|s,a)[R + \gamma V^\pi(s')]$$

改进定理保证 $V^{\pi'} \ge V^\pi$（逐状态），且只有当 $\pi' = \pi$ 时才取等。于是"评估 → 改进"循环：值单调上升，策略最多 $|S|$ 种有限，必然终止于最优策略 $\pi^*$。

```python
def policy_iteration(env, gamma=1.0, theta=1e-4, max_iter=100):
    n = env.n
    P = np.zeros((n, n), dtype=int)          # 初始策略：全部"向上"（0）
    for it in range(max_iter):
        # ---- 评估：把当前策略的 V 算准（确定性策略只需每次取一个动作）----
        V = np.zeros((n, n))
        for sweep in range(1000):
            delta = 0.0
            for r in range(n):
                for c in range(n):
                    if env.is_terminal((r, c)): continue
                    ns, rew = env.step((r, c), P[r, c])
                    v_new = rew + gamma * V[ns]
                    delta = max(delta, abs(V[r, c] - v_new))
                    V[r, c] = v_new          # 就地更新
            if delta < theta:
                break
        # ---- 改进：逐状态贪心 ----
        stable = True
        for r in range(n):
            for c in range(n):
                if env.is_terminal((r, c)): continue
                old = P[r, c]
                qs = [env.step((r, c), a)[1] + gamma * V[env.step((r, c), a)[0]]
                      for a in range(4)]
                P[r, c] = int(np.argmax(qs))
                if P[r, c] != old:
                    stable = False
        print(f"  第 {it+1} 轮: 策略{'已稳定' if stable else '仍有改动'}")
        if stable:
            return V, P, it + 1
    return V, P, max_iter

env = GridWorld(4)
V, P, rounds = policy_iteration(env, gamma=1.0)
arrows = {0: '↑', 1: '→', 2: '↓', 3: '←'}
print(f"策略迭代收敛，共 {rounds} 轮（评估+改进）")
for r in range(4):
    print(" ".join(arrows[P[r, c]] if (r, c) not in env.terminal else 'T'
                   for c in range(4)))
```

最优策略图上每个状态都指向"离终点更近"的方向（次对角线上的状态有两个等价选择，argmax 取先到者）。注意 7 轮 > 理论最少轮数：初始"全向上"策略里有死循环（顶部一行向上撞墙永远走不到终点，$\gamma=1$ 下评估值发散为 $-1000$ 量级才被截断），改进定理仍然把它逐步拉了回来——**策略迭代对糟糕的初始策略极其鲁棒**，这是它理论上的最大优点。

## 5. 值迭代：把两步压成一步

策略迭代的问题是**每次改进前都要把 $V$ 评估到收敛**（本例一个确定性策略要上百次 sweep，随机策略 312 次）。值迭代（value iteration，Sutton & Barto, 2nd ed., §4.4）说：何必等？**改进定理不需要精确的 $V^\pi$，方向对了就行**——把"评估的贝尔曼期望更新"直接换成"max 版本"，一轮顶一轮：

$$V_{k+1}(s) = \max_a \sum_{s'} P(s'|s,a)\left[R + \gamma V_k(s')\right]$$

这等于"每次只做一次评估 sweep 就改进"的策略迭代极限压缩，仍收敛到 $V^*$（max 算子依然是 $\gamma$-压缩）。

```python
def value_iteration(env, gamma=1.0, theta=1e-4, max_iter=1000, verbose=False):
    n = env.n
    V = np.zeros((n, n))
    for sweep in range(max_iter):
        delta = 0.0
        for r in range(n):
            for c in range(n):
                if env.is_terminal((r, c)): continue
                v_old = V[r, c]
                q_vals = [env.step((r, c), a)[1] + gamma * V[env.step((r, c), a)[0]]
                          for a in range(4)]
                V[r, c] = max(q_vals)          # 唯一差别：sum 换 max
                delta = max(delta, abs(v_old - V[r, c]))
        if verbose and sweep in (0, 1, 2, 3, 5, 7):
            print(f"  sweep {sweep:4d}: delta={delta:.6f}")
        if delta < theta:
            return V, sweep + 1
    return V, max_iter

def greedy_policy_from_V(env, V, gamma=1.0):
    """从 V* 一次性提取贪心策略（值迭代结束后只做一次）"""
    n = env.n
    P = np.zeros((n, n), dtype=int)
    for r in range(n):
        for c in range(n):
            if env.is_terminal((r, c)): continue
            qs = [env.step((r, c), a)[1] + gamma * V[env.step((r, c), a)[0]]
                  for a in range(4)]
            P[r, c] = int(np.argmax(qs))
    return P

env = GridWorld(4)
V, sweeps = value_iteration(env, gamma=1.0, theta=1e-4, verbose=True)
print(f"值迭代收敛用了 {sweeps} 次 sweep")
print("最优值 V*:")
print(np.round(V, 1))
P = greedy_policy_from_V(env, V)
arrows = {0: '↑', 1: '→', 2: '↓', 3: '←'}
for r in range(4):
    print(" ".join(arrows[P[r, c]] if (r, c) not in env.terminal else 'T'
                   for c in range(4)))
```

对比读数：值迭代 **7 次 sweep** vs 策略迭代 7 轮（每轮含几十上百次评估 sweep）——总计算量差一个数量级以上。$V^*$ 矩阵本身就是答案的另一种写法：左上角 $-6$ = 最短 6 步 × 每步 $-1$，且从任意状态出发的最短步数可以直接从表里读出来。注意 sweep 0–5 的 $\delta$ 恒为 1.0——$\delta=1$ 说明"有状态的最短距离记录还在缩短一格"，直到第 7 轮所有状态的最短路都被打通后 $\delta$ 骤降。这个现象在更大网格上会更明显：**值迭代的收敛台阶由"信息传播距离"决定**。

策略迭代 vs 值迭代怎么选？策略迭代每轮贵但轮数少（值函数精确）；值迭代每轮便宜但轮数多。中间还有"截断式策略迭代"（评估只跑几轮就改进）——三者其实是同一个光谱上的三个点，这就引出 GPI。

## 6. 广义策略迭代（GPI）：全系列的总纲

广义策略迭代（generalized policy iteration，Sutton & Barto, 2nd ed., §4.6）：**几乎全部 RL 算法 = 一个近似值函数 + 一个近似策略 + 两条互相拉扯的更新线**：

```text
        值函数线（评估）              策略线（改进）
   V ────────────────→ 逼近 V^π    π ────────────→ 相对 V 贪心
        ↑    两条线互相拉动，值与策略       │
        └────── 轮流修正对方，直到 ─────────┘
                二者一致 → 最优 (V*, π*)
```

两条线谁也不等谁：值函数线不等策略定准，策略线不等值函数评估完。**只要两条线互相"把对方往自己的最优方向拉"，且都有不动点，最终就会相遇在 $(V^*, \pi^*)$**——这正是"广义"的含义。

用这把尺子量全系列（也是本系列的组织逻辑）：

| 算法 | 评估线 | 改进线 | GPI 位置 |
| --- | --- | --- | --- |
| 策略迭代 | 评估到收敛 | 每轮贪心 | 两个极端 |
| 值迭代 | 不显式评估 | max 内嵌 | 另一个极端 |
| MC（04 章） | 整条轨迹平均 | 隐式（ε-greedy） | 评估线拉长 |
| TD/Q-learning（04–05 章） | 单步自举 | 隐式/显式贪心 | 评估线压到 1 步 |
| DQN（06 章） | TD 自举 + 网络近似 | ε-greedy | 同上 + 函数近似 |
| Actor-Critic（08 章） | Critic 网络 | Actor 网络 | 两线各自网络化 |
| PPO（09 章） | 优势估计（GAE） | 裁剪后的策略梯度 | 值线弱、策略线强 |

看懂这张表，"新算法"就只是"GPI 两条线上换零件"。**经验做法**：拿到任何不认识的 RL 论文，先问三个问题——评估线用什么信号（MC/TD/n-step）？改进线怎么动（贪心/梯度）？两条线怎么防止互相拉崩（目标冻结/裁剪/信任域）？第三问就是 06/09 章的全部内容。

## 7. 为什么 DP 在现实中少用

三大原因（Sutton & Barto, 2nd ed., §4.5）：

1. **模型未知**。DP 需要 $P(s'|s,a)$ 显式给出。现实任务里这恰恰是最难拿到的东西：机器人不知道自己的物理参数，LLM 环境就是用户本人。→ 04 章起的无模型方法（MC/TD）直接从交互数据学，绕开 $P$。
2. **维度灾难**。计算量 $O(|S|^2 |A|)$ 起步、内存 $O(|S|)$。Backgammon 约 $10^{20}$ 状态，围棋 $10^{170}$——表格存不下，更新也跑不完。→ 06 章用神经网络做函数近似，$V(s;\theta)$ 只需网络参数量级的内存，还能泛化到没见过的状态。
3. **并行扫全表不现实**。DP 假设可以反复"扫"全部状态；真实 agent 只能沿轨迹访问极小部分状态。→ 04 章起的"沿轨迹更新"范式。

但 DP 没有白学：无模型方法的**更新公式长得一模一样**，只是把 $\sum_{s'} P(s'|s,a)(\cdot)$ 换成了"从真实交互里采一个 $(s', r)$"。这个替换叫**从期望到样本**（expectation → sample），是全系列最重要的抽象一步：样本是无偏的（单样本意义下），代价是方差——04 章的偏差-方差之争由此开场。

## 8. 常见误区

1. **$\theta$ 设得太小，误以为"不收敛"。** 迭代停止条件 $\delta < \theta$ 与数值精度强相关：$\gamma=1$、奖励量级大时 $\delta$ 收缩慢，312 sweeps 看着"还在动"其实是几何衰减的尾巴。先用对数刻度画 $\delta$ 随 sweep 的曲线再下结论。
2. **$\gamma=1$ + 不存在终止状态 = 不收敛。** 本章策略迭代 7 轮里，"全向上"初始策略在顶行形成死循环，评估值一路滑向 $-10^3$ 才被截断。排除方法：episodic 任务确认每个策略能以正概率到达终止状态；continuing 任务必须 $\gamma < 1$。
3. **终止状态被更新了。** 终止状态值必须恒为 0，否则奖励会计入"终止之后的假想未来"。实现上就是 `if is_terminal: continue`。这个 bug 的典型症状：$V$ 矩阵整体偏移一个常数，策略却"看似正确"——直到换成要求值精确对齐的任务才暴露。
4. **把值迭代的 $\delta$ 当作误差界直接信任。** $\delta < \theta$ 只保证 $V_k$ 自身变化小；对 $V^*$ 的真实误差约为 $\delta \cdot \gamma/(1-\gamma)$（压缩映射的误差传递）。$\gamma=0.99$ 时真实误差可能是 $\delta$ 的 99 倍——要求"真值误差 < 0.1"需要 $\theta \approx 0.001$。
5. **拿 GridWorld 的收敛速度外推到深度 RL。** 表格 DP 收敛又稳又快是因为没有采样噪声、没有函数近似误差。深度 RL 里同款更新公式配上神经网络和采样噪声后稳定性塌方（06 章 Deadly Triad）——不是公式错了，是它的两个收敛前提（精确表格 + 全状态期望）没了。

## 本篇小结

- 贝尔曼期望方程把 $V^\pi$ 定义为线性方程组；贝尔曼最优方程把 $V^*$ 定义为非线性方程组（max）。两者都是把"未来折进现在"的递归。
- 策略评估 = 迭代贝尔曼期望方程，收敛速度由 $\gamma$ 与信息传播距离决定；就地更新（Gauss-Seidel）比双缓冲快约 34%（312 vs 471 sweeps，本例实测）。
- 策略迭代 = 评估到收敛 + 贪心改进，单调收敛到 $\pi^*$，对烂初始化鲁棒但每轮评估昂贵（本例 7 轮）；值迭代 = max 一步到位，总计算量小一个量级（本例 7 sweeps）。
- GPI：一切 RL 算法 = 值线 + 策略线互相拉扯；后续每章都是这两条线的不同组合与保护机制。
- DP 的三个现实障碍（模型未知/维度灾难/无法扫全表）精确对应后续三章要解决的三个问题（无模型/函数近似/沿轨迹学习）。
