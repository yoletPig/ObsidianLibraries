## 1. 样本效率问题与 Model-Based RL

### 1.1 问题量化

model-free PPO/DQN 学一个 Atari 游戏 → 约 10⁸ 帧交互 ≈ 人类 40 年的游戏时间（Mnih et al. 2015 的数据口径）。人类几百局就上手——差距不在学习算法本身，而在**先验模型**：人自带物理直觉。样本效率（每条经验提取多少信息）是 model-free 的结构性短板：经验回放复用几次、GAE 压方差，都还是"被动消化"数据。

### 1.2 Dyna：学习世界模型，生成虚拟经验

**Dyna**（Sutton, 1990, *Machine Learning*——Sutton & Barto, 2nd ed., §8.2 的完整叙述）是最优雅的答案：在真实交互的间隙，用学到的模型 $\hat P, \hat R$ **幻想（hallucinate）**虚拟转移 $(s, a, \hat r, \hat s')$，对它们照常做表格更新：

```text
真实交互循环:   s, a → r, s'    → ① 更新 Q(s,a)   ② 更新模型 M(s,a)
幻想循环(N次):  随机取历史(s,a) → ③ 用 M 生成虚拟(r,s') → ④ 更新 Q(s,a)
```

每条真实经验被间接利用 $N+1$ 次（1 次直接 + N 次通过模型）——样本效率乘法级提升。风险：**模型学错 → 幻想的错数据污染 Q**（model bias），这是所有 model-based 方法的核心税。

### 1.3 MuZero：隐式模型 + 规划

**MuZero**（Schrittwieser et al., "Mastering Atari, Go, Chess and Shogi by Planning with a Learned Model", *Nature* 588, 2020）把这条线推到深度时代，三网络架构：

- **表示网络** $h$：观测 → 隐状态；
- **动态网络** $g$：隐状态+动作 → 下一个隐状态+即时奖励（**这就是学出来的世界模型**）；
- **预测网络** $f$：隐状态 → 策略与价值。

关键设计：**隐状态不需要重构真实观测**（对比 World Models 的生成式路线）——模型只需在"对价值/奖励预测有用"的维度上准确，把容量省给决策相关的信息。规划 = 在学习到的模型上做 MCTS 模拟搜索。AlphaZero 需要"上帝视角"规则模拟器（已知模型），MuZero 连模型一起学——**从"给定模型"到"学习模型"，正是 03 章 DP 到 04 章无模型的辩证再演一轮回，只是这次"模型"是学的**。

| 方法 | 模型来源 | 规划方式 | 代表成果 |
| --- | --- | --- | --- |
| DP（03 章） | 给定 $P, R$ | 策略/值迭代 | GridWorld 级 |
| Dyna | 表格学习 | 幻想经验 | 小状态空间 |
| AlphaZero | **给定**（游戏规则模拟器） | MCTS | 围棋/象棋超人类 |
| MuZero | **学习**（隐式） | 学到的模型上 MCTS | Atari/围棋统一 |

## 2. 离线 RL：为什么"直接用"会外推误差

### 2.1 问题设定

**离线 RL（batch RL）**：手里只有一个固定数据集（别人的策略采的日志，如历史交易记录、医疗病历、客服对话），训练期间**不允许再与环境交互**。这是工业界最现实的问题形态——很多环境根本不允许试错（医疗、金融、自动驾驶）。

朴素方案：在数据集上跑 Q-learning（off-policy，05 章），看似没问题——**但 max 算子专挑数据没覆盖的动作**。

### 2.2 最小可复现演示

单状态 4 动作，真实 $q^* = [-0.5, -0.5, -3.0, -3.0]$，数据集只含动作 0、1 的轨迹：

```python
import numpy as np
np.random.seed(0)

q_true = np.array([-0.5, -0.5, -3.0, -3.0])
data = [(a, np.random.normal(q_true[a], 0.5)) for a in [0, 1] for _ in range(100)]

Q = np.zeros(4)                    # 未覆盖动作保持初始估计（此处 0）
counts = np.zeros(4)
for a, r in data:                  # 只能更新见过的动作
    counts[a] += 1
    Q[a] += (r - Q[a]) / counts[a]

print("学到的 Q:", np.round(Q, 3))
print("argmax 动作:", int(np.argmax(Q)), " 真实值:", q_true[int(np.argmax(Q))])
```

真实运行结果：

```text
学到的 Q: [-0.47  -0.459  0.     0.   ]
argmax 动作: 2  真实值: -3.0
```

**agent 选择了从未见过的动作 2**：它的 $Q$ 值是残留的初始值 0（"外推"到数据没有支撑的区域），比数据充分学习的 −0.47 更"好看"。深度网络版更糟：神经网络对分布外输入的输出**不可控且系统性过于乐观**（外推误差，extrapolation error；Levine et al., "Offline Reinforcement Learning: Tutorial, Review, and Perspectives", arXiv:2005.01643 的核心论证）。

### 2.3 解法谱系（一句话原理）

- **策略约束**：把学到的策略"拴"在数据分布附近（BCQ、CQL——CQL 对分布外动作的 Q 值做悲观压低，"宁可高估数据内，不可乐观数据外"）；
- **悲观原则**（Pessimism）：显式给 OOD 动作的估计打折——离线 RL 的中心思想，与在线 RL 的乐观探索（UCB，02 章）**互为镜像**；
- **TD3+BC / IQL**：IQL 用 expectile 回归避开对 OOD 动作取 max（只评估数据内更好的动作）。

**经验做法**：拿到离线任务先问"数据集的覆盖度/质量如何"——数据是专家策略（窄而好）还是混合日志（宽而杂），决定选 BC（行为克隆）还是 Q-learning 系。数据覆盖差的离线 RL，效果上限常常就是 BC。

## 3. 课程学习与奖励塑形

### 3.1 潜基塑形（potential-based reward shaping）

**问题**：稀疏奖励（终局才有）时探索极难。加"引导性"中间奖励（离目标近一点给点分）能加速学习——但**随便加会改变最优策略**（agent 可能学会"刷塑形分"不达标）。

**定理**（Ng, Harada & Russell, "Policy invariance under reward transformations...", ICML 1999）：若塑形奖励写成**势函数差**形式

$$F(s, a, s') = \gamma \Phi(s') - \Phi(s)$$

则对所有 $\gamma$，加塑形后所有策略的回报**平移同一常数**，最优策略集合不变。直觉：$F$ 是"保守场"——沿任何闭环走一圈塑形奖励总和为 0，无法通过绕圈刷分。

3×3 GridWorld 实测（起点左上、终点右下，$\Phi(s) = -\text{曼哈顿距离}(s,\text{终点})$）：

```python
def value_iteration(n=3, shape_coef=0.0, gamma=0.99):
    # ... 与 03 章同款, 奖励改为: rew = -1 + shape_coef * (gamma*Phi(s') - Phi(s))
    ...

V0, P0, it0 = value_iteration(shape_coef=0.0)
V1, P1, it1 = value_iteration(shape_coef=1.0)
# 结果: 两者最优策略相同（都指向右下）, 塑形版收敛略快（4 vs 5 sweeps）
# 值的平移关系: V1(0,0) = 0.0596 = V0(0,0) - Phi(0,0) = -3.9404 + 4.0  ✓
```

实测：**最优策略完全一致**；值满足 $V'(s) = V(s) - \Phi(s)$ 的平移关系；塑形版收敛 sweep 数 4 < 5（信息从"每步都在变近"的塑形信号提前流遍）。在随机采样学习的场景（MC/TD），塑形对收敛速度的放大远比 DP 迭代明显——这个 GridWorld 太简单，只够验证"不变性"，速度优势要在稀疏奖励的探索型任务才看得出。

**工程口径**（经验做法）：$\Phi$ 通常取"到目标的启发式距离"或" learned value 的低配版"；RLHF 里的 KL 惩罚（10 章）从塑形视角看就是以 $-\beta \log(\pi/\pi_{ref})$ 的逐 token 势能塑形——同一定理保证它不改变"最优对齐目标"的结构。

### 3.2 课程学习

**课程学习**（curriculum learning，Bengio et al., ICML 2009 起源）：先易后难地安排训练任务分布。RL 里的三条实操路径：

1. **难度递增**：CartPole 先把 `max_episode_steps` 调小/重力调小，逐步恢复（参数化环境族）；
2. **自动课程**：按"当前成功率 50% 附近"选任务（AIM/PLR 思路——在学习信号最陡的任务区训练）；
3. **逆课程**：从终点状态回溯出发状态（"从失败点附近开始练"）。

**经验做法**：课程是把双刃剑——早期任务上过拟合的"坏习惯"（局部最优策略）会成为后期难点。判断标准：难度提升后回报是否在几千回合内恢复；持续不恢复说明课程步子太大或学到了伪策略。

## 4. 分层 RL 概览

**动机**：长时程任务（"去厨房倒杯水"）的信用分配跨越数千步，扁平策略学不动。**分层 RL（HRL）**把策略拆成层级：

- **高层策略**：低频决策，输出**子目标**（subgoal）；
- **低层策略**：高频执行，达成子目标后交还控制权。

代表思想各一句话：

- **Option 框架**（Sutton, Precup & Singh, "Between MDPs and semi-MDPs", AIJ 1999）：子策略 = (入口分布 π_I、内部策略 π、终止条件 β)，把 MDP 推广成半 MDP（SMDP）——值函数在"option 层"上迭代，时间步长变成"一次 option 的持续时长"；
- ** feudal 网络**（Vezhnevets et al., ICML 2017）：高层在隐空间设目标，低层朝目标输出动作，梯度分层回传；
- **HIR / HIRO**：低层学"到达子目标"，高层学"选子目标"，用潜变量目标绕开手工设计。

**与 08 章的连接**：Option 的终止条件 β 本质上是一个"每一时刻被中断的概率"——把 SMDP 的折扣换成 $\gamma^{\tau}$（τ 为 option 时长），GAE 的资格迹视角可以直接推广。HRL 至今没有统一的"SOTA 算法"，更多是问题结构的设计空间（**经验做法**：能用奖励塑形/课程解决的，不要上 HRL——复杂度预算留给真正的长时程结构）。

## 5. RL 在游戏之外的落地事实

盘点"已证明能超人类/已产生商业价值"的 RL 落地，注意它们共同的三个特征（§5.2 提炼）：

| 应用 | RL 角色 | 状态/动作空间 | 关键事实 |
| --- | --- | --- | --- |
| **AlphaGo / AlphaZero**（Silver et al., *Nature* 529/550, 2016/2018） | MCTS + 自我对弈策略改进 | 棋盘（规则已知的完美信息模型） | 2016 胜李世石；AlphaZero 从零自学统一围棋/国象/将棋 |
| **AlphaTensor**（Fawzi et al., *Nature* 610, 2022） | 单玩家游戏化：矩阵乘法分解 | 离散张量分解动作 | 发现 4×4 矩阵乘的 47 次乘法算法（此前最优 49） |
| **芯片布局**（Mirhoseini et al., *Nature* 594, 2021, Google） | PPO + 图嵌入，宏单元摆放 | 数千宏单元的连续+离散混合 | 数小时产出与人类数周相当的布局（论文口径；后续有复现争议，方法有效性部分成立） |
| **数据中心冷却**（DeepMind, 2016 报道） | 模型预测 + 控制优化 | 连续控制 | 报告冷却能耗降约 40%（运营口径，非同行评审） |
| **量化交易持仓** | 组合权重 = 连续动作，PnL/风险 = 奖励 | 分钟级特征 → 目标仓位 | 业内普遍用于执行优化与仓位管理；端到端 PPO 直接管钱的公开成功案例少（非平稳 + 反身性：策略改变市场） |
| **RLHF**（10 章） | 对齐微调 | token 级 | InstructGPT 起 LLM 标配；当前最大规模的 RL 商业应用 |

### 5.2 为什么这些场景"适合 RL"

四个共性，可作为"该不该用 RL"的判据：

1. **环境可大规模廉价模拟**（棋局、EDA 内循环、市场回测）——RL 的样本饥渴只有模拟器喂得起；
2. **奖励可精确定义**（胜负、乘法次数、线长/时延代理指标）——不依赖"学习的 RM"就不受 hacking 困扰；
3. **每步决策的时序耦合强**（当前布局影响后续所有摆放）——这是 RL 相对贪心/优化的结构性优势所在；
4. **容错或可回滚**——试错的代价可控。

反过来，四条都不满足的场景（如真实道路上自动驾驶的学习期），RL 只能退居"仿真内训练 + 真实内验证"的辅助角色。**经验做法**：给业务方评估"要不要上 RL"时，先问这四条各打几分——比报算法名诚实得多。

## 6. 常见误区

1. **以为 model-based 无条件更样本高效**。模型偏差在长程幻想中复合（每步小错 × 规划深度），Dyna 的 $N$ 要保守、MuZero 的搜索深度有代价。正确读法：model-based 用**模型精度**换**样本效率**，模型学不准的任务（高维随机环境）反而更慢。
2. **离线 RL 用在线指标评估**。离线算法的正确评估是**离线策略评估（OPE）**（FQE、重要性采样、Doubly Robust）或留出环境子集的受限交互——拿在线 RL 的"训练回报曲线"习惯去读离线结果必然误判。
3. **奖励塑形乱加"手感好"的分**。非 potential-based 的塑形（如"存活每步 +0.1"叠加在稀疏终局奖上）会改变最优策略——agent 学会苟活刷分不通关。加之前先问"能否写成 $\gamma\Phi(s')-\Phi(s)$"。
4. **课程 = 简单地按时间切换难度**。切换点凭日程表而非学习状态（成功率/学习进度），常见事故：难度跳变时回报崩塌再也爬不起来。课程调度应反馈控制（成功率回落 → 回退难度半档）。
5. **把 AlphaGo 类成功泛化成"RL 万能"**。那些成功全部满足 §5.2 的四判据；LLM 对齐的成功则主要靠 PPO 的工程稳健性（09 章）而非样本效率。RL 的真实版图是"模拟器 + 可定义奖励 + 时序耦合"的交集，别拿例外当规律。

## 本篇小结

- 样本效率是 model-free 的结构性短板；Dyna 用幻想经验、MuZero 用隐式模型 + MCTS 规划——"给定模型→学习模型"是 03→04 章辩证的深度版重演。
- 离线 RL 的死穴是外推误差（实测：agent 盲选了估计 0.0、真值 −3.0 的未见动作）；解法谱系围绕"悲观原则"，与在线的乐观探索互为镜像。
- Potential-based 塑形 $F = \gamma\Phi(s')-\Phi(s)$ 保最优策略不变（GridWorld 实测策略一致、值平移 $V' = V - \Phi$）；课程学习要反馈控制不能按日程表。
- HRL 用 Option/SMDP 结构拆解长时程信用分配；能用塑形和课程解决的别上 HRL。
- RL 落地四判据：可模拟、奖励可定义、时序耦合强、容错可回滚——AlphaGo/AlphaTensor/芯片布局/量化持仓全部命中；不满足时 RL 是辅助而非主角。
