# 07 - 脚本与单文件程序

## 本篇目标

大量 Python 使用形态根本不是"项目"，而是**单个脚本**：数据清洗脚本、运维小工具、教学示例。它们过去面临一个尴尬：要么塞进某个项目借环境（脚本与项目锁纠缠），要么配个独立 venv 并写一份"先装 requests 再装 rich"的 README 小抄。**PEP 723（内嵌脚本元数据）+ uv 的支持**让脚本自己声明依赖、自给自足。

## 1. PEP 723：写在脚本头部的依赖声明

脚本头部加一段特殊注释块（TOML 格式）：

```python
#!/usr/bin/env python3
# /// script
# requires-python = ">=3.12"
# dependencies = [
#   "requests>=2.31",
#   "rich>=13.0",
# ]
# ///
"""fetch_report.py — 拉取报表并格式化输出（独立脚本，无需任何环境配置）"""
import requests
from rich.table import Table
from rich.console import Console
...
```

运行方式：

```bash
uv run fetch_report.py
```

uv 读到头部元数据后自动：创建临时专用环境（缓存复用）→ 按声明安装 → 执行。**脚本从此是自包含的可分发单元**：发给别人，对方有 uv 就能跑，不存在"环境 README"。

## 2. 管理脚本依赖：uv add --script

不想手写注释块？让 uv 维护：

```bash
uv add --script fetch_report.py requests rich   # 自动写入/更新头部 metadata 块
uv remove --script fetch_report.py rich
```

这就是 01 篇事实核查时确认过的官方能力（`uv add --script`）。生成的头部块与手写完全一致——**工具与人写的是同一种格式**，可随时互换。

## 3. 两种形态的分工（与 05 篇的光谱）

| 需求 | 形态 |
| --- | --- |
| 一两行的一次性命令 | `uv run --with rich python -c "..."`（05 篇） |
| 可分享/进 Git 的脚本（几十行+） | **PEP 723 脚本**（本章） |
| 要测试、要打包、有多个模块 | 完整项目（02 篇） |
| 别人写好的 CLI | `uvx`（05 篇） |

判据是**依赖数量与生命周期**：依赖越多、活得越久，越该向"项目"形态迁移。PEP 723 脚本的舒适区上限大约是"单文件 + 少量依赖 + 无内部模块结构"。

## 4. 进阶：--with 与 PEP 723 的组合场景

```bash
uv run --with matplotlib --python 3.12 plot.py       # 临时加包 + 指定解释器
uvx --from "jupyterlab" jupyter lab                  # 一次性 Jupyter（05 篇）

# 实验性第三方脚本（不信任的代码跑在隔离环境里，失败即弃）
uvx --from git+https://github.com/some/cool-tool cool-cli
```

安全视角的一个正面副作用：脚本级隔离环境天然限制了"实验性代码"的影响面（它拿不到你主环境的任何东西）——但不代表可以随意运行不可信脚本，网络与文件系统访问仍然存在（与 Agent 08 篇的沙箱原则同理：隔离 ≠ 安全沙箱）。

## 5. 一个完整的示例脚本（可直接运行）

```python
# /// script
# requires-python = ">=3.10"
# dependencies = ["httpx>=0.27", "rich>=13"]
# ///
"""gh-popular.py — 列出一个 GitHub 仓库的 star 数（演示 PEP 723 全流程）"""
import sys
import httpx
from rich.console import Console

def main(owner_repo: str) -> None:
    r = httpx.get(f"https://api.github.com/repos/{owner_repo}", timeout=10)
    r.raise_for_status()
    data = r.json()
    Console().print(f"[bold]{data['full_name']}[/] ⭐ {data['stargazers_count']}")

if __name__ == "__main__":
    if len(sys.argv) != 2:
        sys.exit("用法: uv run gh-popular.py <owner/repo>")
    main(sys.argv[1])
```

```bash
uv run gh-popular.py astral-sh/uv     # 第一次运行自动建环境装 httpx/rich，之后走缓存
```

把这个文件发给任何人，配一句"装个 uv，然后 `uv run gh-popular.py xxx/yyy`"——完整的可复现分发。
