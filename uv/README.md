# uv 系列教程：一个工具统一 Python 工具链

> 面向被 Python 环境与依赖问题折磨过的学习者：`pip`、`venv`、`virtualenv`、`pyenv`、`pip-tools`、`pipx`、`poetry`……每样都要学、彼此要配合、坏了不知道怪谁。**uv**（Astral 出品、Rust 编写）用单一工具替换了这条工具链，并把速度提升了一个数量级（官方口径 10~100 倍）。
> 事实基准：uv 由 Astral（Ruff 的作者团队）开发，2024 年 2 月发布；本系列按 uv 当前稳定版命令面编写，细节以[官方文档](https://docs.astral.sh/uv/)为准——uv 迭代很快，**以文档为准**是本系列反复强调的原则。

### 阶段划分

1. **上手（01–02）**：装上、建项目，覆盖 80% 的日常。
2. **依赖工程（03–04）**：锁文件与 Python 版本——可复现性的两根支柱。
3. **效率与规模化（05–07）**：工具运行、monorepo、单文件脚本。
4. **落地（08）**：把 uv 带进老项目与团队。

## 与本仓库其他系列的衔接

- **Git 系列**：`uv.lock` 与 `pyproject.toml` 必须提交、`uv` 自身的缓存目录不提交——"哪些文件入库"的决策表在 Git 02 篇；
- **量化投资系列**：其"数据层/策略层"分层的项目骨架，可直接用 02 篇的 `uv init` 搭建；
- **Agent 系列**：生产部署篇强调"依赖锁定 + 版本化部署"，`uv.lock` 就是 Python 侧的实现载体。
