# Stage 6 教程：V2X 与车路协同——全系列收官

本目录是 **Stage 6-V2X与车路协同** 的配套教程，共 4 周，也是「自动驾驶感知」六阶段系列的收官。读者应已学完 Stage 1-5（传感器、2D/3D 检测、标定、融合跟踪、BEV），本教程会直接复用其中的概念（如 KF 的预测-更新两步、匈牙利指派、外参标定、BEV 特征）而不重复展开。

本阶段的作者视角偏**路侧感知**：路侧摄像头/雷达看到的目标如何变成标准消息、如何跨过通信时延与坐标系差异到达车端、如何与车端感知协同成"上帝视角"——这条链路正是本库早期笔记《后融合.md》中"融合后目标 ID 漂移影响 V2X 通信"这句话的完整展开。

## 环境依赖

- Python 3.10+，`numpy`、`scipy`、`matplotlib`（本教程所有 demo 在 CPU 上可完整复现，无需 GPU、无需真实 V2X 设备）。
- 所有 demo 为**机制演示**（固定种子合成数据）：NumPy 手工复现协同融合的核心流程，**不是**真实通信协议栈的实现。真实 DSRC/C-V2X 协议栈（如 Radium/车规模组）超出本教程范围。
- Demo 脚本统一放在 `/tmp/ad_s6/` 下运行（临时目录，代码内嵌在教程中，可自行复制重建）。

## 事实查证说明

教程中所有标准号、频谱规划、论文信息（发表时间、venue、arXiv 编号、数据集规模）均经查证，出处随文标注。关键锚点：IEEE 802.11p-2010、3GPP TS 22.185（Rel-14）、Rel-16 NR-V2X、工信部无〔2018〕232号（5905-5925 MHz）、SAE J2735、T/CSAE 53-2020、ETSI TR 103 562、DAIR-V2X（CVPR 2022）、OPV2V（ICRA 2022）、V2X-Sim（RA-L 2022）、OpenCDA（ITSC 2021）。数据集规模一律为论文/官方仓库自报数字。

## 建议学法

每周先读"本周要回答的问题"，跑通 demo 再读正文；第 3 周的外参变换公式建议拿纸笔画一遍坐标系再跑代码。学完后用学习计划里的"阶段终极自测清单"验收，并完成第 4 周文末的**结课自测大题**——那是六阶段知识的总装验收。
