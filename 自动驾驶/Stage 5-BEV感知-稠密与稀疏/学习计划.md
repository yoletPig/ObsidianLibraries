### 阶段五：BEV 感知——稠密与稀疏（4 周）

**阶段核心目标**：建立「多相机图像如何变成鸟瞰图（BEV）表示，以及 BEV 表示的稠密与稀疏两条技术路线」的完整认知——透视图的病根（深度未知）、稠密路线的 Lift-Splat 与 Transformer 两种建法、稀疏路线的 query 投影采样与流式时序。本阶段结束时，你能徒手写出 2D→BEV 的反投影公式、手算 LSS 的外积视锥、讲清 BEVFormer 空间交叉注意力的逐符号含义，并能在端侧部署语境下做稠密 vs 稀疏的选型论证。

> ⚠️ 前置依赖：Stage 1（传感器与数据）、Stage 2（2D/3D 检测，尤其 PointPillars）、Stage 3（标定——内参/外参在这里被网络"吃进去"）。BEV 公式密集，每周的 MVP 都要求用 NumPy 亲手实现机制而非只读论文。

### 📅 逐周学习路线与 MVP 交付

#### 第 1 周：为什么需要 BEV 与坐标变换基础

* **学习重点**：
* **透视图（perspective view）的三大病**：尺度随距离变化、遮挡、多相机无统一空间——为什么"6 个相机的透视图像"无法直接喂给规划器。
* **BEV 的三个好**：统一度量空间、天然适配规划与多传感器融合（BEVFusion 的伏笔）、空间不变的下游算子。
* **BEV 网格定义**：x/y 范围与分辨率（nuScenes 惯例：LSS x/y ∈ [-50, 50] @ 0.5 m；BEVFormer x/y ∈ [-51.2, 51.2] @ 0.512 m，都是 200×200）。
* **2D→BEV 的核心难题**：一个像素是一条射线而非一个点——反投影公式逐符号拆解，深度 d 是自由度。
* **标定矩阵如何进网络**：内参 K、外参 T 作为常量矩阵参与特征采样（呼应 Stage 3）。

* **推荐资料**：
* 论文：*Lift, Splat, Shoot*（ECCV 2020, arXiv:2008.05711）第 1-2 节
* 论文：*BEVFormer*（ECCV 2022, arXiv:2203.17270）引言部分
* 回顾：Stage 3 教程第 1-2 周（内参、外参）

* **💡 第 1 周 MVP 交付**：
> 用 NumPy 实现 `unproject()`：给定内参 K、外参 T、像素坐标 (u, v) 与深度 d，输出 ego 系 3D 点；再实现 `frustum()`：固定像素网格、扫 3 档深度，输出视锥采样点并画俯视图（保存 PNG）。验证：同一像素不同深度假设的点共线。

#### 第 2 周：稠密 BEV 路线 I——LSS 与 BEVDet

* **学习重点**：
* **Lift**：每个像素预测 C 个离散深度档上的 softmax 分布 α；外积 outer product 得视锥特征——公式逐符号 + 2 像素×3 深度档完整手算。
* **Splat**：视锥特征按标定矩阵反投影进 ego 系，pillar pool 到 BEV 网格 + PointPillars 式 encoder（呼应 Stage 2 第 2 周）。
* **Shoot**：LSS 论文的原始任务是 BEV 分割与轨迹规划——BEV 表示天然服务下游。
* **BEVDet**（arXiv:2112.11790）对 LSS 的工程化改进一句话：图像/BEV 双空间数据增广、定制 BEV encoder、适配 NMS。
* **稠密路线的代价**：显存与算力花在空区域上；视锥中间量 H×W×D×C 的物化成本。

* **推荐资料**：
* 论文：*Lift, Splat, Shoot*（Philion & Fidler, ECCV 2020）
* 论文：*BEVDet*（Huang et al., arXiv:2112.11790）
* 代码：`nv-tlabs/lift-splat-shoot`（重点读 `src/models.py` 的 `get_depth_dist` / `voxel_pooling`）

* **💡 第 2 周 MVP 交付**：
> 用 NumPy 实现缩小版 Lift（1 图像 4×6 像素、深度 3 档、特征 4 维）：验证深度分布沿档求和为 1、外积后视锥特征沿深度求和还原上下文特征；再实现简化 Splat（pillar sum-pooling 到 10×10 BEV 网格），打印完整 shape 链。

#### 第 3 周：稠密 BEV 路线 II——Transformer 与 BEVFormer

* **学习重点**：
* **BEV query 概念**：可学习的"BEV 格栅问句"——每个格子主动去图像里问信息，而不是等像素来投（与 LSS 的方向性反转）。
* **Spatial Cross-Attention（SCA）公式逐符号**：BEV 柱上 4 个高度参考点投影到多相机、视野外相机被 mask、deformable attention 只在命中位置算。
* **Temporal Self-Alignment / TSA 与时序对齐**：上一帧 BEV 特征按 ego 运动 warp 到当前帧——车动了、世界没动。
* **与 DETR 的关系**：BEVFormer 是" DETR 的 query 换成整张 BEV 网格"的变体。
* **稠密路线对比表**：LSS 系 vs Transformer 系（显存/算子友好度/精度）。

* **推荐资料**：
* 论文：*BEVFormer*（Li et al., ECCV 2022, arXiv:2203.17270）
* 代码：`fundamentalvision/BEVFormer`（重点读 `projects/mmdet3d_plugin/bevformer/` 的 spatial_cross_attention.py 与 temporal_self_attention.py）
* 背景：*DETR*（Carion et al., ECCV 2020）集合预测框架

* **💡 第 3 周 MVP 交付**：
> 用 NumPy 模拟 1 个 BEV query 柱（4 个高度参考点）投影到 3 个虚拟相机（前/左前/后）：打印每次投影的像素坐标与 mask 结果；对命中的采样做 softmax 注意力加权，验证权重和为 1；再实现 ego 运动补偿的 BEV 格子 warp 计算，验证位移量纲正确。

#### 第 4 周：稀疏 BEV 与流式时序

* **学习重点**：
* **稀疏动机**：不扫全空间、算力随目标数（几十~几百）而非网格数（数万）增长——端侧芯片视角。
* **DETR3D**（CoRL 2021, arXiv:2110.06922）：3D query→投影采样 2D 特征→集合预测；匈牙利匹配损失一句话+逐符号。
* **Sparse4D 系列演进**：v1 4D 关键点与实例级深度重加权（arXiv:2211.10581）→ v2 循环时序融合（arXiv:2305.14018）→ v3 端到端检测+跟踪、时序实例去噪与质量估计（arXiv:2311.11722）。
* **StreamPETR**（arXiv:2303.11926）：object query 流式传播 + motion-aware layer normalization。
* **稀疏 vs 稀疏对比表**（DETR3D / Sparse4D v3 / StreamPETR，论文自报 nuScenes 成绩）与端侧部署选型收束。

* **推荐资料**：
* 论文：*DETR3D*（Wang et al., CoRL 2021）、*Sparse4D v1/v2/v3*（Lin et al.）、*StreamPETR*（Wang et al.）
* 代码：`HorizonRobotics/Sparse4D`（原 megvii-research/Sparse4D 已迁移）、`exiawsh/StreamPETR`
* 背景：Stage 2 第 3 周 CenterPoint（时序融合的激光路线对照）

* **💡 第 4 周 MVP 交付**：
> 用 NumPy 实现稀疏 query 的投影采样（12 个 3D query → 前向相机特征图，视野外 mask）；用 `scipy.optimize.linear_sum_assignment` 复现 5 预测×4 真值的匈牙利匹配；实现 StreamPETR 式运动补偿的 query 传播（目标速度-ego 位移），打印三目标前后帧位置对照表。
