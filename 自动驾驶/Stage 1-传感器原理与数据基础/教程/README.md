本目录是「自动驾驶感知」系列的第一阶段（Stage 1）教程。目标读者：以 Python 为主、有 CV/DL 基础但没接触过自动驾驶感知的工程师。学习路线偏**路侧/车端多传感器感知**的工程方向。

## 本阶段解决什么问题

Stage 2 以后你要训练 3D 检测模型、做多传感器融合，但这一切之前有一个更基本的问题：**数据从哪来、长什么样、什么时候在说谎**。本阶段按传感器逐一拆解：

| 周次 | 教程 | 核心问题 | 一句话收获 |
| --- | --- | --- | --- |
| 第 1 周 | [[第1周-相机成像与视觉感知基础]] | 一束光怎么变成像素？3D 世界怎么压成 2D 图像？ | 针孔模型 + 内参 + 畸变，理解"深度信息在哪一步丢的" |
| 第 2 周 | [[第2周-激光雷达与点云特性]] | 光飞出去再回来怎么测出米数？点云为什么稀疏不均匀？ | ToF/FMCW 测距 + 点云数据格式 + 三大特性 |
| 第 3 周 | [[第3周-毫米波雷达与IMU-GNSS]] | 电磁波凭什么直接测出速度？IMU 为什么必然漂移？ | FMCW/多普勒 + 4D 雷达 + 惯导漂移实验 + "什么时候靠谁" |
| 第 4 周 | [[第4周-坐标系与时空同步]] | 各传感器说的"前方"是同一个前方吗？同一时刻吗？ | 旋转表示 + 齐次变换 + 硬/软同步，融合的地基 |

**阅读顺序**：严格按周次顺序。第 4 周是前 3 周的汇合点，也是本库 [[../../后融合]] 中"异步时延"难点的根治入口（该文件里每个难点的数据层原因，都在 Stage 1 有对应出处；系统性方案在 Stage 4 展开）。

## 依赖说明

本阶段所有代码只依赖 Python 科学计算栈，无 GPU 要求：

```bash
# 核心依赖（大概率已有）
pip install numpy scipy matplotlib

# 可选：畸变模型交叉验证用（装不上也不影响主线，教程给 numpy 手写版）
pip install --user opencv-python-headless

# 可选：点云可视化（本阶段 matplotlib 散点图也够用）
pip install open3d
```

各教程代码均为完整可运行脚本，复制到本地即可执行；文中的"预期输出"均经过真实运行验证（Python 3.12 + numpy 1.26）。验证环境差异可能导致浮点显示末位略有不同，不影响结论。

## 数据集准备（第 2 周起）

教程示例为降低门槛，默认用**合成数据**（NumPy 模拟点云），保证你零下载即可跑通。当你想看真实数据时：

1. **KITTI**：从 [cvlibs.net](https://www.cvlibs.net/datasets/kitti/) 下载 odometry 的 velodyne + calib 子集（单个 sequence 约 80MB 起）。点云是 `N×4 float32` 二进制。
2. **nuScenes**：下载 [mini split](https://www.nuscenes.org/nuscenes)（约 4GB），含全部 6 类传感器完整标定与时间戳，是第 4 周最佳练习材料。
3. **SemanticKITTI**：在 KITTI odometry 基础上加 `labels/` 目录，逐点 uint32 标签，格式见第 2 周教程。

## 约定

- 术语首现给英文原名，如：飞行时间（Time of Flight, ToF）。
- 每个公式配"这个公式在干什么"的大白话解读。
- 坐标系记号：$T_{A \to B}$ 表示把 A 系坐标变换到 B 系；KITTI/nuScenes 各自的轴向约定在第 4 周单独查证列出。
- "车端"（onboard，传感器装在车上）与"路侧"（roadside，传感器装在龙门架/杆上）两种部署在选型处会对照说明。
