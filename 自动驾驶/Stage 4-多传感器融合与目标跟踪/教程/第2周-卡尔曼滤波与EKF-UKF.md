## 1. 第一性原理："预测-修正"直觉

想象你在开车走陌生路线，手机导航同时开着：

- **预测**：你按"过去 10 秒我一直以 60 km/h 直行"推算自己下一秒在哪——这是**运动模型（motion model）**给的先验。它平滑但会错（你该转弯了）。
- **测量**：GPS 告诉你一个位置——这是**观测**。它不依赖历史所以不会累积漂移，但每次都有噪声（高楼旁能飘十几米）。
- **修正**：你心里"真实位置"= 两者按可信度加权。GPS 今天很飘，你就多信推算；刚从隧道出来推算已经漂了 200 m，你就多信 GPS。

卡尔曼滤波（Kalman Filter, KF；Kalman, *A New Approach to Linear Filtering and Prediction Problems*, 1960）就是把这套直觉写成严格的最优公式：在高斯噪声、线性系统的假设下，它给出的就是**最小方差估计**，且只用上一时刻的结果递推（不需要历史窗口），内存和算力都是常数量级——这就是自动驾驶每帧都要跑它几十次的原因。

两个世界的权重怎么定？KF 自己会算——**卡尔曼增益（Kalman gain）K** 就是那个"配比"，它由模型不确定度（Q）与测量噪声（R）自动算出。你不用拍脑袋"三七开"，你只要如实告诉它"模型多不可靠（Q）、测量多吵（R）"。

## 2. 运动模型：状态向量里装什么

### 2.1 CV 模型（constant velocity，匀速模型）

把一个 2D 目标的状态写成 4 维向量：

$$
\mathbf{x} = [x, y, v_x, v_y]^\top
$$

**匀速假设**下一帧（间隔 $\Delta t$）后的状态：

$$
\mathbf{x}_{k+1} = F \mathbf{x}_k, \qquad
F = \begin{bmatrix} 1 & 0 & \Delta t & 0 \\ 0 & 1 & 0 & \Delta t \\ 0 & 0 & 1 & 0 \\ 0 & 0 & 0 & 1 \end{bmatrix}
$$

**这个矩阵在干什么**：把"位置下一帧 = 当前位置 + 速度×时间；速度下一帧 = 速度（不变）"两句话写成一个矩阵乘法。逐块拆解：

| 块 | 物理含义 | 大白话 |
| --- | --- | --- |
| 左上 $I_2$ | 位置由位置传递 | 下一帧位置里有"现在的位置" |
| 右上 $\Delta t \cdot I_2$ | 位置由速度推 | 匀速 $\Delta t$ 秒走了多远 |
| 右下 $I_2$ | 速度保持 | 匀速假设：速度不变 |

**为什么自动驾驶爱用 CV**：帧间隔 100 ms 时，绝大多数目标（车、人）10~100 ms 内加速度产生的位移是厘米级，匀速近似误差很小；CV 只有 4 维，KF 矩阵是 4×4，计算极便宜。它作为"预测一帧"的模型精度足够，作为"预测一秒"的模型再叠加后续修正也够用。

### 2.2 CA 模型（constant acceleration，匀加速模型）

状态扩成 6 维 $[x, y, v_x, v_y, a_x, a_y]^\top$，F 矩阵多一块：位置里再加 $\tfrac{1}{2}\Delta t^2 a$ 项，速度里加 $\Delta t \cdot a$ 项。用于机动明显的场景（城市路口起步的车辆）。**维度越高，Q 越难调，跟踪启动越慢**——CA 不是严格优于 CV，而是"模型表达力 vs 调参成本"的交换。工程里 2D 跟踪 CV 占多数，3D 跟踪常用 CV + CTRV（constant turn rate and velocity，恒转率）等。

### 2.3 不确定度怎么传播：协方差

KF 不只估计"目标在哪"（均值 $\hat{\mathbf{x}}$），还同时维护"我有多确定"（协方差矩阵 $P$）。预测一步：

$$
\hat{\mathbf{x}}^- = F\hat{\mathbf{x}}, \qquad P^- = F P F^\top + Q
$$

**这两行在干什么**：均值按模型往前推；不确定度也按模型往前推（$FPF^\top$ 是把上一刻的椭球按运动变换"拉伸旋转"），**再平添一份新不确定度 Q**——因为模型本身不可靠，走得越远越没底。

逐符号拆解：

| 符号 | 物理含义 | 大白话 |
| --- | --- | --- |
| $\hat{\mathbf{x}}^-$ | 预测的均值（上标 - 表示"更新前"） | "我猜它在这" |
| $P^-$ | 预测的协方差（4×4） | "我猜得有多不准" |
| $F P F^\top$ | 协方差的线性传播 | 不确定度随运动被拉伸 |
| $Q$ | 过程噪声协方差 | **模型本身的不靠谱程度**（匀速假设被加减速打破等） |

### 2.4 更新：观测来了怎么修

假设观测到位置（速度观测不到很常见）：$H = [I_2 \;\; 0]$（4 维状态取前 2 维）。更新三步：

$$
\mathbf{y} = \mathbf{z} - H\hat{\mathbf{x}}^- \quad \text{（残差/新息）}
$$
$$
K = P^- H^\top (H P^- H^\top + R)^{-1} \quad \text{（卡尔曼增益）}
$$
$$
\hat{\mathbf{x}} = \hat{\mathbf{x}}^- + K\mathbf{y}, \qquad P = (I - KH)P^-
$$

**这三行在干什么**：残差 $\mathbf{y}$ 是"测量说它在这、我预测它在那"的差；增益 K 决定这个差有多少被采信；最后均值被拉向观测，协方差收缩（我们变得更确定了一点）。

| 符号 | 物理含义 | 大白话 |
| --- | --- | --- |
| $\mathbf{z}$ | 本帧观测（这里是 2D 位置） | 测量报的数 |
| $\mathbf{y}$ | 残差（innovation） | 预测与测量的分歧 |
| $S = HP^-H^\top + R$ | 残差方差 | "这个分歧本身有多大才算正常" |
| $R$ | 测量噪声协方差 | **测量仪器有多吵** |
| $K$ | 增益（0~1 之间的"旋钮"，矩阵形式） | 分歧中采信测量的比例 |
| $P = (I-KH)P^-$ | 更新后协方差 | 采信了观测，确定度上升 |

**K 的两个极端**（面试必考）：$R \to \infty$（测量极吵）时 $K \to 0$，完全不采纳测量、纯靠预测；$R \to 0$（测量极准）时 $K \to 1$，完全跟随测量。K 就是"信模型 vs 信测量"的自动配比——第 4 节用实验验证它。

## 3. 可运行实验 1：调 Q/R 的工程经验（exp2）

**经验口诀**：**Q 大信模型会变（跟机动快但输出抖）；R 大信模型平稳（跟得慢但平滑）**。口诀没用，数字才有用——下面的实验固定"5 秒匀速 + 5 秒匀加速"的场景，机动后估计落后真值多少（滞后）直接量化"响应快慢"。

```python
# exp2_kalman_qr.py —— CV 模型 KF + 调 Q/R 数值实验（固定种子）
import numpy as np

np.random.seed(7)
dt = 0.1
N = 100                                   # 10 s @ 10 Hz

# 真值：0~5s 匀速 10 m/s；5~10s 匀加速 +4 m/s^2（机动，速度 10 -> 30 m/s）
t = np.arange(N) * dt
acc = np.where(t < 5.0, 0.0, 4.0)
v_true = 10.0 + np.cumsum(acc) * dt
p_true = 20.0 + np.cumsum(v_true) * dt

F = np.array([[1.0, dt], [0.0, 1.0]])     # CV 状态转移：x' = x + v*dt
Q_OFF = np.diag([1e-4, 1e-3])             # 过程噪声基准（模型不确定度）

def run_kf(sigma_z, q_scale):
    """x = [位置 p, 速度 v]，观测只有 p。初值速度已知（已跟踪一段）。"""
    R = sigma_z ** 2
    Q = q_scale * Q_OFF
    H = np.array([[1.0, 0.0]])
    x = np.array([p_true[0], 10.0])       # 初始状态给准，排除启动瞬态干扰
    P = np.diag([1.0, 1.0])
    est = np.zeros((N, 2))
    for k in range(N):
        # ---- 预测 ----
        x = F @ x
        P = F @ P @ F.T + Q
        # ---- 更新 ----
        z = p_true[k] + sigma_z * np.random.randn()
        y = z - (H @ x)[0]                    # 残差（新息）
        S = (H @ P @ H.T)[0, 0] + R           # 残差方差
        K = (P @ H.T / S).ravel()             # 卡尔曼增益
        x = x + K * y
        P = (np.eye(2) - np.outer(K, H)) @ P
        est[k] = x
    return est

def report(name, est):
    rmse_p = np.sqrt(np.mean((est[:, 0] - p_true) ** 2))
    # 机动后 (t in [6,10] s) 的平均滞后：估计位置落后真值多少（正=落后）
    w = t >= 6.0
    lag = np.mean(p_true[w] - est[w, 0])
    print(f"{name:26s} 位置RMSE = {rmse_p:6.3f} m   机动后平均滞后 = {lag:+7.3f} m")
    return rmse_p, lag

print("==== 固定 Q，改变 R（R 大 -> 更信模型、响应变慢）====")
est_R1 = run_kf(sigma_z=1.0, q_scale=1.0)
report("R=1m^2 (信测量, 响应快)", est_R1)
est_R25 = run_kf(sigma_z=5.0, q_scale=1.0)
report("R=25m^2 (半信半疑)", est_R25)
est_R400 = run_kf(sigma_z=20.0, q_scale=1.0)
report("R=400m^2 (几乎不信测量)", est_R400)

print("\n==== 固定 R=1，改变 Q（Q 大 -> 更信'模型会变'、跟机动快但更抖）====")
report("Q x 0.01 (死信CV模型)", run_kf(1.0, 0.01))
report("Q x 1   (基准)", est_R1)
report("Q x 100 (很信机动)", run_kf(1.0, 100.0))
```

**预期输出**（固定种子实测）：

```
==== 固定 Q，改变 R（R 大 -> 更信模型、响应变慢）====
R=1m^2 (信测量, 响应快)          位置RMSE =  4.848 m   机动后平均滞后 =  +7.115 m
R=25m^2 (半信半疑)             位置RMSE = 16.158 m   机动后平均滞后 = +12.725 m
R=400m^2 (几乎不信测量)          位置RMSE = 10.802 m   机动后平均滞后 = +14.272 m
```

等一下——R=400 的滞后反而只比 R=25 大一点？因为该滤波器"几乎不信测量"，匀加速阶段误差持续累积（模型没加速度），位置估计整体被甩开（RMSE 最大 10.8 m），"滞后"里混进了全程发散的成分。**这是真实的工程现象：R 调太大不是"平滑"，是"迟钝到跟丢"**。看 R 方向的结论要盯滞后单调上升：7.1 → 12.7 → 14.3 m，响应确实越来越慢。

第二组（R=1 固定，调 Q）：

```
==== 固定 R=1，改变 Q（Q 大 -> 更信'模型会变'、跟机动快但更抖）====
Q x 0.01 (死信CV模型)          位置RMSE =  8.184 m   机动后平均滞后 = +11.334 m
Q x 1   (基准)               位置RMSE =  4.848 m   机动后平均滞后 =  +7.115 m
Q x 100 (很信机动)             位置RMSE =  0.844 m   机动后平均滞后 =  +1.129 m
```

Q×100 滞后从 11.3 m 降到 1.1 m——"告诉滤波器模型随时可能变"之后，它的增益变大、速度状态能快速吸收加速度，匀加速场景甚至 RMSE 全面变好。**代价在匀速段**：Q 大时滤波器把每一点测量噪声都当成"可能机动"，输出更抖（把场景改成纯匀速 + 加大测量噪声，会看到 Q×100 的 RMSE 反超基准）。

> **动手验证**：把场景改为全程匀速 10 m/s（`acc` 那两行置零），其余不动、重跑脚本——Q 对照表变成 0.260 / 0.329 / 0.483（固定种子实测）：模型准确时 Q×100 保费立刻显现（RMSE 近乎翻倍），与机动场景正好相反。**Q/R 没有全局最优，只有"预期机动水平"下的最优**，这就是为什么量产系统会按场景（高速巡航 vs 城市路口）切换 Q。

## 4. EKF：非线性观测怎么办

### 4.1 问题：雷达不给笛卡尔坐标

毫米波雷达输出的是**极坐标**：距离 $r$、方位角 $\theta$，它们与状态是非线性关系：

$$
r = \sqrt{(x-x_s)^2 + (y-y_s)^2}, \qquad \theta = \mathrm{atan2}(y-y_s,\, x-x_s)
$$

（$(x_s, y_s)$ 为雷达位置。）$H$ 矩阵没法再写成常数——KF 的更新公式要求观测是状态的线性函数。

### 4.2 EKF 的答案：每步局部线性化

扩展卡尔曼滤波（Extended Kalman Filter, EKF）的做法朴素而有效：**把非线性函数在当前预测点做一阶泰勒展开**，用雅可比矩阵（Jacobian，即多元函数的"斜率"）代替常数 $H$：

$$
H_k = \left.\frac{\partial (r, \theta)}{\partial (x, y)}\right|_{\hat{\mathbf{x}}^-}
= \begin{bmatrix}
\dfrac{x - x_s}{r} & \dfrac{y - y_s}{r} & 0 & 0 \\[2mm]
-\dfrac{y - y_s}{r^2} & \dfrac{x - x_s}{r^2} & 0 & 0
\end{bmatrix}
$$

**这个矩阵在干什么**：第一行是"距离对位置的变化率"——单位方向向量（往远处挪 1 m，r 就多 1 m）；第二行是"角度对位置的变化率"——横着挪 1 m，角度变化约 $1/r$ 弧度，**越近的地方角度越敏感**（分母是 $r^2$）。逐符号拆解：

| 符号 | 物理含义 | 大白话 |
| --- | --- | --- |
| $(x - x_s)/r,\ (y-y_s)/r$ | 距离梯度的方向分量 | 从雷达指向目标的单位向量 |
| $-(y-y_s)/r^2,\ (x-x_s)/r^2$ | 角度梯度 | 同样的横向误差，目标越近转角越大 |
| $\hat{\mathbf{x}}^-$ | 线性化展开点 | 每一步都在"当前预测"处重新展开 |

EKF 的其余公式与 KF 完全一样，只是 $H$ 换成 $H_k$、残差用 $\mathbf{z} - h(\hat{\mathbf{x}}^-)$（非线性函数本体）计算。

### 4.3 实验：三种滤波器对比（exp3）

对比三种做法：**(a) 冻结线性化 KF**——只在第一帧算一次雅可比然后永远沿用（线性化做一次就当 KF 用，这是新手常犯的错）；**(b) EKF**——每步在当前预测处重新线性化；**(c) UKF**——下一节讲。目标从 134 m 外直线开向雷达附近，8 秒 80 帧。

```python
# exp3_ekf_ukf.py —— 极坐标雷达观测下的 KF(冻结线性化) vs EKF vs UKF（节选核心）
# 完整脚本见 实验脚本/exp3_ekf_ukf.py，固定 np.random.seed(11)
def h(x):
    d = x[:2] - SENSOR                     # SENSOR = (0, 0)
    return np.array([np.hypot(d[0], d[1]), np.arctan2(d[1], d[0])])

def jacobian_H(x):
    d = x[:2] - SENSOR
    r = np.hypot(d[0], d[1])
    return np.array([[d[0]/r, d[1]/r, 0, 0],
                     [-d[1]/r**2, d[0]/r**2, 0, 0]])

def kf_frozen(x, P, z):
    x, P = predict(x, P)
    y = z - (H0 @ x + b0)                  # H0/b0：只在第 0 帧线性化一次并冻结
    S = H0 @ P @ H0.T + R_mat
    K = P @ H0.T @ np.linalg.inv(S)
    x = x + K @ y
    P = (np.eye(4) - K @ H0) @ P
    return x, P

def ekf(x, P, z):
    x, P = predict(x, P)
    H = jacobian_H(x)                      # 关键区别：每步在当前预测点重新线性化
    y = z - h(x)
    S = H @ P @ H.T + R_mat
    K = P @ H.T @ np.linalg.inv(S)
    x = x + K @ y
    P = (np.eye(4) - K @ H) @ P
    return x, P
```

**预期输出**（固定种子实测）：

```
==== 极坐标雷达跟踪：三种滤波器位置误差对比 ====
KF(冻结线性化)            位置RMSE =   6.011 m
EKF(每步重线性化)          位置RMSE =   0.473 m
UKF(sigma点)          位置RMSE =   0.457 m
```

**12.7 倍的差距**：冻结的雅可比是在 134 m 远处算的——那里"1 m 横向误差 = 0.43°"；当目标开到 30 m 内，同一个雅可比给出的角度斜率已经错了 4 倍以上，残差被错误地投影回状态，误差系统性偏大。EKF 每步重算雅可比，几乎免费（一个 $4\times4$ 求逆）就解决。UKF 0.457 m 与 EKF 0.473 m 几乎持平——**弱非线性问题里两者相当**，不必为 UKF 的额外开销买单。

### 4.4 UKF 一句话直觉

无迹卡尔曼滤波（Unscented Kalman Filter, UKF；Julier & Uhlmann, 1997）的思路是"**不做泰勒展开，直接把点喂进非线性函数**"：在当前均值周围按确定性规则选 $2n+1$ 个 sigma 点（$n$ 为状态维数），把它们整体过一遍非线性函数 $h(\cdot)$，再用加权平均统计出新的均值与协方差。对二阶非线性，UKF 的均值估计精度高于 EKF（EKF 一阶展开有偏），且**完全不用推雅可比**——运动模型复杂（CTRV 等）时这是巨大红利。代价：每步 $2n+1$ 次函数调用与若干小矩阵运算。选型口诀：**模型好求导用 EKF，模型复杂/强非线性用 UKF；线性系统两者都退化成 KF，谁也不欠谁**。

## 5. 协方差与不确定度椭圆（exp3 后半）

$P$ 的位置块 $P_{xy}$（2×2）可以直接画成**不确定度椭圆**：求特征值/特征向量，椭圆两轴长 $2\sqrt{\lambda_1}, 2\sqrt{\lambda_2}$（2σ），方向为特征向量。

```python
# exp3_ekf_ukf.py 节选：椭圆绘制与收缩统计
print("\n==== EKF 位置不确定度椭圆（2sigma 长轴）====")
for i in [0, 5, 10, 20, 40, 79]:
    a = 2 * np.sqrt(np.linalg.eigvalsh(Ps_ekf[i])[1])
    print(f"帧 {i:3d} (距离 {h(x_true[i])[0]:6.1f} m): 2sigma 长轴 = {a:6.3f} m")
```

## 6. 工程权衡与失效模式

1. **EKF 发散**：线性化点太差（初始误差大、非线性太强）时，残差投影方向错得离谱，估计跑飞且协方差却显示"很确定"。**症状**：估计远离真值但椭圆很小；**修复**：合理的初始协方差、限幅残差（innovation clipping）、必要时换 UKF。
2. **Q/R 拍脑袋**：Q/R 差几个数量级，跟踪表现天壤之别。**症状**：要么抖成狗（Q 大）、要么转弯跟丢（Q 小 R 大）；**修复**：按传感器标称噪声定 R，按"最大合理加速度"反推 Q（$Q \sim (a_{max}\Delta t^2)^2$ 量级），再按第 3 节方法扫描验证。
3. **协方差不一致（covariance inconsistency）**：实现错误（如漏掉 $F P F^\top$ 项、更新后 P 不对称）会让滤波器"自我感觉良好"但实际误差巨大。**症状**：真值落在 2σ 椭圆外的比例远超 5%；**修复**：强制 $P = (P + P^\top)/2$；用 NEES/一致性检验类手段核查。
4. **数值下溢**：长时间运行 P 变得极小，浮点平方/求逆出 NaN。**修复**：Joseph 形式更新或平方根滤波（square-root filter）。

## 7. 延伸思考题（含解析）

**Q1**：为什么 KF 只需要上一帧的结果，不需要历史窗口？
**A**：高斯分布用 $(\hat{\mathbf{x}}, P)$ 完全刻画，递推时这一对就是"全部历史的最优压缩"。这既是 KF 的效率来源（O(1) 内存），也解释了它的局限：非高斯/多峰场景（如目标可能急停也可能转弯）一个高斯装不下，需要粒子滤波或多假设。

**Q2**：观测只有位置、没有速度，滤波器怎么"知道"速度？
**A**：位置观测序列隐含速度信息——连续两帧位置差就是速度证据，KF 通过 $P$ 中位置-速度的互协方差自动利用这种关系。这也是初值 $P$ 里速度方差要给大的原因：留给观测去"教"它。

**Q3**：EKF 在什么场景必挂？
**A**：强非线性 + 线性化点差。典型如纯角度（bearing-only）观测在距离未知时，$1/r$ 的雅可比在近距爆炸。工程信号：残差长期同号且超出 $3\sqrt{S}$——线性化假设已破产，换 UKF 或粒子滤波。

**Q4**：为什么"Q 大信模型会变"还能让匀加速场景 RMSE 变好？和口诀矛盾吗？
**A**：不矛盾。Q 大的含义是"承认模型随时可能错"，当模型**确实**在错（CV 遇上加速），Q 大的滤波器修正得快，收益为正；当模型没错（匀速场景），Q 大只是白白放大测量噪声，收益为负。口诀应读作"Q 是对模型失准的投保，保费与赔付随场景而变"。

**Q5**：不确定度椭圆收缩到稳态后不再变小，为什么？
**A**：每步预测通过 Q 注入新不确定度，每步更新通过观测消去不确定度，两者在 2~3 步内达到平衡（协方差代数里的稳态解）。椭圆大小从此由 Q/R 比值决定，而不是由"看了多少帧"决定——所以观测信息不会被无限累积，漏检几帧后椭圆会重新变大（这正是第 3 周门控需要的性质）。
