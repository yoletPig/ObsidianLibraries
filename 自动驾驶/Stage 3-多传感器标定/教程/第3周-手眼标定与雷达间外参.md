## 1. 手眼标定：AX = XB

### 1.1 两种构型

**Eye-in-hand（眼在手上）**：相机装在机械臂末端/云台上。相机与末端法兰的相对位姿固定但未知——这个未知量就是"眼-手"变换 $X$。车载对应物：相机装在可动云台上、LiDAR 装在悬挂系统上（与车身之间隔着会动的环节）。

**Eye-to-hand（眼在手外）**：相机固定在三脚架/车身上，看机械臂动。未知量是相机与机械臂基座的相对位姿。

### 1.2 运动链推导（eye-in-hand）

场景：机械臂末端在基座系的位姿是 $G_i$（机器人正运动学**精确已知**）；基座上有一块固定标定板；相机看到板在相机系的位姿 $C_i$（由第 2 周的 PnP 得到）。链条：

$$
\underbrace{G_i}_{\text{末端}\leftarrow\text{基座}} \; X \;=\; \text{相机在基座系的位姿}
$$

板是固定的，所以对任意两个位姿 $i, j$：

$$
G_j\, X\; C_j = G_i\, X\; C_i \quad\Longrightarrow\quad \underbrace{G_j^{-1} G_i}_{A}\; X = X\; \underbrace{C_j\, C_i^{-1}}_{B}
$$

$$
\boxed{A\, X = X\, B}
$$

**这个公式在干什么**：A 是"末端怎么动的"（机器人告诉我），B 是"相机看到世界怎么动的"（相机告诉我）。同一个刚体运动，从末端坐标系描述和从相机坐标系描述必须相差那个固定的 X——X 的存在使两边不能直接相等，而要共轭：$B = X^{-1} A X$。解出 X 就得到相机在末端上的安装位姿。

**eye-to-hand 只差一个取逆**：相机固定时用 $G_i G_j^{-1}$ 方向构造 A（或者等价地对 B 取逆），方程形式不变。工程上先画运动链图、把"谁是源谁是目标"标清楚，再套公式——方向错了会得到一个"看起来也收敛但物理上错误"的解。

### 1.3 为什么至少两次不同方向的运动？

一次运动给出一对 (A, B)，约束方程 $AX=XB$ 是 12 个标量方程，但含尺度/共轭冗余，独立信息不足以定出 6 自由度。几何上看旋转部分：$A、B$ 旋转角相同（共轭保持角度），$X$ 把 B 的旋转轴转到 A 的旋转轴。一次运动的"轴"是一条**方向**——X 只被约束到"能把轴 b 转到轴 a"这一族旋转，还有绕轴的一个自由度未定。第二次运动提供一条**不同方向**的轴，两个轴约束交叉才锁死 X 的旋转。所以：

- 运动次数 ≥ 2（工程上 8~20 组位姿，产生几十个运动对做最小二乘）；
- **旋转轴方向必须多样**——所有运动绕平行轴转，等价于只给了一条轴信息，X 解不出（OpenCV 实现甚至会直接报"Not enough informative motions"）。

## 2. 旋转的轴角表示与李代数一句话

一个旋转 = 一条单位轴 $u$ + 一个角度 $\theta$。三种表示互相换算：

| 表示 | 定义 | 用途 |
| --- | --- | --- |
| 旋转矩阵 R | 3×3 正交阵，$\det=+1$ | 复合/变换方便，但 9 个数只有 3 个自由度 |
| 旋转向量 / 轴角（log 映射） | $\theta u \in \mathbb{R}^3$ | 最紧凑；$\exp(\theta [u]_\times) = R$，$[u]_\times$ 是反对称矩阵 |
| 修正 Rodrigues / 四元数向量部 | $2\sin(\theta/2)\,u$ | Tsai-Lenz 的工作变量 |
| Gibbs 向量 | $\tan(\theta/2)\,u$ | Tsai-Lenz 中间解（一会儿见 eq 14） |

**李代数一句话**：所有旋转构成的群 SO(3) 在单位元附近是一个 3 维弯曲空间；它的切平面（李代数 $\mathfrak{so}(3)$）是所有反对称矩阵，$\log$ 把旋转投到这个平面上（旋转向量），$\exp$ 再投回去。标定算法大量使用 $\log$/$\exp$，因为**在切平面上可以做线性代数**——这就是第 2 周以来所有"把非线性变成 $Ax=0$"的统一诀窍在旋转上的样子。

## 3. Tsai-Lenz 两步法（1989，OpenCV 同源）

原论文：Tsai & Lenz, *A New Technique for Fully Autonomous and Efficient 3D Robotics Hand/Eye Calibration*, IEEE Trans. Robotics and Automation 5(3): 345-358, 1989。思路：把 $AX=XB$ 拆成"先旋转后平移"两个**线性**最小二乘。

### 3.1 第一步：旋转

记 $R_A, R_B$ 为运动对 $A, B$ 的旋转部分，$P(\cdot) = 2\sin(\theta/2)\,u$ 为修正 Rodrigues 映射。关键事实：$B = X^{-1}AX$ 是共轭，所以 $R_A$ 与 $R_B$ **旋转角相同**、轴相差 $R_X$ 的旋转。Tsai-Lenz 把这个关系线性化成一个关于未知量 $x$（X 的旋转的 Gibbs 向量 $\tan(\theta_x/2)\,u_x$）的方程：

$$
\mathrm{skew}(P_a + P_b)\; x = P_b - P_a, \qquad \mathrm{skew}(v) = \begin{bmatrix} 0 & -v_z & v_y \\ v_z & 0 & -v_x \\ -v_y & v_x & 0 \end{bmatrix}
$$

**这个公式在干什么**：它编码了"轴 a = $R_X$ 轴 b"这件事的线性化版本。每对运动给 3 个方程（其中 2 个独立），$N$ 对运动堆成 $3N \times 3$ 的超定方程组，SVD/最小二乘解出 $x$。注意解出的 $x$ 是 Gibbs 向量，要按

$$
q = \frac{x}{\sqrt{1 + x^\top x}}, \qquad R_X = I + 2w\,\mathrm{skew}(q) + 2\,q q^\top - 2(q^\top q) I,\quad w = \sqrt{1 - q^\top q}
$$

换算回单位四元数向量部再转旋转矩阵（对应 OpenCV 实现里的 "eq 14" 缩放——漏掉这个缩放是复现 Tsai-Lenz 最常见的 bug，旋转会差一个与 $\theta_x$ 相关的系统角度）。

另外工程细节（OpenCV 源码同款）：旋转角太小（<17°）或接近 180° 的运动对信息量差，直接丢弃。

### 3.2 第二步：平移

旋转已知后，把 $AX = XB$ 的平移部分展开 $R_A\,t_X + t_A = R_X\,t_B + t_B$，移项：

$$
(R_A - I)\; t_X = R_X\, t_B - t_A
$$

**这个公式在干什么**：对每个运动对，这是关于 $t_X$ 的 3 个线性方程（$R_A - I$ 不满秩，单对解不出，多对堆叠成满秩超定方程）。直觉：平移误差在旋转已知的条件下是"运动两端位置差"的线性函数。

> 最后再补一步**非线性精化**（可选但推荐）：把 X 参数化，直接最小化所有运动对的 $\|AX - XB\|_F$（scipy 的 LM）。线性两步法在噪声下有轻微偏差，LM 精化把它消掉——第 2 周 DLT vs PnP 的同款逻辑：线性解是初值，几何误差非线性解是答案。

## 4. 数值实验：numpy 完整实现与验证

```python
# exp5_handeye.py（核心部分；完整脚本见 实验脚本/exp5_handeye.py）
import numpy as np, cv2
from itertools import combinations
from scipy.optimize import least_squares

def rot2quat2(R):
    """Tsai 的 P = 2 sin(theta/2) * 轴（= 2 倍四元数向量部）"""
    c = np.clip((np.trace(R) - 1) / 2, -1, 1)
    th = np.arccos(c)
    if th < 1e-12:
        return np.zeros(3)
    n = np.array([R[2,1]-R[1,2], R[0,2]-R[2,0], R[1,0]-R[0,1]]) / (2 * np.sin(th))
    return 2 * np.sin(th / 2) * n

def tsai_lenz(G, C):
    """两步法。G: 末端位姿列表（基座系）；C: 相机看到的板位姿列表。"""
    M, y, keep = [], [], []
    for i, j in combinations(range(len(G)), 2):
        Hg = np.linalg.inv(G[j]) @ G[i]        # 末端运动 A
        Hc = C[j] @ np.linalg.inv(C[i])        # 相机运动 B（AX=XB）
        Pg, Pc = rot2quat2(Hg[:3, :3]), rot2quat2(Hc[:3, :3])
        if not (0.3 <= np.linalg.norm(Pg) <= 1.7 and 0.3 <= np.linalg.norm(Pc) <= 1.7):
            continue                            # 丢弃旋转太小/接近 180° 的运动对
        M.append(skew(Pg + Pc)); y.append(Pc - Pg); keep.append((Hg, Hc))
    x, *_ = np.linalg.lstsq(np.vstack(M), np.hstack(y), rcond=None)
    q = x / np.sqrt(1 + x @ x)                 # Gibbs -> 单位四元数向量部（eq 14）
    w = np.sqrt(max(0.0, 1 - q @ q))
    Rx = 2*np.outer(q, q) + 2*w*skew(q) + np.eye(3) - 2*(q @ q)*np.eye(3)
    Mt, yt = [], []
    for Hg, Hc in keep:                        # 平移：(R_A - I) t_X = R_X t_B - t_A
        Mt.append(Hg[:3, :3] - np.eye(3))
        yt.append(Rx @ Hc[:3, 3] - Hg[:3, 3])
    t, *_ = np.linalg.lstsq(np.vstack(Mt), np.hstack(yt), rcond=None)
    T = np.eye(4); T[:3, :3] = Rx; T[:3, 3] = t
    return T

def refine(X0, G, C):
    """非线性精化：LM 最小化所有运动对的 ||AX - XB||_F。"""
    def unpack(p):
        R, _ = cv2.Rodrigues(p[:3])
        T = np.eye(4); T[:3, :3] = R; T[:3, 3] = p[3:6]
        return T
    def resid(p):
        X = unpack(p)
        return np.hstack([(np.linalg.inv(G[j]) @ G[i] @ X - X @ C[j] @ np.linalg.inv(C[i])).ravel()
                          for i, j in combinations(range(len(G)), 2)])
    p0 = np.hstack([cv2.Rodrigues(X0[:3, :3])[0].ravel(), X0[:3, 3]])
    return unpack(least_squares(resid, p0, method="lm").x)
```

## 5. LiDAR-LiDAR 标定：ICP 与 NDT

### 5.1 问题与思路

两个 LiDAR 视角不同，各自看到环境的一部分。若先验位姿已知（机械安装图纸），只需精修；若完全未知，先粗对准再精配准。**配准（registration）**的标准答案：

- **ICP（Iterative Closest Point）**（Besl & McKay 1992）：迭代"最近邻找对应 → SVD 解最优刚体变换"，直到收敛。点-点 ICP 对应到面内的点，**点-面 ICP** 用"点到切平面的距离"做残差，对平面丰富的场景更准更快；
- **NDT（Normal Distributions Transform）**（2D：Biber & Straßer 2003；3D：Magnusson 2009 博士论文）：把参考点云体素化、每格拟合一个高斯，配准 = 最大化源点落在这些高斯下的似然——把"点对点"变成"点对分布"，不需要精确对应，对稀疏和噪声更鲁棒。Autoware 的 `ndt_scan_matcher` 就是它的工业实现。

一句话对比：ICP 简单直接但吃初值、怕退化几何；NDT 更平滑更鲁棒但要做体素参数调优。LiDAR-LiDAR 标定通常：NDT/ICP 粗对准 → 精配准 → 用多帧数据做最小二乘平均。

### 5.2 数值实验：两种 ICP + 掉坑演示

```python
# exp6_icp.py（核心部分；场景：两面墙+地面，2400 点，测距噪声 1 cm，完整脚本见 实验脚本/exp6_icp.py）
def icp_point2point(src, dst, max_iter=60, tol=1e-9):
    R = np.eye(3); t = np.zeros(3)
    tree = cKDTree(dst); prev = np.inf
    for it in range(max_iter):
        cur = (R @ src.T).T + t
        dist, idx = tree.query(cur)                    # 最近邻对应
        mu_s, mu_d = cur.mean(0), dst[idx].mean(0)
        H = (cur - mu_s).T @ (dst[idx] - mu_d)         # 3x3 协方差
        U, _, Vt = np.linalg.svd(H)
        d = np.sign(np.linalg.det(Vt.T @ U.T))
        Rs = Vt.T @ np.diag([1.0, 1.0, d]) @ U.T       # 正交 Procrustes（同第 2 周 Wahba）
        ts = mu_d - Rs @ mu_s
        R, t = Rs @ R, Rs @ t + ts
        rms = np.sqrt((dist ** 2).mean())
        if abs(prev - rms) < tol: break
        prev = rms
    return R, t, rms

def icp_point2plane(src, dst, dst_normals, max_iter=60, tol=1e-9):
    """点-面 ICP：残差用点到切平面距离 n·(p_dst - p_cur)，每步解 6 维小扭转。"""
    R = np.eye(3); t = np.zeros(3)
    tree = cKDTree(dst); prev = np.inf
    for it in range(max_iter):
        cur = (R @ src.T).T + t
        dist, idx = tree.query(cur)
        n = dst_normals[idx]
        b = np.einsum("ij,ij->i", n, dst[idx] - cur)   # 残差
        A = np.hstack([n, np.cross(cur, n)])           # 未知量 (平移 v, 旋转 w)
        sol, *_ = np.linalg.lstsq(A, b, rcond=None)
        v, w = sol[:3], sol[3:]
        Rs, _ = cv2.Rodrigues(w)                       # 小扭转左乘到当前变换
        R, t = Rs @ R, Rs @ t + v
        rms = np.sqrt((dist ** 2).mean())
        if abs(prev - rms) < tol: break
        prev = rms
    return R, t, rms
```

## 6. 为什么要标到 ego 车体系

下游的一切融合——目标级关联、占用栅格、BEV 感知、规划——都在**ego 车体系**（通常后轴中心或车中心，x 向前 y 向左 z 向上）进行。每个传感器的外参其实分两段：

$$
T_{ego \leftarrow sensor} = T_{ego \leftarrow ref}\; T_{ref \leftarrow sensor}
$$

把所有传感器各自标到一个**公共参考系**（而不是两两互标）的好处：

1. **组合爆炸 → 线性增长**：$n$ 个传感器两两互标要 $n(n-1)/2$ 次标定，统一到 ego 只要 $n$ 次；
2. **误差不串联**：A-B、B-C 两两互标时误差相乘累积；星型拓扑里每个误差独立可控；
3. **替换传感器不动别人**：换一个 LiDAR 只重标它自己到 ego 的一段。

外参误差对下游的影响随距离放大：旋转误差 $\delta\theta$ 在距离 $d$ 处产生约 $d \cdot \delta\theta$ 的横向错位——**0.1° 在 100 m 外就是 17 cm**，足够把车道线关联错、把静止目标判定为横穿。这就是"标定不是能跑就行"的定量理由。

---

## 7. 常见坑

1. **A/B 方向或取逆写反**：$AX=XB$ 与 $A^{-1}X=XB^{-1}$ 都"合法"，但数据构造必须与构型（eye-in-hand/to-hand）匹配。症状：解出来的 X 旋转角明显不合理（比如接近 180°）。对策：先在无噪声合成数据上验证精确恢复，再上真实数据。
2. **所有运动轴平行**：X 的解族退化解不出。OpenCV 会报 "Not enough informative motions"。设计运动时强制包含绕不同轴的旋转。
3. **忘了 Gibbs → 四元数的 eq 14 缩放**：复现 Tsai-Lenz 最高频 bug，症状是无噪声时旋转仍差一个系统角度（本教程写作时就踩过一次，见 `q = x/np.sqrt(1+x@x)` 那行的来历）。
4. **ICP 当全局配准用**：初值差 60° 以上大概率掉坑（实验证据：90° 初值收敛到错误位姿）。ICP 是精配准，不是配准的全部。
5. **手眼标定完不验证**：至少做两个检验——(1) 无噪声合成数据精确恢复；(2) 真实数据上把标定板投回多个未见过的位姿看重投影一致性。

---

## 8. 小结

- 手眼标定 $AX=XB$：A 是机器人告诉你的运动，B 是传感器看到的运动，X 是固定安装变换；eye-in-hand 与 eye-to-hand 差在 A 的构造方向。
- 至少两次**不同旋转轴**的运动；工程上 8~10 组多方向大角度位姿性价比最高。
- Tsai-Lenz 两步法：$\mathrm{skew}(P_a{+}P_b)x = P_b{-}P_a$（SVD 线性解 Gibbs 向量 → eq 14 缩放回四元数）+ $(R_A - I)t_X = R_X t_B - t_A$；最后用 LM 最小化 $\|AX-XB\|$ 精化。
- ICP/NDT：LiDAR-LiDAR 配准的主食。ICP 吃初值、怕退化几何；点-面残差优于点-点；大初值误差必须先粗对准。
- 所有外参统一到 ego 系（星型拓扑）：组合数从 $O(n^2)$ 降到 $O(n)$，误差不串联。0.1° 旋转误差在 100 m 外 = 17 cm。

## 9. 自测题（带答案）

**Q1：$AX=XB$ 中，若给的数据满足 $B = X^{-1} A X$，为什么不能直接"两边除"解出 X？**
A：矩阵除法（求逆）只能解 $X$ 出现在一侧的方程。这里 X 同时是共轭算子和未知量，方程对 X 是双线性的。标准做法是把共轭关系在旋转（轴角）和平移上分别线性化——这就是 Tsai-Lenz 的两步。

**Q2：为什么所有运动的旋转轴都平行时手眼标定无解？缺的是哪几个自由度？**
A：平行轴提供的信息等价于一条轴方向。X 的旋转需要把 B 的轴转到 A 的轴（2 个约束方向），再加绕轴的转角分配。单一条轴无法区分"绕该轴的任意旋转分量"，旋转解差一个绕轴自由度，连带平移也解不全。数值表现：堆叠的 skew 方程组秩亏。

**Q3：点-面 ICP 为什么在平面丰富的场景比点-点 ICP 更合适？它有什么盲区？**
A：点-点残差把"沿平面的滑动"也当成误差（对应点在面内乱配），点-面残差只惩罚法向偏离，几何含义正确、线性化更准、收敛更快。盲区：点-面对**滑动方向零敏感**——单块大平面上 x/y 平移和绕法向旋转完全不可观测，必须靠场景中其他方向的平面补足（第 2 周的板位姿态多样性问题换了个马甲）。

**Q4：实验里初值差 90° 时 ICP 收敛到了一个"旋转差 90.21°、RMS 1.94 m"的位姿。为什么 RMS 这么大却没有把 ICP 拉回真值？**
A：ICP 只做局部下降：每一步都在当前对应关系下找最优变换，对应关系锁定后误差面是平的，梯度为零。RMS 大只说明终点不好，不构成逃离局部极小的动力。逃离手段在 ICP 之外：多分辨率 NDT、特征粗配准、多初值并行取残差最小者。

**Q5：5 个传感器的车，两两互标和统一标到 ego 各要多少次标定？换掉其中一个传感器各要重标几次？**
A：两两互标 $5\times4/2=10$ 次，换一个传感器要重标它与其余 4 个的 4 次标定；统一到 ego 只要 5 次，换传感器只重标它自己 1 次。且星型拓扑的误差各自独立、可分开验收。
