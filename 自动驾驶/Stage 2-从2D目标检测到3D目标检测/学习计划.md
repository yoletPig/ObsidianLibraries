### 阶段二：从 2D 目标检测到 3D 目标检测（4 周 + 1 周机动）

**阶段核心目标**：建立「检测任务到底是什么、怎么评、模型怎么把无序点云变成 3D 框」的完整认知——从 2D 检测的通用语言（IoU、NMS、anchor、mAP）出发，沿 PointNet → VoxelNet/SECOND → PointPillars → CenterPoint 的主线吃透点云 3D 检测，最后掌握 KITTI/nuScenes 两套评测体系。本阶段结束时，你能徒手写出 IoU/NMS/AP、模拟 PointPillars 的 pillar 化 shape 链、并读懂任何一篇 3D 检测论文的实验表。

> ⚠️ 你有 DL 基础（懂 CNN、会 PyTorch），但没做过检测任务。本阶段不要求训练真实模型（那是 Stage 3 的工程实战）——重点是**把检测的"度量衡"和点云模型的"数据流"建立到能徒手推演的程度**。每周 MVP 全部用 NumPy 亲手实现核心算法，不调库黑盒。

### 📅 逐周学习路线与 MVP 交付

#### 第 1 周：2D 目标检测基础与 YOLO 演进

* **学习重点**：
* **检测任务定义**：分类（classification）→ 分类+定位（localization）→ 检测（detection，未知数量的目标）；输出框 + 类别 + 置信度。
* **IoU 与 NMS**：交并比的公式与手算；非极大值抑制（Non-Maximum Suppression）为什么必须有、阈值怎么影响召回与误报。
* **anchor 机制**：为什么网格单元直接回归框不够，要先"预设一堆先验框再回归偏移"。
* **mAP 全流程**：precision/recall → PR 曲线 → AP（曲线下面积）→ mAP（多类平均）；VOC 与 COCO 插值方式差异。
* **YOLO 主线演进**：v1 网格回归思想（CVPR 2016）→ v2 anchor + BN（CVPR 2017）→ v3 多尺度 + Darknet-53（2018）→ v5/v8 工程化（Ultralytics，无论文）；FPN 一句话。

* **推荐资料**：
* 论文：*You Only Look Once*（arXiv 1506.02640）、*YOLO9000*（arXiv 1612.08242）、*YOLOv3: An Incremental Improvement*（arXiv 1804.02767）
* 博客：Ultralytics 官方文档（YOLOv5/v8 无论文，文档即规范）
* 综述：*Object Detection in 20 Years: A Survey*（arXiv 1905.05055，前半部分当故事读）

* **💡 第 1 周 MVP 交付**：
> 用 NumPy 手写 `iou()` 与 `nms()`，对 5 个含重复框的假框集合运行并验证去重结果；再实现"按置信度排序 → 累计 TP/FP → PR 包络积分"的 AP 计算器，对 8 个预测框（3 个 GT）手算验证 AP = 0.8333。

#### 第 2 周：点云 3D 检测——PointNet 系与 PointPillars

* **学习重点**：
* **3D 检测输出定义**：7 自由度框（x, y, z, w, l, h, yaw），中心约定、朝向角约定；与 2D 框的本质区别。
* **点云直接检测的挑战**：无序性、稀疏不均匀、体素化后 3D 卷积的内存/计算爆炸。
* **PointNet**：共享 MLP + 对称函数（max pooling）解决无序性；T-Net 一句话；PointNet++ 的 FPS 采样 + 球查询分组一句话。
* **VoxelNet → SECOND**：体素特征编码；为什么需要稀疏卷积（sparse convolution）；SECOND 对稀疏卷积的工程化改进。
* **PointPillars 全流程拆解（本阶段最重要结构，量产上车最多）**：pillar 化 → PFN 逐点特征 → scatter 成伪图像 → 纯 2D backbone + SSD 头；逐步追踪 shape 链，NumPy 模拟。
* **anchor-free heatmap 头**：CenterPoint 的由来——为什么大家抛弃了 anchor。

* **推荐资料**：
* 论文：*PointNet*（arXiv 1612.00593）、*PointNet++*（arXiv 1706.02413）、*VoxelNet*（arXiv 1711.06396）、*SECOND*（Sensors 2018, 18(10):3337）、*PointPillars*（arXiv 1812.05784）
* 代码导览（只读结构不训练）：OpenPCDet 的 PillarFeatureNet 模块

* **💡 第 2 周 MVP 交付**：
> 用 NumPy 验证 PointNet 的置换不变性（随机置换/逆序后全局特征差异 < 1e-12，并构造一个非对称对照）；再实现简化版 pillar 化 + PFN + scatter，对 1000 个模拟点打印完整 shape 链 `(N,4) → (M,16,9) → (M,8) → (C,H,W)`。

#### 第 3 周：CenterPoint 与 3D 检测算法谱系

* **学习重点**：
* **CenterPoint**（CVPR 2021）：把 3D 框中心当关键点——中心热图 + 偏移/尺寸/朝向回归；逐符号解读热图损失与回归头。
* **速度估计与跟踪**：额外预测 2D 速度（vx, vy），跟踪退化为贪心最近点匹配；两阶段 CenterPoint 的特征精修。
* **算法谱系对比**：Point-based（PointRCNN）vs Voxel-based（VoxelNet/SECOND）vs Pillar-based（PointPillars）vs Transformer-based（DETR3D，详见 Stage 5）四条路线的速度/精度/内存权衡表。
* **单模态局限**：纯点云检测在远距离小目标、遮挡、反光场景的天花板——引出 Stage 4 多传感器融合与 Stage 5 BEV。

* **推荐资料**：
* 论文：*CenterPoint*（arXiv 2006.11275，CVPR 2021）、*PointRCNN*（arXiv 1812.04244）、*DETR3D*（arXiv 2110.06922，CoRL 2021）
* 讲座：OpenPCDet 官方 MODEL ZOO 页（对照各模型 KITTI/nuScenes 成绩）

* **💡 第 3 周 MVP 交付**：
> 用 NumPy 生成两个目标的中心热图（高斯核），实现"局部峰值提取 + 亚格偏移 + 尺寸/朝向/速度回归"的解码流程；再模拟两帧目标平移，验证"按预测速度外推 + 贪心最近点"即可完成跨帧匹配（跟踪不需要外观特征）。

#### 第 4 周：3D 检测评测与数据集实战

* **学习重点**：
* **KITTI 评测**：3D IoU / BEV IoU 双基准；car 0.7、行人/骑行者 0.5 的匹配阈值；easy/moderate/hard 按框高像素 + 遮挡级 + 截断比定义；40 个 recall 采样点（R40）。
* **nuScenes 评测**：BEV 中心距离 0.5/1/2/4 m 四档匹配（不用 IoU！）；5 类 TP 错误 ATE/ASE/AOE/AVE/AAE；NDS = [5·mAP + Σ(1−min(1,mTP))]/10 逐项解读。
* **数据集规模与传感器配置**：KITTI（7481/7518 帧）、nuScenes（1000 场景 × 20 s，6 相机 + 1 雷达 + 5 毫米波）、Waymo（约 2000 个 20 s 片段，5 雷达 + 5 相机）。
* **NumPy 手写 BEV 旋转框 IoU**：凸多边形裁剪（Sutherland–Hodgman）+ 蒙特卡洛交叉验证；明确 BEV 近似与 3D IoU 的关系。
* **框架导览**：OpenPCDet 与 MMDetection3D 一句话定位。

* **推荐资料**：
* 官方评测页：[KITTI 3D object detection](https://www.cvlibs.net/datasets/kitti/eval_object.php?obj_benchmark=3d)、[nuScenes detection metric](https://www.nuscenes.org/object-detection)
* 论文：*nuScenes: A multimodal dataset for autonomous driving*（arXiv 1903.11027，CVPR 2020）、*Scalability in Perception for Autonomous Driving: Waymo Open Dataset*（CVPR 2020）

* **💡 第 4 周 MVP 交付**：
> 实现 `bev_rotated_iou()`：角点展开 + 凸多边形裁剪 + 鞋带公式面积，通过 4 组数值测试（完全重合 = 1、轴对齐偏移手算 2/14、旋转 90° 手算 4/12、任意旋转与 20 万点蒙特卡洛差异 < 0.01）；再手算一个 NDS 例子与公式核对。

#### 第 5 周（机动）：阶段复盘 + 真实框架跑通

* **学习重点**：
* 把前四周的手写组件整合成 `det_kit.py`：iou/nms/ap + bev_rotated_iou 四件套。
* 安装 OpenPCDet，用官方预训练 PointPillars 权重对一帧 KITTI 点云推理一次，只关注"点云 → 3D 框"的数据流与第 2 周手推的 shape 链逐项对照。

* **💡 第 5 周 MVP 交付**：
> 一页对照表：PointPillars 真实框架各模块输出 shape vs 你第 2 周的 NumPy 模拟 shape，差异点（如 batch 维、anchor 通道数）逐一解释。这是 Stage 3 训练实战的入场券。
