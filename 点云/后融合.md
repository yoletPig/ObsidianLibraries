# 三种典型传感器简介与特性对比
| 传感器             | 优点                           | 缺点              |
| --------------- | ---------------------------- | --------------- |
| **相机**          | 分辨率高，能识别颜色、纹理、语义信息（如交通标志、行人） | 受光照影响大，无法直接测距   |
| **毫米波雷达**       | 对恶劣天气/光照鲁棒，能提供速度信息           | 分辨率低，难以识别物体轮廓   |
| **激光雷达（LiDAR）** | 精准测距，点云分布稠密，可获取3D结构          | 成本高，部分型号在雨雪中表现差 |

#多传感器融合目标
在路侧目标检测（感知）场景中，多传感器融合的最终目的是：**构建一个准确、鲁棒的3D感知系统 

主要实现以下任务：
- 3D目标检测：识别和定位目标（车辆、行人、非机动车等）在3D空间中的位置、大小、类别。
- 目标跟踪：连续识别同一目标在多个时刻的位置与速度。
- 场景建图与语义理解：识别车道线、红绿灯、障碍物、交通标志等。

# ❗ 多源融合中的实际难点
| 问题           | 描述                                                           |
| ------------ | ------------------------------------------------------------ |
| **异步时延**     | 不同传感器帧率不同（毫米波10Hz，相机25Hz，激光雷达10Hz），目标快速运动时同一目标在不同传感器中的位置有偏移。 |
| **检测误差差异大**  | 激光雷达点稀疏时3D框不准；毫米波仅能估粗略位置；相机易受遮挡和光照影响。                        |
| **类别冲突与误检**  | 不同传感器对同一目标可能判断类别不同（如相机识别为person，毫米波识别为car）。                  |
| **空间重叠不准确**  | 3D框姿态不一致，IOU 或中心点匹配易失败，尤其是大车、斜停目标。                           |
| **漂移/ID不一致** | TrackID 无法一致，导致融合后目标ID漂移，影响下游跟踪和V2X通信。                       |
