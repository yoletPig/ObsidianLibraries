# 10 - 过拟合与正则化

## 本篇目标

读完本篇，你应该能做到：

1. 通过 train/val 曲线的形状诊断欠拟合/过拟合，并按诊断结果选对策（而不是瞎调）。
2. 说清五大正则手段的机制与适用场景：weight decay、dropout、数据增强、早停、label smoothing。
3. 避开 BN 与 dropout 的交互陷阱（6 章 4.3 节埋的伏笔在此清账）。
4. 建立"学习率-批量大小"联动的经验框架。

诊断先于治疗。本篇的顺序是：先学会**读曲线**，再谈**开药方**。

## 1. 过拟合诊断：曲线怎么读

### 1.1 三种典型形态

训练时要同时盯两条曲线（train loss 与 val loss，13 章的 TensorBoard 记录的就是它们）：

```text
形态 A(欠拟合):        形态 B(健康):          形态 C(过拟合):
train  ██████______      train  ████████___      train  ↓↓↓↓↓↓ 一直降
val    ███████_____      val    ███████____      val    ↓↓↑↑↑↑ 先降后升
(两条都高, 贴得近)       (两条都低, 贴得近)      (train 低 val 高, 出现剪刀差)
```

- **形态 A**：模型容量不够 / 没训够 / lr 或特征有问题 → **加容量、训久点、先别想正则**；
- **形态 B**：train 与 val 都收敛且接近 → 完事；
- **形态 C**：val 从某点开始回升、train 一路降 → 模型开始"背题"而不是"学规律" → 上正则。

### 1.2 判断标准与数字感受

- **gap = val_loss − train_loss**：gap 持续扩大是过拟合信号；用 02 章的思路做个数值感受——给一个只有 40 个样本的回归任务配 20 维多项式特征，train MSE 能压到 0.05（低于噪声方差 0.25！），val MSE 却是 2.0：**train loss 低于噪声下界是过拟合的铁证**（它在背噪声）。
- 早停点：val 曲线的最低点，之后每个 epoch 都在变差（1.4 节）。
- 一个反直觉点：**深度学习里"val 先升后降再创新低"也常见**（双下降现象，Nakkiran et al., *Deep Double Descent*, 2019）——所以不要看到 val 小幅回升立刻停，配合早停的 patience 机制（1.4 节）观察。

### 1.3 数值实操：用代码"读"曲线

诊断不必靠肉眼——训练脚本里加十行，让曲线自己说话（典型输出见注释，数值来自 MNIST 每 20 个样本留 5 个的极端小数据实验，标注：经验做法级演示）：

```python
# 每个 epoch 结束时追加一条记录
history = []          # (epoch, train_loss, val_loss)
history.append((epoch, train_loss, val_loss))

# 连续 3 个 epoch 的滑动窗口诊断
for e, tl, vl in history[-3:]:
    print(f"epoch {e}: train={tl:.4f} val={vl:.4f} gap={vl-tl:.4f}")
# 典型输出(过拟合现场):
# epoch 28: train=0.0517 val=0.3115 gap=0.2598   <- gap 稳定扩大
# epoch 29: train=0.0479 val=0.3187 gap=0.2708   <- train 还在降, val 已回升
# epoch 30: train=0.0448 val=0.3280 gap=0.2832   <- 连续扩大 => 触发正则/早停
```

判读规则（可写成 if-else）：gap 连续 3 个 epoch 扩大 **且** val loss 回升 → 形态 C；train loss 高位平台 + gap 小 → 形态 A，**先查容量与 lr，不要加正则**。这十行就是 2.4 节早停代码的前置信号。

## 2. 五大正则手段

### 2.1 weight decay（权重衰减）

**机制**：给损失加 $\frac{\lambda}{2}\lVert\theta\rVert^2$（或 AdamW 的解耦形式，9 章），每步把权重往 0 拉一点。直觉：小权重 → 输出对输入扰动不敏感 → 函数更平滑 → 更难"精确背题"。凸优化的角度：偏好范数小的解 = 缩小解空间。

**陷阱**：L2 正则与 weight decay 在 SGD 下等价，在 Adam 下**不等价**（9 章 4.2）——调参时确认你用的是哪种语义。

### 2.2 dropout

**机制**（Srivastava et al., *Dropout: A Simple Way to Prevent Neural Networks from Overfitting*, JMLR 2014）：训练时每个元素以概率 $p$ 被置零，其余**除以 $(1-p)$**（inverted dropout，保证期望不变），推理时什么都不做。

数值例子（$p=0.5$）：

```python
import torch
torch.manual_seed(0)
x = torch.tensor([1.0, 2.0, 3.0, 4.0])
drop = torch.nn.Dropout(p=0.5)
print(drop(x))
# tensor([0., 4., 0., 8.])   mask=[0,1,0,1], 存活元素乘 1/(1-0.5)=2
# 期望验证: 0.5*4 + 0.5*0 = 2 = 原来的 x[1] —— 期望不变, 方差变大
```

直觉有三层：① 相当于**同时训练指数多个子网络**并共享参数；② 打破神经元间的"共谋"（不能依赖某个特定搭档，迫使冗余表征）；③ 训练时注入噪声 ≈ 数据增强作用于特征层。**p 的典型取值**：全连接层 0.5（原论文默认），注意力内部 0.1（Transformer 惯例，8 章代码里就是）。

### 2.3 数据增强

**机制**：在**标签不变的变换**上扩充数据——旋转/裁剪/翻转/色彩抖动（图像，4 章）、Mixup（把两张图按 $\lambda$ 混合、标签按同样比例混合：$x=\lambda x_i+(1-\lambda)x_j$, $y=\lambda y_i+(1-\lambda)y_j$，Zhang et al., ICLR 2018）、CutMix、随机擦除。它是唯一"同时改善分布本身"的正则——其余手段都在损失/结构上做文章。

**陷阱**：增强必须保语义。数字 6 竖直翻转成 9 就是喂错标签（4 章练习 4 的实验）；医学影像的左右翻转可能改变病灶含义——增强策略是任务知识，不是超参数（经验做法：从该领域已发表工作的增强配置抄起）。

### 2.4 早停（early stopping）

**机制**：val 指标连续 `patience` 个 epoch 没有改善就停，并回滚到最好那点。它是"免费的"正则——不需要改模型，只需要勤评估。GD 的视角：在训练损失面上走得太远会走进"背题"的极小值，早停把你按在泛化最好的位置。

```python
best_val, patience, bad_epochs = float("inf"), 5, 0
for epoch in range(epochs):
    train_one_epoch(...)
    val_acc = evaluate(...)
    if val_acc > best_val:                  # 指标型(越大越好); loss 型反过来
        best_val, bad_epochs = val_acc, 0
        torch.save(model.state_dict(), "best.pt")     # 存最佳点(12 章)
    else:
        bad_epochs += 1
        if bad_epochs >= patience:
            print(f"early stop @ epoch {epoch}"); break
model.load_state_dict(torch.load("best.pt"))          # 回滚到最佳
```

### 2.5 label smoothing（标签平滑）

**机制**（Inception-v3 使用并推广：Szegedy et al., CVPR 2016）：

$$y_k^{LS} = (1-\epsilon)\,y_k + \frac{\epsilon}{K}$$

$K$ 类、$\epsilon=0.1$ 时，真类目标从 1.0 变 $0.9$，其余各类分 $\frac{0.1}{9} \approx 0.0111$（$K=10$）。效果：压住 logit 的极端自信（模型不再追求把正确类推到 $+\infty$），校准更好、对噪声标签更鲁棒，是 ViT/GPT 训练的标配之一。

**陷阱**：做了 label smoothing 后，模型输出的概率**不再可按原样当置信度**（真类概率上限约 0.9），做校准敏感的应用要重新标定（经验做法）。

### 2.6 手段速查表

| 手段 | 作用位置 | 一句话机制 | 什么时候用 |
| --- | --- | --- | --- |
| weight decay | 损失/更新 | 把权重往 0 拉 | 几乎总是 |
| dropout | 网络结构 | 随机断路+期望保持 | 全连接/注意力; CNN 主干早期 |
| 数据增强 | 数据 | 扩充标签不变的样本 | 图像必选; 文本小心保语义 |
| 早停 | 训练过程 | 停在 val 最优点 | 几乎总是(配置便宜) |
| label smoothing | 损失 | 软化 one-hot 目标 | 分类/LLM 训练 |

## 3. BN 与 dropout 的交互陷阱

### 3.1 问题机制

BN 在训练时用**当前 batch** 的统计量做归一化；dropout 在 BN **之后**随机置零，会改变下游 BN 看到的分布——更糟的是，这个"训练分布"在 eval 时消失（dropout 关闭 + BN 换用 running stats），造成**训练/推理的统计失配**（variance shift）：训练 acc 很高、部署后莫名其妙掉点。Li et al., *Understanding the Disharmony between Dropout and Batch Normalization by Variance Shift*, CVPR 2019 实验确认了这一机制。

### 3.2 实践守则

1. **别让 dropout 紧贴 BN 放在 BN 之后**：ResNet 风格 `conv-BN-ReLU` 块的 dropout 若要加，放在块与块之间/主干末端（经验做法，与原论文实践一致）；
2. CNN 主干现代实践：**BN + 无 dropout**，靠数据增强与 weight decay 扛过拟合（经验做法）；
3. Transformer 是安全区：注意力内部 dropout 在 **LayerNorm 之后**，而 LN 不依赖 batch 统计量，没有失配问题（这正是 8 章代码可以放心叠 dropout 的原因）。

## 4. 学习率与批量大小的联动

### 4.1 线性缩放法则

把 batch 扩大 $k$ 倍，学习率约乘 $k$（Goyal et al., *Accurate, Large Minibatch SGD: Training ImageNet in 1 Hour*, 2017）：小 batch 的梯度是噪声估计，步长要保守；大 batch 平均后噪声变小，可以走大步。ResNet-50 从 batch 256 提到 8192，lr 按比例放大后保持精度——大 batch 训练的理论拐杖。

### 4.2 大 batch 的隐性代价

Keskar et al., *On Large-Batch Training for Deep Learning: Generalization Gap and Sharp Minima*, ICLR 2017：大 batch 倾向收敛到**尖锐极小值**（对参数扰动敏感），泛化反而变差。折中概念是 critical batch size（McCandlish et al., 2018, *An Empirical Model of Large-Batch Training*）：batch 超过它后，再大只省时间不省样本。实践定位（经验做法）：单卡 batch 32~512 之间调 lr 联动即可；为"省时间"把 batch 推到几千时，先问样本效率是否还重要。

### 4.3 联动调参顺序（经验做法）

1. 固定 batch（受显存限制），扫 lr（数量级扫：1e-4/3e-4/1e-3）；
2. 找到能稳定下降的最大 lr，配 9 章 warmup；
3. 数据/模型更换后，按比例重算 lr，而不是从头再扫。

## 5. 常见陷阱

1. **一过拟合就上 dropout**：先看曲线！形态 A（欠拟合）加正则雪上加霜。对策顺序永远是：诊断 → 容量/数据 → 正则。
2. **dropout 放错位置**（3 节）与 **p 忘记 train/eval 差异**：`eval()` 忘调时 dropout 仍在随机，指标抖动（03 章）。
3. **增强破坏语义**（2.3）：6↔9、医学影像翻转。
4. **weight decay 对所有参数一刀切**：bias/LN γ β 不应衰减（9 章 4.2）。
5. **label smoothing + 早停误判**：平滑后 val loss 更低更平，别与未平滑的旧实验直接对比 loss 数值。
6. **把 val 集当训练集用**：反复按 val 调几百次超参，val 也在"过拟合"——这叫间接过拟合，最终报告必须用从未参与任何决策的 test 集（13 章的实验纪律）。

## 本篇小结

- 诊断先行：train/val 曲线的形态决定加容量还是加正则；train loss 低于噪声下界 = 过拟合铁证；val 波动回升要有 patience 再下结论（警惕双下降）。
- 五大手段作用位置各不同：weight decay 拉权重、dropout 断路保期望、增强改数据分布、早停停在 val 最优、label smoothing 软化目标。
- BN 后紧贴 dropout 会造成 variance shift，训练/推理失配——CNN 主干靠增强+wd，Transformer 里 dropout 在 LN 后安全。
- batch 扩 k 倍 lr 约乘 k（线性缩放）；大 batch 有 sharp minima 泛化代价，调参顺序"先固定 batch 扫 lr，再联动"。

## 练习

1. 构造过拟合现场：MNIST 只取每类 50 张训练（共 500 张），用 3 章 MLP 训 30 epoch，记录 train/val acc 曲线，验证出现形态 C；然后依次单独加 dropout(0.5)、数据增强（RandomCrop）、早停，比较各自把 val acc 拉回多少。
2. 验证 inverted dropout 的期望不变性：对 `x=torch.ones(10000)` 应用 `nn.Dropout(0.3)`，检查输出均值是否仍约等于 1（大数定律）。
3. 手算并实现 label smoothing：$K=10, \epsilon=0.1$，写出 10 维目标向量，并用 `F.cross_entropy(logits, target_soft)` 验证它接受软标签。
4. 复现 3 节实验：`BN→Dropout→BN` 的三层网络在 train 与 eval 模式下对**同一批固定输入**做前向，比较输出的均值/方差差异。
5. 固定模型与数据，用 batch=64/128/256 各配 lr=1e-3/2e-3/4e-3 训 MNIST 5 epoch，验证"batch 翻倍 lr 翻倍"是否保持精度稳定。
