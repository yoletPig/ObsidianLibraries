## 1. 卷积的直觉与数学

### 1.1 为什么需要它：全连接的两宗罪

28×28 的灰度图拉平是 784 维；224×224 的 RGB 图是 150,528 维。接一个 1024 隐层的全连接层，第一层就有 $150528 \times 1024 \approx 1.5$ 亿参数。而且：

1. **参数爆炸**：内存放不下、数据喂不饱（10 章的过拟合天堂）；
2. **丢弃空间结构**：把图片拉平后，"相邻像素相关"这一图像最基本的结构信息被抹掉——把图块打乱重排后全连接网络照样训练，说明它根本没利用空间关系。

### 1.2 卷积的两个思想

**局部连接**：视觉特征是局部的（边缘、角点只关心邻近像素），每个输出只看输入的一小块 $k\times k$ 窗口。

**权重共享**：检测"竖直边缘"的那个小滤波器，应该在图像任何位置都好用——同一个 $k\times k$ 核滑过全图，参数只有 $k^2$ 个，与图像大小无关。

参数对比（感受野等效的情况下）：100×100 输入、128 通道——全连接一层要 $10^4 \times 128 \approx 131$ 万参数；$3\times 3$ 卷积只要 $3\times3\times128 = 1152$ 个（单输入通道时）。

### 1.3 数学定义与"互相关"真相

深度学习里的"卷积"实际是**互相关（cross-correlation）**：滑动窗口做逐元素乘再求和，不翻转核。数学卷积会先翻转核，对学出来的核而言两者等价（要学什么对称性网络自己会学），实现上省了翻转。出处：Goodfellow et al., *Deep Learning* §9.1；PyTorch 官方文档 `nn.Conv2d` 的说明也明确是 cross-correlation。

$$\text{out}[o, i, j] = b_o + \sum_{c}\sum_{u}\sum_{v} \text{in}[c, i\cdot s + u, j\cdot s + v] \cdot W[o, c, u, v]$$

其中 $s$ 是步幅（stride）。张量形状约定（PyTorch）：输入 $(N, C_{in}, H, W)$，权重 $(C_{out}, C_{in}, k_H, k_W)$，输出 $(N, C_{out}, H_{out}, W_{out})$。

### 1.4 输出尺寸公式（配数字）

$$H_{out} = \left\lfloor \frac{H + 2p - k}{s} \right\rfloor + 1$$

- 输入 32×32，k=5，p=2，s=1：$(32+4-5)/1+1 = 32$（**same padding**，p=(k-1)/2 时尺寸不变）；
- 输入 32×32，k=3，p=0，s=2：$(32-3)/2+1 = 15$（**15.5 向下取整**——尾部的 0.5 行被丢弃）；
- 输入 224×224，k=7，p=3，s=2（ResNet 的 stem）：$(224+6-7)/2+1 = 112$。

**背下公式**，然后所有报错 `Sizes of ... must match` 的 shape 问题都能口算定位。

## 2. 手写 2D 卷积（naive 版）

用四重循环把 1.3 的公式变成代码，再和 `F.conv2d` 对拍（这是验证"你真的懂公式"的唯一方式）：

```python
import torch
import torch.nn.functional as F

def conv2d_naive(x, w, stride=1, padding=0):
    """单样本单通道版: x (1,1,H,W), w (1,1,kH,kW) —— 只为看清机制"""
    H, W = x.shape[2], x.shape[3]
    kH, kW = w.shape[2], w.shape[3]
    H_out = (H + 2 * padding - kH) // stride + 1        # 1.4 节公式
    W_out = (W + 2 * padding - kW) // stride + 1
    if padding:
        x = F.pad(x, (padding, padding, padding, padding))  # 四周补 0
    out = torch.zeros(1, 1, H_out, W_out)
    for i in range(H_out):                               # 滑动窗口的行
        for j in range(W_out):                           # 滑动窗口的列
            region = x[0, 0, i*stride:i*stride+kH, j*stride:j*stride+kW]
            out[0, 0, i, j] = (region * w[0, 0]).sum()   # 逐元素乘再求和
    return out

x = torch.arange(16, dtype=torch.float32).reshape(1, 1, 4, 4)
w = torch.ones(1, 1, 3, 3)                                # 3x3 全 1 核 = "9 邻域求和"
out = conv2d_naive(x, w)
print(out[0, 0])
# tensor([[45., 54.],
#         [81., 90.]])   —— 手算: 左上窗口 0+1+2+4+5+6+8+9+10 = 45 ✓
print(torch.allclose(out, F.conv2d(x, w)))                # True —— 与官方实现一致
```

3×3 全 1 核的语义就是"对 9 邻域求和"，相当于一次模糊。换 `w = torch.tensor([[[[-1.,0.,1.],[-1.,0.,1.],[-1.,0.,1.]]]])` 就是经典 Sobel 竖直边缘检测器——卷积核 = 可学习的"特征检测器"，CNN 不过是把"人设计核"换成"从数据学核"。

**性能注记**：naive 版只是教学用；真实实现用 im2col 展开成矩阵乘（GPU 上是 GEMM）。经验做法：四重循环的 Python 卷积只用于验证正确性，跑真实数据用 `nn.Conv2d`。

## 3. 经典架构演进：四代谱系

### 3.1 LeNet（1998）——模板的确立

LeCun 等用于手写数字识别：卷积-池化-卷积-池化-全连接。确立了 **"卷积提特征、池化缩尺寸、末端全连接做分类"** 的模板（LeCun et al., *Gradient-Based Learning Applied to Document Recognition*, 1998）。

### 3.2 AlexNet（2012）——深度学习元年的引信

比 LeNet 深且宽（5 卷积 + 3 全连接，6000 万参数），引入 **ReLU**（缓解梯度消失，见 5 章）、**Dropout**（10 章）、**GPU 训练**与数据增强，把 ImageNet top-5 错误率从 26% 打到 15.3%（Krizhevsky et al., *ImageNet Classification with Deep Convolutional Neural Networks*, NeurIPS 2012）。

### 3.3 VGG（2014）——"小核堆深"的算术

VGG 全部用 3×3 卷积堆到 16-19 层。关键算术：**两层 3×3 串联的感受野 = 一层 5×5；三层 = 一层 7×7**，且参数更少：

```text
两层 3x3xC: 参数 2 × (3·3·C·C) = 18C²
一层 5x5xC: 参数 5·5·C·C       = 25C²   —— 同感受野多 39% 参数, 还少两次非线性
```

（Simonyan & Zisserman, *Very Deep Convolutional Networks*, ICLR 2015。）感受野（receptive field）：某层的一个输出神经元"看得见"的原始输入区域，逐层乘核尺寸增长。经验做法：现代网络几乎不再用 5×5 以上卷积，1×1 卷积负责升降通道（"逐点混合通道，不做空间混合"）。

### 3.4 ResNet（2015）——残差为什么有效

层数过百后，普通网络反而比浅网络**训练误差更高**（不是过拟合，是优化失败——退化问题）。ResNet 的改动只有一行：

$$y = \mathcal{F}(x) + x \quad (\text{若维度不一致，对 } x \text{ 做 } 1\times1 \text{ 卷积对齐})$$

（He et al., *Deep Residual Learning for Image Recognition*, CVPR 2016，arXiv 2015。）

**从梯度通路看为什么有效**（本篇重点）：

$$\frac{\partial y}{\partial x} = \frac{\partial \mathcal{F}(x)}{\partial x} + I$$

- 多了一个恒等的 $+I$ 项：即使 $\mathcal{F}$ 的梯度是 0，梯度仍能**原样直通**——网络再深，靠近输入的层至少能收到和靠近输出层一样大的梯度，**梯度消失被结构性消除**；
- 学习目标从"学出完整变换 $y=H(x)$"变成"学残差 $\mathcal{F}=H-x$"。若某层是多余的，把 $\mathcal{F}$ 推向 0 即可（"恒等映射"极易表达），层数不再有副作用；
- 后续论文（He et al., *Identity Mappings in Deep Residual Networks*, ECCV 2016）用实验证实：把恒等路径改造（加缩放/门控）会重新出现训练困难——恒等无阻塞是关键。

残差思想是全书出现的第二座桥（第一座是注意力）：Transformer 的每个 block 就是"残差 + 子层"，8 章实现时你会再遇到它。

### 3.5 谱系速查

| 网络 | 年份 | 关键词 | 解决的问题 |
| --- | --- | --- | --- |
| LeNet | 1998 | 卷积-池化-FC 模板 | 可学习的特征 |
| AlexNet | 2012 | ReLU/Dropout/GPU | 深网络的训练可行性 |
| VGG | 2014 | 3×3 小核堆深 | 同感受野下更省参数 |
| ResNet | 2015 | $y=\mathcal{F}(x)+x$ | 深网络的退化与梯度通路 |

## 4. BatchNorm：原理与 train/eval 差异

### 4.1 为什么需要它

内部协变量偏移（ICS）直觉：前一层的参数一更新，后一层收到的输入分布就漂移，后一层永远在"追着移动靶"训练。BatchNorm（Ioffe & Szegedy, *Batch Normalization*, ICML 2015）把每层输入强行拉回标准分布，训练立刻提速变稳。（ICS 的严格解释后来有争议——Santurkar et al., *How Does Batch Normalization Help Optimization?*, NeurIPS 2018 认为关键在**损失面平滑化**——但"拉平分布 + 稳训练"的工程效果无争议。）

### 4.2 数学与形状

对形状 $(N, C, H, W)$ 的特征，**沿 $(N, H, W)$ 方向**（每个通道独立）统计均值方差：

$$\hat{x}_{c} = \frac{x_c - \mu_c}{\sqrt{\sigma_c^2 + \epsilon}}, \qquad y_c = \gamma_c \hat{x}_c + \beta_c$$

$\gamma,\beta$ 是可学习参数（允许网络"如果不想要标准化可以学回去"）；$\epsilon=10^{-5}$ 防除零。动手验证数字：

```python
bn = torch.nn.BatchNorm2d(1, eps=1e-5, affine=False)
x = torch.tensor([[[[1.0, 2.0], [3.0, 4.0]]]])   # (1, 1, 2, 2)
print(bn(x))
# tensor([[[[-1.3416, -0.4472],
#           [ 0.4472,  1.3416]]]])
# 手算: mean=2.5, var=1.25, (1-2.5)/sqrt(1.25+1e-5) = -1.3416 ✓
```

### 4.3 train/eval 行为差异（必考）

| | `model.train()` | `model.eval()` |
| --- | --- | --- |
| 归一化用什么统计量 | **当前 batch** 的 $\mu, \sigma^2$ | 全局滑动平均 `running_mean/var` |
| 统计量是否更新 | 是（滑动平均） | 否 |

```python
bn = torch.nn.BatchNorm2d(1)
print(bn.running_mean)        # tensor([0.])
x = torch.full((2, 1, 2, 2), 5.0)
bn.train(); bn(x)
print(bn.running_mean)        # tensor([4.9995]) —— momentum=0.1: 0.9*0 + 0.1*5
bn.eval()
bn(x)
print(bn.running_mean)        # 仍是 4.9995 —— eval 不再更新
print(bn(x)[0,0])             # 全 1（用 running 统计量: (5-4.9995)/sqrt(≈0+eps)≈1）
```

**推理时的含义**：BN 在 eval 下是固定的仿射变换，推理无 batch 依赖。这引出 11 章微调的大坑——**微调时若不处理 BN，验证统计量会被小 batch 数据带偏**。

### 4.4 BN 的使用约束

1. **batch 太小（<8）时统计量噪声大**，效果劣化； batch=1（在线推理训练、大模型显存受限）时几乎不可用 → 9 章的 LayerNorm/RMSNorm 登场；
2. **训练集 `drop_last` 的理由之一**：尾批只有 1 个样本时，方差为 0（train 模式），前向直接出 NaN；
3. BN 层后通常**不再加 bias** 的前置卷积（`Conv2d(..., bias=False)`）：BN 的 $\beta$ 已经承担了偏置角色，省参数（经验做法，ResNet 原实现如此）。

## 5. 组装一个迷你 CNN（MNIST 可运行）

```python
import torch
import torch.nn as nn

class MiniCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(               # 输入 (B, 1, 28, 28)
            nn.Conv2d(1, 16, 3, padding=1),          # -> (B, 16, 28, 28)  same padding
            nn.BatchNorm2d(16),
            nn.ReLU(),
            nn.MaxPool2d(2),                         # -> (B, 16, 14, 14)
            nn.Conv2d(16, 32, 3, padding=1),         # -> (B, 32, 14, 14)
            nn.BatchNorm2d(32),
            nn.ReLU(),
            nn.MaxPool2d(2),                         # -> (B, 32, 7, 7)
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),                            # -> (B, 32*7*7 = 1568)
            nn.Linear(32 * 7 * 7, 10),               # logits (B, 10)
        )
    def forward(self, x):
        return self.classifier(self.features(x))

model = MiniCNN()
x = torch.randn(4, 1, 28, 28)
print(model(x).shape)   # torch.Size([4, 10])
print(sum(p.numel() for p in model.parameters()))   # 18426，比 3 章 MLP 还小
```

把 3 章训练循环里的 `MLP` 换成 `MiniCNN`，MNIST 测试精度 5 epoch 内可从 ~97.8%（MLP）提到 **98.8% 左右**（CPU 每 epoch 约 1-2 分钟；数字为典型量级，标注：经验做法级参考值）。每个 feature map 的 shape 都标注在注释里——**写 CNN 时逐层注释 shape 是防 shape 错误最有效的习惯**。

`Flatten` 处的 `(32*7*7=1568)` 是新手最易错点：改了池化次数/核尺寸后忘记同步改全连接输入维度，报 `mat1 and mat2 shapes cannot be multiplied`。防错姿势（经验做法）：在 `forward` 里放一个 `print(x.shape)` 调试一次，或用 `nn.AdaptiveAvgPool2d(1)` 把空间维压成 1×1，全连接输入就与输入分辨率解耦。

## 6. 常见陷阱

1. **张量布局搞反**：`Conv2d` 要 $(N,C,H,W)$；用 `np/plt` 读进来的图是 $(H,W,C)$，忘 `permute` 就把"颜色通道"当"宽高"卷。
2. **Flatten 维度对不上**（5 节末）：池化改一次，全连接炸一次。
3. **BN 后接 Dropout 相邻**：10 章专讲，两者相互作用会造成 train/eval 统计失配，先记住"别紧挨着放"。
4. **训练时忘了 `model.train()`**：BN 用错统计量模式，症状是"评估精度反而比训练时还高/极不稳定"。
5. **kernel size 与 padding 的奇偶**：想保持尺寸不变，用奇数核 + padding=(k-1)/2；偶数核永远无法 same padding。
6. **以为卷积核必须 3×3**：1×1（通道混合）、7×7 大核（ConvNeXt 又用回来）都是选择；选核是感受野与参数量的权衡。

## 本篇小结

- 卷积 = 局部连接 + 权重共享；参数量与图像大小解耦，这是它对全连接的根本优势。
- 输出尺寸 $\lfloor (H+2p-k)/s\rfloor + 1$ 必须口算；same padding = 奇数核 + p=(k-1)/2。
- 架构谱系：LeNet 定模板，AlexNet 引爆（ReLU/Dropout/GPU），VGG 用小核省参数，ResNet 用 $+\,I$ 的恒等梯度通路解决了"深而训不动"。
- BN 沿 $(N,H,W)$ 每通道标准化，train 用 batch 统计量并维护滑动平均，eval 用全局统计量；batch 小时失效，这是 LayerNorm 存在的理由。
- 手写 naive 卷积对拍 `F.conv2d` 是检验理解的试金石；逐层标注 shape 是工程好习惯。
