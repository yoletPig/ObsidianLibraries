## 1. 链式法则：一切的前提

### 1.1 一元复合函数

若 $y = f(u)$，$u = g(x)$，则

$$\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}$$

直觉：$x$ 动一点，先按 $g$ 的敏感度改变 $u$，$u$ 再按 $f$ 的敏感度改变 $y$——敏感度相乘。

### 1.2 多元情况：偏导照样成立

多输出/多输入时，每个中间变量对上游每个变量的偏导都按上式相乘再相加（全路径求和）。形式化版本用"雅可比矩阵"（第 3 节），但深度学习的绝大多数直觉一元链式法则就够用。

## 2. 手工对计算图求导（配数字）

### 2.1 例一：经典三节点图

计算 $f = q \cdot z$，其中 $q = x + y$。设 $x=2,\ y=3,\ z=4$。

```text
x=2 ──┐
      ├─→ q = x+y = 5 ──→ f = q*z = 20
y=3 ──┘              ↑
z=4 ─────────────────┘
```

前向逐节点算，反向从 $f$ 出发**逆着边**走，每条边乘上"这条边代表的局部导数"：

| 反向目标 | 局部导数 | 结果 |
| --- | --- | --- |
| $\partial f/\partial q$（对乘法） | $z = 4$ | 4 |
| $\partial f/\partial z$ | $q = 5$ | 5 |
| $\partial f/\partial x$ = $\partial f/\partial q \cdot \partial q/\partial x$ | $4 \times 1$ | 4 |
| $\partial f/\partial y$ | $4 \times 1$ | 4 |

**乘法节点把上游梯度"乘上另一个操作数"传下去；加法节点把梯度原样（×1）分发给两个输入。** 记住这两句，加上下面几个常用局部导数，你就能反向穿过任何网络。

常用局部导数速查：

| 运算 | 局部导数 |
| --- | --- |
| $c = a+b$ | $\partial c/\partial a = 1,\ \partial c/\partial b = 1$ |
| $c = a \cdot b$ | $\partial c/\partial a = b$ |
| $c = \tanh(a)$ | $\partial c/\partial a = 1 - c^2$（用**输出**表示，注意！） |
| $c = \sigma(a)$ | $\partial c/\partial a = c(1-c)$ |
| $c = aW$（矩阵） | $\partial L/\partial W = a^\top \delta,\ \partial L/\partial a = \delta W^\top$（$\delta$ 是上游梯度） |

### 2.2 例二：一个真正的迷你网络（全部数字算到底）

网络：$h = \tanh(w_1 x + b_1)$，$\hat y = w_2 h + b_2$，损失 $L = (\hat y - t)^2$（暂时不带 $\frac{1}{2}$ 或均值，方便手算）。取 $x=1.0,\ w_1=0.5,\ b_1=0,\ w_2=1.5,\ b_2=0,\ t=1.0$。

**前向**（每一步都能按计算器）：

| 量 | 公式 | 数值 |
| --- | --- | --- |
| $z_1$ | $w_1 x + b_1$ | 0.5 |
| $h$ | $\tanh(0.5)$ | 0.4621 |
| $\hat y$ | $1.5 \times 0.4621$ | 0.6932 |
| $L$ | $(0.6932-1)^2$ | 0.0941 |

**反向**（从 $L$ 出发）：

| 梯度 | 链条 | 数值 |
| --- | --- | --- |
| $\partial L/\partial \hat y$ | $2(\hat y - t) = 2 \times (-0.3068)$ | $-0.6139$ |
| $\partial L/\partial w_2$ | $\partial L/\partial \hat y \cdot h = -0.6139 \times 0.4621$ | $-0.2837$ |
| $\partial L/\partial h$ | $\partial L/\partial \hat y \cdot w_2 = -0.6139 \times 1.5$ | $-0.9208$ |
| $\partial L/\partial b_1$ | $\partial L/\partial h \cdot (1-h^2) = -0.9208 \times (1-0.2135)$ | $-0.7240$ |
| $\partial L/\partial w_1$ | $\partial L/\partial h \cdot x \cdot (1-h^2)$ | $-0.7240$（因 $x=1$） |

注意两个细节：$\tanh$ 的局部导数用**输出** $h$ 表示（$1-h^2$，其中 $h^2=0.2135$），这是前向值被缓存复用的例子；$\partial L/\partial w_1$ 与 $\partial L/\partial b_1$ 同值仅因 $x=1$ 的巧合。以下代码验证（已实测，数值与上表一致）：

```python
import torch

x  = torch.tensor(1.0, requires_grad=True)
w1 = torch.tensor(0.5, requires_grad=True)
w2 = torch.tensor(1.5, requires_grad=True)
b1 = torch.tensor(0.0, requires_grad=True)

h = torch.tanh(w1 * x + b1)
y_hat = w2 * h
L = (y_hat - 1.0) ** 2
L.backward()
print(w1.grad, w2.grad)   # tensor(-0.7239) tensor(-0.2836) —— 与手算一致
```

### 2.3 为什么"反向"而不是"对每个参数单独前向求导"

设网络有 $N$ 个参数。朴素数值差分要 $2N$ 次前向（02 章的 `numerical_grad`）；**反向传播把总代价降到与一次前向同阶（约 2 倍前向的计算量）**。这就是反向传播 1986 年论文的核心贡献（Rumelhart, Hinton & Williams, *Learning representations by back-propagating errors*, Nature 1986）。工程含义：训练一步 ≈ 3 次前向的算力，参数量再大也承担得起。

## 3. 动态图 vs 静态图，以及 VJP 机制

### 3.1 两种建图方式

- **动态图（PyTorch / JAX 默认）**：前向代码跑一遍，图**边执行边建**，每个 step 一张新图。调试像普通 Python（print/断点都行），控制流（if/while 依赖数据的循环，如 RNN 变长）天然支持。
- **静态图（TF1.x / 老版 Theano）**：先声明整张图再执行。优点是可以先全局优化（算子融合、内存规划）、方便序列化到推理引擎；缺点是"图"和"代码"是两套语言，调试痛苦。

现代框架的走向是**动态图为主 + 编译加速**：PyTorch 2.x 的 `torch.compile` 在动态图语义不变的前提下，把捕获的图编译成优化内核（12 章概览）。出处：PyTorch 2.0 官方发布说明。

### 3.2 backward 的真实机制：VJP（向量-雅可比积）

PyTorch 反向传播的不是"每个参数的梯度"这种大批量标量运算，而是**从 loss 出发的一股梯度流**。每遇到一个多输出节点，就用链式法则的矩阵形式：

$$\bar{x} = \left(\frac{\partial y}{\partial x}\right)^\top \bar{y}$$

$\bar y$ 是上游流下来的梯度（行向量），$\partial y/\partial x$ 是雅可比矩阵。PyTorch **从不显式构造雅可比**，只实现每个算子的 VJP（一次矩阵乘的代价）。这解释了 01 章的现象：

- `backward()` 只能从标量调——因为"梯度流"的源头 $\bar y$ 必须是 1 维的（全 1）。
- `y.backward(torch.ones_like(y))` 等价于"对 y 各分量梯度求和"——因为你手动指定了源头向量。
- 中间节点梯度"用完即弃"——梯度流到达叶子（参数）后，其余分支没人需要，就被释放。

### 3.3 非标量 backward 的语义陷阱

```python
v = torch.randn(3, requires_grad=True)
out = v * v
# out.backward()                        # RuntimeError: grad can be implicitly created only for scalar outputs
out.sum().backward()                     # 等价于 out.backward(torch.ones(3))
print(v.grad)                            # 2*v —— 每个分量的 2v_i 相加(只有一路, 就是本身)
```

注意：`out.sum().backward()` 得到的是 $\sum_k \partial \text{out}_k/\partial v_i$——若 `out` 的多个分量都依赖同一 $v_i$（比如矩阵乘中一个参数影响整行输出），梯度是**所有路径之和**。这正是"多路梯度自动累加"的数学本质。

## 4. 梯度检查：torch.autograd.gradcheck

### 4.1 为什么需要它

自己写了自定义算子/自定义 autograd.Function，怎么确认 backward 实现正确？用**数值差分**当裁判：中心差分的误差是 $O(\epsilon^2)$，在 double 精度下足以检测实现错误。

### 4.2 用法

```python
import torch

def f(x):
    """任意可微函数: 输入输出都是张量"""
    return (torch.tanh(x) ** 2).sum(dim=1, keepdim=True) * x

# 关键: 必须用 float64（float32 的舍入误差会让数值差分与解析梯度对不上）
x = torch.randn(3, 4, dtype=torch.double, requires_grad=True)
ok = torch.autograd.gradcheck(f, (x,), eps=1e-6, atol=1e-5)
print(ok)   # True —— 所有元素的解析梯度与数值差分一致
```

三条纪律（官方文档明示）：

1. 输入用 `dtype=torch.double`；
2. eps 默认 1e-6，atol/rtol 适当放宽（`atol=1e-5` 常用）；
3. 检查点要小（几个到几百个元素）——差分对每个元素都要两次前向，只用于测试，绝不进训练循环。

出处：PyTorch 官方文档 `torch.autograd.gradcheck`。训练中怀疑"梯度断了"时的快速替代（不求精确值）：打印每层参数梯度的范数 `p.grad.norm()`，找范数异常小/大的层——这就是下一节问题的诊断入口。

## 5. 梯度消失与梯度爆炸

### 5.1 数学成因

深度网络的梯度是**沿途局部导数的连乘**：

$$\frac{\partial L}{\partial w_1} = \frac{\partial L}{\partial h_n}\cdot\frac{\partial h_n}{\partial h_{n-1}}\cdots\frac{\partial h_2}{\partial h_1}\cdot\frac{\partial h_1}{\partial w_1}$$

n 层连乘的行为由每层因子决定：

- 每个因子都略小于 1 → 连乘指数衰减 → **消失**（越靠近输入的层梯度越小、学不动）；
- 每个因子都略大于 1 → 连乘指数增长 → **爆炸**（数值溢出、参数飞掉）。

### 5.2 消失：sigmoid 的数字账

$\sigma'(z) = \sigma(z)(1-\sigma(z))$，最大值在 $z=0$ 处取到，**上限 0.25**。若每层经过一个饱和的 sigmoid，10 层后梯度至多剩：

$$0.25^{10} \approx 9.5 \times 10^{-7}$$

何况实际 $\sigma'(z)$ 通常远小于 0.25（远离 0 就趋近 0）。用具体数字跑一遍：

```python
import torch, math

grad = 1.0
for layer in range(10):
    grad *= 0.25          # 假设每层都取到 sigmoid 导数上限
print(grad)               # 9.5367e-07 —— 第 1 层基本收不到学习信号
```

这就是 2010 年之前深网络训不动的核心原因之一。三个经典缓解手段（后文分别展开）：

1. **换激活函数**：ReLU 导数在正区间恒为 1（无衰减因子），6 章 CNN 默认；
2. **更好的初始化**：Xavier/Kaiming 让每层因子接近 1（9 章）；
3. **加"高速公路"**：残差连接让梯度多一条乘 1 的直通路径（6 章 ResNet）。

### 5.3 爆炸：权重稍大的连乘

把上例的"每层因子"换成 1.5（权重初始过大、或 RNN 的循环权重偏大）：

```python
grad = 1.0
for layer in range(30):
    grad *= 1.5
print(grad)   # 191751.0 —— 30 层放大 19 万倍，float32 也快撑不住了
```

爆炸的工程解法直接而有效——**梯度裁剪**：若 $\lVert g\rVert_2 > c$，则 $g \leftarrow g \cdot \frac{c}{\lVert g\rVert_2}$，典型 $c=1.0$（RNN/Transformer 训练标配，9 章给出代码与 TensorBoard 观测方法）。出自 Pascanu, Mikolov & Bengio, *On the difficulty of training recurrent neural networks*, ICML 2013。

### 5.4 一张对照表

| 现象 | 典型症状 | 数学根源 | 缓解 |
| --- | --- | --- | --- |
| 消失 | 深层网络前几层 loss 几乎不动、`p.grad.norm()` 极小 | 局部导数 <1 连乘 | ReLU/初始化/残差/LN |
| 爆炸 | loss 变 nan、梯度范数巨大 | 局部导数 >1 连乘 | 裁剪、初始化、LN、降 lr |
| 饱和 | tanh/sigmoid 输出全压在 ±1 或 0/1 | 局部导数→0 | 换激活、BN、别让 logit 太大 |

## 6. 常见陷阱

1. **对非标量调 backward 忘传 gradient 参数**：报错 `grad can be implicitly created only for scalar outputs`（3.3 节）。
2. **gradcheck 用 float32**：假阳性报警——不是你的梯度错，是差分精度不够（4.2 节）。
3. **以为"中间层梯度可见"**：默认只有叶子有 `.grad`，调试用 `retain_grad()` 或 hook（01 章）。
4. **连乘方向搞反**：消失/爆炸影响的是**靠近输入**的层（梯度从 loss 流向输入，一路相乘）；"最后一层梯度很大、第一层梯度接近 0"才是消失的典型指纹。
5. **把梯度裁剪当成万能药**：裁剪掩盖的是症状；如果每步都在裁剪（clip 系数频繁生效），说明 lr/初始化有问题，应查根因（经验做法：监控"被裁剪的步数占比"）。

## 本篇小结

- 链式法则逐边相乘：加法传 1，乘法传另一个操作数，tanh/sigmoid 的局部导数用输出表示。
- 反向传播把"对 N 个参数求导"从 $O(N)$ 次前向降到约 2 次前向的代价，这是深度学习可行的算力基础。
- PyTorch 是动态图：边执行边建图，`backward` 从标量 loss 反向流动，实现上每步只做 VJP、从不构造雅可比。
- `gradcheck` 用 double 精度 + 数值差分验证自定义梯度；训练中用梯度范数快速定位问题层。
- 梯度消失 = 局部导数小于 1 连乘（sigmoid 上限 0.25 的数字账）；爆炸 = 大于 1 连乘；分别对应"换激活/初始化/残差"与"梯度裁剪"。
