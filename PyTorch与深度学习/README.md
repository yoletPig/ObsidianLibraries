# PyTorch 与深度学习从零开始

> 面向 Python 基础扎实、但**没有系统学过深度学习**的学习者：从"张量是什么"一路讲到"亲手训练一个迷你 GPT"，补上算法工程师的地基。
> 全系列为中文原创，代码全部 **CPU 可跑**（需要 GPU 的地方单独标注）。本仓库的《VLM & VLA》《语音方向》《模型性能优化》都默认你已掌握本系列内容——它就是那块缺失的前置拼图。

### 阶段划分

1. **地基（01–02）**：张量与自动微分、不用框架手写线性回归。学完你就知道"训练"到底在循环什么。
2. **框架与数据（03–04）**：`nn.Module`、optimizer、DataLoader。从"会算"到"会用 PyTorch 写工程代码"。
3. **原理与模型（05–08）**：反向传播数学 → CNN → RNN/注意力 → Transformer。这是全系列的理论主干，08 篇把前面所有知识组装成一个能生成文本的 miniGPT。
4. **训练工程（09–11）**：训练稳定性、正则化、迁移学习。让模型"训得动"之后，让它"训得好、训得省"。
5. **落地（12–13）**：保存、部署、推理优化，最后用一个综合项目把全部知识串成可复现的工程实践。

## 与本仓库其他方向的衔接

- **VLM & VLA Stage 1（VLM 基础与架构深度拆解）**：拆 ViT 与 LLM 的架构时，默认你已经懂卷积（06）、多头注意力与残差结构（07/08）——本系列 06–08 正是它的前置。
- **VLM & VLA Stage 8（训练系统）**：多阶段训练、LoRA 微调、显存优化，全部建立在 03（训练循环）、09（优化器与混合精度）、11（LoRA）之上。
- **语音方向 Stage 2（Whisper）**：Whisper 是 encoder-decoder Transformer，理解它需要 07 的 seq2seq 与 08 的 Transformer 实现。
- **模型性能优化 Stage 1（量化）**：量化为什么有效、fp16/bf16/fp32 的位宽差异，先看 09 的混合精度与 12 的推理部署，量化才有落点。

## 约定

- 代码环境：Python 3.10+，PyTorch 2.x（写作时验证于 2.14，API 以 [PyTorch 官方文档](https://pytorch.org/docs/stable/index.html) 为准）；另有 NumPy、torchvision，个别章节用到 onnxruntime。
- **所有示例默认 CPU 可跑**；需要 GPU 的代码段会用注释 `# [GPU]` 标出，并给出 CPU 上的替代方案或降级参数。
- 每个关键张量操作都写出真实的 shape 与数值，方便你在没有屏幕画板的情况下"看见"计算过程。
- 引用规范：关键论断给出论文/官方文档出处；无法查证的内容一律标注"经验做法"，不冒充定论。
- 随机数：示例输出基于固定种子，你本地运行若种子不同，数值会略有差异，但量级与趋势一致。
