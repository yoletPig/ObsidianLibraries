## 1. 问题设定

### 1.1 为什么从线性回归开始

深度学习的每个环节在线性回归里都有对应物：

| 线性回归 | 深度网络 |
| --- | --- |
| $\hat{y} = wx + b$ | 前向传播 |
| MSE 损失 | 交叉熵等损失函数 |
| $\partial L/\partial w$ | 反向传播 |
| 梯度下降 | optimizer.step() |

唯一的差别是深度网络把 $\hat{y}=wx+b$ 换成了一叠非线性函数。**训练机制本身没有变**。

### 1.2 造一份带噪声的数据

真实世界的数据几乎都有噪声，我们模拟这个过程（设随机种子保证你跑出来的数和文中一致）：

```python
import numpy as np

np.random.seed(0)
n = 100
w_true, b_true = 3.0, 2.0
x = np.random.uniform(-2, 2, size=(n, 1))            # shape (100, 1)，特征
noise = np.random.randn(n, 1) * 0.5                  # shape (100, 1)，高斯噪声 σ=0.5
y = w_true * x + b_true + noise                      # shape (100, 1)，标签
print(x[:3].ravel())   # 示例输出: [0.195  0.861  0.411]（种子固定，可复现）
print(y[:3].ravel())   # 示例输出: [2.003  5.033  3.466]
```

任务：只看 `(x, y)`，把 `w_true=3.0, b_true=2.0` 找回来。

## 2. 手写四件套（NumPy 版）

### 2.1 前向与损失

模型：$\hat{y}_i = w x_i + b$。

损失用均方误差（MSE）：

$$L(w, b) = \frac{1}{n}\sum_{i=1}^{n}(\hat{y}_i - y_i)^2$$

```python
def forward(x, w, b):
    """前向: y_hat = x @ w + b"""
    return x @ w + b

def mse_loss(y_hat, y):
    """MSE: 标量"""
    diff = y_hat - y                     # shape (100, 1)
    return float(np.mean(diff ** 2))
```

### 2.2 手推梯度（本篇核心）

对 $w$ 求偏导，逐条链展开：

$$\frac{\partial L}{\partial w} = \frac{1}{n}\sum_i \frac{\partial (\hat y_i - y_i)^2}{\partial \hat y_i}\cdot\frac{\partial \hat y_i}{\partial w} = \frac{1}{n}\sum_i 2(\hat y_i - y_i)\cdot x_i$$

$$\frac{\partial L}{\partial b} = \frac{1}{n}\sum_i 2(\hat y_i - y_i)\cdot 1$$

写成矩阵形式（5 章会从计算图角度再看一遍）：

$$\frac{\partial L}{\partial w} = \frac{2}{n}\, x^\top(\hat y - y), \qquad \frac{\partial L}{\partial b} = \frac{2}{n}\,\mathbf{1}^\top(\hat y - y)$$

```python
def gradients(x, y_hat, y):
    """返回 (dL/dw, dL/db)"""
    n = len(x)
    residual = y_hat - y                              # (100, 1)
    dw = (2.0 / n) * (x.T @ residual)                 # (1, 1)
    db = (2.0 / n) * np.sum(residual, keepdims=True)  # 标量
    return dw, db
```

**用数值差分验证梯度公式**——这是永不过时的好习惯，PyTorch 把它做成了 `torch.autograd.gradcheck`（5 章）：

```python
def numerical_grad(f, w, b, eps=1e-6):
    """中心差分: (f(x+eps)-f(x-eps)) / (2*eps)"""
    dw = (mse_loss(forward(x, w + eps, b), y) - mse_loss(forward(x, w - eps, b), y)) / (2 * eps)
    db = (mse_loss(forward(x, w, b + eps), y) - mse_loss(forward(x, w, b - eps), y)) / (2 * eps)
    return dw, db

w0, b0 = np.array([[0.5]]), np.array([[0.0]])
y_hat = forward(x, w0, b0)
dw_analytic, db_analytic = gradients(x, y_hat, y)
dw_num, db_num = numerical_grad(w0, b0)
print(dw_analytic, dw_num)   # -6.2314... vs -6.2314... —— 小数点后 8 位一致
print(db_analytic, db_num)   # -3.6482... vs -3.6482...
```

### 2.3 梯度下降

直觉：损失是一座山，梯度指向**上坡最快**的方向，下山就朝反方向走一小步：

$$w \leftarrow w - \eta \frac{\partial L}{\partial w}, \qquad b \leftarrow b - \eta \frac{\partial L}{\partial b}$$

$\eta$ 是学习率。完整训练循环：

```python
w = np.array([[0.0]]); b = np.array([[0.0]])   # 从零开始
lr, epochs = 0.1, 200

for epoch in range(1, epochs + 1):
    y_hat = forward(x, w, b)          # 1. 前向
    loss = mse_loss(y_hat, y)         # 2. 算损失
    dw, db = gradients(x, y_hat, y)   # 3. 算梯度（反向）
    w -= lr * dw                      # 4. 更新参数
    b -= lr * db
    if epoch % 40 == 0 or epoch == 1:
        print(f"epoch {epoch:3d}  loss={loss:.4f}  w={w.item():.4f}  b={b.item():.4f}")

# 输出示例（种子固定时）:
# epoch   1  loss=15.2861  w=0.7573  b=0.3539
# epoch  40  loss=0.2481  w=2.9920  b=2.0948
# epoch 200  loss=0.2481  w=2.9921  b=2.0953
# 收敛到 w≈3.0, b≈2.1；loss≈0.248 接近噪声方差 0.25 —— 已经到头了
```

注意最后一点：噪声方差是 $\sigma^2 = 0.5^2 = 0.25$，MSE 的理论下界就是 0.25（模型不可能"预测噪声"），所以 loss 停在 0.248 不是没训好，而是**已经到头了**。判断"loss 是不是已到噪声下界"是 10 章诊断过拟合的基本功。

### 2.4 常见陷阱

1. **学习率太大直接发散**。把 `lr` 改成 1.0 跑一下：loss 15.3 → 29.1 → 73.2 → 209.6 → 627.5，$w$ 在 7.6、-4.4、15.3、-18.1 之间来回摆动且振幅越来越大——一步迈过了谷底落到对面更高的坡上，最终溢出成 `inf/nan`。经验做法：线性模型从 0.1 起试，loss 发散就除以 10。
2. **梯度公式里忘了除 n**：损失定义变了（sum 而非 mean），梯度必须同步变。两者不一致是"loss 正常、参数乱跳"的常见病因。
3. **shape 对不上**：`w` 必须是 `(1,1)` 列向量，若写成 `(1,)`，`x @ w` 得到 `(100,)` 而不是 `(100,1)`，后面广播静默出错。NumPy/PyTorch 的经典教训：**shape 错误宁可显式 reshape，不要依赖广播碰巧不错**。

## 3. 解析解：正规方程

### 3.1 为什么需要它

梯度下降是**迭代**逼近；而最小二乘有**闭式解**——令梯度为零直接解方程。用它验证迭代法的结果，能立刻知道你的训练代码写没写对。

把模型写成矩阵形式 $\hat y = X\theta$，其中

$$X = \begin{bmatrix} x_1 & 1 \\ \vdots & \vdots \\ x_n & 1 \end{bmatrix} \in \mathbb{R}^{n\times 2}, \quad \theta = \begin{bmatrix} w \\ b \end{bmatrix}$$

令 $\partial L/\partial \theta = \frac{2}{n}X^\top(X\theta - y) = 0$，解得**正规方程（normal equation）**：

$$\theta = (X^\top X)^{-1} X^\top y$$

```python
X = np.hstack([x, np.ones_like(x)])                  # (100, 2)
theta = np.linalg.inv(X.T @ X) @ X.T @ y             # (2, 1)
print(theta.ravel())     # 示例输出: [2.9921 2.0953] —— 与梯度下降结果一致
```

### 3.2 两者的关系

| | 梯度下降 | 正规方程 |
| --- | --- | --- |
| 复杂度 | 每步 $O(n)$，可迭代到任意精度 | 矩阵求逆 $O(d^3)$，$d$ 是特征数 |
| 适用 | $d$ 大、数据大、任何模型 | 仅线性最小二乘 |
| 深度学习中 | **唯一现实选择** | 从不可行：GPT 的 $d$ 是上万维 |

深度网络没有解析解，所以"迭代 + 反向传播"是唯一路径——这正是下一节切到 PyTorch 的动机。

## 4. PyTorch 版：框架替你干了什么

```python
import torch

torch.manual_seed(0)
x_t = torch.tensor(x, dtype=torch.float32)   # (100, 1)
y_t = torch.tensor(y, dtype=torch.float32)   # (100, 1)

# 参数：requires_grad=True 让 PyTorch 帮你记梯度（01 章）
w = torch.zeros(1, 1, requires_grad=True)
b = torch.zeros(1, 1, requires_grad=True)
lr = 0.1

for epoch in range(1, 201):
    y_hat = x_t @ w + b                       # 1. 前向（同时自动建图）
    loss = torch.mean((y_hat - y_t) ** 2)     # 2. 损失
    loss.backward()                           # 3. 反向：w.grad/b.grad 自动填好
    with torch.no_grad():                     # 更新不能进图（01 章）
        w -= lr * w.grad                      # 4. 更新
        b -= lr * b.grad
    w.grad.zero_(); b.grad.zero_()            # 5. 清零！grad 是累加的（01 章）
    if epoch in (1, 200):
        print(f"epoch {epoch} loss={loss.item():.4f} w={w.item():.4f} b={b.item():.4f}")
# epoch 1   loss=15.2861 w=0.7573 b=0.3539
# epoch 200 loss=0.2481 w=2.9921 b=2.0953   —— 与 NumPy 版完全一致
```

对比一下，PyTorch 只替你干了两件事：

1. **`loss.backward()`**：自动求梯度。手推公式（2.2 节）那几行代码全免——模型换成深度网络后，手推不再现实。
2. **`.grad.zero_()`**：清零梯度。**注意框架并不自动清**——这是 PyTorch 的设计哲学（显式优于隐式），3 章的 `optimizer.zero_grad()` 封装的正是这一步。

前向、损失、更新、循环结构——**一行都没少写**。这就是本篇最重要的结论：**训练循环的骨架 = 前向 → 损失 → backward → 清零 → 更新**，从线性回归到 GPT 都是这个骨架。

### 4.1 torch 的 MSE 损失

PyTorch 内置了 MSE，等价于我们手写的版本：

```python
loss_fn = torch.nn.MSELoss()             # 默认 reduction='mean'
loss = loss_fn(y_hat, y_t)               # 与 torch.mean((y_hat-y_t)**2) 一致
```

细节陷阱：`nn.MSELoss` 对 **shape 有广播行为**——`(100,1)` 对 `(100,)` 会广播成 `(100,100)` 再求平均，loss 静默变成错误值且量级看起来"正常"。经验做法：训练前 `assert y_hat.shape == y.shape`，或统一用 `.view(-1)` 拉平。这个坑在回归任务里非常常见。

## 5. 训练循环骨架定型

把 2.3 与 4 节的循环抽象成一张图，这个骨架贯穿全书：

```text
初始化参数 θ
循环:
    ① 前向:    y_hat = f(x; θ)          ← 网络结构
    ② 损失:    L = loss(y_hat, y)       ← 任务目标
    ③ 反向:    g = ∂L/∂θ                ← autograd（01、05 章）
    ④ 清零/更新: θ ← θ - η·g             ← optimizer（03 章）
```

后续章节只往这个骨架里"换零件"：

- 换 ②：MSE → 交叉熵（3 章 MNIST）
- 换 ④：朴素 GD → SGD-momentum → Adam/AdamW（3、9 章）
- 换 ①：线性 → MLP → CNN → Transformer（3–8 章）
- 加料：数据管道（4 章）、正则化（10 章）、调度器（9 章）

## 6. 常见陷阱汇总

1. **忘了 zero_grad**（PyTorch 版）：每步梯度都是历史值累加，loss 表面在降但方向错乱，训练曲线剧烈震荡。这是 PyTorch 新手第一名 bug。
2. **学习率与损失定义不匹配**：损失用 `sum` 而学习率按 `mean` 的量级调，等效学习率放大 $n$ 倍，直接发散。
3. **用 `.data` 更新参数**：`w.data -= ...` 绕过 autograd 检查（01 章），现代写法是 `with torch.no_grad():` 或直接用 optimizer。
4. **收敛了但没到最优**：线性回归如果 loss 停在远高于噪声方差的位置，先怀疑学习率太小/迭代太少，再怀疑梯度公式错（用 2.2 的数值差分对照）。
5. **忘记把数据转 float**：`torch.tensor(x)` 当 `x` 是 int 数组时得到 int64 张量，`@` 运算报 dtype 错误。

## 本篇小结

- 线性回归 = 前向 $\hat y = wx+b$ + MSE + 梯度 $\frac{2}{n}x^\top(\hat y-y)$ + 梯度下降，四件套手写不超过 30 行。
- 梯度公式要用数值差分验证；loss 的理论下界是噪声方差 $\sigma^2$，MSE 停在 0.25 附近不是 bug。
- 正规方程 $\theta=(X^\top X)^{-1}X^\top y$ 提供闭式解用于验证，但深度网络只能用迭代法。
- PyTorch 只替你做两件事：自动求导和（通过 optimizer）更新；**训练循环骨架从此定型**，全书复用。
- `zero_grad` 是 PyTorch 显式哲学的一部分：框架不替你猜"你要不要累加梯度"。
