# Stage 6 教程索引：昇腾 CANN 与 Ascend C 算子开发

本目录是《学习计划》的配套教程，按周组织。每篇教程遵循统一框架：**第一性原理与数学本质 → 系统架构与数据流 → 工程权衡与失效模式 → 实现与验证（可运行代码/命令）→ MVP 交付指导 → 延伸思考题（含解析）**。

> ⚠️ 这是全计划**最难的八周**。策略是「推理先行、开发殿后」：前 4 周在你手上的 310P/Atlas 200I 上建立部署手感，后 4 周才碰云上 910B 与 Ascend C 算子开发。昇腾生态文档不如 CUDA 完善，遇到对不上的地方**一律以昇腾社区官方文档与 `ascend/samples` 实际代码为准**，本教程给的是方法与骨架。

## 贯穿全阶段的一条主线

$$
\text{模型} \xrightarrow{\text{ATC 转换}} \text{OM} \xrightarrow{\text{ACL/MindIE}} \text{推理} \qquad\qquad \text{自定义计算} \xrightarrow{\text{Ascend C}} \text{高性能算子}
$$

前半程（第 1-4 周）走通"**用昇腾跑模型**"（转换 + 推理 + 服务 + 迁移）；后半程（第 5-8 周）进阶到"**给昇腾写算子**"。前者是后者的地基——不先理解昇腾怎么跑模型，写不出对路的算子。

## 前置依赖

- 本地 310P/Atlas 200I（推理）+ 云上 910B（训练/算子开发）；
- Stage 3 的 CUDA fused RMSNorm（第 5-6 周要用 Ascend C 重写，双平台对照）；
- Stage 5 的 vLLM 知识（第 3 周与 MindIE 逐项对照）。
