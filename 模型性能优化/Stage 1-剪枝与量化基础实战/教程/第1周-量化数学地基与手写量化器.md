## 1. 第一性原理：量化 = 把连续值塞进有限网格

### 1.1 问题定义

量化的本质是一个**多对一映射**：把 FP16/FP32 的连续（或高分辨率）数值，映射到 $2^b$ 个离散码点上。位宽 $b$ 决定码点数：8-bit 有 256 个码点，4-bit 只有 16 个。

量化三要素：

- **位宽（bit-width）**：码点数 $2^b$；
- **缩放因子（scale）** $s$：决定网格步长，即一个码点代表多大的实数；
- **零点（zero-point）** $z$：整数网格中哪个码点对应实数 0（仅非对称量化需要）。

### 1.2 对称量化（Symmetric）

假设权重分布关于 0 近似对称（LLM 权重基本满足），直接用绝对值最大值定网格：

$$
s = \frac{\max(|w|)}{2^{b-1} - 1}, \qquad q = \mathrm{round}\!\left(\frac{w}{s}\right), \quad q \in [-2^{b-1},\ 2^{b-1}-1]
$$

反量化（dequantize）：$\hat w = q \cdot s$。

注意 INT8 对称量化的分母是 $2^{7}-1 = 127$ 而不是 128——为了保持网格关于 0 对称，负侧的 -128 被舍弃（否则负侧比正侧多一个码点，0 会偏离网格中心）。

**优点**：无零点、乘法路径简单（整数乘 + 一次缩放）；**缺点**：若分布偏斜（如 ReLU 激活全为正），一半网格被浪费。

### 1.3 非对称量化（Asymmetric）

用完整的 $[w_{\min}, w_{\max}]$ 区间铺满整个码域：

$$
s = \frac{w_{\max} - w_{\min}}{2^b - 1}, \qquad z = \mathrm{round}\!\left(q_{\min} - \frac{w_{\min}}{s}\right)
$$

$$
q = \mathrm{clamp}\!\left(\mathrm{round}\!\left(\frac{w}{s}\right) + z,\ q_{\min},\ q_{\max}\right), \qquad \hat w = (q - z)\cdot s
$$

**优点**：对偏斜分布（激活值常见）网格利用率 100%；**缺点**：多一个零点，GEMM 展开后多出若干校正项，内核更复杂。这就是面试标准答案：**权重常用对称（分布对称、内核简单），激活常用非对称（分布偏斜、范围动态）**。

### 1.4 量化粒度：per-tensor / per-channel / per-group

同一组统计量（$s, z$）作用的张量范围叫**量化粒度（granularity）**：

| 粒度 | 每个张量的 (s, z) 数量 | 精度 | 存储开销 |
| --- | --- | --- | --- |
| per-tensor | 1 | 最差：任一通道的离群值撑爆全局 scale | 可忽略 |
| per-channel（按输出通道） | $d_{out}$ | 通道间隔离 | 极小 |
| per-group（组大小 $g$） | $d_{out} \times d_{in}/g$ | 最好：组内离群值只影响本组 | $g=128$ 时每 128 权重多存 1 个 FP16 scale ≈ +0.125 bpw |

**group=128 的由来**：这是精度-开销-内核效率的三方甜点。$g$ 越小隔离越彻底（$g=32$ 更准但 scale 开销 4 倍，且 GEMV 内核频繁换 scale 访存变碎）；$g$ 越大越接近 per-channel。GPTQ/AWQ/Marlin 全部默认 $g=128$，正是这个权衡的行业共识。

### 1.5 量化误差的理论上界

均匀量化的舍入误差 $\varepsilon = w - \hat w$ 落在 $[-s/2,\ s/2]$。若误差近似均匀分布：

$$
\mathbb{E}[\varepsilon^2] \approx \frac{s^2}{12}
$$

两条直接推论：① 误差与步长平方成正比——**位宽每降 1 位，$s$ 翻倍，MSE 约变 4 倍**；② 若某个离群值把 $s$ 撑大 10 倍，其余 99% 正常权重的误差就放大 100 倍——这就是离群值问题的数学根源。

### 1.6 离群值：LLM.int8() 的实证

*LLM.int8()*（Dettmers et al., 2022）观察到一个规模相关的涌现现象：**模型 ≥ 6.7B 后，Transformer 隐藏状态中出现幅度高达 ±100 的离群值**（普通激活幅度约 ±10），且它们**集中在固定的少数通道**（128 个维度里约 0.1%），跨层、跨样本位置不变。

后果：对激活做 per-tensor 量化时，$s$ 被这 0.1% 的通道拉大两个数量级，其余通道的有效分辨率几乎归零，精度崩塌。LLM.int8() 的解法是把离群通道拆出来走 FP16（混合精度分解）；后续的 SmoothQuant（难度迁移）与 AWQ（显著通道保护）是两条不同的路线——第 2 周与 Stage 2 第 2 周详解。

### 1.7 位宽谱系与动态范围对比

浮点格式 = 符号位 + 指数位 + 尾数位。**指数位决定动态范围，尾数位决定相对精度**；整数格式则是在校准区间内均匀铺网格。

| 格式 | 构成 | 最大可表示值 | 相对精度 | 特点 |
| --- | --- | --- | --- | --- |
| FP32 | 1+8+23 | $3.4\times10^{38}$ | $\sim 2^{-23}$ | 训练主精度 |
| FP16 | 1+5+10 | 65504 | $\sim 2^{-10}$ | 易上溢/下溢 |
| BF16 | 1+8+7 | $3.4\times10^{38}$ | $\sim 2^{-7}$ | 范围同 FP32，精度换稳定性 |
| FP8 E4M3 | 1+4+3 | **448** | $\sim 2^{-3}$ | 前向/权重：精度优先 |
| FP8 E5M2 | 1+5+2 | 57344 | $\sim 2^{-2}$ | 反向/梯度：范围优先 |
| INT8 对称 | 8-bit 均匀 | 取决于 $s$ | 绝对均匀 | 需校准定 $s$ |
| INT4 对称 | 4-bit 均匀 | 16 个码点 | 绝对均匀 | 网格极粗，必须 per-group |
| NF4 | 4-bit 非均匀 | 16 个码点按正态分位数分布 | 0 附近密、两端疏 | 信息论最优（假设权重 ~ $\mathcal{N}(0,\sigma^2)$） |

两个关键对比：

1. **FP8 vs INT8**：FP8 是"恒定相对误差"（尾数固定 → 大数误差大、小数误差小），INT8 是"恒定绝对误差"。权重幅度分布集中，INT8 网格利用率反而高；梯度跨多个数量级，必须用范围更大的 E5M2。
2. **NF4 vs INT4**：LLM 权重经 LayerNorm 约束后近似零均值正态。NF4 把 16 个码点放在正态分布的**分位数中点**上，使每个码点的期望代表误差最小——这是"对已知分布的信息论最优量化"。Stage 2 第 3 周将手写码本生成器并与 `bitsandbytes` 数值对齐。

## 2. 系统架构与数据流：量化发生在哪

### 2.1 权重量化（Weight-Only）vs 激活量化

$$
Y = X W^\top \quad \xrightarrow{\text{W4A16}} \quad Y = X\ \mathrm{dequant}(\hat W)^\top
$$

- **W4A16**（GPTQ/AWQ/NF4）：权重离线量化存储，推理时反量化成 FP16 再算。收益 = **显存/带宽省 4×**，算力不变。适合 batch=1 decode（访存瓶颈，见 Stage 3 第 1 周 Roofline）。
- **W8A8**（SmoothQuant）：权重和激活都量化，走 INT8 Tensor Core。收益 = **算力 + 带宽双省**，适合大 batch 云端服务。

### 2.2 本周数据流

```
HF 权重 (FP16) ──► 选一层权重 w ──► quantize(w, bits, mode) ──► (q, s[, z])
                                       │
                              dequantize(q, s[, z]) ──► ŵ
                                       │
                    指标：cosine(w, ŵ)、MSE(w, ŵ)、直方图对比
```

## 3. 实现与验证（本周交付核心）

### 3.1 手写量化器（完整可运行）

```python
import torch
import torch.nn.functional as F

def quantize(w: torch.Tensor, bits: int = 8, mode: str = "symmetric",
             dim: int = -1, group: int = -1):
    """
    均匀量化。返回 (q, scale, zero_point)。
    mode: "symmetric" 或 "asymmetric"
    dim : per-channel 的量化轴（-1 表示 per-tensor 时忽略）
    group: >0 时沿最后一维按 group 分组（per-group 量化）
    """
    w = w.float()
    if group > 0:
        assert w.shape[-1] % group == 0, "最后一维必须被 group 整除"
        w = w.view(*w.shape[:-1], w.shape[-1] // group, group)
        dim = -1
    if mode == "symmetric":
        qmax = 2 ** (bits - 1) - 1
        amax = w.abs().amax(dim=dim, keepdim=True).clamp(min=1e-8)
        scale = amax / qmax
        zero = torch.zeros_like(scale)
        q = torch.round(w / scale).clamp(-qmax - 1, qmax)
    else:  # asymmetric
        qmin, qmax = 0, 2 ** bits - 1
        wmin = w.amin(dim=dim, keepdim=True)
        wmax = w.amax(dim=dim, keepdim=True)
        scale = ((wmax - wmin) / (qmax - qmin)).clamp(min=1e-8)
        zero = torch.round(qmin - wmin / scale)
        q = torch.round(w / scale + zero).clamp(qmin, qmax)
    return q, scale, zero

def dequantize(q, scale, zero):
    return (q - zero) * scale

def report(w, q, scale, zero, tag):
    w_hat = dequantize(q, scale, zero).view_as(w)
    cos = F.cosine_similarity(w.flatten(), w_hat.flatten(), dim=0).item()
    mse = ((w - w_hat) ** 2).mean().item()
    print(f"{tag:>28s}  cos={cos:.6f}  MSE={mse:.3e}")
    return cos

# ---- 单元自检：数值性质 ----
w = torch.linspace(-3.2, 4.8, 81)          # 学习计划自测题的区间
q, s, z = quantize(w, bits=8, mode="symmetric")
assert abs(s.item() - 4.8 / 127) < 1e-7, "对称 scale 公式错误"
q, s, z = quantize(w, bits=8, mode="asymmetric")
assert abs(s.item() - (4.8 + 3.2) / 255) < 1e-7, "非对称 scale 公式错误"
# 反量化必须落在网格上且误差 <= s/2
w_hat = dequantize(q, s, z)
assert (w_hat - w).abs().max() <= s.item() / 2 + 1e-6
print("单元自检通过 ✓")
```

### 3.3 假量化（Fake Quant）与 STE：为 QAT 预埋的地基

量化函数 `round()` 处处不可导，训练时如何模拟量化？答案是**假量化（Fake Quantization）+ STE（Straight-Through Estimator）**：前向走完整的"量化→反量化"（输出落在网格上），反向把 `round` 当作恒等映射直接透传梯度。最小实现：

```python
import torch

class RoundSTE(torch.autograd.Function):
    """前向取整，反向直通（STE）。"""
    @staticmethod
    def forward(ctx, x):
        return torch.round(x)
    @staticmethod
    def backward(ctx, grad_output):
        return grad_output          # round 的"梯度"按 1 透传

def fake_quantize(w, scale, qmax):
    """假量化：输出落在网格上，但保持可导（近似）。"""
    return RoundSTE.apply(w / scale).clamp(-qmax, qmax) * scale

# ---- 单元自检 ----
w = torch.randn(1000, requires_grad=True)
wq = fake_quantize(w, scale=0.05, qmax=7)
assert ((wq / 0.05).round() * 0.05 - wq).abs().max() < 1e-6, "输出必须落在网格上"
(wq ** 2).sum().backward()
assert torch.allclose(w.grad, 2 * w, atol=1e-6), "STE 应透传梯度"
print("Fake Quant + STE 自检通过 ✓（Stage 2 第 4 周 QAT 的核心组件）")
```

**预期输出**：两个断言通过。要点：① 前向输出已"网格化"，与真实推理数值一致；② 反向梯度原样透传——`round` 的真实导数是 0（几乎处处），但用恒等映射近似在实践中足够有效。为什么足够？因为假量化是 $w$ 的"有界扰动"（误差 ≤ $s/2$），梯度方向大体不变。这个近似何时失效、QAT 还有什么配套技巧，留到 Stage 2 第 4 周。

### 3.4 量化 GEMM 的展开式：scale 和 zero-point 去哪了

推理时真正执行的是量化后的矩阵乘。以非对称量化为例展开 $Y = XW^\top$：

$$
Y = \big(s_X(X_q - z_X)\big)\big(s_W(W_q - z_W)\big)^\top = s_X s_W \underbrace{X_q W_q^\top}_{\text{纯整数 GEMM}} - s_X s_W\big(z_W X_q \mathbf{1}^\top + z_X \mathbf{1} W_q^\top - z_X z_W \mathbf{1}\mathbf{1}^\top\big)
$$

三条工程结论：① 主体是**纯整数乘累加**（INT8 Tensor Core / NEON 快路径），浮点缩放只在最后做一次——所以"先整数累加再缩放"是正确顺序；② 对称量化 $z=0$，三个校正项全部消失——这就是"权重用对称"的内核侧理由；③ 激活非对称的代价就是这三个校正项，推理框架会用预计算（如 $\mathbf{1}W_q^\top$ 离线算好）把它们摊薄。

## 4. 工程权衡与失效模式

### 4.1 权衡

- **对称 vs 非对称**：对称内核简单但浪费偏斜分布的网格；非对称多一个零点与校正项。**权重对称、激活非对称**是默认配方。
- **粒度越细越准，但 scale 存储与内核复杂度上升**：per-group(128) 相比 per-tensor 每 128 权重多 2 字节（FP16 scale），4-bit 下相对开销 +3%（0.125/4.25），换来显著的精度隔离——值得。
- **位宽与误差的平方律**：降位宽是最便宜的压缩（8→4 体积减半），但 MSE 是平方恶化，4→2 通常需要换算法（NF4/imatrix/QAT）而不是硬降。

### 4.2 失效模式（至少记住四条）

1. **离群值撑爆 scale**：症状——per-tensor 量化后 PPL 暴涨；根因——个别通道幅度超主体 1-2 个数量级；定位——画激活/权重直方图、按通道统计 `abs().amax()`；修复——per-group、SmoothQuant 或混合精度。
2. **校准区间未覆盖**：症状——部署分布与校准分布不同（如长序列、新领域）时精度骤降；根因——$w_{\min/\max}$ 只是校准集的统计；修复——校准集覆盖真实流量分布（第 2 周）。
3. **舍入偏置累积**：症状——深层网络逐层误差漂移，输出分布偏移；根因——`round` 的期望误差在偏斜输入下非零；修复——随机舍入（stochastic rounding，QAT/QLoRA 用）或二阶补偿（GPTQ，Stage 2 第 1 周）。
4. **反量化位置放错**：症状——自己写的推理路径与官方结果不一致；根因——scale 应作用在 GEMM 之后（先整数累加再缩放），放错位置既慢又可能溢出；修复——核对内核的数据流图。

## 5. 延伸思考题（含解析）

**Q1**：权重范围 $[-3.2, 4.8]$，INT8 对称量化的 scale 和步长是多少？与非对称相比谁的量化误差更小？
**A**：对称 $s = 4.8/127 \approx 0.0378$；非对称 $s = 8.0/255 \approx 0.0314$。非对称步长更小且区间铺满，本例误差更小；但对称量化把 4.8~8.0 之外的负区间也留给网格（对称扩展到 ±4.8），若真实分布对称则两者接近。偏斜越严重，非对称优势越大。

**Q2**：per-group(128) 相比 per-tensor 额外存储多少？7B 模型 INT4+g128 的总 bpw 是多少？
**A**：每 128 个权重多一个 FP16 scale = 16 bit / 128 = 0.125 bpw；若零点也用 FP16 则再加 0.125。常见实现只存 FP16 scale（零点为常数 8 或与 scale 打包），总位宽 ≈ 4 + 0.125 ≈ 4.125~4.25 bpw。7B ≈ 7×10⁹ × 4.25/8 ≈ 3.7 GB。

**Q3**：为什么 FP8 需要两种格式？E4M3 和 E5M2 分别用在哪？
**A**：前向的权重/激活幅度集中（±448 足够），需要尾数精度 → E4M3；反向梯度跨多个数量级且可能瞬时很大，需要动态范围 → E5M2（最大 57344）。这是"精度优先"与"范围优先"的分工。

**Q4**：NF4 为什么对 LLM 权重是"信息论最优"？如果权重不服从正态分布会怎样？
**A**：NF4 码点取正态分布的分位数中点，使每码点期望平方误差最小——前提假设就是权重 ~ 正态（QLoRA 用分块归一化强制满足该假设）。若权重分布明显偏离正态（如稀疏化后、某些蒸馏模型），码点失配，NF4 优势消失甚至不如 INT4+GPTQ。

**Q5**：量化误差为什么可能让 softmax 后的分布"偏移"而不仅仅是"变噪"？
**A**：softmax 对 logits 的差异做指数放大：若量化误差在类别维度上**系统性偏置**（非对称舍入、离群通道），头部 token 的相对优势被压缩或放大，采样分布整体漂移——表现为生成质量下降但 PPL 只微涨。这就是评测不能只看 PPL 的原因（Stage 2 第 5-6 周展开）。
