# Stage 2 教程索引：大模型进阶量化与 QAT——七方案横评弹药库

本目录是《学习计划》的配套教程，按周组织。每篇教程遵循统一框架：**第一性原理与数学本质 → 系统架构与数据流 → 工程权衡与失效模式 → 实现与验证（可运行代码）→ 延伸思考题（含解析）→ 交付清单**。

> 前置假设：Stage 1 的量化数学地基已牢固（手写量化器、四策略校准、评测基线脚本）。本阶段不再重复 scale/zero-point 的定义，直接进入算法核心。

> 本阶段的主线问题：**同一个 7B 模型，七种量化方案各自把误差藏在了哪里？** GPTQ 用二阶补偿摊还、SmoothQuant 把难度迁移给权重、AWQ 保护显著通道、FP8/NF4 换数值格式、QAT 用训练硬扛。六周后你应能闭卷推导 GPTQ 列补偿与 NF4 码本，并拿出一份面试级的七方案横评报告。

## 贯穿全阶段的一条主线

$$
\text{离群值与网格失配} \xrightarrow{\text{补偿/迁移/保护/换格式/训练}} \text{低比特模型} \xrightarrow{\text{引擎匹配}} \text{真实加速}
$$

第 1-2 周处理"误差往哪放"（GPTQ 摊还、SmoothQuant 迁移、AWQ 保护），第 3 周换数值格式本身（FP8/NF4），第 4 周用训练消化残余误差（QAT），第 5-6 周把七个方案放进同一张表——横评报告直接就是面试展示材料。

## 前置依赖与环境

- Stage 1 的《压缩评测基线报告》脚本直接复用，七方案结果追加进同一张表；
- 全部实验需云 GPU：GPTQ/AWQ 量化 7B 建议 A100-40G，QLoRA 微调建议 A100-40G 或双 A10；
- 依赖：`pip install llmcompressor autoawq bitsandbytes transformers datasets vllm`（TensorRT-LLM 按官方容器安装）。
