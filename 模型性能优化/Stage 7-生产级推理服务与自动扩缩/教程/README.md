## 贯穿全阶段的一条主线

$$
\text{请求} \xrightarrow{\text{接入层}} \xrightarrow{\text{路由层}} \xrightarrow{\text{推理层（引擎集群）}} \xrightarrow{\text{存储层}} \text{响应}
$$

从"单引擎调优"（Stage 5）上升到"生产级服务架构"：容量规划定规模、编排定结构、扩缩定弹性、可观测性定信心、成本定可持续性。本阶段的最终产出是一份**生产级部署设计文档**——它同时是你架构面试的主答卷。

## 前置依赖

- Stage 5 的单引擎调优结论（单卡最优配置与压测基线）；
- 单台云主机（跑 Kind 集群与模拟）；
- 依赖：`pip install ray[serve] locust`，Docker + Kind。

## 与语音方向的接口

本阶段的架构设计要能承载语音方向的云端服务（ASR/TTS/Omni serving）。第 2 周的 Ray Serve 多模型编排会直接用"VAD→ASR→LLM→TTS"级联做例子——两个方向在这里汇合。
