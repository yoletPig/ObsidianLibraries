## 贯穿全阶段的一条主线

$$
\text{请求} \xrightarrow{\text{路由层}}
\begin{cases}
\text{端侧（隐私/低延迟/兜底）} \\
\text{云端（能力/重载）}
\end{cases}
\xrightarrow{\text{级联 + 回填}} \text{响应}
$$

核心创新点在**路由层的分流决策**与**级联推理闭环**：端侧先答、置信度低升级云端、结果回填缓存——这是端云协同区别于"纯云端"的灵魂。
