# 07 - 组合构建与风险控制

## 本篇目标

选股回答"买什么"，本篇回答"**买多少**"——多数情况下，仓位配置对结果的影响不小于选股本身。内容：分散化的数学（马科维茨）、等权为什么难打败、风险平价直觉、以及仓位/止损/杠杆的量化纪律。

## 1. 马科维茨：分散化的数学基础

Harry Markowitz 1952 年的《Portfolio Selection》（1990 年诺贝尔经济学奖）给出了组合理论的起点。核心结论一句话：

> **组合的波动 ≤ 成分的加权波动，只要成分收益不完全相关。**

```python
import numpy as np

# 两资产：收益 r1, r2，权重 w 与 1-w，方差 sigma1², sigma2²，相关系数 rho
# 组合方差 = w²σ1² + (1-w)²σ2² + 2w(1-w)ρσ1σ2
def portfolio_vol(w, vols, corr):
    n = len(vols)
    C = np.full((n, n), corr); np.fill_diagonal(C, 1.0)
    cov = np.outer(vols, vols) * C
    return float(np.sqrt(w @ cov @ w))

vols = np.array([0.30, 0.20])          # 年化波动 30% 与 20%
w = np.array([0.5, 0.5])
print(portfolio_vol(w, vols, rho=1.0))   # 0.25 —— 完全相关：分散零收益
print(portfolio_vol(w, vols, rho=0.0))   # ≈0.180 —— 零相关：波动低于任一成分
print(portfolio_vol(w, vols, rho=-0.5))  # ≈0.132 —— 负相关：分散威力最大
```

三个推论（按重要性排序）：

1. **相关系数是分散化的灵魂**：等权配两只 ρ=1 的股票 = 没有分散。A 股内部大部分股票 ρ>0.5（系统性风险主导），所以**跨资产类别**（股/债/现金/商品）的分散威力远大于"多买几只股票"；
2. **组合收益是权重的线性函数，波动却不是**——优化波动端有免费午餐，优化收益端没有（不要指望组合魔法提高预期收益，只能降低波动）；
3. **均值-方差优化的现实问题**：最优权重对预期收益的估计**极端敏感**（输入误差被放大），而预期收益恰恰是最难估的（Michaud 1989 年称其为 "Markowitz optimization envelope" 陷阱，"error maximization"）。这就是为什么实务中少用理论最优权重。

## 2. 等权组合：难缠的基准

因子选股（06 篇）后每只买多少？学术文献与业界对比反复发现：**等权（或市值加权）是极难打败的基准**——DeMiguel, Garlappi & Uppal（2009）的经典论文《Optimal Versus Naive Diversification》用多个数据集检验了 14 种优化模型，**没有一种稳定战胜 1/N 等权**。

原因：优化模型把"估计误差"当成了"真实信息"去下重注。对个人的实操建议：

- **第一版组合永远用等权**，作为一切改进的对照基准；
- 后续任何"更聪明"的加权方案，必须**干净地**（05 篇纪律）证明优于等权，才允许采用。

## 3. 风险平价与波动率目标（直觉版）

**风险平价（risk parity）**：不是让资金权重相等，而是让**每个资产贡献的组合风险相等**。直觉：60% 股票 + 40% 债券的组合，因股票波动远大于债券，其风险贡献约 90% 来自股票——名为分散，实为单腿。风险平价把权重向"每单位波动"拉平（桥水全天候基金是著名实践者；学术表述见 Maillard, Roncalli & Teïletche 2010）。

**波动率目标（volatility targeting）**：给组合设定目标年化波动（如 10%），按近期实现波动反向调节总仓位：

```python
TARGET_VOL = 0.10
realized_vol = ret.rolling(60).std() * np.sqrt(252)   # 最近 60 日实现波动
position = (TARGET_VOL / realized_vol).clip(0, 1)     # 波动大 → 降仓位，上限满仓
```

注意其中隐藏的**杠杆悖论与平仓循环**：波动飙升时自动降仓 = 高位卖出，可能是止损也可能是"在最该买的时候卖"。它是风控工具不是收益工具，效果因市况而异（研究见 Moreira & Muir, *Volatility-Managed Portfolios*, JoF 2017——结论也是"有效但有限、依情形"）。**使用前自己回测，别当默认真理**。

## 4. 仓位管理：凯利公式的保守使用

**凯利公式**（John Kelly 1956；用于投资的表述见 Edward Thorp 的推广）给出"长期增长最大化"的最优仓位：

```
f* = (p·b - q) / b        二元情形：胜率 p、赔率 b（赢/亏比）、q = 1-p
连续收益情形近似：f* ≈ μ / σ²（μ 为超额收益、σ² 为方差）
```

例：胜率 55%、盈亏比 1:1 → f* = 0.55 - 0.45 = 10%。数学上满仓 f* 使长期复合增长最大，**但实务几乎都取"半凯利"或更低**，原因：

1. p 和 μ 的估计误差极大（你"以为的胜率"几乎必然比真实的高——05 篇）；
2. 满凯利的**路径波动难以承受**：drawdown 极深，多半人会在低谷放弃（03 篇心理模型）；
3. 仓位过重的数学后果是精确的：连续近似下，长期复合增长率在 f\* 处最大，**超过约 2f\* 即转负**（下注过重，哪怕胜率占优也会在长期破产）——这也是赌徒破产问题的工程表述。

**实务纪律**：单只股票仓位上限（如 10%~20%）、单行业上限、总仓位的波动率目标化——这些"粗糙规则"的价值在于**保证你在任何单一错误下都还活着**。

## 5. 止损、杠杆与风控的分层

**风控分三层，从外到内**：

| 层 | 对象 | 手段 |
| --- | --- | --- |
| 组合层 | 总体暴露 | 波动率目标、最大回撤熔断（回撤超 X% 强制降仓并复盘） |
| 持仓层 | 单票风险 | 仓位上限、相关性检查、止损线 |
| 策略层 | 模型失效 | 信号衰减监控（滚动 IC 走弱）、参数漂移、离场标准 |

关于**止损**的两面性（诚实陈述）：止损控制单笔最大损失（心理与生存价值），但在震荡市会频繁"止损在最低点"；学术证据上动量/趋势类策略与止损搭配较好，均值回归类策略反而被止损伤害。**止损参数同样需要干净的回测，不是"设 8% 因为别人都这么说"**。

关于**杠杆**，本系列的立场是明确的：

> 学习阶段杠杆为零。杠杆不改变策略的期望，只放大路径波动；而**爆仓是路径依赖事件**——策略长期方向正确也可能因为一次极端波动被强制平仓出局（LTCM 的死法，01 篇）。融资融券、场外配资在验证期一概不碰。

## 6. 风控先行的一页总结

```
选股（06 篇）→ 等权起步 → 相关性检查 → 波动率目标定总仓位
→ 单票/单行业上限 → 记录回撤熔断规则 → 定期复盘（策略层监控）
```
