# 05 - 回测：方法与陷阱

## 本篇目标

回测是量化的"实验方法"。本篇先给出一个最小但**诚实**的回测引擎，然后逐个拆解五大偏差——**每个偏差都配有"检测方法"**。读完本篇，你应该能用"作弊自查清单"审查任何一份回测报告，包括你自己写的。

> 全系列的立场：**回测的价值不在于产生收益数字，而在于产生"可信度评级"**。一份年化 50% 但有前视偏差的回测，价值低于一份年化 5% 但干净的回测。

## 0. 最小回测引擎（向量化，无框架依赖）

```python
import numpy as np
import pandas as pd

def backtest(close: pd.Series, signal: pd.Series,
             cost_bps: float = 15.0) -> pd.DataFrame:
    """
    close:  后复权收盘价
    signal: 目标仓位（0 或 1），已按"成交时刻可得"对齐（见 02 篇 shift 纪律）
    cost_bps: 单边成本（佣金+滑点+税），万 15 是 A 股单边的粗略量级：
              佣金约万 2.5、印花税卖出万 5（2023-08 减半后）、滑点视流动性
    """
    pos = signal.shift(1).fillna(0)          # 今天的仓位 = 昨天收盘决定的信号
    ret = close.pct_change().fillna(0)       # 简单收益（组合层面）
    trades = pos.diff().abs().fillna(0)      # 换手：仓位变动幅度
    strat_ret = pos * ret - trades * cost_bps / 1e4   # 扣成本
    equity = (1 + strat_ret).cumprod()       # 净值曲线（初始 1.0）
    return pd.DataFrame({
        "equity": equity,
        "ret": strat_ret,
        "dd": equity / equity.cummax() - 1,
    })

# 指标输出（03 篇的统一语言）
def report(bt: pd.DataFrame, rf: float = 0.02) -> dict:
    n_years = len(bt) / 252
    ann = bt["equity"].iloc[-1] ** (1 / n_years) - 1
    vol = bt["ret"].std() * np.sqrt(252)
    return {"年化": f"{ann:.1%}", "波动": f"{vol:.1%}",
            "最大回撤": f"{bt['dd'].min():.1%}",
            "夏普": f"{(ann - rf) / vol:.2f}"}
```

这个 20 行引擎刻意保持简单——它没有处理开盘价成交、停牌、涨跌停、T+1 等真实约束（09 篇实战会补）。**引擎简单的好处是：作弊无处藏身**。框架越复杂，"框架替你做了什么"越不透明。

## 1. 陷阱一：前视偏差（Look-ahead Bias）

**定义**：决策用到了"决策时刻不可能知道"的数据。

```python
# 作弊示例：用今天的收益决定今天的持仓
pos = (ret > 0).astype(int)            # 今天涨 → 今天持有。这不叫策略，叫时间机器
correct = (ret > 0).astype(int).shift(1).fillna(0)   # 正确：昨天的判断，今天执行
```

**三个隐蔽变种**（比直接作弊更常见）：

1. **用当天收盘价算指标、当天收盘买入**：指标值在收盘那一刻才确定，你不可能以收盘价成交——至少要 shift 到次日执行；
2. **前复权存档数据**：前复权价按"今天的除权信息"改写了历史价格，等于把未来信息注入过去（02 篇）。用后复权，或确保复权因子按历史时点计算；
3. **用"修正后"的基本面数据回测历史**：财务数据是**公告日**才可得的（年报 4 月底才出，你 1 月就能在回测里用它的期末值）——必须把数据对齐到公告日。这是基本面量化的头号坑。

**检测方法**：把信号数据人为延迟一天再跑一遍回测——**延迟一天后结果剧变，说明策略高度依赖"时机精度"，大概率有残余前视**。真正的信号不应该对一天的延迟如此敏感。

## 2. 陷阱二：幸存者偏差（Survivorship Bias）

**定义**：样本里只有"活到今天的"资产。

选股回测只拉"当前上市股票"，等于把退市的乐视/康美们从历史中抹掉——**回测收益系统性虚高**。经典类比：二战轰炸机装甲加固（Abraham Wald 的幸存者偏差分析：应该加固"返航机上没有弹孔的部位"，因为那些部位中弹的飞机没能返航）。

**检测/缓解**：
- 问一句：**回测期开始时的股票全集，在数据源里能完整拿到吗？**（含后来退市的）
- 免费数据源（02 篇表格）通常拿不到退市股 → **学习阶段接受这一局限，但明确声明"本回测存在幸存者偏差，绝对收益不可信，只参考相对逻辑"**；
- 更稳妥的替代：用**指数成分股历史时点快照**（当时的成分股名单）近似还原当时的市场全集。

## 3. 陷阱三：过拟合（Overfitting）

**定义**：模型/参数记住了历史噪声，而非规律。金融数据信噪比极低，过拟合是回测的头号死因。

### 参数面实验：亲手做一次

```python
# 双均线：穷举参数组合，看"最优参数"有多可信
results = {}
for s in range(5, 30, 5):
    for l in range(40, 120, 10):
        sig = (price.rolling(s).mean() > price.rolling(l).mean()).astype(int)
        bt = backtest(price, sig)
        results[(s, l)] = bt["equity"].iloc[-1]
grid = pd.Series(results).unstack()
print(grid)   # 参数面：行=短均线, 列=长均线，观察是"孤峰"还是"高原"
```

典型结果形态：参数面上**孤峰耸立**（某个 (s,l) 组合特别高，邻居都很差）——**孤峰 = 过拟合**。稳健策略的参数面应呈**高原（plateau）**：最优点的邻域参数都表现相近，说明结论不依赖精调的参数值。

**缓解手段**（组合使用）：

1. **样本内/样本外切分**：前 70% 数据选参数，后 30% 只验证一次。**样本外只许看一次**——反复"看外测集再调参"等于把外测集变成了训练集（这是机器学习同理、投资更严重的问题，08 篇再谈）；
2. **Walk-forward（滚动前进验证）**：模拟真实的"用过去选参数、往后用一段时间、再滚动"，是比单次切分更接近实盘的验证方式；
3. **参数取中心而非最优点**：选高原的中心参数，哪怕它样本内收益略低；
4. **多重比较校正意识**：你试了 100 个参数组合选最好的，相当于掷 100 次硬币挑"最像正面"的——Sullivan 等人的 White's Reality Check（04 篇）就是校正这类数据窥探的方法。

### 一条著名的定量警句

回测中尝试的策略/参数组合越多，"最好那个"的虚高越严重。 quantitative 社区流传的经验校正是：**对你的最优夏普打对折再打折**（Bailey & López de Prado 2014 年给出的 deflated Sharpe ratio 用试错次数、样本长度对夏普做统计折扣，属正式方法）。

## 4. 陷阱四：成本与流动性低估

- **成本清单要完整**：佣金 + 印花税（A 股卖出单边 0.05%，2023 年 8 月 28 日起）+ 滑点 + 冲击成本。高频换手策略对成本极端敏感：日换手 100% × 单边万 15 → 一年成本吃掉约 7.4%；
- **敏感性测试**：把成本参数乘 2 再跑一遍——**收益归零甚至转负的策略，本质是在赚"回测里不存在的钱"**；
- **流动性现实**：回测默认"想买多少买多少"，实盘小市值股票你根本买不到足量，或者你的单子自己把价格推上去（冲击成本）。

## 5. 陷阱五：数据窥探与叙事偏差

**定义**：反复"看数据→改策略→再看数据"直到回测好看。它与过拟合的区别：过拟合发生在参数层面，数据窥探发生在**策略选择层面**——你无形中从 1000 个灵感里挑了回测最好的那个，而"试过 1000 个"这件事没有被记录。

**对策**：
- **研究日志**：记录每个试过的想法与结果（包括失败的）——试错次数本身是统计校正的输入（deflated Sharpe 需要它）；
- **先有机制假说，再看数据**：先写下"这个策略为什么可能赚钱（赚谁的钱，01 篇）"，再用数据验证；顺序反了（先看数据挖规律再编故事），几乎必然过拟合；
- **预注册精神**：写好策略与验证标准后锁定，跑样本外前不回头改。
