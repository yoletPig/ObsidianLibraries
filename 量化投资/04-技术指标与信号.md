# 04 - 技术指标与信号

## 本篇目标

1. 实现三个最具代表性的指标：均线（趋势）、动量、RSI（超买超卖）；
2. 把"指标"变成"可回测的信号"（注意 02 篇的 shift 纪律）；
3. 建立**证据意识**：技术指标的实证地位远比书上说的弱，本篇会给出关键证据。

## 1. 从指标到信号的两步

```
指标 = 对价格的变换（一条曲线）
信号 = 指标 + 交易规则（买/卖/持有的条件）        ← 回测的对象是信号，不是指标
```

任何信号代码在写完后必须回答（02 篇⑤的纪律）：**这个条件在成交时刻，用到的数据都已发生吗？**

## 2. 均线与双均线交叉

```python
import numpy as np
import pandas as pd

close = price                                      # 后复权收盘价（02 篇）
ma_short = close.rolling(20).mean()                # 20 日均线
ma_long  = close.rolling(60).mean()                # 60 日均线

# 信号：短均线在长均线上方 → 持有（=1），否则空仓（=0）
signal = (ma_short > ma_long).astype(int)
signal = signal.shift(1)                           # ⚠ 关键：今天的持仓用昨天的信号决定
                                                    # 明天开盘/收盘执行——消除前视偏差
# 信号切换点
golden  = (signal.diff() == 1)                     # 金叉（做多信号出现）
dead    = (signal.diff() == -1)                    # 死叉（平仓）
```

关于"金叉/死叉"要有清醒认识：它是**趋势跟随**规则的简化形式，本质是"近期价格相对强于远期则做多"。它的收益特征是**小亏多次、大赚少数**——在震荡市反复止损（俗称"钝化/反复打脸"），在单边市才赚钱。这不是缺陷，是趋势跟随策略的固有属性（胜率低、盈亏比高）。

## 3. 动量（Momentum）

动量是**学术实证最充分**的价格类因子（01 篇提到的 Jegadeesh & Titman 1993），定义朴素：

```python
momentum_12_1 = close.shift(21) / close.shift(252) - 1
# 经典 "12-1 动量"：过去 12 个月收益，剔除最近 1 个月
# 剔除近月的原因：原始文献（Jegadeesh & Titman 1993；随后研究如
# Novy-Marx 2012 提出的 intermediation）发现短期反转效应——
# 最近一个月的涨跌倾向于反转而非延续，混入会污染动量信号
```

动量与均线的差别：均线是"绝对水平 vs 相对水平"的判别，动量是"区间收益率"的度量；用于**横截面选股**（06 篇：比较所有股票的动量、买强的卖弱的）比用于单只股票择时更接近学术原始形态。

## 4. RSI（相对强弱指数）

Welles Wilder 1978 年在《New Concepts in Technical Trading Systems》中提出：

```python
delta = close.diff()
gain  = delta.clip(lower=0).rolling(14).mean()     # 14 日平均涨幅（Wilder 原版用
loss  = (-delta).clip(upper=0).rolling(14).mean()  # 其自定义的平滑，此处用 SMA 简化，
                                                    # 两者数值略有差异，见 2.4 节辨析）
rs = gain / loss
rsi = 100 - 100 / (1 + rs)                          # 值域 [0, 100]
```

传统解读：RSI > 70 超买（可能回落），< 30 超卖（可能反弹）。**实证上的诚实结论**：把"超买即卖、超卖即买"当独立交易系统，在趋势市会持续亏损（强趋势中 RSI 可以长期停在 70 以上——超买可以更超买）；它更实际的用法是作为**过滤器/确认条件**与其他信号组合。

## 5. 指标的实证地位：一个必须直面的证据

新手教程通常暗示"学会指标就能赚钱"。必须给出反方向的证据：

1. **参数敏感**：双均线策略从 (20,60) 改成 (21,63)，收益可能从 +30% 变 -10%（05 篇将演示参数面）。这说明"这个参数赚钱"大概率是噪声拟合而非规律；
2. **经典检验**：Brock, Lakonishok & LeBaron（1992）曾支持双均线在道指历史数据有效；但 Sullivan, Timmermann & White（1999）用 **White's Reality Check（数据窥探校正）**重检发现：考虑了"你试过多少种规则组合"之后，技术交易规则的显著性大幅缩水；后续对美股与更多市场的研究（如 Bajgrowicz & Scaillet 2012）发现动量类技术规则的有效性在衰减；
3. **机制解释**：广为人知的规则会被套利摊薄（01 篇 alpha 衰减）；指标对价格的变换并不产生新信息。

**本篇立场**：指标值得学，因为它们是**信号的词汇表**和动量等因子的实现载体；但评价任何指标信号，唯一标准是**含成本的、无作弊的回测 + 样本外验证**（05 篇），而不是"书上说的用法"。

## 6. 信号工程的三个通用原则

1. **信号要稀疏**：条件越多越"准"，样本越少越不可信——一个 3 年只触发 5 次的信号，统计上等于没有验证过；
2. **先横截面后择时**：对新手而言，"比较 A/B/C 谁强买谁"（选股）通常比"预测涨跌时点"（择时）更可研究——择时本质是预测极难的低信噪比问题（后续 06 篇展开）；
3. **信号与执行分离**：signal 函数只产出 0/1 或权重，执行细节（开盘买还是收盘买、滑点多少）在回测引擎里统一处理（05/09 篇）——混在一起会导致"调指标顺手调成本"的自欺。
