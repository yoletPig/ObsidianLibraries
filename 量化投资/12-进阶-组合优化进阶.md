# 12 - 进阶：组合优化进阶

> 进阶篇第 3 章。07 篇给了马科维茨与等权基准；本章补全"优化器"的完整工程：为什么原始 MVO 会失败、约束如何拯救它、Black-Litterman 如何处理"估计误差"、以及风险模型的角色。目标是**判断自己的问题需不需要优化器，以及需要什么样的优化器**。

## 1. 原始 MVO 的三宗罪（从 07 篇的"极端敏感"展开）

1. **输入误差放大**：最优权重是预期收益的凸函数，μ 估计的微小扰动 → 权重剧烈跳变（Michaud "error maximization"，07 篇已引）；
2. **角点解**：无约束 MVO 的解常常是"三只股票各 33%"式的极端组合——优化器把权重压到它**认为**收益最高的少数资产上，而"认为"建立在噪声上；
3. **未建模的现实约束**：无卖空限制、无换手约束、无行业暴露约束——解出的组合实盘不可执行（借不到那么多券、换手成本爆炸、行业赌注超风控线）。

结论：**裸 MVO 在实务中几乎从不直接使用**。它被拯救的方式有三类：加约束（§2）、换输入（§3 Black-Litterman）、换目标（§4 风险预算）。

## 2. 约束：把优化器从"放大噪声"改造成"表达规则"

约束是**风控与合规规则的数学表达**，每条都该能追溯到一条业务理由：

```python
# 约束矩阵形式（以 scipy.optimize 或 cvxpy 表达）
w = cp.Variable(n)
constraints = [
    cp.sum(w) == 1,                    # 满仓
    w >= 0,                            # 不卖空（A 股学习期立场，07 篇）
    w <= 0.10,                         # 单票上限：任何单一错误不致命（07 篇生存纪律）
    sector_exposure @ w <= 0.30,       # 行业上限：不做单一行业全押
    cp.norm(w - w_prev, 1) <= 0.20,    # 换手约束：L1 距离限仓（直连 10 篇成本）
    tracking = cp.norm(w - benchmark_w, 2) <= 0.05,   # 跟踪误差约束（指数增强场景）
]
prob = cp.Problem(cp.Maximize(alpha @ w - lambda_risk * cp.quad_form(w, cov)),
                  constraints)
```

四条常被忽略的工程要点：

1. **换手约束（L1 距离）是成本模型的优化器内表达**——比"事后扣成本"更有效，因为它在求解时就放弃了低价值的高换手调仓；
2. **协方差矩阵必须正则化**：n 只股票的样本协方差在 n 大时病态（秩不足/噪声主导）。标准处理：收缩估计（Ledoit & Wolf 2004 的 shrinkage：向"常数相关"或"单位方差"目标收缩）或因子模型协方差（§4）；
3. **约束之间会打架**：单票 10% × 20 只 ≤ 100% 意味着组合必须 ≥ 20 只——约束系统不可行时优化器报错而不是提示哪条冲突，排查要有准备；
4. **解的稳定性检查**：把 μ 加扰动 ±10% 重解——**最优权重剧烈翻转 = 这个优化器在放大噪声**，回到收缩/简化。

## 3. Black-Litterman：给"观点"一个贝叶斯框架

### 3.1 解决的问题

MVO 需要 μ（预期收益），而 μ 几乎不可估。Black-Litterman（1992，高盛）的思路：**不从零估 μ，而是从市场均衡出发，把主观观点当作对均衡的贝叶斯修正**。

```
市场隐含收益：μ_eq = δΣw_mkt        （δ 风险厌恶系数、Σ 协方差、w_mkt 市值权重）
              —— 反解：若市场组合是最优的，市场权重"隐含"的预期收益是多少
观点融合：   μ_posterior ∝ 融合（μ_eq 均衡先验, PΩP 观点似然）
              P：观点矩阵（"股票A将跑赢股票B 2%"），Ω：观点置信度
再优化：     把 μ_posterior 喂给 MVO
```

### 3.2 为什么它有效（以及局限）

- **自动得率的改善**：观点只影响与观点相关的资产（贝叶斯收缩的自然结果），不再出现"一个观点 → 全组合重排"的 MVO 病态；
- **观点可以稀疏**：对没观点的资产，就留在均衡（等价于"我不知道"的诚实表达）；
- **局限**：观点矩阵 P 与置信度 Ω 仍是人工输入——**BL 把"估 μ"的难题转换成"表达观点置信度"的难题**，没有消灭主观，只是给了主观一个有纪律的位置。

对个人学习者的务实建议：BL 的完整实现依赖风险模型与市场组合定义，工程量不小；**其思想（先验=均衡、观点=修正、置信度=显式参数）比完整实现更值得先掌握**——它能立刻改善你对"该给一个观点多大仓位"的直觉（与 07 篇凯利半仓的精神同源：观点越弱，仓位越向均衡退）。

## 4. 风险模型：协方差的工业化估计

大组合的 Σ 估计是独立课题，行业标准是**因子风险模型**（Barra 式，11 篇已提）：

```
r_i = Σ_k f_ik × F_k + ε_i        （股票收益 = 因子暴露×因子收益 + 特异残差）
Σ = B Φ Bᵀ + Δ                    （因子协方差 + 特异方差对角阵）
```

好处：协方差从 n(n+1)/2 个自由参数压缩到"因子数 × 因子数 + n 个特异方差"——估计稳定、正定性有保证、且**风险可归因**（"这个组合 60% 的风险来自市值因子"）。行业公开方法论见 Grinold & Kahn 与 MSCI Barra 公开文献；开源实现有 sklearn 的 FactorAnalysis 类思路与国内社区的风险模型项目（以各自文档为准）。

## 5. 风险平价与波动率目标的优化器视角

07 篇给了风险平价直觉，此处补其优化形式：**最小化各资产风险贡献的方差**：

```python
def risk_parity_objective(w, cov):
    mrc = cov @ w / np.sqrt(w @ cov @ w)      # 边际风险贡献
    rc = w * mrc / np.sqrt(w @ cov @ w)       # 风险贡献占比（和为 1）
    return np.sum((rc - 1/n) ** 2)            # 等风险贡献的目标
```

要点：风险平价**只用协方差、不用 μ**——绕开了 MVO 的最大噪声源，代价是完全放弃预期收益信息（牛市里跑输进攻型组合是特性不是缺陷）。它与波动率目标（07 篇）可叠加：风险平价管"内部怎么分"，波动率目标管"总杠杆多大"。

## 6. 决策树：你需要哪种优化

```
持仓 < 20 只、无杠杆 → 等权 + 单票上限，不需要优化器（07 篇结论依然成立）
指数增强/对标基准     → 带跟踪误差与换手约束的 MVO（§2）+ 因子风险模型（§4）
有明确观点、多资产配置 → BL 思想（§3）或等权 + 主动偏离额度
不做择时、只管风险    → 风险平价（§5）
```

**任何优化器落地前，先跑"扰动检验"（§2.4）**：μ 加 10% 噪声、Σ 用收缩前后各解一次——解的漂移量就是优化器里噪声的含量。
