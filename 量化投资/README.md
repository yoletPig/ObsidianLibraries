# 量化投资系列教程：用数据做投资决策

> 面向有基础 Python 能力、想系统学习**量化投资与股票选股**的初学者。全系列从"量化是什么、和赌博/玄学的区别"讲起，到数据获取、指标、回测、多因子选股、组合与风控，最后用机器学习视角收尾。
>
> **⚠️ 重要声明**：本系列全部内容仅用于**学习与研究**，不构成任何投资建议。回测结果不代表未来表现，教程中的示例数据均为虚构演示。真实投资有本金损失风险；文中涉及的工具与数据源接口可能随时间变化，以各自官方文档为准。

### 阶段划分

1. **认知与地基（01–03）**：先建立预期，再打数据与度量基础。**跳过 01 直接学策略，是最常见的失败路径。**
2. **信号与验证（04–05）**：产生信号 + 验证信号。**05 篇的陷阱清单是全系列的灵魂。**
3. **选股与组合（06–07）**：从"选一只股"到"管一组股票"。
4. **进阶与实战（08–09）**：机器学习的真实角色与端到端项目。
5. **进阶篇（10–13）**：走向实盘的纵深——执行成本、因子工程、组合优化、生产工程。建议在读完 01–07 后按需进入。

## 本系列的立场（提前说清，避免误导）

1. **量化 ≠ 稳赚**。量化是用统计方法管理概率与风险，亏损月/亏损年是常态；
2. **回测赚钱 ≠ 实盘赚钱**（05 篇列举的每个偏差都在扩大这个差距）；
3. 本系列**不推荐任何具体标的、不预测行情**，所有示例只用历史数据做方法论演示；
4. 对"低风险高收益"的宣称保持本能怀疑——这同样适用于本系列自己给出的任何示例结果。

## 环境要求

Python 3.10+，`pandas`、`numpy`、`matplotlib` 为核心依赖；数据获取示例以 **akshare**（开源财经数据接口库）为主，因其免费且无需注册；涉及接口的部分均注明"以官方文档为准"。无需任何付费数据服务。
