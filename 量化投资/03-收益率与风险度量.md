# 03 - 收益率与风险度量

## 本篇目标

本篇是量化的"语言课"。学完你将能实现并正确解读：对数收益率、年化收益、波动率、最大回撤、夏普比率，并理解**回撤与连亏的心理现实**。

约定：本篇代码接续 02 篇的 `price`（Series，日频后复权收盘价），`TRADING_DAYS = 252`（A 股与美股的年交易日数均约 250±5，252 为行业惯例）。

## 1. 收益率：简单收益 vs 对数收益

```python
simple_ret = price.pct_change()                       # 简单收益率 (P_t - P_{t-1})/P_{t-1}
log_ret    = np.log(price).diff()                     # 对数收益率 ln(P_t / P_{t-1})
```

| | 简单收益 | 对数收益 |
| --- | --- | --- |
| 跨资产可加（组合收益） | ✅ 这正是组合权重的加权和 | ❌ 不可直接加权 |
| 跨时间可加（多年累计） | ❌ 要连乘 (1+r₁)(1+r₂)… | ✅ 直接相加 |
| 数学性质 | 值域 (-1, ∞)，不对称 | 接近对称，适合统计建模 |

经验法则（业界通行）：**跨时间累计与统计建模用对数收益，组合层面与向人汇报用简单收益**。两者在收益率小（|r| ≪ 1）时近似相等（ln(1+r) ≈ r），日频差异可忽略；但大波动时差异显著（单日 -50% 的对数收益是 -69%）。

```python
# 年化：把日频换算到年（几何口径）
total_return   = price.iloc[-1] / price.iloc[0] - 1
years          = len(price) / TRADING_DAYS
annualized     = (1 + total_return) ** (1 / years) - 1      # 几何年化（CAGR）
```

**必须警惕的年化陷阱**：用短周期数据年化会制造荒谬数字——两个月赚 5%，年化 ≈ 34%（(1.05)^6-1），但两个月根本不足以证明策略有效。**看年化必须连同"数据时长"一起看**，短于 1~2 年的回测结论基本无意义。

## 2. 波动率（Volatility）

```python
vol_daily  = log_ret.std()
vol_annual = vol_daily * np.sqrt(252)          # 年化：波动率随时间开方累积（√T 法则）
```

√T 法则的适用前提是收益**独立同分布**——真实价格序列有波动聚集（大波动连着大波动，Engle 1982 年的 ARCH 现象），所以 √T 年化是近似值，但作为度量口径业界统一使用。

波动率的**直觉换算**很有用：年化波动率 20% ≈ 单日波动 20%/√252 ≈ **1.26%**。看到"某股波动率 60%"，先换算成"单日 ±3.8%"再感受它。

## 3. 最大回撤（Maximum Drawdown）

```python
running_max = price.cummax()               # 历史最高点
drawdown    = price / running_max - 1      # 当前回撤（≤0）
max_dd      = drawdown.min()               # 最大回撤，如 -0.35 表示最深亏 35%
```

**为什么最大回撤比收益率更重要**：回撤决定你**能不能拿得住**。-35% 的回撤意味着要先涨 53.8% 才回本（回本涨幅 = 1/(1-0.35)-1）——回撤越深，回本所需的涨幅呈非线性放大：

| 回撤 | 回本所需涨幅 |
| --- | --- |
| -10% | +11.1% |
| -30% | +42.9% |
| -50% | +100% |
| -70% | +233% |

这条非线性关系是"风控优先"价值观的数学基础：**避免深坑比追求高收益更可控**。

## 4. 夏普比率（Sharpe Ratio）

```python
rf = 0.02  # 无风险利率（示例值；实际应取同期国债/存单利率）
sharpe = (annualized - rf) / vol_annual    # 年化口径
# 日频等价写法：sharpe ≈ (log_ret.mean() - rf/252) / log_ret.std() * sqrt(252)
```

定义（William Sharpe, 1966 提出"reward-to-variability ratio"，1990 年获诺贝尔经济学奖）：**每承担一单位波动，换回多少超额收益**。它是量化界最通用的"性价比"度量。

**解读基准**（经验区间，非定理）：长期夏普 < 0.5 一般，≈1.0 良好（多数公开的多因子/趋势策略在这个量级），> 2.0 显著——**先怀疑数据错误或过拟合**（05 篇），顶级机构的长期策略也极少稳定超过 2。

**夏普的两个盲区**（面试常考，实盘重要）：

1. **对偏度与尾部不敏感**：策略 A"每年稳定赚 10%"与策略 B"99% 的日子赚 0.05%、1% 的日子亏 5%"可以有相同夏普——但体验天差地别。补充度量：偏度（skewness）、峰度，或 Sortino 比率（只用下行波动做分母）；
2. **受持有期影响**：高频再平衡与低频策略的夏普不能直接比。

## 5. 一个必须建立的心理模型：连亏与回撤是常态

用蒙特卡洛感受：夏普比率 1.0（年化超额 10%、年化波动 8%）、**真实的优秀策略**，月度胜率大约只有多少？粗算：月度超额收益均值 ≈ 10%/12 ≈ 0.83%，月波动 ≈ 8%/√12 ≈ 2.31%，正态近似下单月为正的概率 ≈ Φ(0.83/2.31) ≈ **64%**。于是：

```python
rng = np.random.default_rng(0)
months = rng.normal(0.0083, 0.0231, (1000, 36))      # 1000 条 3 年路径
p_loss_year = (months.sum(axis=1).reshape(1000, 3, 12).sum(axis=2) < 0).mean()
print(f"3 年中至少出现一个亏损年的概率 ≈ {p_loss_year:.0%}")
# 输出量级：约 30%（按文中参数推算约 29%，随参数浮动）
# 解析：年超额 10%/波动 8% 下，单年亏损概率 Φ(-1.25) ≈ 10.6%，
#       3 年至少一次 ≈ 1 - (1-10.6%)^3 ≈ 29%
```

结论（来自同一套统计的推论，具体数字随假设浮动）：**一个长期优秀的策略，出现亏损月份是家常便饭，出现整年亏损的概率也相当可观**。执行层面的含义：如果你无法在策略回撤 15% 时继续按信号执行，问题不在策略，在匹配——**选择与心理承受力匹配的策略，是风控的一部分**。

## 6. 度量速查表

```python
def perf_stats(log_ret: pd.Series, rf: float = 0.02) -> dict:
    eq = log_ret.cumsum().apply(np.exp)              # 净值曲线（初始 1.0）
    n_years = len(log_ret) / 252
    ann = eq.iloc[-1] ** (1 / n_years) - 1
    vol = log_ret.std() * np.sqrt(252)
    mdd = (eq / eq.cummax() - 1).min()
    return {"年化": f"{ann:.1%}", "波动": f"{vol:.1%}",
            "最大回撤": f"{mdd:.1%}", "夏普": f"{(ann - rf) / vol:.2f}"}
```

这套 4 指标（年化、波动、最大回撤、夏普）是后续每篇评估策略的统一语言。
