# 06 - 多因子选股入门

## 本篇目标

多因子选股是机构量化的主流范式（A 股的公募量化、私募指数增强大多以此为基础）。本篇讲清楚：因子是什么 → 怎么评价一个因子（IC 与分层回测）→ 怎么把多个因子组合成选股模型。全程贯穿 05 篇的防作弊纪律。

## 1. 范式转变：从"预测这只股票"到"排序所有股票"

前几篇的思路是**择时**（这只股票现在该买吗）；多因子选股是**横截面排序**：

```
每个调仓日：
1. 计算全市场每只股票的若干"因子值"（如动量、低波动、低估值）
2. 按因子值排序，买入排名靠前的 N 只（同时卖出跌出排名的）
3. 定期（如每月）重复
```

核心思想：**不预测绝对涨跌，只预测相对强弱**——"未来一个月，这批股票平均比那批强"是统计上更容易的问题（01 篇 6.2 节的"先横截面后择时"）。

## 2. 因子：定义与经典例子

**因子 = 一个可计算的变量，使得"该变量的值"与"未来收益"存在稳定（且有机理解释）的相关性。**

三大经典因子族（均有长期跨市场实证，注意均为"历史实证有效、当下有效性会波动/衰减"）：

| 因子族 | 代表变量 | 机理假说 | 原始文献 |
| --- | --- | --- | --- |
| 价值 | 账面市值比 B/M、盈利收益率 E/P | 低估值股票被过度悲观定价；承载更高基本面风险 | Fama & French, 1992/1993 |
| 动量 | 过去 12-1 个月收益 | 投资者反应不足，趋势延续 | Jegadeesh & Titman, 1993 |
| 质量/低风险 | ROE、低波动、低beta | 彩票偏好推高高波动股价格；机构约束 | Baker, Bradley & Wurgler, 2011（低beta）；Frazzini & Pedersen, 2014（Betting Against Beta） |

Fama-French 三因子模型（1993）把市场、规模（SMB）、价值（HML）作为系统性定价因子——**"因子"这个词的正式出处**；此后五因子（2015）等不断扩展。注意学术因子的构造细节（分位数分组、多空对冲）与实盘因子有差异，学机理以论文为准，做工程以本篇方法为准。

## 3. 因子评价方法一：IC（信息系数）

**IC = 因子值与下期收益的横截面相关系数**（常用 Spearman 秩相关），每个调仓日算一个，看时间序列：

```python
from scipy import stats

def ic_series(factor: pd.DataFrame, fwd_ret: pd.DataFrame) -> pd.Series:
    """
    factor / fwd_ret: index=调仓日, columns=股票代码
    fwd_ret: 未来一期收益（注意：必须用"当时可知"的因子值预测"未来"收益）
    """
    ics = {}
    for date in factor.index:
        f, r = factor.loc[date], fwd_ret.loc[date]
        mask = f.notna() & r.notna()
        if mask.sum() > 30:                       # 截面样本太少则无统计意义
            ics[date] = stats.spearmanr(f[mask], r[mask]).statistic
    return pd.Series(ics)

# 评价口径（经验基准）：
# |IC 均值| > 0.03 且 IC 为正的比例 > 55% → 值得进一步研究
# |IC 均值| > 0.05 在单因子里已算相当强
# ICIR = IC均值 / IC标准差（类比夏普），> 0.5 算优秀
```

要点：
- **IC 的符号要预先约定**：低波动因子"波动越低收益越高"，IC 为负——负 IC 同样是有用因子（做多低值做空高值），关键是**方向稳定**；
- **IC 均值的意义靠 ICIR 放大**：均值 0.03 但波动 ±0.3 的因子，不可用。

## 4. 因子评价方法二：分层回测

IC 只看线性相关，更直观的验证是**分层**：按因子值把股票分 5 组（Q1~Q5），每组等权持有，比较各组收益：

```python
def layer_backtest(factor: pd.DataFrame, fwd_ret: pd.DataFrame, q: int = 5):
    """返回每组每期的平均收益。健康因子应呈单调排列。"""
    out = {}
    for date in factor.index:
        f, r = factor.loc[date], fwd_ret.loc[date]
        mask = f.notna() & r.notna()
        if mask.sum() < 50:
            continue
        groups = pd.qcut(f[mask].rank(method="first"), q, labels=False)
        out[date] = r[mask].groupby(groups).mean()
    return pd.DataFrame(out).T          # 行=日期, 列=组号 0..4

# 判断标准：
# ① 单调性：Q0 到 Q4 收益大致单调 → 因子逻辑在整个截面上一致
# ② 多空收益：Q4-QQ0 之差（多空组合收益）要显著为正且稳定
# ③ 只有 Q0 和 Q4 有差异、中间乱 → 因子只在尾部有效，容量/稳健性存疑
```

**单调性是最重要的判据**：如果收益从 Q0 到 Q4 大致阶梯排列，说明因子捕捉的是系统性的横截面规律；如果只是两端有差异，可能是尾部少数极端股票的特异行为（也常是财务数据质量问题的产物）。

## 5. 因子预处理：三个必做步骤

原始因子值直接用会出问题，标准流水线：

1. **去极值（winsorize）**：极端值（财务数据的量纲错误、ST 股的异常值）会主导排序。常用 3σ 截断或分位数截断；
2. **标准化（z-score）**：不同量纲的因子（市盈率 vs 动量）才能组合；
3. **中性化（进阶但重要）**：A 股中"小市值股票波动更大"等效应会污染因子——把因子对市值等**风格变量做横截面回归取残差**，得到"剔除风格后的纯因子暴露"。不做中性化的因子组合，常常只是隐形的市值因子。

```python
def zscore_cross(x: pd.Series) -> pd.Series:
    x = x.clip(x.quantile(0.01), x.quantile(0.99))   # 去极值（分位截断）
    return (x - x.mean()) / x.std()                   # 截面标准化
```

## 6. 多因子组合：从单因子到选股模型

多个因子怎么合成一个打分？由简到繁：

1. **等权打分**：每只股票的各因子 z-score 直接相加。**首选**——简单、稳健、难以过拟合（05 篇：结构越简单越可信）。很多"自研模型"跑不赢等权组合；
2. **IC 加权**：按各因子滚动 IC 均值加权。逻辑清晰，但引入了"IC 估计"这个新的过拟合面；
3. **回归法**：用多因子回归预测收益取拟合值（风险：多重共线性，因子间常常相关——动量与低波动就正相关）；
4. **机器学习**：08 篇，单独讨论为什么它在这里容易翻车。

**因子相关性检查**（合成前必做）：计算各因子截面 z-score 的相关性矩阵，相关 > 0.7 的两个因子视为一个信息源，等权合成会变相加倍它的权重。
