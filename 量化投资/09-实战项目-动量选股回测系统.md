## 2. 核心实现

### 2.1 因子与打分（06 篇流水线）

```python
import numpy as np
import pandas as pd

def momentum_12_1(close: pd.DataFrame) -> pd.DataFrame:
    """close: index=交易日, columns=股票代码（后复权）
    返回: index=月末, columns=代码 的动量值"""
    monthly = close.resample("ME").last()
    return monthly.shift(1) / monthly.shift(13) - 1     # 过去12月，剔除最近1月

def zscore_cross(x: pd.Series) -> pd.Series:
    x = x.clip(x.quantile(0.01), x.quantile(0.99))      # 去极值
    return (x - x.mean()) / x.std()                     # 截面标准化

def score_stocks(factor: pd.DataFrame) -> pd.DataFrame:
    """单因子打分：截面 z-score。多因子时各因子 z-score 相加（等权，07 篇纪律）。"""
    return factor.apply(zscore_cross, axis=1)
```

### 2.2 多资产组合回测引擎（05 篇最小引擎的扩展）

```python
def backtest_portfolio(close: pd.DataFrame, weights: pd.DataFrame,
                       cost_bps: float = 20.0) -> pd.DataFrame:
    """
    weights: index=调仓日（月末）, columns=代码, 值=目标权重（已含等权归一）
    执行假设: 月末收盘计算信号 → 次月第一个交易日收盘价成交（保守假设）
    cost_bps: 单边成本万20（含冲击的保守估计，敏感性测试时翻倍）
    """
    daily_ret = close.pct_change()
    # 权重按"持有期"展开：调仓日设定目标权重，期内保持
    held = weights.reindex(daily_ret.index, method="ffill").fillna(0)
    held = held.shift(1).fillna(0)                       # ⚠ 信号错位一天
    gross = (held * daily_ret).sum(axis=1)               # 组合日收益
    turnover = held.diff().abs().sum(axis=1).fillna(0)   # 日换手（双边和）
    net = gross - turnover * cost_bps / 1e4
    equity = (1 + net).cumprod()
    return pd.DataFrame({"equity": equity, "ret": net,
                         "dd": equity / equity.cummax() - 1,
                         "turnover": turnover})

def build_monthly_weights(scores: pd.DataFrame, top_n: int = 20,
                          min_universe: int = 100) -> pd.DataFrame:
    """每个调仓日：取得分最高的 top_n 只，等权。"""
    rows = {}
    for date, row in scores.iterrows():
        valid = row.dropna()
        if len(valid) < min_universe:                    # 截面太薄不交易
            continue
        picked = valid.nlargest(top_n).index
        rows[date] = pd.Series(1 / top_n, index=picked)  # 等权
    return pd.DataFrame(rows).T.fillna(0)
```

### 2.3 评估与基准对比（03 篇统一语言）

```python
def perf_stats(bt: pd.DataFrame, bench_ret: pd.Series = None,
               rf: float = 0.02) -> dict:
    n_years = len(bt) / 252
    ann = bt["equity"].iloc[-1] ** (1 / n_years) - 1
    vol = bt["ret"].std() * np.sqrt(252)
    stats = {"年化": f"{ann:.1%}", "波动": f"{vol:.1%}",
             "最大回撤": f"{bt['dd'].min():.1%}",
             "夏普": f"{(ann - rf) / vol:.2f}",
             "年换手": f"{bt['turnover'].mean() * 252:.0f} 倍"}
    if bench_ret is not None:                            # 相对基准：超额收益
        stats["超额年化(对基准)"] = f"{(bt['ret'] - bench_ret.reindex(bt.index).fillna(0)).mean() * 252:.1%}"
    return stats
```

**评估必须包含基准**：策略年化 8% 而基准同期 12% 的"策略"是失败的。基准用对应市场指数（如沪深 300 全收益——注意价格指数不含分红，会低估基准 1.5~3 个百分点/年，对比时要在同一口径）。

## 5. 预期结果与诚实的解读框架

跑完之后你会得到类似结构的结果（**具体数字完全取决于数据段与股票池，不要把任何示例数字当预期**）：

- 动量选股相对基准可能有小幅超额，但**月度波动大、某几年持续跑输**（动量因子有著名的"动量崩溃"时段——市场剧烈反转时动量策略大幅回撤，如 2009 年美股反弹期，学术讨论见 Daniel & Moskowitz 2016）；
- 年换手可能达数倍——扣完成本后超额所剩无几，这是 A 股做动量的现实摩擦，也是为什么很多 A 股量化更偏低频调仓与质量类因子；
- 如果你的回测显示"年化 30%+、夏普 2.5、回撤 5%"——**按 05 篇清单重查，几乎必有作弊**。
