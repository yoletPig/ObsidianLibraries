## 1. 0-1 背包：每件物品"选或不选"

**问题**：n 件物品各有重量 w[i]、价值 v[i]，容量 C 的背包，每件至多选一次，求最大价值。这是"资源约束下的决策"的原型（面试、量化里的组合约束、推理引擎里的显存分配，都是它的变体）。

```python
def knapsack_01(weights: list[int], values: list[int], cap: int) -> int:
    """0-1 背包：二维 DP。O(n·C) 时间，O(n·C) 空间。
    状态：dp[i][c] = 只考虑前 i 件、容量 c 时的最大价值。
    转移（第 i 件 选 or 不选）：
      不选：dp[i][c] = dp[i-1][c]
      选：dp[i][c] = dp[i-1][c - w[i]] + v[i]   （要求 c >= w[i]）
    注意"选"来自 dp[i-1] 行——每件只能用一次。"""
    n = len(weights)
    dp = [[0] * (cap + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        w, v = weights[i - 1], values[i - 1]
        for c in range(cap + 1):
            dp[i][c] = dp[i - 1][c]                # 默认不选
            if c >= w:
                dp[i][c] = max(dp[i][c], dp[i - 1][c - w] + v)
    return dp[n][cap]

# w=[1,3,4], v=[15,30,45], C=6 的最优：选 {1,4}（重 5）得 60；
# {3,4} 重 7 超容、全选重 8 超容，所以 60 就是答案。
assert knapsack_01([1, 3, 4], [15, 30, 45], 6) == 60   # 选重量 1 和 4 两件：15 + 45
```

### 一维化与"倒序"之谜

`dp[i][*]` 只依赖 `dp[i-1][*]` → 压到一维。**但内层必须倒序**：正序会让 `dp[c - w]` 读到"本行已更新"的值——等于"这件物品被用了两次"，0-1 变成了完全背包。这是 12 篇"循环顺序 = 依赖拓扑序"的最著名案例：

```python
def knapsack_01_1d(weights: list[int], values: list[int], cap: int) -> int:
    """0-1 背包一维版：内层容量倒序。O(n·C) 时间，O(C) 空间。
    倒序保证 dp[c - w] 还是"上一行"（未含第 i 件）的旧值。"""
    dp = [0] * (cap + 1)
    for w, v in zip(weights, values):
        for c in range(cap, w - 1, -1):        # 倒序！正序 = 每件可重复选
            dp[c] = max(dp[c], dp[c - w] + v)
    return dp[cap]

assert knapsack_01_1d([1, 3, 4], [15, 30, 45], 6) == 60
```

## 2. 完全背包：每件物品无限选

只有一处不同：**内层正序**——`dp[c - w]` 允许读到本行（含第 i 件）的新值，正是"可以再选一件"：

```python
def coin_change_min(coins: list[int], amount: int) -> int:
    """LC 322 零钱兑换：凑出 amount 的最少硬币数（每币无限）。完全背包。
    状态：dp[c] = 凑出金额 c 的最少硬币数。转移：dp[c] = min(dp[c-coin] + 1)。
    O(n·C) 时间 O(C) 空间。"""
    INF = amount + 1                          # "不可能"哨兵（不能用 float('inf')+1 语义混乱）
    dp = [INF] * (amount + 1)
    dp[0] = 0                                 # 边界：凑 0 用 0 枚
    for coin in coins:
        for c in range(coin, amount + 1):     # 正序：同币可重复使用
            if dp[c - coin] + 1 < dp[c]:
                dp[c] = dp[c - coin] + 1
    return dp[amount] if dp[amount] <= amount else -1

def coin_change_count(coins: list[int], amount: int) -> int:
    """LC 518 零钱兑换 II：凑出 amount 的组合数（顺序无关）。
    关键细节：外层枚硬币、内层枚金额 → 组合数（1,2 与 2,1 只算一次）；
    外层枚金额、内层枚硬币 → 排列数（LC 377）。一字之差，答案天壤之别。"""
    dp = [0] * (amount + 1)
    dp[0] = 1                                 # 空集凑 0：1 种
    for coin in coins:
        for c in range(coin, amount + 1):
            dp[c] += dp[c - coin]
    return dp[amount]

assert coin_change_min([1, 2, 5], 11) == 3          # 5+5+1
assert coin_change_min([2], 3) == -1
assert coin_change_count([1, 2, 5], 5) == 4         # 5 / 2+2+1 / 2+1+1+1 / 1×5
```

> **提示**：背包一族的一个记忆锚点（经验做法）：**0-1 倒序、完全正序**；**求组合数：物品在外层；求排列数：容量在外层**。四格矩阵背下来，LC 322/377/416/494/518 全部覆盖。

## 3. 编辑距离：二维字符串 DP 的巅峰

**问题**（LC 72）：把 word1 变成 word2 的最少操作（插入/删除/替换）。状态：`dp[i][j]` = word1 前 i 个字符变成 word2 前 j 个字符的最少操作。转移按"最后一个字符怎么处理"分类：

```python
def min_distance(word1: str, word2: str) -> int:
    """LC 72 编辑距离。O(mn) 时间/空间。
    转移（看 a[i-1] 与 b[j-1] 是否相等）：
      相等：dp[i][j] = dp[i-1][j-1]            （末位白送，不用操作）
      不等：dp[i][j] = 1 + min(
              dp[i-1][j],      # 删 word1 末位
              dp[i][j-1],      # 在 word1 末位插入 word2 末位
              dp[i-1][j-1],    # 把 word1 末位替换成 word2 末位
           )"""
    m, n = len(word1), len(word2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1):
        dp[i][0] = i                    # 变成空串：删 i 次
    for j in range(n + 1):
        dp[0][j] = j                    # 空串变过来：插 j 次
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i - 1] == word2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = 1 + min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1])
    return dp[m][n]

assert min_distance("horse", "ros") == 3      # 替换 r、删 h、删 e
assert min_distance("intention", "execution") == 5
```

**LCS 与编辑距离的统一视角**（12 篇练习 3 的回收）：`dp[i][j]` 的"相等白送、不等取最优"结构同时覆盖 LCS、编辑距离、正则匹配等一族题——二维字符串 DP 的转移几乎总在"末位匹配与否"上分岔。

## 4. DP 调试硬技能：打印表格

DP 的 bug 几乎从不报错，只是"答案不对"。**打印表格逐格核对**是唯一可靠的调试法（经验做法，竞赛与面试共识）：

```python
def debug_edit_distance(a: str, b: str) -> None:
    """打印 dp 表格：行是 a 的前缀，列是 b 的前缀。"""
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            dp[i][j] = (dp[i - 1][j - 1] if a[i - 1] == b[j - 1]
                        else 1 + min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]))
    header = "      " + "  ".join(f"∅ {ch}" for ch in b)
    print(header)
    for i in range(m + 1):
        row_label = "∅" if i == 0 else a[i - 1]
        print(f"   {row_label}  " + "  ".join(f"{dp[i][j]:2d}" for j in range(n + 1)))

debug_edit_distance("horse", "ros")
# 期望表格（逐格人肉验证转移）：
#        ∅  r  o  s
#    ∅   0  1  2  3
#    h   1  1  2  3
#    o   2  2  1  2
#    r   3  2  2  2
#    s   4  3  3  2
#    e   5  4  4  3
```

调试流程（三问）：① 边界行/列对吗？② 挑 2–3 个格子，**手工按转移方程重算**，和表对得上吗？③ 最终格子是否语义一致（dp[m][n] 确实是"整串变整串"）？三步走完，90% 的 DP bug 当场现形。

## 5. 区间 DP：石子合并/戳气球

**模式**：状态是**区间 [i, j]**，转移枚举"区间内的分割点 k"或"最后处理哪个元素"。典型：合并石子（LC 1000 变体）、戳气球（LC 312）、最长回文子序列（LC 516）。

```python
def longest_palindrome_subseq(s: str) -> int:
    """LC 516 最长回文子序列。区间 DP。O(n²)。
    状态：dp[i][j] = s[i..j] 中最长回文子序列长度。
    转移：s[i]==s[j]：dp[i][j] = dp[i+1][j-1] + 2（两端配对）
          否则：dp[i][j] = max(dp[i+1][j], dp[i][j-1])（丢一端）
    依赖"更短的区间" → 按 i 从大到小（或区间长度从小到大）扫。"""
    n = len(s)
    dp = [[0] * n for _ in range(n)]
    for i in range(n - 1, -1, -1):        # i 倒序：先算长区间依赖的短区间
        dp[i][i] = 1                      # 单字符是回文
        for j in range(i + 1, n):
            if s[i] == s[j]:
                dp[i][j] = dp[i + 1][j - 1] + 2
            else:
                dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])
    return dp[0][n - 1]

assert longest_palindrome_subseq("bbbab") == 4    # bbbb
assert longest_palindrome_subseq("cbbd") == 2     # bb
```

区间 DP 的循环框架二选一：`i 倒序 + j 正序`（如上），或外层枚举区间长度 `len = 2..n`、内层枚举左端 `i`。哪个顺手用哪个，但要能说清"转移依赖的所有格子都已在之前算好"。

## 6. 状态机 DP：股票问题族

**问题族**（LC 121/122/309/714）：每天可买/卖/休息，各种交易限制。解法：**给状态加一维——"当前处于什么交易状态"**，状态之间的合法迁移画成状态机图，转移就是沿图走边。

```python
def max_profit_multi(prices: list[int]) -> int:
    """LC 122 买卖股票的最佳时机 II：可多次交易（同日不能既买又卖）。
    状态机：持有（hold）/ 不持有（free）。
      free[i] = max(free[i-1], hold[i-1] + prices[i])   # 今天卖出 or 继续观望
      hold[i] = max(hold[i-1], free[i-1] - prices[i])   # 今天买入 or 继续持有
    O(n) 时间 O(1) 空间。"""
    free, hold = 0, float("-inf")         # 第 0 天前：不持有收益 0；"持有"不可能
    for p in prices:
        free, hold = max(free, hold + p), max(hold, free - p)
        # 注意同时更新：两边都用昨天的值（Python 元组赋值天然原子）
    return free

def max_profit_fee(prices: list[int], fee: int) -> int:
    """LC 714 含手续费：在卖出时扣 fee，其余同上。"""
    free, hold = 0, float("-inf")
    for p in prices:
        free, hold = max(free, hold + p - fee), max(hold, free - p)
    return free

def max_profit_cold(prices: list[int]) -> int:
    """LC 309 含冷冻期：卖出后隔一天才能买。三个状态：
    free0 今天没卖（可买）；free1 昨天刚卖（冷冻，只能休息）；
    hold 持有。转移严格按状态机边走。"""
    hold, free0, free1 = float("-inf"), 0, float("-inf")
    for p in prices:
        hold, free0, free1 = (max(hold, free0 - p),   # 买入 or 续持
                              max(free0, free1),      # 观望 or 冷冻结束
                              hold + p)               # 卖出 → 进入冷冻
    return max(free0, free1)

assert max_profit_multi([7, 1, 5, 3, 6, 4]) == 7     # (1买5卖)+(3买6卖)
assert max_profit_fee([1, 3, 2, 8, 4, 9], 2) == 8    # (8-1-2) + (9-4-2) = 5 + 3
assert max_profit_cold([1, 2, 3, 0, 2]) == 3         # 买1卖2,冷冻,买0卖2
```

> **提示**：状态机 DP 的检查点——**同一天的状态迁移不能"接力"**（今天卖出又立刻买入）：更新顺序必须全部基于"昨天"的值（元组同时赋值），否则状态串味。LC 123/188（至多 k 次交易）再加一维"已完成交易数"即可，框架不变。

## 7. 路径 DP 补全：带障碍与滚动压缩

```python
def unique_paths_with_obstacles(grid: list[list[int]]) -> int:
    """LC 63 不同路径 II：障碍物（1）不可走。滚动数组一维化。O(mn) 时间 O(n) 空间。
    一维 dp[j] 从左到右更新时：dp[j]（未更新）= 上一行，dp[j-1]（已更新）= 本行左。"""
    n = len(grid[0])
    dp = [0] * n
    dp[0] = 1 if grid[0][0] == 0 else 0
    for row in grid:
        for j in range(n):
            if row[j] == 1:
                dp[j] = 0                 # 障碍：0 条
            elif j > 0:
                dp[j] += dp[j - 1]        # 上（旧 dp[j]）+ 左（新 dp[j-1]）
    return dp[n - 1]

assert unique_paths_with_obstacles([[0, 0, 0], [0, 1, 0], [0, 0, 0]]) == 2
```

一维滚动读法的口诀：**"旧 dp[j] 是从上面来，新 dp[j-1] 是从左边来"**——把二维转移在一维数组上还原，理解了这个，背包一维化也不再神秘。

## 本篇小结

1. 背包四格锚点：0-1 内层倒序、完全内层正序；组合数物品在外层、排列数容量在外层；
2. 一维化的本质是把"上一行旧值 / 本行新值"混存于一个数组，循环方向控制读哪个——依赖拓扑序（12 篇）的具体化；
3. 编辑距离：末位匹配与否分岔的三选一转移；打印表格逐格核对是 DP 调试的硬技能；
4. 区间 DP：状态是 [i, j]，转移枚举分割点或端点，循环顺序保证短区间先算；
5. 状态机 DP：交易限制转成状态与合法迁移；同日迁移禁止 → 所有更新基于昨天的值。

## 练习

4. （LC 312 - 戳气球）区间 DP 进阶：反转思路为"最后戳破哪个气球"，开区间边界补 1；与 516 对比两种"枚举最后一步"的方向。
5. （LC 188 - 买卖股票的最佳时机 IV）至多 k 次交易：状态机加一维，验证框架扩展性；k >= n//2 时退化为 LC 122（剪枝，经验做法）。
