## 1. 回溯：有系统地枚举所有可能

**回溯（backtracking）= 决策树上的 DFS**（10 篇图 DFS 的决策树特化）。三个概念（出自《算法（第 4 版）》回溯章节的表述框架）：

- **路径**：已经做过的选择；
- **选择列表**：当前还能做的选择；
- **结束条件**：路径到达叶子（满足要求/越界）时收集或终止。

模板一个，变体无穷：

```python
def backtrack_template(items: list) -> list[list]:
    """回溯骨架（伪代码：按题意把中文占位换成具体实现，即得 2 节三例）。"""
    result: list[list] = []
    path: list = []

    def backtrack(choice_start: int) -> None:
        if 满足结束条件():                       # 1. 结束条件
            result.append(path[:])               # 注意拷贝！path 会被复用
            return
        for choice in 可选项(choice_start):      # 2. 遍历选择列表
            if not 合法(choice):                 # 3. 剪枝 1：合法性
                continue
            path.append(choice)                  # 做选择（进入下一层）
            backtrack(下一状态(choice))
            path.pop()                           # 撤销选择（回到本层）

    # backtrack(0)  # 具体化三个占位函数后取消注释即可运行
    return result
```

> **陷阱一**：`result.append(path)` 不拷贝——最后所有"答案"都是同一个（已清空的）path。必须 `path[:]` 或 `list(path)`。
>
> **陷阱二**：`path.pop()` 的撤销必须与 `append` 严格对称，漏一个就串树。

## 2. 三件套：子集、组合、排列

```python
def subsets(nums: list[int]) -> list[list[int]]:
    """LC 78 子集：每个元素 选/不选。决策树节点即答案（全部收集）。
    用 start 防止回头选已考虑过的元素（保证每个子集只生成一次）。O(2^n)"""
    result: list[list[int]] = []
    path: list[int] = []
    def backtrack(start: int) -> None:
        result.append(path[:])               # 每个节点都是一个合法子集
        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(i + 1)                 # 只看 i 之后的元素
            path.pop()
    backtrack(0)
    return result

def combine(n: int, k: int) -> list[list[int]]:
    """LC 77 组合：子集的"长度 == k"特例。结束条件换成 len(path)==k。
    剪枝：剩余元素不足以凑满 k → 提前止损（有序性剪枝）。"""
    result: list[list[int]] = []
    path: list[int] = []
    def backtrack(start: int) -> None:
        if len(path) == k:
            result.append(path[:])
            return
        # 还需要 k - len(path) 个，而 i..n 最多 n - i + 1 个：
        # n - i + 1 < k - len(path) 时剪掉 → i 上限收紧为 n - (k - len(path)) + 1
        for i in range(start, n - (k - len(path)) + 2):
            path.append(i)
            backtrack(i + 1)
            path.pop()
    backtrack(1)
    return result

def permute(nums: list[int]) -> list[list[int]]:
    """LC 46 全排列：顺序有关 → 不能用 start，用 used 数组。O(n·n!)"""
    result: list[list[int]] = []
    path: list[int] = []
    used = [False] * len(nums)
    def backtrack() -> None:
        if len(path) == len(nums):
            result.append(path[:])
            return
        for i in range(len(nums)):
            if used[i]:
                continue                    # 合法性剪枝：同元素不重复用
            used[i] = True
            path.append(nums[i])
            backtrack()
            path.pop()
            used[i] = False
    backtrack()
    return result

assert subsets([1, 2, 3]) == [[], [1], [1, 2], [1, 2, 3], [1, 3], [2], [2, 3], [3]]
assert combine(4, 2) == [[1, 2], [1, 3], [1, 4], [2, 3], [2, 4], [3, 4]]
assert permute([1, 2, 3])[0] in ([1, 2, 3], [1, 3, 2])
assert len(permute([1, 2, 3])) == 6
```

三题的差异全部落在"**选择列表怎么定义**"上：子集/组合用 `start` 索引（无序），排列用 `used` 数组（有序）。**去重**（LC 90/47 输入含重复）：先排序，同层跳过与前一个相同且未使用的元素（`if i > start and nums[i] == nums[i-1]: continue`）——"先排序"是回溯去重与剪枝的共同前提。

## 3. 回溯实战：N 皇后与剪枝的艺术

```python
def solve_n_queens(n: int) -> int:
    """LC 51/52 N 皇后：返回解的数量。O(n!) 上界，剪枝后实际小得多。
    三组标记数组对应三个约束：列、主对角线(r-c)、副对角线(r+c)。"""
    cols = [False] * n
    diag1 = [False] * (2 * n)        # r - c + n
    diag2 = [False] * (2 * n)        # r + c
    count = 0
    def place(row: int) -> None:
        nonlocal count
        if row == n:
            count += 1
            return
        for col in range(n):
            d1, d2 = row - col + n, row + col
            if cols[col] or diag1[d1] or diag2[d2]:
                continue              # O(1) 判合法性：这是剪枝效率的关键
            cols[col] = diag1[d1] = diag2[d2] = True
            place(row + 1)
            cols[col] = diag1[d1] = diag2[d2] = False
    place(0)
    return count

assert solve_n_queens(4) == 2
assert solve_n_queens(8) == 92
```

剪枝的两类（经验做法归纳）：**合法性剪枝**（当前选择直接违反约束，如皇后冲突）与**有序性剪枝**（利用排序后的单调性提前止损，如 combine 的剩余数量检查、LC 40 组合总和 II 中"同层相同元素跳过"）。写回溯时对着决策树问：哪些分支明知无解还进去？每个"明知"都对应一个可写的剪枝条件。

## 4. 贪心：用交换论证证明"局部最优 = 全局最优"

**贪心**：每步取当前最优，永不回头。它比 DP 快得多，但成立需要证明。最常用的证明工具是**交换论证（exchange argument）**：假设存在最优解与贪心选择不同，证明"交换后不变差"，逐步把最优解变换成贪心解——贪心至少一样优。

**例 1：区间调度**（LC 435 无重叠区间/452 射气球）——按**结束时间**排序，能选就选：

```python
def erase_overlap_intervals(intervals: list[list[int]]) -> int:
    """LC 435 移除最少区间使无重叠。等价于"最多保留多少不重叠区间"。O(n log n)
    贪心：按结束时间升序，每次选结束最早的——给后面留最多空间。
    交换论证：任取最优解，其第一个区间若不是结束最早的，换成结束最早的
    只会腾出更多空间（与后续区间重叠的更少），解仍最优 → 归纳成立。"""
    if not intervals:
        return 0
    intervals.sort(key=lambda x: x[1])     # 按右端点排序
    kept = 1
    end = intervals[0][1]
    for lo, hi in intervals[1:]:
        if lo >= end:                      # 不重叠：保留
            kept += 1
            end = hi
    return len(intervals) - kept

assert erase_overlap_intervals([[1, 2], [2, 3], [3, 4], [1, 3]]) == 1
```

**为什么按结束时间而不是开始时间/长度**：按开始排，一个很早开始但巨长的区间霸占全场；按长度排，反例 `[1,10],[9,11],[10,20]`（最短者 9-11 同时挡住两个）。交换论证能证"结束最早"对，其余证不出来——**证明本身就是选型的依据**。

**例 2：跳跃游戏**（LC 55）——维护"能到达的最远位置"：

```python
def can_jump(nums: list[int]) -> bool:
    """LC 55。贪心：扫一遍维护 furthest。O(n)。
    交换论证：若位置 i 可达（i <= furthest），则 i+1..i+nums[i] 全部可达；
    贪心的 furthest 是所有可达位置贡献的并集上界，不小于任何策略。"""
    furthest = 0
    for i, step in enumerate(nums):
        if i > furthest:
            return False                   # 当前格已不可达
        furthest = max(furthest, i + step)
        if furthest >= len(nums) - 1:
            return True
    return True

assert can_jump([2, 3, 1, 1, 4]) and not can_jump([3, 2, 1, 0, 4])
```

**贪心 vs DP 的判断口诀**（经验做法）：能用交换论证证明"当前最优不损害未来" → 贪心；决策之间有相互牵制、必须比较多种"当前选择"的后果 → DP。面试拿不准时先讲贪心思路与证明，证明不出再退 DP——**展示的是"知道何时贪心不成立"**。

## 6. 白板沟通规范：把思考过程变成得分点

面试考的是协作沟通，不只是答案（经验做法，与大厂面试官公开分享的口径一致）：

1. **复述与澄清**（1–2 分钟）：用自己的话复述题目，主动问清：输入规模？有无重复/负数/为空？要求最优解还是任意解？——这些直接决定复杂度档位；
2. **先给暴力解**：说清 O(n²) 暴力并指出瓶颈（"瓶颈在对每个 i 重复找 target-x"），这一步展示完整性；
3. **提出优化并说依据**：'瓶颈是查找 → 哈希表 O(1) 查找 → 总 O(n)"——**每个优化都挂在 01 章的复杂度语言上**；
4. **说不变式再写代码**：双指针说"两端淘汰的安全性"，二分说区间定义，回溯说决策树结构。边写边讲；
5. **主动跑测试**：写完立刻用空输入、单元素、极值、典型例走一遍——面试官等着看你有没有这个习惯；
6. **复杂度表述模板**："时间 O(n log n)，来自排序；空间 O(n)，来自哈希表。"——**时间与空间分开说、都给出处**，这是 01 章要求的面试落地版。忌说"大概是 n 平方吧"这种无出处表述。

## 本篇小结

1. 回溯 = 决策树 DFS：路径/选择列表/结束条件三件套，三经典题差异全在"选择列表"定义；
2. 剪枝分两类：合法性（约束违反）与有序性（排序后单调止损）；先排序是去重与剪枝的共同前提；
3. 贪心的正确性用交换论证证明：区间调度按结束时间、跳跃游戏维护 furthest——证明本身就是选型依据；
4. 面试流程六步：复述澄清 → 暴力 → 优化依据 → 不变式 → 测试 → 双复杂度给出处；
5. 刷题路线按本系列章节节奏推进，间隔重复 + 限时口述是内化的关键。
