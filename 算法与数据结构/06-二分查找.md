# 06 - 二分查找

## 本篇目标

1. 掌握一套**不会写错**的二分模板，彻底解决"闭区间还是半开区间"的边界纠结；
2. 学会面试最高频的变体：**二分答案**（"最小化最大值"问题的万能钥匙）；
3. 会做旋转数组、浮点二分，并了解三分法在单峰函数上的用法；
4. 会用 `bisect` 库把二分变成日常工具而不是手写负担。

## 1. 为什么二分容易写错：三个决策点

二分查找的思想 30 秒讲完（有序、每次砍半、O(log n)，承接 01 篇对数直觉），但手写实现臭名昭著地容易错。原因：写之前有**三个决策点**必须先定，不定就必然纠结：

1. **区间定义**：`[lo, hi]` 左闭右闭，还是 `[lo, hi)` 左闭右开？——两种都对，但**循环不变式必须与之一致**；
2. **循环条件**：`while lo <= hi` 还是 `while lo < hi`？——由区间定义决定；
3. **边界移动**：`lo = mid + 1` 还是 `lo = mid`？——同样由区间定义决定。

死记"标准写法"没有用，记**不变式**：**"mid 之前（含/不含）的区间一定不包含答案"**。

## 2. 主模板：左闭右闭 + 查找精确值

```python
def binary_search(a: list[int], target: int) -> int:
    """标准二分：在有序数组 a 中找 target，返回下标，不存在返回 -1。
    区间约定：[lo, hi] 左闭右闭，含义是"答案（若存在）在 [lo, hi] 内"。"""
    lo, hi = 0, len(a) - 1
    while lo <= hi:                 # 区间非空才继续（闭区间：lo==hi 时还有一个元素）
        mid = lo + (hi - lo) // 2   # 防溢出写法（C++/Java 必须这样；Python 无溢出，但养成习惯）
        if a[mid] == target:
            return mid
        elif a[mid] < target:
            lo = mid + 1            # 答案若存在，必在 mid 右侧 → 闭区间收紧为 [mid+1, hi]
        else:
            hi = mid - 1            # 答案若存在，必在 mid 左侧 → [lo, mid-1]
    return -1

def test() -> None:
    a = [1, 3, 5, 7, 9]
    assert binary_search(a, 7) == 3
    assert binary_search(a, 4) == -1
    assert binary_search([], 1) == -1
    assert binary_search([5], 5) == 0
    assert binary_search([5], 4) == -1
test()
print("全部通过")
```

四个测试点不是装饰：空数组、单元素命中、单元素未命中、目标在边界外——**二分的 bug 全藏在边界**，写完立刻跑这四类。

## 3. 边界变体：找第一个 ≥ target（lower_bound）

实际工程与算法题中，"精确查找"反而少见，**"找第一个满足条件的位置"**（lower_bound）是主力：

```python
def lower_bound(a: list[int], target: int) -> int:
    """返回第一个 >= target 的下标（若都小于 target 返回 len(a)）。
    这是 C++ lower_bound 的语义。区间约定：[lo, hi) 左闭右开，
    不变式：[0, lo) 内全部 < target，[hi, len) 内全部 >= target。
    循环结束时 lo == hi == 第一个满足条件的位置。"""
    lo, hi = 0, len(a)
    while lo < hi:                  # 半开区间：lo==hi 即空，停
        mid = (lo + hi) // 2
        if a[mid] >= target:
            hi = mid                # mid 满足 → 答案可能是 mid，保留在区间内
        else:
            lo = mid + 1            # mid 不满足 → 答案必在右侧，mid 排除
    return lo

def upper_bound(a: list[int], target: int) -> int:
    """第一个 > target 的下标：把 >= 改成 > 即可。"""
    lo, hi = 0, len(a)
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] > target:
            hi = mid
        else:
            lo = mid + 1
    return lo

def test_bounds() -> None:
    a = [1, 2, 2, 2, 3]
    assert lower_bound(a, 2) == 1        # 第一个 2
    assert upper_bound(a, 2) == 4        # 最后一个 2 的下一格
    assert lower_bound(a, 0) == 0        # 全部满足
    assert lower_bound(a, 4) == 5        # 全部不满足 → len(a)
    assert upper_bound(a, 2) - lower_bound(a, 2) == 3   # 值为 2 的元素个数
test_bounds()
```

记住语义映射，90% 的二分题直接化归：**"第一个满足 f 的位置" → lower_bound 把比较换成 f(mid) 为真则 hi=mid**。值域上做二分（下节）用的正是这个泛化。

## 4. Python 标准库 bisect：日常首选

工程里别手写，`bisect` 就是上面的两个函数（出处：Python 标准库文档 `bisect` 模块，C 实现）：

```python
import bisect

a = [1, 2, 2, 2, 3]
assert bisect.bisect_left(a, 2) == 1     # == lower_bound
assert bisect.bisect_right(a, 2) == 4    # == upper_bound（insort 用它插尾部）
bisect.insort(a, 2)                      # 插入并保持有序（内部就是 bisect+insert）
print(a)

# 经典用法：统计某值出现次数 = right - left；找最接近的值：
def closest(a: list[int], x: int) -> int:
    i = bisect.bisect_left(a, x)
    if i == 0:
        return a[0]
    if i == len(a):
        return a[-1]
    return min(a[i - 1], a[i], key=lambda v: abs(v - x))

assert closest([1, 4, 9], 6) in (4, 9)   # 距离相同取先出现者（经验做法：先定义清楚）
```

> **陷阱**：`bisect` 只保证结果位置正确，前提是你自己保证列表有序。往"无序列表"里 bisect 不报错、只给垃圾答案——这是静默 bug 的重灾区。

## 5. 二分答案：把"求最优"化归为"求第一个满足"

面试最值钱的变体。**适用信号**：题目问"最小的最大值 / 最大的最小值 / 最少多少天 / 最多装多少"，且存在一个单调的判定函数 `check(x)`——"x 可行"则一切 ≥ x 可行（或反之）。于是答案 = 值域上第一个满足 check 的位置 = lower_bound（对可行性做二分）。

```python
def min_eating_speed(piles: list[int], h: int) -> int:
    """LC 875 爱吃香蕉的珂珂：h 小时内吃完所有香蕉的最小吃速。
    check(k)：速度 k 能否在 h 小时内吃完 —— k 越大越容易满足（单调）。
    答案 = [1, max(piles)] 上第一个满足 check 的 k。O(n log max(p))"""
    def check(k: int) -> bool:
        return sum((p + k - 1) // k for p in piles) <= h   # 向上取整除法

    lo, hi = 1, max(piles)
    while lo < hi:                    # 在值域 [lo, hi] 上找第一个满足者
        mid = (lo + hi) // 2
        if check(mid):
            hi = mid                  # mid 可行 → 更小的可能也可行，压缩上界
        else:
            lo = mid + 1              # mid 不可行 → 排除
    return lo

def split_array_largest_sum(nums: list[int], m: int) -> int:
    """LC 410 分割数组的最大值：把数组分成 m 段使"段和最大值"最小。
    check(cap)：以 cap 为每段上限，贪心装箱，看段数是否 <= m。
    "最大值越小越难分"单调 → 二分答案。O(n log sum)"""
    def check(cap: int) -> bool:
        parts, cur = 1, 0
        for x in nums:
            if cur + x > cap:         # 装不下就开新段（贪心：能塞就塞）
                parts += 1
                cur = x
                if parts > m:
                    return False
            else:
                cur += x
        return True

    lo, hi = max(nums), sum(nums)     # 下界：单元素最大值；上界：整段一段
    while lo < hi:
        mid = (lo + hi) // 2
        if check(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo

assert min_eating_speed([3, 6, 7, 11], 8) == 4
assert split_array_largest_sum([7, 2, 5, 10, 8], 2) == 18
```

二分答案的流程总结：① 找到单调判定函数 check；② 定值域上下界（宁可放大，别漏答案）；③ lower_bound 形状二分；④ 返回 lo。**"最小化最大值"几乎必是二分答案**（经验做法，与竞赛界共识一致）。

## 6. 旋转数组与山形数组

**LC 33 搜索旋转排序数组**：有序数组在某个点断开旋转（如 [4,5,6,7,0,1,2]）。关键观察：**任取 mid，左右两半必有一半是有序的**——判断 target 在不在有序的那半里，不在就去另一半。每步仍砍半，O(log n)：

```python
def search_rotated(nums: list[int], target: int) -> int:
    """LC 33。O(log n)。核心：mid 把数组分成一半有序、一半含断点。"""
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        if nums[lo] <= nums[mid]:            # 左半 [lo, mid] 有序
            if nums[lo] <= target < nums[mid]:
                hi = mid - 1                 # target 在有序左半
            else:
                lo = mid + 1
        else:                                # 右半 [mid, hi] 有序
            if nums[mid] < target <= nums[hi]:
                lo = mid + 1
            else:
                hi = mid - 1
    return -1

def find_min_rotated(nums: list[int]) -> int:
    """LC 153 旋转数组的最小值：找"断点"。与右端比较（不是左端！）：
    nums[mid] > nums[hi] → 最小值在右侧；否则最小值在 mid 及其左侧。"""
    lo, hi = 0, len(nums) - 1
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] > nums[hi]:
            lo = mid + 1
        else:
            hi = mid
    return nums[lo]

assert search_rotated([4, 5, 6, 7, 0, 1, 2], 0) == 4
assert find_min_rotated([4, 5, 6, 7, 0, 1, 2]) == 0
assert find_min_rotated([2, 1]) == 1
```

> **陷阱**：find_min 为什么和 `nums[hi]` 比而不是 `nums[lo]`？和 `nums[lo]` 比无法区分"数组整体有序（最小值在左）"与"最小值在右半"两种情形（除非额外特判 lo<hi 时完全有序）。**选对参照端点**是本题的全部技巧。

## 7. 浮点二分与三分法

浮点数没有"相邻"概念，循环条件改为精度控制。另外，若函数**单峰**（先增后减，如抛物线），不能用二分（不单调），要用**三分法**：

```python
def float_sqrt(x: float, eps: float = 1e-9) -> float:
    """浮点二分求 sqrt。O(log((hi-lo)/eps))。"""
    lo, hi = (0.0, x) if x >= 1 else (x, 1.0)   # 覆盖 x<1 时根大于 x 的情形
    for _ in range(100):                          # 固定次数更稳：每次区间折半
        mid = (lo + hi) / 2
        if mid * mid < x:
            lo = mid
        else:
            hi = mid
    return (lo + hi) / 2

def ternary_max(f, lo: float, hi: float, eps: float = 1e-9) -> float:
    """三分法求单峰函数 f 在 [lo, hi] 上的最大值点。
    取两点 m1 < m2：f(m1) < f(m2) → 峰在 (m1, hi]；否则在 [lo, m2)。"""
    for _ in range(200):
        m1 = lo + (hi - lo) / 3
        m2 = hi - (hi - lo) / 3
        if f(m1) < f(m2):
            lo = m1
        else:
            hi = m2
    return (lo + hi) / 2

import math
assert abs(float_sqrt(2) - math.sqrt(2)) < 1e-8
assert abs(ternary_max(lambda x: -(x - 3) ** 2 + 10, 0, 10) - 3) < 1e-6
print("浮点二分与三分法通过")
```

> **提示**：三分法每轮区间缩为 2/3，100 轮即 (2/3)^100，足够任何精度；比较时注意相等情形 `f(m1) == f(m2)` 时取哪半边都安全（峰在两测点之间，经验做法：统一用 `<` 判断避免浮点相等比较）。

## 本篇小结

1. 二分不难在思想、难在边界：先定区间约定，不变式（"排除区不含答案"）推着写，四类边界测试兜底；
2. 两个主模板：精确查找（闭区间 `lo<=hi`）与 lower_bound（半开区间 `lo<hi`，hi=mid）；
3. 二分答案 = 对"可行性"在值域上做 lower_bound，适用于一切"最小化最大值"单调判定题（LC 875、LC 410）；
4. 旋转数组靠"一半必有序"保持 log；最小值要与右端比较；
5. 浮点二分用精度/固定轮数控制；单峰函数用三分法。日常工程用 `bisect`。

## 练习

1. （LC 35 - 搜索插入位置）就是 lower_bound：用 bisect 一行解，再手写一遍半开区间模板。
2. （LC 34 - 在排序数组中查找元素的第一个和最后一个位置）bisect_left + bisect_right 各一次，注意"不存在"的返回约定。
3. （LC 1011 - 运送包裹的最低运力）二分答案：自设计 check 函数（贪心装箱），并说明值域上下界怎么定。
4. （LC 162 - 寻找峰值）这是三分法/二分的交界题：用"nums[mid] < nums[mid+1] 则峰在右侧"的二分解法（为什么这也算二分？因为上山方向单调指向峰）。
5. （LC 69 - x 的平方根）整数版与浮点版各写一遍，注意整数版别用浮点乘法判断（大数精度，经验做法：用 `mid*mid <= x` 的整数比较）。
