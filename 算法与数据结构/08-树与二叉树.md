## 1. 树：递归定义的结构

树是没有环的连通结构（正式定义与术语见任何教材；二叉树 = 每节点至多两子）。**天然递归**：一棵树 = 根 + 左子树 + 右子树，子树仍是树。所以树上的问题大多直接写递归三要素（07 篇）：

```python
from __future__ import annotations

class TreeNode:
    __slots__ = ("val", "left", "right")
    def __init__(self, val: int = 0, left: TreeNode | None = None,
                 right: TreeNode | None = None) -> None:
        self.val = val
        self.left = left
        self.right = right

def tree_depth(root: TreeNode | None) -> int:
    """LC 104 最大深度。递归三要素：基准 None→0；缩小；合并 max+1。O(n)"""
    if root is None:
        return 0
    return 1 + max(tree_depth(root.left), tree_depth(root.right))

def count_nodes(root: TreeNode | None) -> int:
    if root is None:
        return 0
    return 1 + count_nodes(root.left) + count_nodes(root.right)

#      3
#     / \
#    9  20
#      /  \
#     15   7
root = TreeNode(3, TreeNode(9), TreeNode(20, TreeNode(15), TreeNode(7)))
assert tree_depth(root) == 3 and count_nodes(root) == 5
```

## 2. 遍历：递归、迭代与层序

**先序（根左右）/ 中序（左根右）/ 后序（左右根）**三种 DFS 序，递归版只差一行位置。迭代版的意义：避免深树的调用栈溢出、或需要在中途暂停处理：

```python
def preorder(root: TreeNode | None) -> list[int]:
    """迭代先序：栈 + 右先左后压（让左边先出栈）。O(n) 时间 O(h) 空间。"""
    out, stack = [], [root] if root else []
    while stack:
        node = stack.pop()
        out.append(node.val)                  # 先访问根
        if node.right:
            stack.append(node.right)          # 右先压（后出）
        if node.left:
            stack.append(node.left)
    return out

def inorder(root: TreeNode | None) -> list[int]:
    """迭代中序：一路向左压栈，弹栈访问，转向右子树。O(n) O(h)。"""
    out, stack = [], []
    node = root
    while node or stack:
        while node:                           # 1. 左链全压栈
            stack.append(node)
            node = node.left
        node = stack.pop()                    # 2. 弹出最左
        out.append(node.val)                  # 3. 访问
        node = node.right                     # 4. 转向右子树
    return out

from collections import deque

def level_order(root: TreeNode | None) -> list[list[int]]:
    """层序遍历（BFS，10 篇图 BFS 的树特例）：队列按层处理。O(n)"""
    out = []
    if root is None:
        return out
    q: deque[TreeNode] = deque([root])
    while q:
        level = []
        for _ in range(len(q)):               # 固定本层节点数：一次取完一层
            node = q.popleft()
            level.append(node.val)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        out.append(level)
    return out

assert preorder(root) == [3, 9, 20, 15, 7]
assert inorder(root) == [9, 3, 15, 20, 7]
assert level_order(root) == [[3], [9, 20], [15, 7]]
```

三种序的适用信号（经验做法）：**位置相关用先序**（自顶向下传递信息，如路径前缀）；**BST 输出有序/验证用中序**；**子树信息汇总用后序**（自底向上，如最大深度、LCA、树形 DP）。迭代中序模板（左链压栈四步）值得背下来，BST 相关题全靠它。

## 3. BST：中序有序性

**BST 性质**：左子树所有节点 < 根 < 右子树所有节点（CLRS 12 章；本节用严格不等式假设无重复，重复值的处理是工程变体，经验做法：挂计数或约定同值靠右）。推论：

1. **中序遍历输出严格递增序列**——验证 BST 与 BST 上查找都是它派生的；
2. 查找/插入/删除 O(h)，h 是树高；平衡时 h=O(log n)，退化成链时 O(n)。

```python
def bst_search(root: TreeNode | None, target: int) -> TreeNode | None:
    """BST 查找：与当前节点比较，走一边。O(h)。"""
    while root and root.val != target:
        root = root.left if target < root.val else root.right
    return root

def bst_insert(root: TreeNode | None, val: int) -> TreeNode:
    """BST 插入：一路走到底，挂在空位上。O(h)。"""
    if root is None:
        return TreeNode(val)
    if val < root.val:
        root.left = bst_insert(root.left, val)
    else:
        root.right = bst_insert(root.right, val)
    return root

def is_valid_bst(root: TreeNode | None) -> bool:
    """LC 98 验证 BST：带上下界的递归。O(n)。
    经典错法：只比较节点与左右孩子——反例 [5,4,6,null,null,3,7]，
    3 在右子树里却 < 5。正确做法：每个节点继承一个 (min, max) 开区间。"""
    def check(node: TreeNode | None, lo: float, hi: float) -> bool:
        if node is None:
            return True
        if not (lo < node.val < hi):
            return False
        return check(node.left, lo, node.val) and check(node.right, node.val, hi)
    return check(root, float("-inf"), float("inf"))

def kth_smallest(root: TreeNode, k: int) -> int:
    """LC 230 BST 第 k 小：中序的第 k 个。迭代中序模板直接复用。O(h+k)"""
    stack: list[TreeNode] = []
    node: TreeNode | None = root
    while node or stack:
        while node:
            stack.append(node)
            node = node.left
        node = stack.pop()
        k -= 1
        if k == 0:
            return node.val
        node = node.right
    raise ValueError("k 超出节点数")

r: TreeNode | None = None
for v in [5, 3, 8, 1, 4, 7, 9]:
    r = bst_insert(r, v)
assert inorder(r) == [1, 3, 4, 5, 7, 8, 9]      # 中序有序
assert is_valid_bst(r) and not is_valid_bst(root)
assert kth_smallest(r, 3) == 4
```

**BST 删除**（LC 450）：三种情形——叶子直接删；单孩子用孩子顶替；**双孩子用"右子树最小节点"（后继）或"左子树最大"（前驱）的值替换后转去删那个节点**（CLRS 12.3 的 TRANSPLANT 思路，代码从略，练习 5 手写）。核心不变式：删除后中序序列保持不变。

## 4. LCA：递归返回信息的范式

```python
def lowest_common_ancestor(root: TreeNode, p: TreeNode, q: TreeNode) -> TreeNode:
    """LC 236 二叉树的最近公共祖先。O(n)。
    后序递归：左右分别找 p/q；两边都非空 → 当前节点就是 LCA；
    一边非空 → 非空侧的返回值向上传（可能 p/q 本身，也可能是更深的 LCA）。"""
    if root is None or root is p or root is q:
        return root                                 # 基准：找到目标或走空
    left = lowest_common_ancestor(root.left, p, q)
    right = lowest_common_ancestor(root.right, p, q)
    if left and right:
        return root                                 # p、q 分居两侧：我是 LCA
    return left or right                            # 只有一侧有：向上传递

def lca_bst(root: TreeNode, p: TreeNode, q: TreeNode) -> TreeNode:
    """LC 235 BST 的 LCA：利用有序性，O(h)。
    p、q 都 < 根 → 去左；都 > 根 → 去右；第一次分叉的节点就是答案。"""
    node = root
    while True:
        if p.val < node.val and q.val < node.val:
            node = node.left
        elif p.val > node.val and q.val > node.val:
            node = node.right
        else:
            return node
```

LC 236 的递归形态是**树形 DP 的最小样例**：函数返回"子树里有用的信息"（这里是有无目标/答案本身），父节点基于子树返回值做决策。13 篇的树形 DP（如二叉树中的最大路径和 LC 124）是同一范式的加料版：返回值 = "从这个节点往下走的最优"。

## 5. 序列化：前序 + 空标记

```python
def serialize(root: TreeNode | None) -> str:
    """LC 297 序列化：前序 + None 标记。任何二叉树都能唯一重建。"""
    if root is None:
        return "#"
    return f"{root.val},{serialize(root.left)},{serialize(root.right)}"

def deserialize(data: str) -> TreeNode | None:
    vals = iter(data.split(","))
    def build() -> TreeNode | None:
        v = next(vals)
        if v == "#":
            return None
        node = TreeNode(int(v))
        node.left = build()               # 递归顺序必须与序列化一致（前序）
        node.right = build()
        return node
    return build()

s = serialize(root)
assert serialize(deserialize(s)) == s    # 序列化-反序列化往返一致
print(s)                                  # 3,9,#,#,20,15,#,#,7,#,#
```

> **陷阱**：只用"前序 + 中序"这对遍历恢复整棵树（LC 105 正确做法）要求**值互不相同**且能容忍 O(n²) 建界；而"带 # 的前序"对任意树唯一且 O(n)。面试说序列化方案时，说清"为什么这组信息足以唯一确定树"是加分点。

## 6. 平衡概念：AVL 旋转的直觉与红黑树的性质

BST 退化成链（顺序插入 1,2,3,...）时 O(h) 全变 O(n)。**平衡树**的目标：让 h 恒定 O(log n)。理解思路即可，手写不现实（面试也几乎不要求手写）：

**AVL 树**（1962，Adelson-Velsky & Landis）：每个节点维护平衡因子（左右子树高差 ≤1）。插入破坏平衡时用**旋转**恢复——只需理解两种原子操作：

```
右旋（LL 情形，左子树太高）:        左旋（RR 情形，右子树太高）:
      z                y                 z                y
     / \              / \               / \              / \
    y   D    →       A   z             A   y    →       z   D
   / \                  / \               / \          / \
  A   B                B   D             B   D        A   B
（B 过继给 z 当左孩子；y 上位）                  （C 过继给 z 当右孩子）
```

LR/RL 情形 = 先对子节点做一次反向旋再套上式。**旋转的本质：局部换根，保持中序序列不变**——所有平衡树操作的共同底牌。

**红黑树**（CLRS 13 章）：不追求高差 ≤1（AVL），而用 5 条性质保证树高 ≤ 2·log₂(n+1)：

1. 每节点红或黑；2. 根黑；3. 叶（NIL）黑；4. 红节点的孩子必黑（无红红相连）；5. 任一节点到其后代叶的路径含相同数目黑节点（黑高相等）。

工程视角只需要知道：红黑树插入/删除的调整比 AVL 便宜（旋转次数 ≤ 3），而 AVL 查询略深但更矮；**C++ `std::map`、Linux 内核 CFS 调度器、Java TreeMap 都是红黑树**。Python 标准库没有平衡树——需要有序字典/有序集合时用 `bisect`（有序数组）或三方库 `sortedcontainers`（经验做法：Python 生态事实标准）。

## 本篇小结

1. 树的问题默认递归三要素；三种遍历序对应三种信息流向：先序自顶向下、后序自底向上、中序对 BST 有序；
2. BST 一切操作的代价是 O(h)：平衡时 log n、退化时 n——"怕退化"正是平衡树存在的理由；
3. 验证 BST 要用继承的 (min, max) 区间，不能只看孩子；BST 第 k 小 = 迭代中序走 k 步；
4. LCA 的后序递归是树形 DP 范式的起点：返回子树的"有用信息"，父层决策；
5. 平衡的直觉 = 旋转保持中序不变；红黑树五性质背下来即可，工程上知道谁在用红黑树比会手写更重要。
