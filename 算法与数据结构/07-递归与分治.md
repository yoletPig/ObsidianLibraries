## 1. 递归三要素：先把"信任"建立起来

写递归最忌讳"脑内展开调用树追第三层"——人脑栈会溢出。正确姿势是**信任归纳**：只看一层。三要素检查清单（经验做法，与 MIT 6.006 教学口径一致）：

1. **基准情形（base case）**：最小的输入直接返回，不递归。缺它=无限递归（Python 里体现为 `RecursionError`）；
2. **递归步骤**：调用自己解决**规模严格更小**的同类问题。不缩小=死递归；
3. **合并（combine）**：相信子问题答案正确，用它们拼出本层答案。这一步是逻辑全部所在。

```python
def factorial(n: int) -> int:
    if n <= 1:                      # 要素 1：基准情形
        return 1
    return n * factorial(n - 1)     # 要素 2：规模 -1；要素 3：本层 = n × 子层结果

def tree_depth(node) -> int:
    """二叉树深度（LC 104）：同样三要素。"""
    if node is None:                # None 就是最小输入
        return 0
    return 1 + max(tree_depth(node.left), tree_depth(node.right))
```

**正确性论证**就是数学归纳法：基准情形成立（n=1）；假设 n−1 时正确，推出 n 时正确（要素 3 做的事）。所以只要三要素都成立，递归必然正确——**不用展开树，一层内完成证明**。

## 2. 调用栈：递归的空间代价与 Python 的限制

每次函数调用在**调用栈（call stack）**上压一个栈帧（局部变量、返回地址）。递归深度 d 的算法栈空间 O(d)——这就是"递归版反转链表 O(n) 空间"的来源（02 篇练习埋的伏笔）。

Python 的调用栈深度默认上限约 1000（`sys.getrecursionlimit()`，CPython 文档），超了抛 `RecursionError`。工程对策按优先级：

1. **改成迭代**（显式栈/循环）——首选；
2. `sys.setrecursionlimit()` 调大——只适合自知的浅层场景，盲目调大有段错误风险（C 栈溢出，经验做法）；
3. 分治算法尽量平衡（深度 log n），天然安全。

**尾递归**（递归调用是函数最后一个动作）理论上可被编译器优化成循环、栈空间 O(1)。但**CPython 不做尾递归优化**（Guido 的明确决定，历史上多次讨论不采纳），所以 Python 里写尾递归没有性能意义——必须写成迭代：

```python
def factorial_tail(n: int, acc: int = 1) -> int:
    """尾递归版：累积值通过参数传递。概念示例——CPython 不会优化它！"""
    if n <= 1:
        return acc
    return factorial_tail(n - 1, n * acc)

def factorial_iter(n: int) -> int:
    """真正的工程写法：尾递归手动转循环（ accumulator 模式）。"""
    acc = 1
    for k in range(2, n + 1):
        acc *= k
    return acc

import sys
print(sys.getrecursionlimit())     # 通常 1000
assert factorial_iter(10) == factorial(10) == factorial_tail(10)
```

> **提示**：任何尾递归都能机械地转成循环：把参数改成循环变量。面试被问"递归会爆栈吗"，标准答案框架是：深度多少 → 深度受谁控制 → 改迭代还是改平衡分治。

## 3. 分治：归并排序

分治（divide and conquer）三步：**分（divide）→ 治（conquer）→ 合（combine）**。归并排序是结构最纯正的例子：

```python
def merge_sort(a: list[int]) -> list[int]:
    """归并排序。时间 O(n log n) 恒定（最好=最坏），空间 O(n)。
    三步：分（取中点）→ 治（递归排两半）→ 合（线性归并）。"""
    if len(a) <= 1:                       # 基准：0/1 个元素天然有序
        return a
    mid = len(a) // 2
    left = merge_sort(a[:mid])            # 治：信任递归
    right = merge_sort(a[mid:])
    return _merge(left, right)            # 合：两个有序表线性归并

def _merge(x: list[int], y: list[int]) -> list[int]:
    """合并两个有序表：O(len(x)+len(y))。这就是 02 篇练习的合并链表数组版。"""
    out = []
    i = j = 0
    while i < len(x) and j < len(y):
        if x[i] <= y[j]:                  # <= 保证稳定性（相等取左表）
            out.append(x[i]); i += 1
        else:
            out.append(y[j]); j += 1
    out.extend(x[i:])                     # 一边空了，另一边整段接上
    out.extend(y[j:])
    return out

import random
arr = [random.randint(0, 99) for _ in range(20)]
assert merge_sort(arr) == sorted(arr)
```

**复杂度推导**（递归式）：T(n) = 2T(n/2) + O(n)。每层合并总代价 O(n)，共 log n 层 → O(n log n)。这就是主定理的第一个实战案例（第 6 节）。归并排序的两个工程价值：**稳定**（相等元素保持原序，多关键字排序的基石）与**最坏 O(n log n) 有保证**（对比快排）；代价是 O(n) 辅助空间。链表版归并用快慢指针找中点可做到 O(1) 额外空间（02 篇第 5 节），LC 148 排序链表正是它。

## 4. 快速排序与 _partition

快排的分治方向与归并相反：**先在原地做"划分"（partition）再递归**，合并是免费的（原地）。

```python
def _partition(a: list[int], lo: int, hi: int) -> int:
    """Lomuto 划分：取 a[hi] 为基准 pivot，让左边全 <= pivot、右边全 > pivot，
    返回 pivot 最终落点。O(hi-lo)。
    不变式：[lo, i] 全 <= pivot；(i, j) 全 > pivot。"""
    pivot = a[hi]
    i = lo - 1
    for j in range(lo, hi):
        if a[j] <= pivot:
            i += 1
            a[i], a[j] = a[j], a[i]       # 把小的换到左区
    a[i + 1], a[hi] = a[hi], a[i + 1]     # pivot 归位到分界
    return i + 1

def quick_sort(a: list[int], lo: int = 0, hi: int | None = None) -> None:
    """原地快排。平均 O(n log n)，最坏 O(n²)；空间 O(log n) 栈（平均）。"""
    if hi is None:
        hi = len(a) - 1
    if lo < hi:
        p = _partition(a, lo, hi)
        quick_sort(a, lo, p - 1)
        quick_sort(a, p + 1, hi)

arr = [random.randint(0, 99) for _ in range(20)]
quick_sort(arr)
assert arr == sorted(arr)

def quick_sort_randomized(a: list[int], lo: int = 0, hi: int | None = None) -> None:
    """随机化快排：随机选基准与 a[hi] 交换，再走 Lomuto。
    期望 O(n log n)：让最坏输入与划分行为统计独立（CLRS 7.3 随机化分析）。"""
    if hi is None:
        hi = len(a) - 1
    if lo < hi:
        k = random.randint(lo, hi)
        a[k], a[hi] = a[hi], a[k]
        p = _partition(a, lo, hi)
        quick_sort_randomized(a, lo, p - 1)
        quick_sort_randomized(a, p + 1, hi)
```

`_partition` 的不变式（面试必画图讲）：扫描指针 `j` 把数组切成三段——`[lo, i]` ≤ pivot、`(i, j)` > pivot、`[j, hi]` 未看；`a[j] <= pivot` 就扩张左段。最后 pivot 与左段右端交换归位。

> **陷阱一（工程）**：已排序数组是 Lomuto+固定基准的最坏输入（每层只切出一个元素，O(n²)）——真实数据大量"接近有序"，所以工业实现（如 C++ std::sort 的 introsort 混合策略、Python Timsort）都有对抗手段。Python 内置 `sorted()` 是 Timsort：归并思想的混合变体，稳定、对部分有序数据接近 O(n)（出处：CPython listsort.txt，Tim Peters）。
>
> **陷阱二（细节）**：快排不稳定（划分交换会打乱相等元素相对序）；对稳定性有要求就换归并。

## 5. 快速选择：TopK 的期望 O(n)

**问题**：n 个数里找第 k 大（LC 215）。排序 O(n log n)、堆 O(n log k)（09 篇）；更快的是**快速选择（quickselect）**：partition 之后答案在哪半边已知，**只递归一边**：

```python
import random

def quickselect(a: list[int], k: int) -> int:
    """返回第 k 大（k 从 1 计）。期望 O(n)：T(n)=T(n/2)+O(n) → n + n/2 + ... < 2n。
    最坏 O(n²)（划分持续偏斜），随机化后概率意义下不会发生。"""
    lo, hi = 0, len(a) - 1
    target = len(a) - k                   # 第 k 大 = 升序下标 len-k
    while lo < hi:
        p = _partition(a, lo, hi)         # 复用 04 节的 Lomuto 划分（先随机化更稳）
        if p == target:
            return a[p]
        elif p < target:
            lo = p + 1                    # 只走一边——这就是比快排省的原因
        else:
            hi = p - 1
    return a[lo]

data = [3, 2, 1, 5, 6, 4]
assert quickselect(data[:], 2) == 5      # 第 2 大
```

递归式 T(n) = T(n/2) + O(n) 展开是 n(1 + 1/2 + 1/4 + ...) < 2n——**几何级数再次出场**（01 篇、03 篇扩容，这是第三次，值得形成条件反射：砍半递归 + 线性单层 = 线性总量）。

## 6. 主定理：分治复杂度的速查表

分治递归式 T(n) = a·T(n/b) + f(n)（a 个子问题、每个规模 n/b、分解合并代价 f）。**主定理（Master Theorem，出处：CLRS 4.6；也可表述为 Akra-Bazzi 特例）**：比较 f(n) 与 n^(log_b a)——即"叶子代价"与"根上代价"谁占主导：

| f(n) 与 n^(log_b a) 的关系 | 结论 | 实例 |
| --- | --- | --- |
| f 更小（多项式意义上） | T(n) = Θ(n^(log_b a)) | T(n)=2T(n/2)+O(1)：二叉树遍历 Θ(n) |
| 同阶（差个 log^k） | T(n) = Θ(n^(log_b a) · log n) | T(n)=2T(n/2)+O(n)：归并 Θ(n log n) |
| f 更大且可正则 | T(n) = Θ(f(n)) | T(n)=2T(n/2)+O(n log n)：Θ(n log²n) |

用法（经验做法）：算出 n^(log_b a)，与 f 比大小——**谁大听谁的，同阶乘个 log**。三个算法对号入座：归并 a=2,b=2,f=n → n^(log₂2)=n 同阶 → n log n；二分查找 a=1,b=2,f=O(1) → n⁰=1 同阶 → log n；快速选择 a=1,b=2,f=O(n) → f 大 → O(n)。

> **提示**：主定理是"速查"不是"推理工具"。面试讲复杂度时，先口头展开"每层代价 × 层数"（几何级数或算术级数），再报主定理验证——比直接背结论可信。

## 本篇小结

1. 递归 = 数学归纳法的执行：三要素（基准、缩小、合并）齐全即正确，一层内思考不展开树；
2. 递归空间 = 调用栈深度 O(d)；CPython 无尾递归优化，尾递归手动转循环；
3. 归并：稳定、恒定 O(n log n)、O(n) 空间；快排：原地、平均 O(n log n)、最坏 O(n²) 靠随机化对抗；Timsort 是两者的工程混合体；
4. `_partition` 不变式是快排与快速选择共同的核心；只递归一边，快速选择把 TopK 做到期望 O(n)；
5. 主定理口诀：n^(log_b a) 与 f 谁大听谁的，同阶乘 log。
