## 本篇目标

1. 手写二叉堆（上浮/下沉），理解"数组存储的完全二叉树"为什么是堆的完美底座；
2. 对比 TopK 的三种解法（排序/快选/堆）并建立选型判断；
3. 掌握堆的两类系统级应用：**多路归并**与**调度（优先队列）**；
4. 会用 `heapq`（含小顶堆取大、懒删除等惯用法）。

## 1. 优先队列：比"先进先出"更聪明的顺序

队列按到达顺序出队，但真实系统常按**重要性**出队：OS 调度取最高优先级进程、图算法（11 篇 Dijkstra）取当前最短距离节点、推理引擎取最紧急请求（衔接模型性能优化 Stage 7 的调度组件）。**优先队列（priority queue）**：支持 `push`（插入）与 `pop`（取出最值）的抽象数据类型，两者都 O(log n)、peek 最值 O(1)。

堆（heap）是优先队列最常用的实现。备选方案对比：

| 实现 | push | pop | 备注 |
| --- | --- | --- | --- |
| 无序数组 | O(1) | O(n) | pop 要扫全表 |
| 有序数组 | O(n)（找位插入） | O(1) | push 昂贵 |
| **二叉堆** | O(log n) | O(log n) | 标准答案 |
| 平衡树 | O(log n) | O(log n) | 功能多但常数大（08 篇） |

## 2. 二叉堆：数组里的完全二叉树

**二叉堆 = 完全二叉树 + 堆序性质**（父 ≤ 两个孩子，小顶堆；CLRS 第 6 章）。用数组存完全二叉树毫无浪费，且下标关系是纯算术：

```
下标 i（0 起）：parent = (i-1)//2，left = 2i+1，right = 2i+2
        1              数组: [1, 3, 2, 6, 4, 5]
      /   \
     3     2           每层至少半满 → 树高 log n →
    / \   /            上浮/下沉最多 log n 步
   6   4 5
```

两个核心操作，方向相反：

- **上浮（sift-up）**：新元素放在末尾，比父小就交换上移——服务于 push；
- **下沉（sift-down）**：末尾元素换到根，与较小孩子交换下移——服务于 pop。

```python
class MinHeap:
    """手写小顶堆：数组 + 上浮/下沉。push/pop 均 O(log n)。"""

    def __init__(self) -> None:
        self._a: list[int] = []

    def __len__(self) -> int:
        return len(self._a)

    def push(self, x: int) -> None:
        a = self._a
        a.append(x)                       # 放到末尾
        i = len(a) - 1
        while i > 0:                      # 上浮：比父小就和父换
            p = (i - 1) // 2
            if a[i] < a[p]:
                a[i], a[p] = a[p], a[i]
                i = p
            else:
                break                     # 堆序恢复，提前停

    def pop(self) -> int:
        a = self._a
        if not a:
            raise IndexError("pop from empty heap")
        top = a[0]
        last = a.pop()                    # 拿走末尾元素
        if a:                             # 末尾放到根，开始下沉
            a[0] = last
            i, n = 0, len(a)
            while True:
                l, r = 2 * i + 1, 2 * i + 2
                smallest = i
                if l < n and a[l] < a[smallest]:
                    smallest = l
                if r < n and a[r] < a[smallest]:
                    smallest = r
                if smallest == i:         # 比两个孩子都小：稳定
                    break
                a[i], a[smallest] = a[smallest], a[i]
                i = smallest
        return top

h = MinHeap()
for x in [5, 3, 8, 1, 9, 2]:
    h.push(x)
out = [h.pop() for _ in range(len(h))]
assert out == [1, 2, 3, 5, 8, 9]          # 每次弹最小：天然是堆排序
```

> **陷阱**：下沉时必须**与较小的孩子**交换——跟大孩子换会把更小的孩子压在父节点下面，堆序立刻破坏。这是手写堆第一高频 bug。

**建堆 O(n)**：对 `n//2-1 .. 0` 逐个下沉，一次建好整个堆。为什么不是 O(n log n)？下沉代价与节点高度成正比，高 h 的节点有约 n/2^(h+1) 个，求和 Σ n/2^(h+1)·O(h) = O(n)（CLRS 6.3 的精确分析：几何级数第四次出场）。`heapq.heapify` 就是它：

```python
import heapq
data = [9, 4, 7, 1, 3, 6]
heapq.heapify(data)          # 原地建堆 O(n)
assert data[0] == 1          # 堆顶即最小
print(heapq.heappop(data), data[0])   # 1 3
```

## 3. TopK 三种解法对比

**问题**（LC 215/347）：n 个元素里取最大/最小的 k 个（或出现频率前 k 高）。

```python
import heapq
from collections import Counter

def topk_sort(nums: list[int], k: int) -> list[int]:
    """解法一：全排序取前 k。O(n log n)。最直接，k≈n 时最优。"""
    return sorted(nums, reverse=True)[:k]

def topk_quickselect(nums: list[int], k: int) -> list[int]:
    """解法二：快速选择（07 篇）。期望 O(n + k log k)：
    先 O(n) 把第 k 大归位，左边 k 个再排一下。k 小、不要求实时时性价比之王。"""
    import random
    def qsel(a: list[int], k: int) -> None:
        lo, hi = 0, len(a) - 1
        t = len(a) - k                      # 第 k 大的下标
        while lo < hi:
            p_idx = random.randint(lo, hi)
            a[p_idx], a[hi] = a[hi], a[p_idx]
            pivot, i = a[hi], lo - 1
            for j in range(lo, hi):
                if a[j] <= pivot:
                    i += 1
                    a[i], a[j] = a[j], a[i]
            a[i + 1], a[hi] = a[hi], a[i + 1]
            if i + 1 == t:
                return
            elif i + 1 < t:
                lo = i + 2
            else:
                hi = i
    a = nums[:]
    qsel(a, k)
    return sorted(a[len(a) - k:], reverse=True)

def topk_heap(nums: list[int], k: int) -> list[int]:
    """解法三：小顶堆维护"当前最大的 k 个"。O(n log k)。
    只对堆内元素付出 log k：n 大 k 小（TopK 的典型形态）时最优，
    且支持数据流——来一个处理一个，不必攒全量。"""
    heap: list[int] = []                    # 小顶堆：堆顶是 k 个里的最小者
    for x in nums:
        if len(heap) < k:
            heapq.heappush(heap, x)
        elif x > heap[0]:
            heapq.heapreplace(heap, x)      # 弹最小进新元素：一次下沉，比 push+pop 快
    return sorted(heap, reverse=True)

nums = [5, 2, 9, 1, 7, 3, 8]
assert topk_sort(nums, 3) == topk_heap(nums, 3) == [9, 8, 7]
assert topk_quickselect(nums, 3) == [9, 8, 7]

def top_k_frequent(words: list[str], k: int) -> list[str]:
    """LC 347/692 前k个高频词：计数 + 堆。（词, -次数, 词本身）构造可比较元组"""
    cnt = Counter(words)
    # 频次大者优先（取负），同频按字典序小者优先
    return [w for _, _, w in heapq.nsmallest(k, ((-c, w, w) for w, c in cnt.items()))]

assert top_k_frequent(["i", "love", "you", "i", "love", "code"], 2) == ["i", "love"]
```

选型结论（经验做法，与竞赛/工业界共识一致）：

| 场景 | 选谁 |
| --- | --- |
| k ≈ n | 排序 |
| 一次性、k 小、数据在内存 | 快速选择 |
| **n 很大/数据流/只见过一遍** | **堆 O(n log k)** |
| 面试口述"数据流 TopK" | 必答堆 + 提"海量数据用近似算法（如 Count-Min Sketch），经验做法" |

## 4. 多路归并：k 个有序序列合成一个

**问题**：k 条各长 n 的有序链合成一条。两两归并要 O(kn·log k) 次合并轮次（总代价同阶但常数大）；**堆一次搞定 O(kn log k)**，且每步只维护 k 个"当前候选"：

```python
import heapq

def merge_k_sorted(lists: list[list[int]]) -> list[int]:
    """LC 23 合并K个升序链表（数组版）。O(N log k)，N 为总元素数。
    堆里只放 k 个元素——每条链的"当前指针"所指元素。"""
    heap: list[tuple[int, int, int]] = []   # (值, 链号, 链内下标)
    for li, lst in enumerate(lists):
        if lst:
            heap.append((lst[0], li, 0))
    heapq.heapify(heap)                     # O(k) 建堆
    out: list[int] = []
    while heap:
        val, li, idx = heapq.heappop(heap)  # 全局最小必然在 k 个候选中
        out.append(val)
        nxt = idx + 1
        if nxt < len(lists[li]):
            heapq.heappush(heap, (lists[li][nxt], li, nxt))
    return out

assert merge_k_sorted([[1, 4, 5], [1, 3, 4], [2, 6]]) == [1, 1, 2, 3, 4, 4, 5, 6]
```

为什么对：**k 条链的当前头部中必含全局最小**（每条链内部有序），弹出后只补充它的后继。这个"维护每路当前候选"的模式还直接服务于：LC 378 有序矩阵第 k 小、LC 632 最小区间（k 个列表的滑动覆盖）。链表版（LC 23 原题）思路全同，只是"下标+1"换成"node.next"。

## 5. 堆与调度：从 OS 到推理引擎

优先队列是调度系统的核心部件。用一道高频题（LC 621 任务调度器）与一个简化调度器演示：

```python
import heapq
from collections import Counter, deque

def least_interval(tasks: list[str], n: int) -> int:
    """LC 621 任务调度器：同种任务间隔至少 n。贪心 + 优先队列。
    每个执行槽取"已冷却任务中剩余次数最多"的一个；冷却队列管到期时刻。"""
    counts = Counter(tasks)
    heap = [-c for c in counts.values()]    # 取负变"最大堆"（heapq 只有最小堆）
    heapq.heapify(heap)
    time = 0
    cooling: deque[tuple[int, int]] = deque()   # (最早可再次执行的槽时刻, 剩余次数)
    while heap or cooling:
        # 下一执行槽之前已到期的任务先归队
        while cooling and cooling[0][0] <= time + 1:
            heapq.heappush(heap, cooling.popleft()[1])
        if not heap:                        # 全部在冷却：空转到最近可用槽
            time = cooling[0][0] - 1
            continue
        time += 1                           # 执行一个任务
        c = heapq.heappop(heap) + 1         # 负计数 +1 = 剩余次数减 1
        if c < 0:                           # 还有剩余：最早 time+n+1 槽可再执行
            cooling.append((time + n + 1, c))
    return time

assert least_interval(["A", "A", "A", "B", "B", "B"], 2) == 8
assert least_interval(["A", "A", "A", "A", "A", "A", "B", "C", "D", "E", "F", "G"], 2) == 16

def simple_scheduler(jobs: list[tuple[int, str]]) -> list[str]:
    """按优先级调度的最小骨架：数字越小越优先。
    真实系统（如推理引擎的请求调度）在此骨架上加：动态优先级、抢占、
    截止时间（用 (deadline, seq) 复合键）——骨架不变。经验做法。"""
    heap: list[tuple[int, int, str]] = []
    for i, (prio, name) in enumerate(jobs):
        heapq.heappush(heap, (prio, i, name))   # 序号 i 破平局：稳定且免比较 str
    return [heapq.heappop(heap)[2] for _ in range(len(heap))]

assert simple_scheduler([(3, "load"), (1, "infer"), (2, "encode")]) == [
    "infer", "encode", "load"]
```

> **提示**：heapq 只有最小堆。三个惯用法：① 存负数实现最大堆（LC 621）；② `(key, seq, item)` 复合键破平局且避免比较不可比对象（如 dict）；③ `heapreplace` 代替"pop 后 push"（一次 sift 而非两次）。**懒删除**：堆里不支持的"删任意元素"就打标（如记录失效版本号），弹出时跳过——11 篇 Dijkstra 的松弛更新用的正是它。

## 本篇小结

1. 优先队列是"按重要性出队"，二叉堆是其标准实现：数组存完全二叉树 + 上浮/下沉，push/pop O(log n)；
2. 下沉要跟较小孩子换；heapify 建堆 O(n)（几何级数分析）；
3. TopK 选型：k≈n 排序、一次性快选、数据流用堆 O(n log k)；高频词 = 计数 + 堆；
4. 多路归并：堆维护 k 路当前候选，O(N log k)；LC 23/378/632 同一模式；
5. 调度系统 = 优先队列 + 复合键（优先级, 序号）；heapq 三惯用法：负数最大堆、复合键、heapreplace；懒删除是堆的通用补丁。
