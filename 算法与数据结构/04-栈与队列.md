# 04 - 栈与队列

## 本篇目标

1. 手写栈与队列，理解"访问受限的线性表"为什么反而更强大（限制暴露意图）；
2. 掌握本章最有价值的两个结构：**单调栈**（每日温度/柱状图最大矩形）与**单调队列**（滑动窗口最大值）；
3. 会用栈做括号匹配与表达式求值，理解"最近匹配"是栈的本质场景。

## 1. 栈与队列：受限的线性表

栈（stack）：**后进先出 LIFO**，只能在栈顶操作。队列（queue）：**先进先出 FIFO**，队尾进、队头出。它们都是对线性表加限制：限制换来两样东西——**语义清晰**（代码读者立刻知道访问模式）与**某些操作可达 O(1)**（任何位置都要支持的结构做不到这么极致的简单）。

```python
class Stack:
    """用 Python list 实现栈：append 是入栈，pop 是出栈，都在尾部 O(1) 均摊。"""
    def __init__(self) -> None:
        self._items: list[int] = []

    def push(self, x: int) -> None:
        self._items.append(x)          # O(1) 均摊（01 篇倍增分析）

    def pop(self) -> int:
        if not self._items:
            raise IndexError("pop from empty stack")
        return self._items.pop()       # O(1)

    def peek(self) -> int:
        return self._items[-1]         # O(1)

    def is_empty(self) -> bool:
        return not self._items

    def __len__(self) -> int:
        return len(self._items)

from collections import deque

class Queue:
    """用 deque 实现队列。不能用 list：list.pop(0) 要整体前移，O(n)。"""
    def __init__(self) -> None:
        self._items = deque()

    def enqueue(self, x: int) -> None:
        self._items.append(x)          # 队尾进 O(1)

    def dequeue(self) -> int:
        if not self._items:
            raise IndexError("dequeue from empty queue")
        return self._items.popleft()   # 队头出 O(1)（deque 是分块双向链表）

    def is_empty(self) -> bool:
        return not self._items
```

> **陷阱**：Python 里"用 list 当队列"（`pop(0)`）是新手高频性能 bug——每次出队 O(n)，n 大时整体复杂度悄悄变 O(n²)。标准库 `queue.Queue` 用于多线程场景（带锁），单线程算法题用 `deque`。

## 2. 括号匹配：栈的"最近匹配"直觉

栈的本质场景是**最近匹配**：最后一个进去的未闭合项，最先被闭合。括号匹配是它的最小样例（LC 20）：

```python
def is_valid(s: str) -> bool:
    """LC 20 有效的括号。O(n) 时间，O(n) 空间（最坏全左括号）。"""
    pairs = {')': '(', ']': '[', '}': '{'}
    stack: list[str] = []
    for ch in s:
        if ch in "([{":
            stack.append(ch)               # 左括号：压栈等待闭合
        elif ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False               # 栈空（没有可配的）或配错类型
        # 其他字符忽略
    return not stack                       # 有剩余左括号也算无效

assert is_valid("([{}])") and not is_valid("([)]") and not is_valid("((")
```

运行栈、编辑器的撤销栈、深度优先搜索（10 篇）、函数调用（07 篇调用栈）全是同一思想的不同外衣：**最近的上下文最先被恢复**。

## 3. 表达式求值

栈的第二个经典应用。中缀表达式（人写的 `1+2*3`）求值的核心难点是**优先级**：`*` 抢在 `+` 前面算。两步法是标准解法：中缀 → 后缀（逆波兰，RPN），再对后缀求值（LC 227/150）。

```python
def eval_rpn(tokens: list[str]) -> int:
    """LC 150 逆波兰表达式求值。后缀式无需优先级：遇到运算符，弹两个数算完压回。"""
    stack: list[int] = []
    ops = {
        '+': lambda a, b: a + b,
        '-': lambda a, b: a - b,
        '*': lambda a, b: a * b,
        '/': lambda a, b: int(a / b),      # LC 150 要求向零截断，Python 的 // 是向负无穷
    }
    for t in tokens:
        if t in ops:
            b = stack.pop()                # 注意顺序：先弹的是右操作数
            a = stack.pop()
            stack.append(ops[t](a, b))
        else:
            stack.append(int(t))
    return stack.pop()

assert eval_rpn(["2", "1", "+", "3", "*"]) == 9          # (2+1)*3
assert eval_rpn(["10", "6", "9", "3", "+", "-11", "*", "/", "*", "17", "+", "5", "+"]) == 22

def infix_to_rpn(tokens: list[str]) -> list[str]:
    """调度场算法（Shunting Yard, Dijkstra 1961）：中缀转后缀。"""
    prec = {'+': 1, '-': 1, '*': 2, '/': 2}
    output: list[str] = []
    ops: list[str] = []
    for t in tokens:
        if t not in prec and t != '(' and t != ')':
            output.append(t)               # 操作数直接进输出
        elif t in prec:
            # 栈顶优先级 >= 当前：先弹出来（保证高优先级先算、同级从左到右）
            while ops and ops[-1] != '(' and prec[ops[-1]] >= prec[t]:
                output.append(ops.pop())
            ops.append(t)
        elif t == '(':
            ops.append(t)
        else:                              # ')': 弹到左括号为止
            while ops and ops[-1] != '(':
                output.append(ops.pop())
            ops.pop()                      # 丢掉 '('
    while ops:
        output.append(ops.pop())
    return output

assert eval_rpn(infix_to_rpn("2 + 1 * 3".split())) == 5
```

> **提示**：面试里若只要求"一个栈直接算中缀"，做法是运算数栈 + 运算符栈双栈同时操作，本质就是把调度场算法揉进一次遍历。先讲清楚两步法再提合并，沟通上更稳（14 篇的白板沟通）。

## 4. 单调栈：下一个更大元素

**问题**（LC 739 每日温度）：每天有温度，问"还要等几天才有更高温"。暴力 O(n²)；单调栈做到 O(n)。

**直觉**：栈里保存"还没找到答案的日子"，且温度从栈底到栈顶**严格递减**。新的一天温度更高时，它恰好是栈顶那些日子等了许久的答案——一次结算一串。

```python
def daily_temperatures(T: list[int]) -> list[int]:
    """LC 739 每日温度。每个下标至多入栈、出栈各一次，O(n) 均摊。"""
    n = len(T)
    ans = [0] * n
    stack: list[int] = []                  # 存下标，对应温度栈内递减
    for i in range(n):
        while stack and T[i] > T[stack[-1]]:   # 今天比栈顶热：栈顶的答案就是 i
            j = stack.pop()
            ans[j] = i - j                # 间隔天数
        stack.append(i)                   # 自己也进栈等答案
    return ans                            # 栈里剩下的：右边没有更高温，保持 0

assert daily_temperatures([73, 74, 75, 71, 69, 72, 76, 73]) == [1, 1, 4, 2, 1, 1, 0, 0]
```

**为什么 O(n)**：不是"两层循环 = O(n²)"——内层 while 每弹一个元素就永不回来，总弹出次数 ≤ 总入栈次数 n。这是**均摊分析**（01 篇）的第二个实战场景。

> **陷阱**：相等温度要不要出栈？先想清楚题意：找"严格更高"则 `T[i] > T[栈顶]` 才弹，相等也进栈（保持非严格递减）；若找">="，条件改成 `>=`。一字之差答案全错，边界条件要在写代码前说出口（14 篇）。

单调栈套路总结（经验做法，刷题社区共识）：

- 求"**右侧第一个更大**"：从左到右扫，栈顶递减，大于栈顶时结算；
- 求"**右侧第一个更小**"：栈顶递增，小于栈顶时结算；
- 左右都要（如每日温度的变体）：结算时把"当前元素"和"弹出的元素"各算一遍，或正反各扫一遍。

## 5. 单调栈进阶：柱状图最大矩形

**问题**（LC 84）：一排柱子高度 h[i]，宽度都是 1，求能框出的最大矩形面积。这是单调栈的招牌题，也是"接雨水"（LC 42）的近亲。

```python
def largest_rectangle_area(heights: list[int]) -> int:
    """LC 84 柱状图中最大的矩形。O(n)。
    关键：对每根柱子，求"左右第一个比它矮的位置"——
    以它为高的最大矩形宽度 = 右边界 - 左边界 - 1。单调栈一遍同时算出两侧。"""
    stack: list[int] = []                  # 存下标，高度递增
    max_area = 0
    # 哨兵技巧：末尾补一根高度 0 的柱子，逼栈清空，免写收尾循环
    extended = heights + [0]
    for i, h in enumerate(extended):
        while stack and extended[stack[-1]] > h:
            height = extended[stack.pop()]         # 这根柱子的矩形在此结算
            left = stack[-1] if stack else -1      # 左边第一个更矮的位置
            width = i - left - 1                   # (left, i) 开区间内都比它高
            max_area = max(max_area, height * width)
        stack.append(i)
    return max_area

assert largest_rectangle_area([2, 1, 5, 6, 2, 3]) == 10   # 5 和 6 那两根，高 5 宽 2
assert largest_rectangle_area([2, 4]) == 4
```

**逐字拆解**：栈保持高度递增；遇到更矮的柱子 `h`，说明栈顶柱子的"右边界"找到了（就是 i），而它弹出后新栈顶就是它的"左边界"（第一个更矮的位置）。宽 = 右 − 左 − 1。哨兵 `[0]` 是一个通用技巧：**用虚拟元素触发收尾，替代循环结束后的清理代码**。

## 6. 单调队列：滑动窗口最大值

**问题**（LC 239）：固定大小 k 的窗口在数组上滑动，每个时刻输出窗口内最大值。朴素 O(n·k)；单调队列（monotonic deque）O(n)。

```python
from collections import deque

def max_sliding_window(nums: list[int], k: int) -> list[int]:
    """LC 239 滑动窗口最大值。每个元素至多进出队各一次，O(n)。"""
    dq: deque[int] = deque()              # 存下标；对应值从队头到队尾严格递减
    out: list[int] = []
    for i, x in enumerate(nums):
        # 1) 新元素从队尾进：所有比它小的都不可能再当最大值（更老、更小），淘汰
        while dq and nums[dq[-1]] <= x:
            dq.pop()
        dq.append(i)
        # 2) 队头过期（滑出窗口左界）则移除
        if dq[0] <= i - k:
            dq.popleft()
        # 3) 窗口成型后，队头即当前最大值
        if i >= k - 1:
            out.append(nums[dq[0]])
    return out

assert max_sliding_window([1, 3, -1, -3, 5, 3, 6, 7], 3) == [3, 3, 5, 5, 6, 7]
```

单调队列 vs 单调栈，一句话分清：**单调栈只在一端结算（旧的被新的"覆盖"答案），单调队列两端各管一件事——队尾维持单调性（淘汰弱者），队头维护合法性（淘汰过期者）**。

> **提示**：候选淘汰的正确性论证值得在面试时说一遍——队里比新元素小的旧元素，既比新元素小（不配当最大），又比新元素先过期（更早出局），所以留着毫无意义。这就是单调结构共同的不变式思维：**维护"将来还可能成为答案"的候选集，且候选集内部有序**。

## 7. 什么时候用栈/队列/单调结构

| 信号 | 用什么 |
| --- | --- |
| 最近匹配、嵌套结构、撤销回退 | 栈 |
| 处理顺序 = 到达顺序（广度优先、缓冲） | 队列（10 篇 BFS） |
| "下一个更大/更小"、跨度类问题 | 单调栈 |
| 滑动窗口最值 | 单调队列 |
| 滑动窗口中位数/任意最值 | 前提不满足时退回有序结构/堆（09 篇） |

## 本篇小结

1. 栈与队列是"限制访问方式的线性表"，限制换来语义与 O(1) 关键操作；Python 用 list 当栈、deque 当队列；
2. 括号匹配与表达式求值展示了栈的"最近匹配"本质；调度场算法是中缀转后缀的标准方案；
3. 单调栈解决"下一个更大/更小"类问题，均摊 O(n)；柱状图最大矩形是它的完整应用，哨兵元素替代收尾循环；
4. 单调队列解决滑动窗口最值：队尾保单调、队头保合法；
5. 单调结构的不变式：只保留"将来还可能成为答案"的候选，候选间保持有序。
