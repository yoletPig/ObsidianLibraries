# 算法与数据结构系列教程：从"会做题"到"会选型"

> 面向以 Python 为主、目标成为**顶尖算法工程师（端侧/云端推理方向）**的学习者。全系列的立场：**算法面试是副产品，底层素养才是目的**——不理解数据结构的内存形态与代价模型，就写不出 FlashAttention 那样的算子，也调不好跟踪器里的匈牙利匹配。
> 全系列为中文原创，共 14 章。关键论断标注可查证来源（CLRS《算法导论》、Sedgewick《算法（第 4 版）》、原始论文），无法查证的经验做法一律明确标注"经验做法"。文中代码以 Python 为主、只依赖标准库，全部完整可运行；需要底层视角的地方（缓存、指针、连续内存）会同时给出 C/C++ 视角的对照说明（详见 [C++ 系列](../C++/README.md)）。

### 阶段划分

1. **地基篇（01–03）**：复杂度分析、数组/链表、哈希表。这三篇决定你能不能"看代码就估出代价"，是后面所有篇的语言。
2. **线性结构篇（04–06）**：栈/队列（单调结构）、双指针/滑动窗口、二分查找。面试出现频率最高的一组技巧，套路性强、必须练到肌肉记忆。
3. **递归与层次结构篇（07–09）**：递归与分治、树、堆。从"递归是函数调自己"升级为"递归是数学归纳法的执行"。
4. **图论篇（10–11）**：图基础、最短路/最小生成树。跟踪、规划、调度问题的统一抽象。
5. **DP 与策略篇（12–14）**：动态规划两连 + 回溯/贪心/面试实战。前 13 章的所有思维工具在这里收敛成可复用的方法论。

## 与本仓库其他方向的衔接

- **自动驾驶 Stage 4（多传感器融合与目标跟踪）**：跟踪器的数据关联核心是匈牙利算法，卡尔曼滤波做递归状态估计——匈牙利是图论匹配问题（10 篇的图建模 + 11 篇的组合优化直觉），KF 的"预测-更新"递推与 12 篇 DP 的"状态转移"是同一思想；学完 10/11/12 再看 Stage 4 会明显轻松。
- **模型性能优化系列（FlashAttention 等）**：FlashAttention 的本质是"用 tiling 重排访存换取 HBM 带宽"——为什么重排能省时间、为什么 tiling 大小影响性能，答案的地基是 01 篇（摊还与常数项）、02 篇（缓存友好性）；Priority/Scheduler 类推理引擎组件（Stage 5/7）用 09 篇的堆与优先队列。
- **量化投资系列**：回测中的信号筛选是 TopK（09 篇），组合优化是带约束的最优化（13 篇背包/DP 思想的连续版），前缀和+哈希在"区间收益统计"里同样出现（03 篇）；08 篇 BST/平衡树对应有序价格序列的动态维护。
- **C++ 系列**：07（STL 容器与字符串）、08（STL 算法）直接对应本系列 02–09 篇的数据结构；本系列讲"为什么这样设计"，C++ 系列讲"怎么在 C++ 里用好它"。链表、堆、哈希的内存语义两边互相引用。

## 约定

- 代码环境：Python 3.10+，只用标准库（`heapq`、`collections`、`bisect` 等）。所有代码块完整可运行，可直接复制执行。
- 复杂度规范：除非特别说明，n 表示数据规模，记号采用 `O(·)` 渐近上界；涉及均摊的地方标注"均摊"。面试表述的规范在 14 篇统一给出。
- 引用规范：关键论断给出出处（CLRS 即《算法导论》第 3 版，Cormen 等；算法（第 4 版）即 Sedgewick & Wayne）；无法查证的经验做法一律标注"经验做法"，不冒充定论。
- 术语规范：优先使用中文术语、首次出现附英文；LeetCode 题号在练习中标注，刷题时对照。
- 本系列不使用 Obsidian 双链以外的特殊语法，任何 markdown 阅读器都能正常渲染。
