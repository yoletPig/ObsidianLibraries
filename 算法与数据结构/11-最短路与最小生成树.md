## 1. 最短路问题地图

加权图 G=(V, E)，边权 w(e)，求从源点 s 到各点的最小代价路径。三个算法按"问什么、图长什么样"分工（CLRS 第 22–25 章）：

| 算法 | 问题 | 权重要求 | 复杂度 | 场景 |
| --- | --- | --- | --- | --- |
| BFS | 无权单源 | 全 1 | O(V+E) | 10 篇已讲 |
| **Dijkstra** | 单源 | **非负** | O(E log V)（堆版） | 地图导航、网络路由 |
| Bellman-Ford | 单源 | 允许负权（检负环） | O(V·E) | 有负代价、汇率套利检测 |
| SPFA | 单源 | 允许负权 | 平均 O(k·E)（经验常数 k 小，最坏 O(V·E)） | BF 的队列优化 |
| Floyd-Warshall | **全源** | 允许负权（检负环） | O(V³) | 小图全对最短路、传递闭包 |

**为什么 Dijkstra 怕负权**：它的贪心前提是"已确定的最短路不会再被更新"，负边能让"晚确定的节点"通过负边反过来改善"早确定的节点"，前提崩塌。记住这句话，四个算法的边界就全清楚了。

## 2. Dijkstra：贪心 + 优先队列

**不变式**：每次从候选集取出"当前 dist 最小"的节点 u，断言 `dist[u]` 已是最终最短路（非负权下，任何其他路径都要经过更远的中间节点）。候选集用什么维护？——**09 篇的堆**：

```python
import heapq

def dijkstra(n: int, adj: list[list[tuple[int, int]]], src: int) -> list[int]:
    """Dijkstra：邻接表 adj[u] = [(v, w), ...]。O(E log V)。
    惰性删除（lazy deletion）版本——Python 生态的标准写法。"""
    dist = [float("inf")] * n
    dist[src] = 0
    heap: list[tuple[int, int]] = [(0, src)]     # (当前距离, 节点)
    done = [False] * n                            # 已最终确定的节点
    while heap:
        d, u = heapq.heappop(heap)                # 取当前最近者：贪心一步
        if done[u]:                               # 惰性删除：旧条目直接跳过
            continue
        done[u] = True
        for v, w in adj[u]:
            nd = d + w
            if nd < dist[v]:                      # 松弛（relax）：发现了更短的到 v 的路
                dist[v] = nd
                heapq.heappush(heap, (nd, v))     # 新条目入堆，旧的不删（弹出时跳过）
    return dist

def add_edge(adj: list[list[tuple[int, int]]], u: int, v: int, w: int,
             directed: bool = False) -> None:
    adj[u].append((v, w))
    if not directed:
        adj[v].append((u, w))

#        (2)      (7)
#   0 -------- 1 -------- 3
#    \ (9)    / |        (4)
#     `-----'  |
#        (10)  v (1)
#              2
n = 4
adj: list[list[tuple[int, int]]] = [[] for _ in range(n)]
add_edge(adj, 0, 1, 2); add_edge(adj, 1, 3, 7); add_edge(adj, 0, 2, 10)
add_edge(adj, 1, 2, 1); add_edge(adj, 3, 2, 4, directed=True)
assert dijkstra(n, adj, 0) == [0, 2, 3, 9]   # 0->1: 2；0->2: 0-1-2=3；0->3: 2+7=9
```

**路径重建**：松弛成功时记 `prev[v] = u`，结束后从终点回溯。复杂度：堆操作 O(E) 次入堆 + O(V) 次出堆，每次 O(log) → **O(E log V)**（惰性删除让堆里可能有陈旧条目，09 篇的懒删除惯用法正是为此准备）。优化到 O(E log V) 严格版用"decrease-key"，但 Python 无此 API，惰性删除是标准做法（经验做法）。

## 3. Bellman-Ford 与 SPFA

**Bellman-Ford**：不做贪心假设，**蛮力松弛 V−1 轮**——每轮把所有边都试一遍更新。正确性：最短路至多 V−1 条边（无负环时），i 轮后所有"至多 i 条边"的最短路都已确定（归纳可证，CLRS 24.1）。

```python
def bellman_ford(n: int, edges: list[tuple[int, int, int]], src: int) -> list[int] | None:
    """edges = [(u, v, w)]。返回 dist；存在从 src 可达的负环返回 None。O(V·E)"""
    dist = [float("inf")] * n
    dist[src] = 0
    for _ in range(n - 1):                      # V-1 轮
        changed = False
        for u, v, w in edges:
            if dist[u] + w < dist[v]:           # 松弛
                dist[v] = dist[u] + w
                changed = True
        if not changed:                          # 提前终止：一轮无更新即收敛
            break
    # 第 V 轮还能松弛 => 存在可达负环（最短路无定义）
    for u, v, w in edges:
        if dist[u] + w < dist[v]:
            return None
    return dist

edges = [(0, 1, 4), (0, 2, 5), (1, 2, -3), (2, 3, 4), (1, 3, 6)]
assert bellman_ford(4, edges, 0) == [0, 4, 1, 5]   # 0->2 走 0-1-2 = 4-3 = 1
```

**SPFA**（队列优化的 Bellman-Ford，中国竞赛圈流行叫法；学术名 Bellman-Ford-Moore）：只有"上一轮被更新的节点"才可能松弛别人——用队列代替全量轮次，被更新的节点入队待处理。平均很快，但被构造数据打成 O(V·E)，**负权稠密图才用它，否则无脑 Dijkstra**（经验做法）。

```python
from collections import deque

def spfa(n: int, adj: list[list[tuple[int, int]]], src: int) -> list[int] | None:
    dist = [float("inf")] * n
    dist[src] = 0
    in_queue = [False] * n
    q: deque[int] = deque([src])
    in_queue[src] = True
    while q:
        u = q.popleft()
        in_queue[u] = False
        for v, w in adj[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                if not in_queue[v]:          # 已在队中不必重复入队
                    q.append(v)
                    in_queue[v] = True
    return dist
```

## 4. Floyd-Warshall：全源最短路

**问题**：所有点对之间的最短路。Dijkstra 跑 V 遍是 O(V·E log V)；Floyd 动态规划做到 O(V³)、代码五行（思想上是 12 篇 DP 的又一变体：`dp[k][i][j]` = 只允许经过中间点 1..k 时 i→j 的最短路，转移"经过 k 中转 or 不经过"）：

```python
def floyd(n: int, adj: list[list[tuple[int, int]]]) -> list[list[int]]:
    """Floyd-Warshall。O(V³) / O(V²) 空间。V ≤ 数百时全源问题的首选。"""
    INF = float("inf")
    dist = [[INF] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
    for u in range(n):
        for v, w in adj[u]:
            dist[u][v] = min(dist[u][v], w)      # 重边取最小
    for k in range(n):            # 中转点放最外层：DP 阶段
        for i in range(n):
            dik = dist[i][k]
            if dik == INF:
                continue
            for j in range(n):
                nd = dik + dist[k][j]
                if nd < dist[i][j]:
                    dist[i][j] = nd        # 经 k 中转更短就更新
    return dist

n = 3
adj3: list[list[tuple[int, int]]] = [[] for _ in range(n)]
add_edge(adj3, 0, 1, 1); add_edge(adj3, 1, 2, 2); add_edge(adj3, 0, 2, 5)
d = floyd(n, adj3)
assert d[0][2] == 3 and d[2][0] == 3      # 无向图对称；0->2 走中转 1 更短
```

> **陷阱**：k 必须放**最外层**循环——它是 DP 的阶段（"允许的中转点集合"逐个扩张），放里层语义就错了。这是 Floyd 唯一容易记错的地方。负环检测：结束后 `dist[i][i] < 0` 的节点在负环上。

## 5. 最小生成树：Kruskal 与 Prim

**问题**（LC 1584）：无向带权连通图中选 V−1 条边把所有点连通，总权最小。两个贪心，成立条件不同：

- **Kruskal**：边按权排序，从小到大加入，**不成环**就要（用并查集判环，O(α) 近似 O(1)，CLRS 21 章）。贪心依据：割性质（cut property）——任何把点集分成两半的割中，权最小的跨割边必在某棵 MST 里。
- **Prim**：从任意点开始，每次把"离已长成部分最近"的新点拉进来——**Dijkstra 的亲兄弟**，把"路径长"换成"单边长"。

```python
def kruskal(n: int, edges: list[tuple[int, int, int]]) -> tuple[int, list[tuple[int, int]]]:
    """Kruskal：O(E log E)。并查集 + 按边权排序。"""
    parent = list(range(n))
    def find(x: int) -> int:
        while parent[x] != x:
            parent[x] = parent[parent[x]]   # 路径减半：一步跳到祖父
            x = parent[x]
        return x

    total, picked = 0, []
    for u, v, w in sorted(edges, key=lambda e: e[2]):   # 边权升序
        ru, rv = find(u), find(v)
        if ru != rv:                        # 不同集合：加入不会成环
            parent[ru] = rv                 # union
            total += w
            picked.append((u, v))
            if len(picked) == n - 1:        # V-1 条边：完成，提前结束
                break
    return total, picked

def prim(n: int, adj: list[list[tuple[int, int]]]) -> int:
    """Prim：O(E log V)。堆存 (边权, 对端)，Dijkstra 把 d+w 换成 w。"""
    visited = [False] * n
    heap: list[tuple[int, int]] = [(0, 0)]  # (连入代价, 节点)，从 0 出发
    total = 0
    while heap:
        w, u = heapq.heappop(heap)
        if visited[u]:
            continue
        visited[u] = True                   # 拉进已长成部分
        total += w
        for v, wv in adj[u]:
            if not visited[v]:
                heapq.heappush(heap, (wv, v))   # 注意：压的是"单边权"
    return total

pts_edges = [(0, 1, 2), (0, 2, 9), (1, 2, 10), (1, 3, 7), (2, 3, 4)]
adj4: list[list[tuple[int, int]]] = [[] for _ in range(4)]
for u, v, w in pts_edges:
    add_edge(adj4, u, v, w)
assert kruskal(4, pts_edges)[0] == prim(4, adj4) == 13   # MST = {0-1(2), 2-3(4), 1-3(7)} = 13
```

选型：**稀疏图 Kruskal（排序即可，代码短）；稠密图 Prim（邻接矩阵版 O(V²) 反而占优）**。MST 的工程影子：网络布线、聚类（单 linkage）、以及 TSP 的 2-近似解（用 MST 的两倍遍历，CLRS 35 章）。

## 6. A*：带先知的 Dijkstra

**动机**：Dijkstra 均匀地向四周扩张（像水波），去往"东边 5 公里"却把西边探了个遍——浪费。**A***（Hart, Nilsson, Raphael 1968；自动驾驶规划教材必引）给扩张方向加"先知"：优先级从 `dist[u]` 改为

```
f(u) = g(u) + h(u)     # g: 起点到 u 的实际代价（Dijkstra 的 dist）
                       # h: u 到终点的"乐观估计"（启发函数）
```

**h 必须可采纳（admissible，不高估真实剩余代价）**——这是正确性的全部条件：估计可以悲观（绕远才到），不能乐观（以为很近实际很远），否则可能提前"确定"错误的路径。地图上 h 用欧氏/曼哈顿距离（直线距离不可能被超过，物理事实）。

```python
import math
import heapq

def a_star(n: int, adj: list[list[tuple[int, int]]],
           coords: list[tuple[float, float]], src: int, dst: int) -> tuple[float, list[int]]:
    """A* 最短路：h = 欧氏距离（地图坐标，可采纳）。返回(代价, 路径)。
    h ≡ 0 时 A* 退化为 Dijkstra——它是一族算法的框架。"""
    def h(u: int) -> float:
        (x1, y1), (x2, y2) = coords[u], coords[dst]
        return math.hypot(x1 - x2, y1 - y2)      # 欧氏距离：永不高估

    g = [float("inf")] * n
    g[src] = 0
    prev = [-1] * n
    heap: list[tuple[float, int]] = [(h(src), src)]   # f = g + h
    while heap:
        f, u = heapq.heappop(heap)
        if u == dst:                              # 第一次弹出终点即最优（h 可采纳）
            break
        if f > g[u] + h(u):                       # 陈旧条目（g 已被更优值替代）
            continue
        for v, w in adj[u]:
            ng = g[u] + w
            if ng < g[v]:
                g[v] = ng
                prev[v] = u
                heapq.heappush(heap, (ng + h(v), v))
    path, cur = [], dst
    while cur != -1:                              # prev 回溯路径
        path.append(cur)
        cur = prev[cur]
    return g[dst], path[::-1]

# 5 个路口：地面 0-1-2 直路，绕行点 3、4 在上方。边权 >= 欧氏距离（物理合理，
# 这保证 h=欧氏距离可采纳——直线距离是"至少要走这么远"的下界）
n5 = 5
coords = [(0, 0), (2, 0), (4, 0), (1, 1), (3, 1)]
adj5: list[list[tuple[int, int]]] = [[] for _ in range(n5)]
add_edge(adj5, 0, 1, 2); add_edge(adj5, 1, 2, 2)      # 地面直路：0-1-2 = 4
add_edge(adj5, 0, 3, 2); add_edge(adj5, 3, 4, 2); add_edge(adj5, 4, 2, 2)
                                                       # 绕行：0-3-4-2 = 6
cost, path = a_star(n5, adj5, coords, 0, 2)
assert cost == 4.0 and path == [0, 1, 2]
# 对比实验：h ≡ 0（即 Dijkstra）会弹出全部 5 个节点；
# 欧氏 h 只需弹出 3 个（0、1、2）就终止——先知收窄了探索范围（可打印计数验证）。
print(f"A* 路径: {path}，代价 {cost}")
```

**直觉总结**（衔接自动驾驶规划）：Dijkstra 答"从起点能到的所有地方各多远"（全局必要）；A* 答"从起点到这个终点"（目标导向，探索范围向终点收窄）。h 设计得越准（越接近真实且不高估），探索越少；h 是 0 就是 Dijkstra。Stage 5/6 里规划模块的 Hybrid A*、lattice planner 都在这一族上做扩展——本篇给的是它们的共同内核。

## 本篇小结

1. Dijkstra 贪心成立靠"非负权"，`dist[u]` 出堆即终值；堆版 O(E log V)，惰性删除是 Python 标准姿势；
2. Bellman-Ford 蛮力 V−1 轮松弛换负权兼容，第 V 轮还能松弛 = 负环；SPFA 是它的队列优化，平均快、最坏同阶；
3. Floyd 用"允许中转点 1..k"的阶段化 DP 做全源，k 在最外层；
4. Kruskal 按边贪 + 并查集判环，Prim 按点贪 + 堆——割性质给两者背书；
5. A* = Dijkstra + 可采纳启发 h，h=0 退化为 Dijkstra；自动驾驶规划器的共同祖先。

## 练习

1. （LC 743 - 网络延迟时间）Dijkstra 模板题：所有节点收到信号的时间 = 最大 dist；顺手判不可达（返回 -1）。
2. （LC 787 - K 站中转内最便宜的航班）带"至多 k 条边"约束——Bellman-Ford 天然适配（只跑 k+1 轮），体会 Dijkstra 为什么此处不直接适用。
3. （LC 1584 - 连接所有点的最小费用）MST：任意两点都有边（完全图），稠密图——用 Prim 矩阵版 O(n²) 而不是 Kruskal（边数 O(n²) 排序吃亏）。
4. （LC 1631 - 最小体力消耗路径）"路径上最大边权最小化"——用 Dijkstra 变体（dist = 路径最大边，松弛取 max）或二分答案 + BFS（06 篇），两种都写。
5. （LC 778 - 水位上升的泳池游泳）同 1631 的"瓶颈路径"思想 + 时间轴二分或并查集按时间加边（10 篇连通分量的动态版）。
