# 05 - 双指针与滑动窗口

## 本篇目标

1. 掌握双指针的三大形态：**对撞指针、快慢指针、原地读写指针**，并知道各自适用的不变式；
2. 把滑动窗口统一定义为"**双指针维护的区间 + 可增量更新的统计量**"，学会定长与变长两个模板；
3. 独立写出最小覆盖子串（LC 76）这类"硬题"，理解窗口收缩的正确性论证。

## 1. 双指针的本质：用单调性消灭重复扫描

双重循环暴力是 O(n²)，因为它对每个左端点都重新扫一遍右端点。双指针的获胜条件：**当左端点（或某个决策量）单调移动时，右端点的最优位置也单调移动**——于是两个指针各走 O(n) 步，总 O(n)。这个"决策单调性"就是所有双指针题的共同前提（经验做法：面试先说不变式，再写代码）。

```python
def two_sum_sorted(nums: list[int], target: int) -> tuple[int, int] | None:
    """对撞指针原型：有序数组找两数之和 = target。O(n) 时间 O(1) 空间。
    （LC 167 两数之和 II；LC 1 无序版用 03 篇哈希表）"""
    lo, hi = 0, len(nums) - 1
    while lo < hi:
        s = nums[lo] + nums[hi]
        if s == target:
            return lo, hi
        if s < target:
            lo += 1        # 和太小：左指针唯一能做的事就是变大
        else:
            hi -= 1        # 和太大：右指针唯一能做的事就是变小
    return None

assert two_sum_sorted([2, 7, 11, 15], 9) == (0, 1)
```

**正确性论证**（面试值得说）：假设答案在 (i, j)，若当前 `lo` 被跳过时 `nums[lo]+nums[hi] < target`，则 `nums[lo]` 与任何 `nums[k] (k≤hi)` 的和都 < target——它确实不可能出现在任何剩余答案里，丢弃是安全的。这就是"每一步都排除一个不可能"的 elimination 论证。

## 2. 对撞指针的三个经典应用

```python
def reverse_array(a: list[int]) -> None:
    """原地反转：交换后两端向中间收。"""
    lo, hi = 0, len(a) - 1
    while lo < hi:
        a[lo], a[hi] = a[hi], a[lo]
        lo, hi = lo + 1, hi - 1

def is_palindrome(s: str) -> bool:
    """回文判断（LC 125 思路）：对撞指针逐对比较。"""
    lo, hi = 0, len(s) - 1
    while lo < hi:
        if s[lo] != s[hi]:
            return False
        lo, hi = lo + 1, hi - 1
    return True

def container_with_most_water(height: list[int]) -> int:
    """LC 11 盛最多水的容器：经典对撞 + 贪心移动短边。O(n)。
    论证：移动较长的一边不可能让结果变好（宽度变小、高度受短板约束不会超过
    原短板），所以每步丢弃短边是安全的。"""
    lo, hi = 0, len(height) - 1
    best = 0
    while lo < hi:
        best = max(best, (hi - lo) * min(height[lo], height[hi]))
        if height[lo] < height[hi]:
            lo += 1
        else:
            hi -= 1
    return best

assert container_with_most_water([1, 8, 6, 2, 5, 4, 8, 3, 7]) == 49
assert is_palindrome("abcba") and not is_palindrome("abcd")
```

对撞指针的适用信号：**问题关于"一对元素"且两端信息可判断优劣**（有序两数之和、回文、容器容量、三数之和外层循环配对撞 LC 15）。

## 3. 快慢指针与原地读写

02 篇用快慢指针判环。这里补全数组上的"读写双指针"模式——**原地删除/移动**类问题的统一解法：写指针 `w` 指向"下一个可写位置"，读指针 `r` 扫描全数组，有效元素写入 `w` 后两者同进，无效时只 `r` 进。

```python
def remove_element(nums: list[int], val: int) -> int:
    """LC 27 移除元素：原地删除所有等于 val 的元素，返回新长度。O(n) O(1)"""
    w = 0
    for r in range(len(nums)):
        if nums[r] != val:
            nums[w] = nums[r]      # 有效元素搬到写指针位置
            w += 1
    return w

def remove_duplicates_sorted(nums: list[int]) -> int:
    """LC 26 删除有序数组中的重复项：写指针只在"新值"出现时前进。"""
    w = 1 if nums else 0
    for r in range(1, len(nums)):
        if nums[r] != nums[w - 1]:  # 与"已写入的最后一个"比较
            nums[w] = nums[r]
            w += 1
    return w

def move_zeroes(nums: list[int]) -> None:
    """LC 283 移动零：保持非零元素相对顺序——读写指针同向模式的标志性要求。"""
    w = 0
    for r in range(len(nums)):
        if nums[r] != 0:
            nums[w] = nums[r]
            w += 1
    for i in range(w, len(nums)):
        nums[i] = 0                  # 尾部填零（或交换版：全程一次遍历）

a = [0, 1, 0, 3, 12]
move_zeroes(a)
assert a == [1, 3, 12, 0, 0]
```

> **提示**："保持相对顺序"与"允许乱序"决定写法：允许乱序可用交换（LC 75 颜色分类的三指针分区），必须保序就用覆盖 + 回填（或交换但理解其保序性）。

## 4. 滑动窗口：定长模板

窗口本质：**用两个同向指针 [l, r) 围出一个区间，右端扩张采集信息，左端按条件收缩丢弃信息**，同时维护一个可 O(1) 增量更新的统计量（和、计数、哈希表）。先看定长版：

```python
def fixed_window_max_sum(nums: list[int], k: int) -> int:
    """定长 k 窗口的最大和：进出各 O(1)，整体 O(n)。
    直觉：相邻两个窗口只差一头一尾两个元素。"""
    window_sum = sum(nums[:k])          # 第一个窗口
    best = window_sum
    for r in range(k, len(nums)):
        window_sum += nums[r] - nums[r - k]   # 加新进来的，减滑出去的
        best = max(best, window_sum)
    return best

assert fixed_window_max_sum([2, 1, 5, 1, 3, 2], 3) == 9   # [5,1,3]
```

定长窗口要维护的信息若不可增量更新（如"窗口内最大值"），就升级成 04 篇的单调队列；若要"窗口内第 k 小"则是有序结构/双堆问题（09 篇）。**先判断统计量能否增量更新，再选工具**，这是窗口类题的第一决策。

## 5. 滑动窗口：变长模板

变长窗口（不定长）的标准形态：**右指针无条件前进采集，左指针在"违反约束"时收缩**。每一刻窗口都保持"合法"或"恰好非法"的状态，答案是过程中某个统计量的最值。

```python
def length_of_longest_substring(s: str) -> int:
    """LC 3 无重复字符的最长子串。O(n)。
    约束：窗口内字符不重复。违反时左端收缩到刚好恢复合法。"""
    last_pos: dict[str, int] = {}       # 字符 -> 最近一次出现的下标
    left = 0
    best = 0
    for right, ch in enumerate(s):
        if ch in last_pos and last_pos[ch] >= left:
            left = last_pos[ch] + 1     # 直接跳过上一次出现处（比逐格收缩快）
        last_pos[ch] = right
        best = max(best, right - left + 1)
    return best

assert length_of_longest_substring("abcabcbb") == 3
assert length_of_longest_substring("bbbbb") == 1

def min_window(s: str, t: str) -> str:
    """LC 76 最小覆盖子串：变长窗口的巅峰题。O(|s| + |t|)。
    约束（反向）：窗口必须"包含" t 的全部字符；右端扩张补足，左端收缩到
    刚好不满足，收缩前的窗口就是一个候选答案。"""
    need: dict[str, int] = {}
    for ch in t:
        need[ch] = need.get(ch, 0) + 1
    missing = len(t)                    # 还缺多少个字符（总量计数）
    left = 0
    best = (float("inf"), 0, 0)         # (长度, 左, 右)
    for right, ch in enumerate(s):
        # 右端扩张：新字符若还是"需要的"，missing 减一
        if need.get(ch, 0) > 0:
            missing -= 1
        need[ch] = need.get(ch, 0) - 1  # 负数表示"过剩"
        # 已满足（missing == 0）：尽量收缩左端，但保持满足
        if missing == 0:
            while need[s[left]] < 0:    # 左端是过剩字符：安全移除
                need[s[left]] += 1
                left += 1
            if right - left + 1 < best[0]:
                best = (right - left + 1, left, right + 1)
            # 收缩一格制造"不满足"，逼右端继续扩张寻找下一个覆盖
            need[s[left]] += 1
            missing += 1
            left += 1
    return "" if best[0] == float("inf") else s[best[1]:best[2]]

assert min_window("ADOBECODEBANC", "ABC") == "BANC"
assert min_window("a", "a") == "a"
```

**min_window 的收缩正确性**（面试常被追问）：`missing == 0` 时窗口已覆盖 t；只要左端字符是"过剩"的（计数 < 0），移除后依然覆盖，所以一路收缩到左端是"恰好必需"的字符为止——此刻窗口是最小的覆盖窗口之一，记录答案后主动收缩一格破坏覆盖，让右端去找下一个。`missing` 单一整数代替"逐字符比对是否齐了"，是本题从 O(26·n) 到干净 O(n) 的关键小优化。

## 6. 定长 vs 变长：一张决策表

| 特征 | 定长窗口 | 变长窗口 |
| --- | --- | --- |
| 窗口大小 | 固定 k | 由约束动态决定 |
| 右指针 | 每步进 1 | 无条件每步进 1 |
| 左指针 | 跟随右指针（r−k） | 满足/违反约束时收缩 |
| 典型题 | LC 239、LC 643、LC 567 | LC 3、LC 76、LC 209 |
| 常配结构 | 单调队列/计数数组 | 哈希计数 + missing 式总量计数 |

共同的不变式模板（经验做法，背下来能覆盖八成窗口题）：

```python
def window_template(s: str) -> int:
    state = ...          # 你的统计量：计数表/和/集合
    left = 0
    ans = 0
    for right, ch in enumerate(s):
        update_state_add(state, ch)         # 1. 右端进
        while invalid(state):               # 2. 违反约束则左端收缩
            update_state_remove(state, s[left])
            left += 1
        ans = max(ans, right - left + 1)    # 3. 此刻窗口合法，更新答案
    return ans
```

## 7. 常见误区

1. **先写代码后找不变式**：窗口题的 bug 几乎都来自"收缩条件没想清"。开口先说：窗口合法的定义是什么？违反时左端收缩到哪？
2. **计数用错时机**："先查后插"（两数之和）与"先加后查"（前缀和配对）是两个方向，混用会漏掉/多算；
3. **用 `if` 收缩应该用 `while`**：违反约束可能需要连续收缩多格。看到 `while` 里改 `left` 的地方，问自己"收缩一次够吗"；
4. **把双指针当成万能 O(n)**：没有单调性就退回 O(n²)。判断方法（经验做法）：想象左指针右移一格，最优的右指针位置会倒退吗？会——双指针不适用。

## 本篇小结

1. 双指针三大形态对应三种不变式：对撞（两端淘汰）、快慢（间距/速度差）、读写（有效元素搬运）；
2. 滑动窗口 = 同向双指针 + 可增量更新的统计量；定长看"一头一尾"，变长看"进 1 收多"；
3. 最小覆盖子串是窗口模板的天花板：need 表 + missing 总量计数 + "收缩到刚好不满足"；
4. 每个指针的每一步都要有"安全丢弃"的理由——这就是双指针 O(n) 的合法性来源；
5. 决策顺序：统计量能否增量更新 → 定长还是变长 → 需要最值吗（配单调队列/堆）。
