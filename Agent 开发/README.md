# Agent 系列教程：从 ReAct 到可控、安全的 Agent 开发

> 面向已经会用 LLM API（会写一个 chat 调用）的初学者，系统讲清楚 **AI Agent（智能体）到底是什么、怎么一步步搭起来、以及开发中最常踩的坑和最重要的安全边界**。
> 全系列为中文原创，涉及的关键事实（论文出处、协议细节、时间线）均标注了可查证的来源；文中代码以 Python 为主，只依赖标准库和最常见的三方库。

### 阶段划分

1. **概念与骨架（01–03）**：Agent 是什么、ReAct 循环、工具调用。学完就能写出"能干活"的单 Agent。
2. **协议与能力扩展（04–06）**：MCP、记忆、多 Agent。让 Agent 从"玩具"走向"系统工程"。
3. **可靠性与安全（07–09）**：本系列最重要的部分。**没有这三篇，前面的 Agent 只是演示；有了这三篇，才谈得上开发。**
4. **实战（10）**：综合项目。
5. **进阶篇（11–14）**：面向真实生产的纵深——上下文工程、长任务规划、评测体系、部署运维。每篇都建立在基础篇对应章节之上（11↔05、12↔07、13↔07、14↔08/09），建议先读基础篇再读对应进阶章。

## 与本仓库其他方向的衔接

- **VLM & VLA Stage 9（Multimodal Agent）** 讲多模态场景下的 Agent 规划与闭环执行，本系列提供其单模态基础。
- **语音方向 Stage 7（端侧语音助手）** 的"语音前端 + LLM 决策 + 工具执行"链路，就是一个语音交互的 Agent，可直接套用本系列 03（工具调用）与 08（权限）。

## 约定

- 代码环境：Python 3.10+。示例中 `llm_call` 一类函数是抽象占位，实际接入任选一家 SDK。
- 引用规范：关键论断给出论文/官方文档出处，无法查证的内容一律标注"经验做法"，不冒充定论。
- 本系列不推荐任何"某某框架是最好的"——框架选择放在 06 篇末尾讨论，且只列事实性对比。
