# 操作系统系列教程：用 OS 的眼睛看程序

> 面向以 Python 为主、能读懂 C、在 WSL2/Linux 上动手、目标成为**算法工程师（模型性能优化/推理服务方向）**的学习者。本系列的立场：**操作系统不是背概念，而是性能问题的"案发现场"**——CPU 为什么忽高忽低、内存为什么涨了不回、一个请求为什么偶尔慢 50ms，答案几乎都写在 OS 里。库里的 C++ 并发编程篇、模型性能优化全系列（CUDA/端侧部署）、Agent 生产部署都假设你已懂 OS，这一套就是那块地基。
> 全系列为中文原创，共 14 章。关键论断标注可查证来源（OSTEP 即《Operating Systems: Three Easy Pieces》、CSAPP 即《深入理解计算机系统》、《Linux 内核设计与实现》即 Robert Love, Linux Kernel Development、man 手册注明节号）；无法查证的经验做法一律明确标注"经验做法"。演示代码 C 与 Python 混用、中文注释、完整可运行，终端命令在 Ubuntu 22.04 / WSL2 上验证过。

### 阶段划分

1. **地基篇（01–03）**：OS 是什么、进程与线程、CPU 调度。建立"程序 = 进程在 CPU 上被调度地执行"的世界观，这是后面所有篇的语言。
2. **内存篇（04–06）**：虚拟内存、页与置换、分配器。内存是性能问题第一大案发现场：缺页、TLB miss、碎片、OOM 都在这里。
3. **IO 与系统交互篇（07–10）**：中断与系统调用、文件系统、IO 多路复用、进程间通信。推理服务本质是 IO 密集系统，这四篇是读懂 Redis/推理服务框架的门票。
4. **并发与综合篇（11–14）**：同步原语、网络栈与 socket、容器与虚拟化、综合实战。C++ 并发篇的 OS 底层、Docker 的原理、以及把所有工具合起来的实战。

## 与本仓库其他方向的衔接

- **C++ 系列 12（并发编程）**：那篇讲"怎么用" `std::thread`/`std::mutex`，本系列 02（线程模型）、07（上下文切换成本）、11（锁的实现与 futex）讲"底下发生了什么"。读完 11 再回头看 C++ 12 的数据竞争反例，你会明白它为什么是未定义行为。
- **模型性能优化 Stage 4/5（端侧与推理引擎）**：llama.cpp 的 mmap 加载模型文件是本系列 05 的 mmap 文件映射；vLLM/SGLang 的 PagedAttention 名字里的"页"就是 04/05 的分页思想（KV cache 当虚拟内存管理）；Continuous Batching 的调度直觉与 03 的调度指标一一对应。端侧推理的内存预算、内存带宽瓶颈分析，地基都在内存篇。
- **模型性能优化 Stage 7 与 Agent 生产部署**：推理服务的并发模型（9 篇 Reactor）、进程管理与信号处理（2 篇、10 篇）、容器化部署与资源限制（13 篇 cgroup）是这些篇的日常操作对象；OOM killer 杀掉你的推理服务时，5 篇教你怎么读现场。
- **Linux 性能工程系列 = 本系列的实战续篇**：本系列负责"OS 概念怎么在性能问题上现形"（strace、/proc、ps、top 这些观察级工具）；性能工程系列往下走一层，用 perf、eBPF、火焰图做定量归因。先读本系列，再去那边会顺得多。
- **算法与数据结构系列**：CFS 的红黑树（03 篇）、页表的多级索引（05 篇）、epoll 的就绪队列（09 篇），全是数据结构课的"真实客户"，学 OS 时回头看看那边的复杂度分析非常有体感。

## 约定

- 平台约定：以 Linux 为准（Ubuntu 22.04 验证），Windows/WSL2 差异在文中以 **WSL2 注** 标出；涉及 systemd/cgroup 的操作在 WSL2 上可能受限，文中给出替代观察路径。
- 代码约定：C 代码用 `gcc xxx.c -o xxx` 编译（涉及线程加 `-pthread`），Python 用 3.10+ 只依赖标准库；所有演示代码完整可运行，关键处有中文注释。
- 命令约定：需要 root 的命令标 `sudo` 并提示风险；真实输出示例来自作者机器（WSL2, kernel 6.6），你机器上的地址/数字必然不同，**看形状不看数值**。
- 引用约定：OSTEP 引用章节号（如 OSTEP 第 13 章《Address Spaces》）；man 手册标注节号（`man 2 fork` 的 2 表示系统调用节）；《Linux 内核设计与实现》简称 LKD；经验做法不冒充定论。
- 术语约定：优先中文术语、首次出现附英文；"上下文切换"（context switch）、"缺页"（page fault）等高频词以文中定义为准。
- 本系列不使用 Obsidian 双链以外的特殊语法，任何 markdown 阅读器都能正常渲染。
